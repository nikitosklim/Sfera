# Примеры пакетов

Три маленьких пакета, чтобы каталог на сайте не был пустым и чтобы было с чего начать автору:

- `математика`: степень, целый корень, НОД и НОК, факториал, простые числа;
- `строки`: повтор, начало и конец текста, число вхождений, числа с нулями слева;
- `цвета`: RGB в `#rrggbb`, смешивание, яркость.

Пакет называется `строки`, а не `текст`: `текст` в Сфере зарезервированное слово и не подходит как имя модуля.

## Как опубликовать

Нужен токен автора (его создаёт администратор в `/управление`, раздел «Пакеты»). Затем из папки пакета:

```
сфера войти
сфера опубликовать
```

Версия публикуется один раз. Чтобы выпустить правку, увеличьте `версия` в `пакет.сфера`.
