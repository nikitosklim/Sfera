# математика

Целые числа без лишнего: `модуль`, `минимум`, `максимум`, `ограничить`, `степень`, `корень_целый`, `нод`, `нок`, `факториал`, `простое`.

## Установка

```
сфера установить математика
```

## Пример

```
подключить математика.математика;

функция главная(): целое
    вывести("2 в степени 10 = %(степень(2, 10))%");
    вывести("корень из 50 = %(корень_целый(50))%");
    вывести("НОД(84, 36) = %(нод(84, 36))%");
    вывести(простое(12));
    вернуть 0;
конец
```

## Что важно знать

- `факториал` считается верно до 20: дальше число не помещается в целое.
- `степень` принимает только целый неотрицательный показатель.
