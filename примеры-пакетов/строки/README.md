# строки

Мелкие помощники для работы с текстом: `повторить`, `начинается_на`, `заканчивается_на`, `число_вхождений`, `с_нулями`, `пусто`.

## Установка

```
сфера установить строки
```

## Пример

```
подключить строки.строки;

функция главная(): целое
    вывести(повторить("ab", 3));
    вывести(с_нулями(7, 3));
    вывести(число_вхождений("абвабг", "аб"));
    вывести(заканчивается_на("файл.код", ".код"));
    вернуть 0;
конец
```

## Что важно знать

- Длина и срезы считаются в байтах: русская буква занимает два байта.
- Функции работают с точным совпадением, регистр важен.
