# цвета

Цвет задаётся тремя целыми от 0 до 255 (красный, зелёный, синий). Функции: `в_шестнадцатеричный`, `смешать_канал`, `яркость`, `светлый`, `затемнить_канал`, `осветлить_канал`.

## Установка

```
сфера установить цвета
```

## Пример

```
подключить цвета.цвета;

функция главная(): целое
    вывести(в_шестнадцатеричный(255, 128, 0));
    вывести(светлый(255, 255, 0));
    вывести(смешать_канал(0, 200, 50));
    вернуть 0;
конец
```

## Что важно знать

- Значения вне 0..255 обрезаются при выводе в `#rrggbb`.
- Смешивание идёт по каждому каналу отдельно: вызовите функцию для красного, зелёного и синего.
