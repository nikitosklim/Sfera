## Первая программа

```
функция главная() -> целое {
    вывести("Привет, мир!");
    вернуть 0;
}
```

Каждая программа обязана иметь функцию `главная`, возвращающую `целое`
(код завершения — `0` означает успех). Компилируется командой:

```bash
sfera привет.код -c
```

---

## Основы синтаксиса

- **Комментарии**: `//` до конца строки, `/* ... */` — многострочные
- **Каждый оператор заканчивается точкой с запятой** (`;`)
- **Блоки кода** — в фигурных скобках `{ }`
- Язык **полностью кириллический** — все ключевые слова, имена
  встроенных функций и типов пишутся кириллицей

## Типы данных

### Целые числа

| Тип | Размер | Знаковый |
|---|---|---|
| `целое` | 64 бита | да |
| `целое8` | 8 бит | да |
| `целое16` | 16 бит | да |
| `целое32` | 32 бита | да |
| `целое64` | 64 бита | да (то же, что `целое`) |
| `беззнак8` | 8 бит | нет |
| `беззнак16` | 16 бит | нет |
| `беззнак32` | 32 бита | нет |
| `беззнак64` | 64 бита | нет |

⚠️ **Важно**: типы разной разрядности **не смешиваются неявно** —
`целое32` и `целое` в одном выражении требуют явного приведения:

```
целое32 а = 5;
целое б = 10;
целое итог = целое(а) + б;   // явное приведение обязательно
```

### Дробные числа

`дробное` (по умолчанию, 64 бита), `дробное32`, `дробное64`.

### Текст

`текст` — строка. Литералы в двойных кавычках: `"привет"`.
Конкатенация — оператором `+`:

```
текст имя = "Аня";
текст приветствие = "Привет, " + имя + "!";
```

### Логический тип

`верно` — булев тип. Литералы: `да` (истина) и `нет` (ложь) —
**не** `true`/`false`.

```
верно готово = да;
если (готово) {
    вывести("Готово!");
}
```

## Переменные

Объявление — `тип имя = значение;`:

```
целое возраст = 25;
текст имя = "Иван";
верно активен = да;
```

### Неизменяемые переменные

Ключевое слово `неизменно` перед типом запрещает переприсваивание:

```
неизменно целое максимум = 100;
```

### Явные приведения типов

Синтаксис — имя типа как функция: `целое32(значение)`, `дробное(значение)`.

⚠️ **Важно**: приведение нужно даже при инициализации **числовым
литералом** — типы разной разрядности не смешиваются неявно нигде:

```
целое32 а = целое32(5);    // так, не "целое32 а = 5;"
целое итог = целое(а) + б;  // и здесь тоже явно
```

## Операторы

### Арифметические

`+` `-` `*` `/` `%` (остаток от деления)

### Сравнение

`==` `!=` `<` `>` `<=` `>=`

### Логические

`&&` (И) `||` (ИЛИ) `!` (НЕ)

### Текст

`+` — конкатенация. `==`/`!=` — сравнение по содержимому (не по адресу).

## Управляющие конструкции

### Условие

```
если (х > 10) {
    вывести("Больше десяти");
} иначе если (х > 0) {
    вывести("Положительное");
} иначе {
    вывести("Ноль или отрицательное");
}
```

### Цикл с условием

```
целое счётчик = 0;
пока (счётчик < 5) {
    вывести(целое_в_текст(счётчик));
    счётчик = счётчик + 1;
}
```

### Цикл по коллекции

```
целое[3] числа = [1, 2, 3];
для каждого элемент в числа {
    вывести(целое_в_текст(элемент));
}
```

⚠️ `для каждого` работает **только с массивом** — не со `Список<T>` (для
перебора элементов списка используй обычный `пока` со счётчиком и
`.получить(индекс)`/`.размер()`).

## Функции

```
функция сложить(целое а, целое б) -> целое {
    вернуть а + б;
}
```

- Тип возврата указывается через `->` после списка параметров
- `вернуть` — оператор возврата значения
- Функция без возвращаемого значения просто не пишет `-> тип`:

```
функция напечатать_дважды(текст сообщение) -> целое {
    вывести(сообщение);
    вывести(сообщение);
    вернуть 0;
}
```

### Обобщённые функции

Пока **не поддержаны** кодогенератором (обобщёнными могут быть только
структуры — см. раздел про обобщённые типы).

---

## Массивы

Фиксированного размера, размер — часть типа. **Требуют явной
инициализации** литералом при объявлении:

```
целое[5] числа = [10, 20, 30, 40, 50];
числа[0] = 99;              // обращение и запись по индексу
вывести(целое_в_текст(числа[0]));
```

---

## Структуры

```
структура Точка {
    целое х;
    целое у;

    функция сумма_координат() -> целое {
        вернуть это.х + это.у;
    }
}
```

- Поля объявляются как обычные переменные, без значений по умолчанию
- Методы — обычные функции внутри тела структуры
- **`это`** — ссылка на текущий экземпляр внутри метода (аналог
  `self`/`this` в других языках)
- **Конструктор генерируется автоматически**, по всем полям в порядке
  объявления:

```
Точка точка = Точка(3, 4);
вывести(точка.сумма_координат());   // выведет 7
```

Структуры — всегда объекты в куче (передаются по ссылке), с
автоматическим подсчётом ссылок — см. [ARC](#управление-памятью-arc).

### Слабые ссылки

Поле, объявленное как `слабая Тип`, не увеличивает счётчик ссылок —
нужно для разрыва циклических ссылок (например, родитель ↔ потомок):

```
структура Цель {
    текст имя;
}

структура Держатель {
    текст имя;
    слабая Цель цель;    // не увеличивает счётчик ссылок "Цель"
}

функция главная() -> целое {
    Цель цель = Цель("моя цель");
    Держатель держатель = Держатель("держатель", цель);
    вывести(держатель.цель.имя);
    вернуть 0;
}
```

⚠️ **Не "настоящая" слабая ссылка** — в отличие от Swift/Objective-C, не
становится автоматически пустой при освобождении цели: если
использовать слабую ссылку уже после того, как цель освобождена
(больше никто не держит на неё сильную ссылку), получится обращение к
уже освобождённой памяти. Слабая ссылка полезна для разрыва цикла, но
не даёт автоматической защиты от использования после освобождения.

## Обработка ошибок — результат\<T\>

Вместо исключений — обёртка `результат<T>`, содержащая три поля:
`.успешно` (`верно`), `.значение` (тип `T`, валиден только при успехе),
`.сообщение` (текст ошибки, валиден только при неудаче).

```
функция разделить(целое а, целое б) -> результат<целое> {
    если (б == 0) {
        вернуть ошибка("деление на ноль");
    }
    вернуть успех(а / б);
}

функция главная() -> целое {
    результат<целое> итог = разделить(10, 2);
    если (итог.успешно) {
        вывести(целое_в_текст(итог.значение));
    } иначе {
        вывести("Ошибка: " + итог.сообщение);
    }
    вернуть 0;
}
```

Многие встроенные функции (`подстрока`, `найти`, `прочитать_файл` и
другие) сами возвращают `результат<T>` — обязательно проверяй
`.успешно` перед использованием `.значение`.

## Обобщённые типы

### Список\<T\>

```
Список<целое> числа = Список<целое>();
числа.добавить(10);
числа.добавить(20);

целое первое = числа.получить(0);
целое количество = числа.размер();
```

### Словарь\<K, V\>

```
Словарь<текст, целое> возрасты = Словарь<текст, целое>();
возрасты.положить("Аня", 25);

результат<целое> возраст = возрасты.получить("Аня");   // ключ может отсутствовать!
если (возраст.успешно) {
    вывести(целое_в_текст(возраст.значение));
}

целое количество = возрасты.размер();
```

⚠️ В отличие от `Список.получить(индекс)` (возвращает значение
напрямую), `Словарь.получить(ключ)` возвращает `результат<T>` — ключа
может не быть в словаре, обязательно проверяй `.успешно`.

⚠️ **Важное синтаксическое ограничение**: `Список<T>`/`Словарь<K,V>`
нельзя объявить через вывод типа (простое присваивание без явного
типа слева) — всегда указывай тип явно, как в примерах выше.

### Обобщённые структуры (пользовательские)

```
структура Коробка<Т> {
    Т содержимое;
}

коробка = Коробка<целое>(42);   // без явного типа слева — только так!
вывести(целое_в_текст(коробка.содержимое));
```

⚠️ **Важное, честное ограничение**: пользовательскую обобщённую
структуру можно объявить **только через вывод типа** (без явного
типа в левой части) — `Коробка<целое> коробка = ...;` **не работает**
(семантика пока не умеет сопоставлять явно указанный обобщённый тип с
результатом конструктора). Это отличается от `Список`/`Словарь`,
которые можно объявлять и явно.

## Контракты и полиморфизм

Контракт — описание требуемых методов, аналог интерфейса:

```
контракт Печатаемый {
    функция напечатать() -> текст;
}

структура Кот : Печатаемый {
    функция напечатать() -> текст {
        вернуть "Мяу";
    }
}

структура Собака : Печатаемый {
    функция напечатать() -> текст {
        вернуть "Гав";
    }
}
```

Компилятор на этапе сборки проверяет, что структура, заявляющая `:
Контракт`, реально имеет все требуемые методы с совпадающими
сигнатурами.

### Настоящий полиморфизм

Контракт можно использовать как тип параметра функции или переменной —
один и тот же код тогда работает с *любой* структурой, реализующей
контракт (динамический выбор нужной реализации в момент выполнения):

```
функция озвучить(Печатаемый существо) -> целое {
    вывести(существо.напечатать());
    вернуть 0;
}

функция главная() -> целое {
    Кот кот = Кот();
    Собака пёс = Собака();

    озвучить(кот);   // выведет "Мяу"
    озвучить(пёс);   // выведет "Гав" — та же функция, другая реализация

    вернуть 0;
}
```

⚠️ **Важно**: аргумент-структуру нужно сначала сохранить в переменную —
`озвучить(Кот())` (временный экземпляр напрямую, без промежуточной
переменной) **не работает**.

## Многопоточность

### параллельно

Запускает блок кода в отдельном потоке операционной системы:

```
параллельно {
    вывести("Работаю в фоне");
}
```

⚠️ **Важное ограничение**: тело блока `параллельно` **не может
использовать переменные из окружающей области видимости** (защита от
обращения к уже освобождённой памяти) — единственное исключение,
описанное ниже.

### канал\<T\>

Безопасный способ передать одно значение из фонового потока обратно:

```
функция главная() -> целое {
    канал<целое> канал_результата = создать_канал();

    параллельно {
        целое вычислено = 2 + 2;
        канал_результата.отправить(вычислено);
    }

    целое значение = канал_результата.получить();   // ждёт, пока не придёт значение
    вывести(целое_в_текст(значение));

    вернуть 0;
}
```

Поддерживаются только целочисленные и указательные типы значения (не
дробные, не встроенные напрямую структуры).

## Управление памятью (ARC)

Структуры управляются автоматически через подсчёт ссылок (ARC) —
писать `free`/`delete` не нужно, память освобождается сама, когда на
объект больше никто не ссылается.

Текст **частично** под управлением ARC — простые локальные переменные,
цепочки конкатенации и результаты некоторых функций отслеживаются и
освобождаются автоматически. Полный, честный список того, что ещё не
покрыто (переменные внутри циклов, поля структур), — в
`ИСТОРИЯ_РАЗРАБОТКИ.md`.

## Модули

```
подключить утилиты;
```

Подключает файл `утилиты.код` из той же папки (или из папки `пакеты/`,
если рядом файла нет — так подключаются установленные пакеты).

Доступ к содержимому — либо напрямую по имени, либо явно, через имя
модуля:

```
целое итог = удвоить(21);              // обычный вызов
целое итог2 = утилиты.удвоить(21);     // то же самое, но с указанием модуля
```

## Внешние функции (FFI)

Позволяет вызывать функции из C-библиотек напрямую:

```
внешняя функция получить_переменную_окружения(текст имя) -> текст как "getenv";
```

Строка после `как` — настоящее имя символа в библиотеке (если
совпадает с именем в Сфере, можно опустить).

## Стандартная библиотека

### Текст

| Функция | Описание |
|---|---|
| `длина(текст)` | Длина строки в байтах |
| `подстрока(текст, начало, длина)` | Часть строки → `результат<текст>` |
| `содержит(текст, подстрока)` | Проверка вхождения → `верно` |
| `найти(текст, подстрока)` | Позиция вхождения → `результат<целое>` |
| `регистр_в_верхний(текст)` | В верхний регистр |
| `регистр_в_нижний(текст)` | В нижний регистр |
| `текст_в_целое(текст)` | Разбор числа → `результат<целое>` |

### Преобразование в текст

| Функция | Описание |
|---|---|
| `целое_в_текст(целое)` | Число → текст |
| `дробное_в_текст(дробное)` | Дробное → текст |
| `верно_в_текст(верно)` | `да`/`нет` → текст |

### Математика

| Функция | Описание |
|---|---|
| `абс(число)` | Модуль числа |
| `мин(а, б)` | Меньшее из двух |
| `макс(а, б)` | Большее из двух |

### Ввод-вывод

| Функция | Описание |
|---|---|
| `вывести(текст)` | Печать строки на экран |
| `прочитать_строку()` | Чтение строки из консоли → `результат<текст>` |
| `прочитать_файл(путь)` | Чтение файла целиком → `результат<текст>` |
| `записать_файл(путь, содержимое)` | Запись файла |
| `выполнить_команду(команда)` | Запуск команды операционной системы |
| `аргументы_командной_строки()` | Аргументы запуска программы → `Список<текст>` |

### Память "по смещению" (для низкоуровневой работы)

| Функция | Описание |
|---|---|
| `прочитать_целое32(буфер, смещение)` | Чтение 4 байт из буфера |
| `записать_целое32(буфер, смещение, значение)` | Запись 4 байт в буфер |
| `прочитать_текст_по_смещению(буфер, смещение)` | Чтение строки по адресу |

## Известные ограничения

Список ниже — то, что **пока не работает или работает не полностью**,
на момент написания этого документа:

- Обобщённые **функции** (не структуры) не поддержаны
- Текст под ARC не покрывает: поля структур, переменные внутри циклов
  (частично), результат без промежуточной переменной
- `Список<Контракт>` (коллекция разнотипных объектов через общий
  интерфейс) не проверялась
- Контракт как тип возврата функции не реализован
