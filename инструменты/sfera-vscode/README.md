# Сфера для VS Code

Поддержка языка программирования [«Сфера»](https://языксфера.рф), где на русском всё: ключевые слова, типы и стандартная библиотека.

## Возможности

- Подсветка синтаксиса: ключевые слова, типы, строки с подстановкой `%имя%`, комментарии, числа.
- **Подсказки при наборе кода.** Предлагаются переменные и параметры текущей функции, ваши функции и структуры, содержимое подключённых модулей и стандартной библиотеки, ключевые слова, типы и встроенные функции.
- **Подсказки после точки:** поля и методы структур (в том числе `это.`), методы `Список`, `Словарь`, `канал`, поля `результат` и `тип?`, содержимое модуля (`хеш.`).
- **Подсказка параметров** при вводе `(` и `,`, справка при наведении, «перейти к определению» (в том числе в файлы библиотек).
- **Библиотеки.** После `подключить ` предлагаются имена модулей. Функции из ещё не подключённых библиотек тоже подсказываются, а строка `подключить …;` добавляется сама.
- **Ошибки в реальном времени** показывает языковой сервер `сфера_lsp`, вшитый в расширение.
- Сниппеты: `главная`, `функция`, `если`, `пока`, `длякаждого`, `структура` и другие.
- Автоотступы для блоков, которые закрываются словом `конец`.

Ничего устанавливать отдельно не нужно: стандартная библиотека и языковой сервер входят в расширение. Подсказки работают, даже если компилятор не установлен. Подсказки видят файлы вашего проекта, лежащие рядом, и пакеты из папки `пакеты/`.

## Настройки

| Настройка | Описание |
|---|---|
| `sfera.enableLanguageServer` | Показывать ошибки в реальном времени. Подсказки от этой настройки не зависят. |
| `sfera.serverPath` | Свой `сфера_lsp` вместо вшитого. |
| `sfera.stdlibPath` | Дополнительная папка со стандартной библиотекой. Обычно не нужна. |
| `sfera.suggestFromUnimported` | Предлагать функции из ещё не подключённых библиотек с автоматическим `подключить`. |
