# Сфера для VS Code

Поддержка языка программирования [«Сфера»](https://языксфера.рф), где на русском всё: ключевые слова, типы и стандартная библиотека.

## Возможности

- Подсветка синтаксиса: ключевые слова, типы, строки с подстановкой `%имя%`, комментарии, числа.
- Ошибки в реальном времени, подсказки при наведении, автодополнение и «перейти к определению». Для этого нужен языковой сервер `сфера_lsp` (входит в архив с компилятором).
- Сниппеты: `главная`, `функция`, `если`, `пока`, `длякаждого`, `структура` и другие.
- Автоотступы для блоков, которые закрываются словом `конец`.

## Как подключить языковой сервер

1. Скачайте компилятор со страницы [загрузок](https://языксфера.рф/загрузки). В архиве есть файл `сфера_lsp`.
2. Добавьте его в `PATH` либо укажите полный путь в настройке `sfera.serverPath`.
3. Откройте любой файл `.код`.

Если сервера нет, подсветка и сниппеты всё равно работают.

## Настройки

| Настройка | Описание |
|---|---|
| `sfera.serverPath` | Путь к `сфера_lsp`. Пусто — искать в `PATH`. |
| `sfera.enableLanguageServer` | Включить или выключить языковой сервер. |
