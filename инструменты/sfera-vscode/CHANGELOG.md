# История изменений

## 0.4.2
- Подсказки теперь запрашиваются при каждой набранной букве (раньше автопоказ не срабатывал для кириллицы). В канал «Сфера» пишутся первые запросы подсказок — для диагностики.

## 0.4.1
- Исправлено: подсказки не появлялись при наборе букв (автопоказ не срабатывал для кириллицы), работал только список после «подключить ». Теперь подсказки открываются сами, пока вы печатаете.

## 0.4.0
- Подсказки при наборе кода теперь делает встроенный движок расширения: они работают сразу после установки, без компилятора, PATH и настроек.
- Подсказываются функции, структуры, константы и модули из подключённых файлов и стандартной библиотеки (она вшита в расширение), в том числе вложенных подключений.
- Подсказки после точки: поля и методы структур, `это.`, методы `Список`/`Словарь`/`канал`, поля `результат` и `тип?`, содержимое модуля (`хеш.`).
- Переменные и параметры текущей функции, а также элемент цикла `для каждого`.
- Подсказка параметров при вводе `(` и `,`; всплывающая справка; переход к определению (в том числе в файлы библиотек).
- Функции из ещё не подключённых библиотек предлагаются сразу, строка `подключить …;` добавляется сама (отключается настройкой `sfera.suggestFromUnimported`).
- После `подключить ` предлагаются имена модулей с описаниями.
- Подсказки не пропадают, пока код недописан.
- Языковой сервер `сфера_lsp` вшит в расширение (Windows, macOS, Linux); он показывает ошибки. Если сервера нет, подсказки работают всё равно, окон с ошибками больше нет.
- Требуется VS Code 1.82 или новее.

## 0.3.5
- Подсказки для работы с оборудованием: `аппаратное_чтение8/16/32/64`, `аппаратная_запись8/16/32/64`, `порт_ввод8/16/32`, `порт_вывод8/16/32`, `машинная_команда`.
- Подсветка шестнадцатеричных (`0xB8000`), двоичных (`0b1010`) чисел и чисел с разделителем `_`.

## 0.3.4
- Расширение само находит `сфера_lsp` (папка `~/.sfera/bin`, панель разработчика, `/usr/local/bin`, Windows: `%LOCALAPPDATA%\Сфера\bin`): VS Code, запущенный не из терминала, не видит PATH.
- Запасное автодополнение: ключевые слова, типы и функции библиотеки подсказываются, даже если языковой сервер не запустился.
- Подсказки включаются сами при вводе слова (настройки по умолчанию для языка).

## 0.3.3
- Подсветка синтаксиса нового (русского) синтаксиса: `конец`, `из`, `и`, `или`, `не`, `%имя%`.
- Подключение языкового сервера `сфера_lsp`.
- Сниппеты и автоотступы.
