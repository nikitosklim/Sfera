# История изменений

## 0.3.5
- Подсказки для работы с оборудованием: `аппаратное_чтение8/16/32/64`, `аппаратная_запись8/16/32/64`, `порт_ввод8/16/32`, `порт_вывод8/16/32`, `машинная_команда`.
- Подсветка шестнадцатеричных (`0xB8000`), двоичных (`0b1010`) чисел и чисел с разделителем `_`.

## 0.3.4
- Расширение само находит `сфера_lsp` (папка `~/.sfera/bin`, панель разработчика, `/usr/local/bin`, Windows: `%LOCALAPPDATA%\Сфера\bin`): VS Code, запущенный не из терминала, не видит PATH.
- Запасное автодополнение: ключевые слова, типы и функции библиотеки подсказываются, даже если языковой сервер не запустился.
- Подсказки включаются сами при вводе слова (настройки по умолчанию для языка).

## 0.3.3
- Подсветка синтаксиса нового (русского) синтаксиса: `конец`, `из`, `и`, `или`, `не`, `%имя%`.
- Подключение языкового сервера `сфера_lsp`.
- Сниппеты и автоотступы.
