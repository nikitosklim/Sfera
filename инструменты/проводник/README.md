# Проводник

Окно 600×600: слева файлы сервера Сферы, справа сведения о сервере (память, диск, процессор, ОС, время работы).
Токен запоминается в `~/.sfera-проводник/настройки.txt` (права 600). Подробности: документация «Программа Проводник»
(`сайт/content/docs/tool-explorer.md`).

```bash
запустить проводник.код --только-собрать --линковать SDL2 --линковать SDL2_ttf --линковать m
./проводник
```

macOS и Linux. Нужны `curl`, `sh`, SDL2 и SDL2_ttf. Сервер: `сайт/проводник.код` (ручки `/api/файлы`, `/api/сервер`, `/api/скачать`).
