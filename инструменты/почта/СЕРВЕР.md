# Что настроить на почтовом сервере для «Почты Сферы»

Клиент работает с любым IMAP-сервером. Чтобы папки (Отправленные, Корзина, Спам) были «настоящими» и
видны в любых почтовых программах, а корзина сама очищалась, на сервере с Dovecot нужны две вещи.

## 1. Особые папки и автоочистка корзины

В `/etc/dovecot/conf.d/15-mailboxes.conf` (блок `namespace inbox`):

```
namespace inbox {
  inbox = yes
  mailbox Drafts {
    special_use = \Drafts
    auto = subscribe
  }
  mailbox Sent {
    special_use = \Sent
    auto = subscribe
  }
  mailbox Trash {
    special_use = \Trash
    auto = subscribe
    autoexpunge = 7d
  }
  mailbox Junk {
    special_use = \Junk
    auto = subscribe
  }
}
```

`auto = subscribe` создаёт папку сам; `autoexpunge = 7d` удаляет из корзины письма, пролежавшие там
больше семи дней (считается время, когда письмо попало в эту папку). Применить:

```
sudo systemctl reload dovecot
```

Если папок нет, клиент сам создаст «Sent» и «Trash» при первом входе — но без `special_use` другие
программы узнают их только по названию.

## 2. Запасная очистка по расписанию

Dovecot чистит корзину, когда её открывают; чтобы она очищалась и без этого, добавьте задачу
(для единственного пользователя `pochta`):

```
echo '17 3 * * * root /usr/bin/doveadm expunge -u pochta mailbox Trash savedbefore 7d' | sudo tee /etc/cron.d/sfera-trash
```

Проверить вручную: `sudo doveadm expunge -u pochta mailbox Trash savedbefore 7d` и затем
`sudo doveadm mailbox status -u pochta messages Trash`.
