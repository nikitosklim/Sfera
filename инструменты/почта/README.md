# Почта Сферы

Почтовый клиент, целиком написанный на Сфере. Космический фон и градиентные кнопки — как на сайте
языксфера.рф. Слева папки (Входящие, Отправленные, Спам, свои папки, «Создать папку» и внизу Корзина),
посередине список писем, справа открытое письмо с вложениями, сверху панель кнопок, внизу строка состояния.
На macOS меню (Файл, Правка, Вид, Письмо, Переход, Окно, Справка) стоит в самой верхней строке экрана,
рядом с названием программы, как у любой программы Mac; на других системах оно рисуется в окне.

Он работает с любым почтовым ящиком, доступным по IMAP и SMTP поверх TLS — в том числе с
`почта@языксфера.рф` (сервер `mail.языксфера.рф`, порты 993 и 465). Кириллические имена серверов
переводятся в `xn--…` автоматически (модуль `почта_имена`).

## Запуск

### macOS: отдельное приложение

```
brew install openssl@3 sdl2 sdl2_ttf
./инструменты/почта/собрать-приложение-macos.sh
```

Скрипт собирает «Почту Сферы.app» в папку `~/Applications` (другую папку можно указать
первым аргументом, например `/Applications`). Дальше она запускается как любое приложение:
двойным щелчком, из Launchpad или Spotlight; перетащите её в Dock, чтобы была под рукой.
Для обновления после новых версий исходников просто запустите скрипт ещё раз.

Если родное меню по какой-то причине не нужно — запуск с переменной `СФЕРА_ПОЧТА_МЕНЮ=окно`
рисует меню внутри окна.

### Из исходников (любая система)

macOS: `brew install openssl@3 sdl2 sdl2_ttf` (один раз), затем из корня проекта:

```
export LIBRARY_PATH="$(brew --prefix openssl@3)/lib:$(brew --prefix)/lib"
export CPATH="$(brew --prefix openssl@3)/include:$(brew --prefix)/include"
./target/release/запустить инструменты/почта/почта_мак.код \
  --линковать SDL2 --линковать SDL2_ttf --линковать m --линковать ssl --линковать crypto --линковать objc
```

Linux и Windows — `почта.код` (меню в окне), без `--линковать objc`:

```
./target/release/запустить инструменты/почта/почта.код \
  --линковать SDL2 --линковать SDL2_ttf --линковать m --линковать ssl --линковать crypto
```

Только собрать, не запуская: добавить `--только-собрать`.

При первом запуске — экран входа: сервер, имя пользователя, пароль, адрес отправителя.
Сервер, имя и адрес запоминаются в `~/.sfera-почта/настройки.txt` (права 600). **Пароль нигде
не сохраняется** — его вводят при каждом запуске.

## Что умеет

| Действие | Как |
|---|---|
| Новая почта | приходит сама: раз в ~15 секунд клиент спрашивает сервер; число непрочитанных видно у папки. Кнопка «Обновить» (⌘G, F5) — если не хочется ждать |
| Папки | слева: Входящие (⌘1), Отправленные (⌘2), Спам, свои папки, внизу Корзина (⌘3); число непрочитанных рядом с названием |
| Создать папку | «+ Создать папку» слева или «Файл → Создать папку…» |
| Прочитать письмо | щелчок по письму в списке, стрелки ↑ ↓; письмо отмечается прочитанным на сервере |
| Вложения | щелчок по вложению сохраняет его в папку «Загрузки» (Downloads); «Файл → Сохранить все вложения» |
| Написать | «Написать» или ⌘N: кому (несколько — через запятую), тема, текст |
| Прикрепить файл | «Прикрепить файл…» (путь к файлу) или перетащить файл в окно; щелчок по вложению убирает его |
| Отправить | кнопка или ⌘↵; копия письма остаётся в «Отправленных» |
| Ответить | «Ответить» или ⌘R: адрес, «Re: тема» и цитата подставляются |
| Удалить | «Удалить» или Delete: письмо уходит в Корзину (с подтверждением); в самой Корзине — удаляется навсегда |
| Корзина | «Очистить корзину» — сразу и навсегда; письма старше 7 дней сервер удаляет сам (см. `СЕРВЕР.md`) |
| Вернуть из корзины | «Письмо → Вернуть во «Входящие»» |
| Поиск | ⌘F, ввод по отправителю, получателю и теме; Esc сбрасывает |
| Вид | «Только непрочитанные» (⌘U), «Плотный список» (⌘D) |

Сочетания работают и с Ctrl, и на русской раскладке. Все сочетания — «Справка → Сочетания клавиш» (⌘/).

Имя, которое видят получатели (по умолчанию «Сфера»), задаётся на экране входа в поле «Имя отправителя».

## Что пока не умеет (честно)

* Ввод в письме только в конец: нет курсора внутри текста, выделения, правки посередине.
* Нет черновиков: недописанное письмо при закрытии отбрасывается.
* Письмо с разметкой (HTML) показывается как текст, без картинок и оформления.
* Обращения к серверу выполняются в основном потоке: на время получения или отправки окно
  замирает (при долгой связи это заметно).
* В панели слева помещается до 9 папок (кроме Корзины); остальные не показываются.
* Кириллические адреса в заголовках пока показываются в форме `xn--…`, как их прислал сервер.

## Как устроено

* `кисть.код` — рисование (SDL2/SDL2_ttf), цвета, перенос строк, Retina.
* `меню.код` — описание пунктов меню; панель меню в окне (Linux, Windows) и сочетания клавиш.
* `меню_мак.код` — родное меню macOS через libobjc (те же пункты, что в `меню.код`).
* `приложение.код` — экраны, папки, состояние, команды, цикл.
* `почта.код`, `почта_мак.код` — точки входа (окно с меню внутри / родное меню macOS).
* `собрать-приложение-macos.sh` — сборка «Почты Сферы.app».
* `СЕРВЕР.md` — что настроить на почтовом сервере (папки, автоочистка корзины).
* Почтовая логика — библиотеки `стандартная_библиотека/почта_*.код` (TLS, IMAP, разбор писем,
  кодировки, отправка, имена); примеры и проверки — `examples/почта/`.
