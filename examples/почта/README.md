# Почта на Сфере

Основа почтового клиента: всё написано на Сфере, кроме самого защищённого соединения (его даёт библиотека OpenSSL, подключённая через `внешняя функция`).

| Модуль (стандартная библиотека) | Что делает |
|---|---|
| `почта_защита.код` | защищённое соединение (проверка сертификата и имени сервера, чтение строк, отправка) |
| `почта_кодирование.код` | основание 64, «печатаемое с экранированием», заголовки с русскими буквами, windows-1251, КОИ8-Р |
| `почта_письмо.код` | разбор письма: заголовки, части, вложения, имена файлов по RFC 2231 |
| `почта_получение.код` | вход, список писем, чтение, отметка «прочитано», удаление |
| `почта_отправка.код` | сборка письма с вложениями и защищённая отправка с входом |
| `почта_файлы.код` | файлы целиком в виде байтов (для вложений) |

## Сборка

```
запустить программа.код --линковать ssl --линковать crypto
```

На macOS нужна библиотека OpenSSL: `brew install openssl@3`.

## Примеры

- `проверка_защиты.код` — подключиться к серверу и прочитать приветствие
- `проверка_разбора_письма.код` — разобрать письма из папки `образцы` (русские темы, вложения, windows-1251, письмо только из HTML)
- `проверка_получения.код` — войти в ящик, показать список, прочитать письмо
- `проверка_отправки.код` — собрать письмо с вложением и отправить

В примерах стоят адреса и пароль тестового сервера: замените их на свои. Пароль в код не записывают: для настоящего ящика спрашивайте его при запуске.

## Честные ограничения

- Проверено только на локальных серверах (настоящий Dovecot для получения, учебный сервер для отправки), включая отказ при неверном пароле и при чужом сертификате. На почтовом сервере проекта клиент ещё не запускали, и окна пока нет.
- Имена серверов с русскими буквами нужно писать в виде `xn--…`: перевод имён пока не сделан.
- Письма с нулевыми байтами внутри текста (редкость) читаются неполностью.
- Разбор писем оставляет небольшие утечки временного текста (около 17 КБ на письмо), клиент это учтёт перезапуском разбора.
