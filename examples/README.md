# Примеры

- **`привет.код`** — минимальная программа ("Hello, world")
- **`кликер.код`** — полноценная небольшая игра (сохранение/загрузка,
  структуры, обработка ошибок через `результат<T>`)
- **`многопоточность.код`** — `параллельно` + `канал<T>`
- **`полиморфизм.код`** — контракты и настоящий полиморфизм
  (динамический диспетчинг)
- **`модули/`** — подключение файлов друг к другу (`подключить`), в том
  числе через папку `пакеты/` (так же работают установленные пакеты)
- **`голое-железо/`** — экспериментальный запуск программ на Сфере без
  операционной системы, напрямую в QEMU (см. README внутри папки)

Полный справочник по синтаксису — в `../ДОКУМЕНТАЦИЯ_ЯЗЫКА.md`.
