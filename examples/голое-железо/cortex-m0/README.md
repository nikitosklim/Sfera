# Cortex-M0 / M0+ (без сопроцессора и без деления)

Проверка в QEMU: `./проверить.sh` — код собирается под `thumbv6m-none-eabi` (набор команд ARMv6-M, как у Raspberry Pi Pico)
и выполняется на плате `mps2-an385` (ядро Cortex-M3 выполняет тот же код). Дробные числа, 64-битные деление, умножение и
сдвиги считает библиотека `дробные_программно` — она написана на самой Сфере (`подключить дробные_программно;`).

**Что не проверено:** работа на настоящей плате. Файлы для Raspberry Pi Pico (запуск, плата RP2040, упаковка UF2) лежат в `../pico` — они собираются, но на плате не запускались.
