# Примеры — запуск на "голом железе"

Экспериментальная возможность: программы на Сфере, загружаемые прямо в
QEMU через Multiboot, без операционной системы, без BIOS-загрузчика,
без диска. Подробности и честные ограничения — в
`../../ИСТОРИЯ_РАЗРАБОТКИ.md` (раздел про голое железо).

## Требуется

- `qemu-system-x86_64`
- `as`/`ld` (обычно уже есть, часть `binutils`)
- собранный компилятор `sfera` (`cargo build --release` в корне проекта)

## Быстрая проверка

```bash
./проверить.sh            # собрать и запустить в QEMU все примеры
./проверить.sh куча_тест  # только один
```

Скрипт собирает программу флагом `--только-собрать --без-ос`, линкует её со
стартовым кодом `запуск_х86_64.s`, запускает в QEMU и сравнивает вывод
последовательного порта с файлом `<имя>.ожидание`. Нужны `qemu-system-x86_64`
и `binutils`; подходит для GitHub Actions.

## Вручную

```bash
as запуск_х86_64.s -o запуск.o
sfera куча_тест.код --только-собрать --без-ос
ld -m elf_x86_64 -T компоновка_ядра_64.ld запуск.o куча_тест.o -o ядро.bin
qemu-system-x86_64 -kernel ядро.bin -display none -serial stdio
```

Программа подключает библиотеки `голое_железо` (свой рантайм на Сфере) и
`плата_х86_пк` (вывод через COM1).

## Другие процессоры

- `riscv/` — RISC-V 64 (QEMU `virt`), `./riscv/проверить.sh`; нужны `qemu-system-riscv64`, `clang`, `ld.lld`
- `cortex-m/` — ARM Cortex-M7 (QEMU `mps2-an500`), `./cortex-m/проверить.sh`; нужны `qemu-system-arm`, `clang`, `ld.lld`

В обоих есть пример с прерыванием таймера (`таймер.код`).

## Примеры

- `серийный_порт.код` — вывод через порт напрямую
- `рантайм_тест.код` — числа, текст, списки, структуры без libc
- `куча_тест.код` — выделение и освобождение памяти, слияние блоков

## Старые примеры (до рантайма на Сфере) в этой папке

- `ядро_голое_железо.s` + `компоновка_ядра.ld` — более ранняя, 32-битная
  версия (первый, самый простой тест — вывод текста на экран)
- `минимальный_рантайм.s` + `арена_распределитель.код` — автономный
  режим (без голого железа, но и без операционной системы под собой —
  обычный Linux-процесс, просто без libc)
- `пример_автономно_linux.код` / `пример_структуры_автономно_linux.код`
  — примеры именно для автономного режима (собираются иначе — см.
  `--автономно` в общей документации языка)
