# Raspberry Pi Pico (RP2040)

**Статус: собирается, на настоящей плате не проверялось.** Написано по описанию микросхемы (Datasheet RP2040); если вы запустите на плате, расскажите нам, что получилось.

Программа целиком загружается в оперативную память (UF2 для SRAM), поэтому второй загрузочный сектор flash-памяти (boot2) не нужен. Минус: после отключения питания программа пропадает.

## Что здесь

- `запуск_pico.s` — таблица векторов и вход (`sfera_reset`), куча 128 КБ;
- `компоновка_pico.ld` — всё в SRAM с `0x20000000`, стек в конце 264 КБ;
- `стандартная_библиотека/плата_rp2040.код` — «плата»: запуск кварца 12 МГц, снятие со сброса GPIO и UART0, вывод символов в UART0 (GP0, 115200 бод);
- `привет_pico.код` — текст в UART и мигание светодиода GP25;
- `в_uf2.py` — упаковка образа в UF2; `собрать.sh` — вся цепочка.

## Сборка и запуск

```
./собрать.sh привет_pico        # получится привет_pico.uf2
```

1. Подключите Pico к компьютеру с зажатой кнопкой BOOTSEL: появится диск `RPI-RP2`.
2. Скопируйте на него `привет_pico.uf2`: плата сама запустит программу.
3. Чтобы увидеть текст, подключите USB-UART адаптер к GP0 (TX), GND, и откройте порт на 115200 бод.

Светодиод на плате должен мигать, а в терминале идти строки «мигнули раз: N».

Дробные числа считает `дробные_программно` (у RP2040 нет блока для дробных), на самой Сфере.
