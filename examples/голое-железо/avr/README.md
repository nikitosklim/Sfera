# Сфера на Arduino (AVR: Uno, Nano, Pro Mini — ATmega328P)

Экспериментальная возможность: программы на Сфере для 8-битных микроконтроллеров AVR.
Компилятор выдаёт код через цель AVR из LLVM, а запуск и загрузка идут обычными инструментами
Arduino (avr-gcc и avrdude, они уже лежат внутри Arduino IDE).

**Проверено только в эмуляторе (simavr). На настоящей плате не проверялось.**

## Быстрый старт

```bash
./собрать.sh мигалка.код                        # получится мигалка.hex
./собрать.sh мигалка.код /dev/cu.usbserial-1    # собрать и загрузить на плату
BAUD=57600 ./собрать.sh мигалка.код /dev/cu.usbserial-1   # Nano со старым загрузчиком
```

Сам компилятор запускается так: `запустить мигалка.код --только-собрать --без-ос --целевая-платформа avr`
(для другого процессора: `avr:atmega2560`). Получается объектный файл, его соединяет `avr-gcc`:
готовый стартовый код сам настроит стек, обнулит память и вызовет программу.

## Что нужно знать

- На Nano всего 2 КБ оперативной памяти. Таблицы потоков и прочая обвязка, которые Сфера создаёт для
  обычных программ, на AVR не создаются.
- Куча (`malloc`) на AVR не подключена, поэтому пока можно использовать числа, `верно` и обращения к
  регистрам. Структуры на куче, списки, словари, текст и `вывести` для AVR пока не поддерживаются.
- Регистры микроконтроллера читаются и пишутся функциями `аппаратное_чтение8` и `аппаратная_запись8`
  (адрес — в адресном пространстве данных: например, `PORTB` = `0x25`, `DDRB` = `0x24`).
- `целое` — 64 бита. На 8-битном чипе это медленно, для быстрых циклов берите `целое16`, `целое8`,
  `беззнак8`, `беззнак16`.
- Прерываний пока нет: они появятся следующим шагом.

## Проверка

`./проверить.sh` собирает мигалку и запускает её в эмуляторе simavr: вывод PB5 (светодиод на плате)
должен включаться и выключаться примерно раз в 0,3 секунды. Нужны `avr-gcc`, `avr-libc`, `simavr`
(пакеты `gcc-avr`, `avr-libc`, `simavr`, `libsimavr-dev`, `libelf-dev`).
