# Панель разработчика

Графическая среда разработки для языка Сфера (вкладки "Обзор",
"Пакеты", "Документация") — написана на самом языке Сфера, поверх SDL2.

`графика.код` здесь — копия файла из `../стандартная_библиотека/`
(нужна рядом, поскольку `подключить` пока ищет файлы только по
относительному пути, без поддержки путей вида `../папка/файл`).

## Сборка (только macOS — установщик под другие платформы ещё готовится)

```bash
sfera панель.код --только-собрать --линковать SDL2 --линковать SDL2_ttf --линковать m
```

Подробности архитектуры, самоустановки языка и найденных по пути багов
— в `../ИСТОРИЯ_РАЗРАБОТКИ.md`.
