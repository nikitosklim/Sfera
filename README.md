# Сфера

**Язык программирования, в котором на русском всё**: ключевые слова, типы,
стандартная библиотека и даже адреса сайта. Компилятор написан на Rust и
выдаёт настоящий машинный код через LLVM 18.

🌐 Сайт, уроки и загрузки: **[языксфера.рф](https://языксфера.рф)**

```
функция главная(): целое
    Список из целых числа = Список из целых();
    числа.добавить(10);
    числа.добавить(20);
    если (числа.размер() больше 1 и не (числа.получить(0) == 0))
        вывести("Сумма: %(числа.получить(0) + числа.получить(1))%");
    конец
    вернуть 0;
конец
```

Весь код набирается на обычной русской раскладке — без `{}`, `->`, `&&`,
`<>`, `[]`, `$`. Блоки закрываются словом `конец`. Старая запись со
скобками по-прежнему работает, а `запустить --в-русский файл.код`
переводит старый код в новый.

## Установка

Готовые сборки лежат на странице **[языксфера.рф/загрузки](https://языксфера.рф/загрузки)**
и в [релизах](https://github.com/nikitosklim/Sfera/releases):

| Платформа | Что внутри |
|---|---|
| Windows | панель разработчика и компилятор, установка одним архивом |
| macOS (Intel и Apple Silicon) | панель разработчика и компилятор |
| Linux | панель разработчика и компилятор |
| Android | приложение-среда разработки: код пишется, компилируется и запускается на самом телефоне |

Возле каждого файла на сайте указана контрольная сумма SHA-256, а на странице
есть пошаговая инструкция установки для каждой системы.

Из исходников (нужны Rust и LLVM 18):

```bash
cargo build --release
```

`LLVM_SYS_180_PREFIX` должен указывать на установку LLVM. Скрипты:
`собрать.sh` (macOS/Linux), `установить-windows.ps1` (Windows),
`собрать-apk.sh` (Android).

`сайт/content/`.

## Что умеет язык

- Нативная компиляция в машинный код, не интерпретатор
- Автоматическое управление памятью для структур (ARC), без ручного `free`
- Обобщённые типы: `Список из целых`, `Словарь из текста и целого`
- Ошибки без исключений: `результат из T`
- Контракты и полиморфизм (динамическая диспетчеризация)
- Многопоточность: `параллельно … конец` и `канал из T`
- Модули, пакетный менеджер, FFI к C-библиотекам
- Интерполяция строк: `"Привет, %имя%!"`, `"Итог: %(а + б)%"`
- Отладчик: флаг `-g` даёт настоящую DWARF-информацию для lldb/gdb
- Логи, метрики (формат Prometheus) и трейсинг в стандартной библиотеке
- Сеть и HTTP-сервер, встроенное хранилище «ключ → значение», SQLite
- Графика и окна: на этом написаны сами среды разработки
- Кросс-компиляция, в том числе под ARM64 и Android
- Экспериментально: запуск без операционной системы

Подробный перечень с историей исправлений — в
[ВОЗМОЖНОСТИ.md](ВОЗМОЖНОСТИ.md).

## Что уже написано на самой «Сфере»

- **[Сайт языксфера.рф](сайт/)**: HTTP-сервер с пулом потоков, разбор
  Markdown, поиск, загрузка установщиков, карта сайта. Внешних
  веб-фреймворков нет.
- **Панель разработчика** для Windows, macOS и Linux: редактор, запуск, вывод.
- **Приложение для Android** (`инструменты/android/`): компилятор, линковщик и
  замена `clang` лежат внутри APK, поэтому код компилируется и запускается
  прямо на телефоне, без root и без Termux.

## Честно о состоянии

Язык молодой, он в версии 0.3.x, и совместимость между версиями пока не
гарантируется. Известные ограничения перечислены в
[ДОКУМЕНТАЦИЯ_ЯЗЫКА.md](ДОКУМЕНТАЦИЯ_ЯЗЫКА.md) в разделе «Известные ограничения».
Главные из них:
- в отладчике нельзя посмотреть значение переменной по имени (`print x`);
- вложенные обобщённые типы в некоторых позициях всё ещё требуют старых `<>`;
- на Windows установщик не подписан цифровой подписью, поэтому система может
  показывать предупреждение при первом запуске.

## Планы

- пакетный индекс для `сфера_пакеты`;
- значения переменных в отладчике;
- подписанные установщики;
- больше примеров и уроков, проекты сообщества на сайте.

## Структура репозитория

- `src/` — компилятор (лексер, парсер, семантика, кодогенерация), языковой
  сервер `сфера_lsp` и пакетный менеджер `сфера_пакеты`
- `стандартная_библиотека/` — встроенные модули (`сеть`, `веб`, `разметка`,
  `хранилище`, `графика`, `база_данных`, `лог`, `метрики`, `трейсинг` и др.);
  лежит в корне, компилятор ищет её по пути от бинарника
- `examples/` — рабочие примеры от «Привет, мир!» до веб-сервера
- `сайт/` — исходный код сайта и его материалы
- `инструменты/` — панель разработчика и Android-приложение
- `ИСТОРИЯ_РАЗРАБОТКИ.md` — дневник разработки: решения, найденные ошибки,
  как они были исправлены
