# Файлы и папки

Создать папку, записать, переименовать и удалить файл.

## Код

```
// Файлы: создание папки, переименование, удаление (кириллица в путях тоже работает).
подключить файлы;

функция главная(): целое
    создать_папку("папка_тест");
    записать_файл("папка_тест/файл.txt", "привет");
    верно есть = файл_существует("папка_тест/файл.txt");
    вывести("существует: %есть%");
    переименовать_файл("папка_тест/файл.txt", "папка_тест/другой.txt");
    результат из текста т = прочитать_файл("папка_тест/другой.txt");
    вывести(т.значение);
    результат из верного р = удалить_файл("папка_тест/другой.txt");
    верно ещё_есть = файл_существует("папка_тест/другой.txt");
    вывести("удалён: %(р.успешно)%, существует: %ещё_есть%");
    результат из верного р2 = удалить_файл("папка_тест");
    вывести("папка удалена: %(р2.успешно)%");
    результат из верного р3 = удалить_файл("нет_такого");
    вывести("ошибка: %(р3.сообщение)%");
    вернуть 0;
конец
```

## Как запустить

Сохраните код в файл, например `файлы_удаление.код`, и выполните:

```
запустить файлы_удаление.код
```

## Как это работает

- `подключить файлы;` добавляет функции для работы с файловой системой.
- Операции, которые могут не удаться, возвращают `результат из ...`: проверяйте `.успешно`.
- Кириллица в путях работает и на Windows.

Исходник лежит в репозитории: [examples/файлы_удаление.код](https://github.com/nikitosklim/Sfera/blob/main/examples/файлы_удаление.код).
