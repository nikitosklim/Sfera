# Файлы и папки

Создать папку, записать, переименовать и удалить файл.

## Код

```
// Файлы: создание папки, переименование, удаление (кириллица в путях тоже работает).
подключить файлы

функция главная(): целое
    создать_папку("папка_тест")
    записать_файл("папка_тест/файл.txt", "привет")
    верно есть = файл_существует("папка_тест/файл.txt")
    вывести("существует: %есть%")
    переименовать_файл("папка_тест/файл.txt", "папка_тест/другой.txt")
    результат из текста т = прочитать_файл("папка_тест/другой.txt")
    вывести(т.значение)
    результат из верного р = удалить_файл("папка_тест/другой.txt")
    верно ещё_есть = файл_существует("папка_тест/другой.txt")
    вывести("удалён: %(р.успешно)%, существует: %ещё_есть%")
    результат из верного р2 = удалить_файл("папка_тест")
    вывести("папка удалена: %(р2.успешно)%")
    результат из верного р3 = удалить_файл("нет_такого")
    вывести("ошибка: %(р3.сообщение)%")
    вернуть 0
конец
```

## Как запустить

Сохраните код в файл, например `файлы_удаление.код`, и выполните:

```
запустить файлы_удаление.код
```

## Как это работает, строка за строкой

Идём сверху вниз, как компьютер. Нажмите «инфо», если нужно подробнее.

- `// Файлы: ...` — комментарий. Компьютер его пропускает, это заметка для людей.
- `подключить файлы` — «возьми готовые команды для работы с файлами». {{инфо: Сфера знает не все команды сразу. Часть лежит в отдельных «модулях», как инструменты в отдельных ящиках. `подключить файлы` открывает ящик «файлы»: после этого вам доступны `создать_папку`, `удалить_файл` и `файл_существует`. Без этой строки компилятор скажет, что не знает такой команды.}}
- `функция главная(): целое` — начало программы, с неё всегда всё стартует.
- `создать_папку("папка_тест")` — делает новую папку с таким именем рядом с программой.
- `записать_файл("папка_тест/файл.txt", "привет")` — создаёт файл `файл.txt` внутри папки и кладёт в него слово «привет». {{инфо: У команды два значения в скобках, через запятую. Первое — путь к файлу: сначала папка, потом косая черта `/`, потом имя файла. Второе — то, что записать внутрь. Если такой файл уже был, его старое содержимое пропадёт.}}
- `верно есть = файл_существует("папка_тест/файл.txt")` — спрашиваем «этот файл есть?» и запоминаем ответ. {{инфо: `верно` — тип переменной, которая хранит только `да` или `нет`. Слово `есть` — имя, которое придумали мы сами, как подпись на коробке. Знак `=` значит «положить в коробку то, что справа». Справа команда `файл_существует`, и она отвечает `да` или `нет`.}}
- `вывести("существует: %есть%")` — печатаем ответ. {{инфо: Знаки `%...%` внутри текста значат «вместо этого подставь значение переменной». Если в `есть` лежит `да`, на экране будет «существует: да».}}
- `переименовать_файл("папка_тест/файл.txt", "папка_тест/другой.txt")` — меняет имя файла с `файл.txt` на `другой.txt`. Первый путь — старое имя, второй — новое.
- `результат из текста т = прочитать_файл("папка_тест/другой.txt")` — читаем файл целиком. {{инфо: Чтение может не получиться: файла нет или нет прав. Поэтому команда отдаёт не просто текст, а «коробочку» `результат из текста` с двумя ячейками: `.успешно` (получилось ли) и `.значение` (сам текст). В этом примере мы точно знаем, что файл есть, поэтому берём `.значение` сразу. В настоящей программе сначала проверьте `.успешно`.}}
- `вывести(т.значение)` — печатаем то, что прочитали. Должно быть «привет».
- `результат из верного р = удалить_файл("папка_тест/другой.txt")` — стираем файл. Ответ в `р`: получилось или нет.
- `верно ещё_есть = файл_существует(...)` — проверяем: теперь файла быть не должно.
- `вывести("удалён: %(р.успешно)%, существует: %ещё_есть%")` — печатаем оба факта сразу. {{инфо: Когда внутри `%...%` не просто имя, а выражение, его берут в скобки: `%(р.успешно)%`. Точка в `р.успешно` значит «заглянуть в ячейку `успешно` коробочки `р`».}}
- `результат из верного р2 = удалить_файл("папка_тест")` — теперь удаляем саму папку. Она уже пустая, поэтому получится.
- `вывести("папка удалена: %(р2.успешно)%")` — сообщаем результат.
- `результат из верного р3 = удалить_файл("нет_такого")` — нарочно пытаемся удалить то, чего нет. {{инфо: Это проверка на прочность: хорошая программа не падает, когда просят невозможное, а сообщает об ошибке. Здесь `р3.успешно` будет `нет`, а в `р3.сообщение` будет объяснение.}}
- `вывести("ошибка: %(р3.сообщение)%")` — печатаем это объяснение.
- `вернуть 0` — программа закончилась без ошибок (подробнее в уроке 1).
- `конец` — конец функции `главная`.

Что увидите на экране:

```
существует: да
привет
удалён: да, существует: нет
папка удалена: да
ошибка: не удалось удалить: нет_такого
```
