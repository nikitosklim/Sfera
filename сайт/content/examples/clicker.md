# Кликер: игра с сохранением

Текстовая игра, которая помнит прогресс между запусками.

## Код

```
// Кликер — текстовая игра на языке Сфера. Сохраняет прогресс между
// запусками в файл "кликер_сохранение.txt" — простой текстовый формат:
// "очки\nочков_за_клик" (два числа, разделённые переводом строки).

структура Улучшение
    текст название
    целое цена
    целое бонус
конец

структура СостояниеИгры
    целое очки
    целое очков_за_клик
конец

функция сохранить_игру(целое очки, целое очков_за_клик): результат из верного
    текст данные = целое_в_текст(очки) + "\n" + целое_в_текст(очков_за_клик)
    вернуть записать_файл("кликер_сохранение.txt", данные)
конец

функция загрузить_игру(): результат из СостояниеИгры
    результат из текста файл_результат = прочитать_файл("кликер_сохранение.txt")
    если ( не файл_результат.успешно)
        вернуть ошибка(файл_результат.сообщение)
    конец
    текст данные = файл_результат.значение

    результат из целого позиция_результат = найти(данные, "\n")
    если ( не позиция_результат.успешно)
        вернуть ошибка("повреждённый файл сохранения (нет разделителя)")
    конец
    целое инд = позиция_результат.значение

    результат из текста текст_очков = подстрока(данные, 0, инд)
    если ( не текст_очков.успешно)
        вернуть ошибка("повреждённый файл сохранения")
    конец

    целое остаток_начало = инд + 1
    целое остаток_длина = длина(данные) - остаток_начало
    результат из текста текст_бонуса = подстрока(данные, остаток_начало, остаток_длина)
    если ( не текст_бонуса.успешно)
        вернуть ошибка("повреждённый файл сохранения")
    конец

    результат из целого очки_результат = текст_в_целое(текст_очков.значение)
    если ( не очки_результат.успешно)
        вернуть ошибка("повреждённый файл сохранения (очки не число)")
    конец
    результат из целого бонус_результат = текст_в_целое(текст_бонуса.значение)
    если ( не бонус_результат.успешно)
        вернуть ошибка("повреждённый файл сохранения (бонус не число)")
    конец

    вернуть успех(СостояниеИгры(очки_результат.значение, бонус_результат.значение))
конец

функция главная(): целое
    целое очки = 0
    целое очков_за_клик = 1

    результат из СостояниеИгры загрузка = загрузить_игру()
    если (загрузка.успешно)
        очки = загрузка.значение.очки
        очков_за_клик = загрузка.значение.очков_за_клик
        вывести("Прогресс загружен. Очки:")
        вывести(очки)
    конец

    Список из Улучшение магазин = Список из Улучшение()
    магазин.добавить(Улучшение("Быстрые пальцы", 10, 1))
    магазин.добавить(Улучшение("Механическая клавиатура", 50, 3))
    магазин.добавить(Улучшение("Автокликер", 200, 10))

    вывести("=== Кликер ===")
    вывести("Команды: к (клик), м (магазин), с (статистика), 1/2/3 (купить улучшение), сх (сохранить), в (выход)")

    верно продолжать = да
    пока (продолжать)
        результат из текста ввод = прочитать_строку()
        если ( не ввод.успешно)
            продолжать = нет
        иначе
            текст команда = ввод.значение

            если (команда == "к")
                очки = очки + очков_за_клик
                вывести(очки)
            иначе если (команда == "с")
                вывести("Очки:")
                вывести(очки)
                вывести("Очков за клик:")
                вывести(очков_за_клик)
            иначе если (команда == "м")
                вывести("=== Магазин ===")
                целое индекс = 0
                пока (индекс меньше магазин.размер())
                    Улучшение у = магазин.получить(индекс)
                    вывести(у.название)
                    вывести(у.цена)
                    индекс = индекс + 1
                конец
            иначе если (команда == "1" или команда == "2" или команда == "3")
                результат из целого номер_результат = текст_в_целое(команда)
                если (номер_результат.успешно)
                    целое номер = номер_результат.значение - 1
                    если (номер не меньше 0 и номер меньше магазин.размер())
                        Улучшение выбранное = магазин.получить(номер)
                        если (очки не меньше выбранное.цена)
                            очки = очки - выбранное.цена
                            очков_за_клик = очков_за_клик + выбранное.бонус
                            вывести("Куплено:")
                            вывести(выбранное.название)
                        иначе
                            вывести("Не хватает очков")
                        конец
                    конец
                конец
            иначе если (команда == "сх")
                результат из верного сохранение = сохранить_игру(очки, очков_за_клик)
                если (сохранение.успешно)
                    вывести("Прогресс сохранён")
                иначе
                    вывести("Не удалось сохранить прогресс:")
                    вывести(сохранение.сообщение)
                конец
            иначе если (команда == "в")
                сохранить_игру(очки, очков_за_клик)
                продолжать = нет
            иначе
                вывести("Неизвестная команда")
            конец
        конец
    конец

    вывести("Игра окончена. Итоговые очки:")
    вывести(очки)

    вернуть 0
конец
```

## Как запустить

Сохраните код в файл, например `кликер.код`, и выполните:

```
запустить кликер.код
```

## Как это работает, строка за строкой

Игра состоит из структур, трёх функций и главного цикла.

### Структуры

- `структура Улучшение` — что продаёт магазин: `название`, `цена`, `бонус` (на сколько вырастут очки за клик). {{инфо: Структура — набор полей под одним именем. Один предмет в магазине это одна структура `Улучшение`: «Быстрые пальцы», цена 10, бонус 1.}}
- `структура СостояниеИгры` — то, что нужно сохранить: сколько `очки` и сколько `очков_за_клик`.

### Сохранение: `сохранить_игру`

- `текст данные = целое_в_текст(очки) + "\n" + целое_в_текст(очков_за_клик)` — делаем из двух чисел текст из двух строк. {{инфо: `\n` — перевод строки: невидимый символ, который разделяет строки. Получается файл вида «40» и «3» на разных строчках.}}
- `вернуть записать_файл("кликер_сохранение.txt", данные)` — записываем файл и сразу отдаём его ответ (получилось или нет).

### Загрузка: `загрузить_игру`

- `прочитать_файл(...)` — читаем сохранение. Если файла нет (первый запуск), возвращаем ошибку, а в `главной` это просто означает «начинаем с нуля».
- `найти(данные, "\n")` — ищем, где кончается первая строка. Если не нашли, файл повреждён. {{инфо: Программа не доверяет файлу: его могли испортить или отредактировать вручную. Поэтому на каждом шаге есть проверка `.успешно`, и при проблеме функция честно возвращает ошибку.}}
- `подстрока(...)` — вырезаем из текста два числа в виде текста, `текст_в_целое(...)` превращает их в числа.
- `вернуть успех(СостояниеИгры(...))` — возвращаем готовую структуру в «коробочке».

### Главная функция

- `целое очки = 0` и `целое очков_за_клик = 1` — значения для новой игры.
- `загрузка.значение.очки` — если сохранение есть, берём из него очки. Две точки подряд: сначала открываем коробочку (`.значение`), потом поле структуры (`.очки`).
- `Список из Улучшение магазин = ...` и три `магазин.добавить(Улучшение("Быстрые пальцы", 10, 1))` — делаем магазин: три предмета с названием, ценой и бонусом.
- `верно продолжать = да` и `пока (продолжать)` — главный цикл: игра идёт, пока флаг `да`. {{инфо: Такой флаг удобен, чтобы выйти из цикла из любого места: достаточно записать `нет`. Тогда цикл закончится на следующей проверке.}}
- `прочитать_строку()` — ждём команду игрока. Если ввод закончился, ставим `продолжать = нет`.
- `если (команда == "к")` — клик: `очки = очки + очков_за_клик`. Дальше цепочка `иначе если` разбирает остальные команды: `с` — статистика, `м` — магазин.
- Команда `м` — цикл по списку магазина: `магазин.получить(индекс)` достаёт предмет, `у.название` и `у.цена` печатаются.
- Команды `1`, `2`, `3` — покупка. Номер превращаем в число и вычитаем 1 (номера в списке с нуля). {{инфо: Три проверки подряд: хватает ли очков (`очки не меньше выбранное.цена`), нужный ли номер, получилось ли превратить текст в число. Если хватает, вычитаем цену и увеличиваем `очков_за_клик` на бонус.}}
- Команда `сх` — сохранить в файл. Команда `в` — сохранить и выйти: `продолжать = нет`.
- Всё остальное — «Неизвестная команда».
- Последние строки печатают итог. `вернуть 0` — всё закончилось нормально.

## Что выведет программа

Если по очереди ввести команды `к`, `к`, `м`, `с`, `в` (каждую с новой строки):

```
=== Кликер ===
Команды: к (клик), м (магазин), с (статистика), 1/2/3 (купить улучшение), сх (сохранить), в (выход)
1
2
=== Магазин ===
Быстрые пальцы
10
Механическая клавиатура
50
Автокликер
200
Очки:
2
Очков за клик:
1
Игра окончена. Итоговые очки:
2
```
