# Обобщённая функция

Один код для чисел разных типов.

## Код

```
// Обобщённая функция — один и тот же код работает для разных типов.
// Тип нужно указывать явно при вызове (макс_из_двух<целое>(...)),
// вывод типа из аргументов пока не реализован.

функция макс_из_двух из Т (Т а, Т б): Т
    если (а больше б)
        вернуть а
    конец
    вернуть б
конец

функция главная(): целое
    целое итог_целое = макс_из_двух из целое(3, 7)
    вывести("макс(3, 7) = " + целое_в_текст(итог_целое))

    дробное итог_дробное = макс_из_двух из дробное(2.5, 1.5)
    вывести("макс(2.5, 1.5) = " + дробное_в_текст(итог_дробное))

    вернуть 0
конец
```

## Как запустить

Сохраните код в файл, например `обобщённые_функции.код`, и выполните:

```
запустить обобщённые_функции.код
```

## Как это работает, строка за строкой

- `функция макс_из_двух из Т (Т а, Т б): Т` — функция, у которой тип не назван заранее. `Т` — «пустое место для типа». {{инфо: Представьте бланк с пропуском вместо слова. Вы вписываете в пропуск `целое` или `дробное`, и компилятор делает готовую версию. Букву `Т` можно заменить любой, это просто имя пропуска.}}
- `(Т а, Т б): Т` — оба параметра и результат одного и того же типа.
- `если (а больше б)` и `вернуть а` — если первое больше, отдаём его, иначе второе (последняя строка). Работает для любого типа, который можно сравнивать.
- `макс_из_двух из целое(3, 7)` — вызов: после слова `из` пишем, чем заменить `Т`. Для целых получится 7. {{инфо: Компилятор пока не умеет сам догадываться о типе по аргументам, поэтому после `из` его нужно указать явно.}}
- `макс_из_двух из дробное(2.5, 1.5)` — тот же код, но уже для дробных чисел: получится 2.5.
- `целое_в_текст(...)` и `дробное_в_текст(...)` — превращают число в текст, чтобы склеить со строкой знаком `+`.

## Что выведет программа

```
макс(3, 7) = 7
макс(2.5, 1.5) = 2.500000
```
