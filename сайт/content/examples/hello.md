# Привет, мир

Самая короткая программа на «Сфере».

## Код

```
функция главная(): целое
    вывести("Привет, мир!");
    вернуть 0;
конец
```

## Как запустить

Сохраните код в файл, например `привет.код`, и выполните:

```
запустить привет.код
```

## Как это работает, строка за строкой

- `функция главная(): целое` — «начало программы». Слово `функция` вводит набор команд с именем. {{инфо: Функцию с именем `главная` компьютер запускает первой. Без неё программа не знает, с чего начать. `: целое` значит «в конце вернёт целое число».}}
- `вывести("Привет, мир!");` — показать текст на экране. Текст в двойных кавычках, а точка с запятой заканчивает команду.
- `вернуть 0;` — завершить программу и сообщить системе число 0. {{инфо: Ноль значит «всё хорошо». Любое другое число значит ошибку. Систему и другие программы интересует именно оно.}}
- `конец` — закрывает функцию. Фигурных скобок в Сфере нет, блок всегда заканчивается словом `конец`.

## Что выведет программа

```
Привет, мир!
```
