# Привет, мир

Самая короткая программа на «Сфере».

## Код

```
функция главная(): целое
    вывести("Привет, мир!");
    вернуть 0;
конец
```

## Как запустить

Сохраните код в файл, например `привет.код`, и выполните:

```
запустить привет.код
```

## Как это работает

- Каждая программа начинается с функции `главная`. Она возвращает целое число: `0` значит «всё хорошо».
- `вывести(...)` печатает строку и переводит строку.
- Блок функции закрывается словом `конец`, фигурных скобок нет.
