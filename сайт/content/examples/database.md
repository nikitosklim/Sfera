# SQLite: база данных

Создать таблицу, добавить запись и прочитать её.

## Код

```
// Пример работы с базой данных SQLite через стандартную_библиотека/база_данных.код.
// Демонстрирует полный, типичный цикл: открыть базу, создать таблицу,
// вставить запись безопасным, параметризованным способом (без риска
// SQL-инъекции — значение никогда не подставляется в текст SQL напрямую),
// прочитать все записи через SELECT.

подключить база_данных

функция главная(): целое
    результат из текста бд_результат = открыть_базу("пример.db")
    если ( не бд_результат.успешно)
        вывести("не удалось открыть базу данных")
        вернуть 1
    конец
    текст бд = бд_результат.значение

    результат из целого создание = выполнить_ясз(бд,
        "CREATE TABLE IF NOT EXISTS пользователи (id INTEGER PRIMARY KEY, имя TEXT);")
    если ( не создание.успешно)
        вывести("ошибка создания таблицы: " + создание.сообщение)
        вернуть 1
    конец

    // Параметризованная вставка через "?" — безопасный способ передать
    // значение, введённое пользователем (или пришедшее откуда угодно
    // извне), без риска SQL-инъекции. Простая склейка строк ("... VALUES
    // ('" + имя + "')") была бы опасна именно этим — если бы "имя"
    // содержало символ кавычки или фрагмент SQL-кода, он выполнился бы
    // как часть запроса.
    текст stmt_буфер = выделить_память(8)
    sqlite_подготовить(бд, "INSERT INTO пользователи (имя) VALUES (?);", целое32(-1), stmt_буфер, нулевой_указатель_бд())
    текст stmt_вставки = прочитать_указатель(stmt_буфер, 0)
    // целое(-1) — SQLITE_TRANSIENT, говорит SQLite самой скопировать
    // строку себе (безопаснее, чем вручную следить за временем жизни
    // исходного буфера).
    sqlite_привязать_текст(stmt_вставки, целое32(1), "Никита", целое32(-1), целое(-1))
    sqlite_шаг(stmt_вставки)
    sqlite_завершить(stmt_вставки)
    освободить_память(stmt_буфер)

    вывести("запись добавлена, читаем все записи:")

    текст stmt_буфер_select = выделить_память(8)
    sqlite_подготовить(бд, "SELECT id, имя FROM пользователи;", целое32(-1), stmt_буфер_select, нулевой_указатель_бд())
    текст stmt_выборки = прочитать_указатель(stmt_буфер_select, 0)

    целое32 шаг = sqlite_шаг(stmt_выборки)
    пока (шаг == целое32(100))  // 100 = SQLITE_ROW — есть ещё строка
        целое32 id = sqlite_колонка_целое(stmt_выборки, целое32(0))
        текст имя = sqlite_колонка_текст(stmt_выборки, целое32(1))
        // НОВОЕ: строка собирается в промежуточную переменную, а не
        // передаётся в "вывести(...)" прямой конкатенацией — известное,
        // честно задокументированное ограничение ARC для текста (см.
        // "Известные ограничения" в ДОКУМЕНТАЦИЯ_ЯЗЫКА.md): результат
        // конкатенации, переданный напрямую в вызов функции без
        // промежуточной переменной, не попадает под отслеживание ARC и
        // не освобождается — не крах, просто небольшая, безопасная утечка.
        текст строка_вывода = "  id=" + целое_в_текст(целое(id)) + ", имя=" + имя
        вывести(строка_вывода)
        шаг = sqlite_шаг(stmt_выборки)
    конец
    sqlite_завершить(stmt_выборки)
    освободить_память(stmt_буфер_select)

    sqlite_закрыть(бд)
    вернуть 0
конец
```

## Как запустить

Сохраните код в файл, например `база_данных_пример.код`, и выполните:

```
запустить база_данных_пример.код --линковать sqlite3
```

Флаг `--линковать sqlite3` говорит сборщику: «подключи системную библиотеку SQLite». Без него будет ошибка линковки «undefined reference to sqlite3_open». Библиотека обычно уже есть на macOS и Linux; на Windows положите `sqlite3.dll` рядом с программой.

## Как это работает, строка за строкой

- `подключить база_данных` — подключаем готовую обёртку над SQLite. {{инфо: SQLite — маленькая база данных, которая живёт в одном файле. Она есть в телефонах, браузерах и тысячах программ. База хранит таблицы: строки и столбцы, как в таблице Excel.}}
- `результат из текста бд_результат = открыть_базу("пример.db")` — открываем файл базы (если его нет, он создастся). Может не получиться, поэтому ответ в коробочке.
- `текст бд = бд_результат.значение` — запоминаем «ручку» открытой базы, она нужна всем следующим командам.
- `выполнить_ясз(бд, "CREATE TABLE IF NOT EXISTS ...")` — команда на языке SQL: «создай таблицу `пользователи` с двумя столбцами, если её ещё нет». {{инфо: SQL — отдельный язык для разговора с базами данных. Строка в кавычках не Сфера, а SQL: её прочитает и выполнит SQLite. `id INTEGER PRIMARY KEY` — столбец с номером записи, `имя TEXT` — столбец с текстом.}}
- `sqlite_подготовить(...)` с `?` — готовим вставку: вместо значения пока стоит вопросительный знак. {{инфо: Вопросительный знак резервирует место для значения. Значение подставляется отдельно, и база никогда не принимает его за SQL-команду. Так защищаются от «SQL-инъекции», когда чужой ввод вроде `'); DROP TABLE ...` пытается стать частью запроса. Склеивать запрос из строк в таком случае опасно.}}
- `sqlite_привязать_текст(stmt_вставки, 1, "Никита", ...)` — вместо первого `?` подставляем «Никита».
- `sqlite_шаг(...)` — выполнить подготовленную команду, `sqlite_завершить(...)` — закончить с ней.
- `SELECT id, имя FROM пользователи` — «выбери все записи». Читаем их по одной в цикле `пока (шаг == 100)`. {{инфо: Число 100 в SQLite значит «есть ещё строка». Пока база отвечает 100, мы читаем очередную строку: номер через `sqlite_колонка_целое`, имя через `sqlite_колонка_текст`.}}
- `sqlite_закрыть(бд)` — закрываем базу. Не забывайте: незакрытая база держит файл.

## Что выведет программа

```
запись добавлена, читаем все записи:
  id=1, имя=Никита
```

При повторных запусках записей будет больше: база хранится в файле `пример.db` и помнит старые.
