# Фоновый поток и канал

Считаем в отдельном потоке и получаем результат безопасно.

## Код

```
// Пример: запуск фонового потока (параллельно) и безопасная передача
// результата обратно через канал.
функция главная(): целое
    канал из целого канал_результата = создать_канал();

    параллельно
        целое вычислено = 2 + 2;
        канал_результата.отправить(вычислено);
    конец

    // Ждёт, пока фоновый поток не отправит значение.
    целое значение = канал_результата.получить();
    вывести(целое_в_текст(значение));

    вернуть 0;
конец
```

## Как запустить

Сохраните код в файл, например `многопоточность.код`, и выполните:

```
запустить многопоточность.код
```

## Как это работает, строка за строкой

- `канал из целого канал_результата = создать_канал();` — создаём «трубу» для целых чисел. По ней фоновый поток передаст ответ. {{инфо: Два потока работают одновременно и не должны лезть в одну и ту же переменную: можно испортить данные. Канал — безопасная труба: один кладёт в неё число, другой достаёт.}}
- `параллельно` ... `конец` — всё внутри выполняется в отдельном потоке, одновременно с основным. {{инфо: Поток — это второй исполнитель в программе. Пока главный ждёт, второй считает.}}
- `целое вычислено = 2 + 2;` — работа фонового потока: считаем.
- `канал_результата.отправить(вычислено);` — кладём ответ в трубу.
- `целое значение = канал_результата.получить();` — главный поток ждёт, пока в трубе что-нибудь не появится, и достаёт. Если ответ ещё не готов, программа просто подождёт.
- `вывести(целое_в_текст(значение));` — печатаем 4.

## Что выведет программа

```
4
```
