# Контракты: Кот и Собака

Одна функция работает с любым объектом, который умеет «напечатать».

## Код

```
// Пример: контракты и настоящий полиморфизм (динамический диспетчинг).
// Одна и та же функция работает с любой структурой, реализующей контракт.
контракт Печатаемый
    функция напечатать(): текст;
конец

структура Кот : Печатаемый
    функция напечатать(): текст
        вернуть "Мяу";
    конец
конец

структура Собака : Печатаемый
    функция напечатать(): текст
        вернуть "Гав";
    конец
конец

функция озвучить(Печатаемый существо): целое
    вывести(существо.напечатать());
    вернуть 0;
конец

функция главная(): целое
    Кот кот = Кот();
    Собака пёс = Собака();

    озвучить(кот);   // выведет "Мяу"
    озвучить(пёс);   // выведет "Гав" — та же функция, другая реализация

    вернуть 0;
конец
```

## Как запустить

Сохраните код в файл, например `полиморфизм.код`, и выполните:

```
запустить полиморфизм.код
```

## Как это работает, строка за строкой

- `контракт Печатаемый` — список умений. Внутри: `функция напечатать(): текст;`. Тела нет: контракт говорит только, что структура должна уметь, а не как. {{инфо: Как должностная инструкция: перечислены обязанности, но не способ. Каждая структура делает это по-своему.}}
- `структура Кот : Печатаемый` — структура `Кот` обещает выполнить контракт (после двоеточия). {{инфо: Если забыть метод `напечатать` или написать его с другим заголовком, компилятор не соберёт программу и объяснит почему.}}
- `функция напечатать(): текст` внутри `Кот` — реализация: возвращает слово «Мяу». У `Собака` то же имя, но другой ответ.
- `функция озвучить(Печатаемый существо)` — параметр типа «контракт»: годится любая структура, которая его выполняет.
- `вывести(существо.напечатать());` — вызываем метод. Какой именно, кошкин или собачий, выяснится во время работы. {{инфо: Это называется полиморфизмом, то есть «много форм»: одна строка кода, разные поведения.}}
- `Кот кот = Кот();` — создаём объект и кладём в переменную. Сначала переменная, потом передача в функцию: `озвучить(Кот())` напрямую не работает.
- `озвучить(кот);` и `озвучить(пёс);` — одна функция, два результата: «Мяу» и «Гав».

## Что выведет программа

```
Мяу
Гав
```
