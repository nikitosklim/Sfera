# Проводник: окно с файлами вашего сервера

Настоящая программа на «Сфере»: окно с папками и файлами сервера, сведения о его памяти и диске, правка файлов прямо в окне. Мы пользуемся ею каждый день, чтобы управлять сервером этого сайта.

![Проводник Сферы: слева файлы сервера, справа память, диск и процессор](/статика/examples/provodnik.png)

## Что умеет программа

- Ходит по папкам сервера, как Finder или Проводник Windows. Кнопки «<» и «>» работают как в браузере.
- Удаляет, переименовывает, переносит файлы, создаёт папки, ищет по имени и сортирует.
- Открывает текстовый файл в окне, даёт его править и сохраняет обратно на сервер.
- Принимает файлы перетаскиванием на окно.
- Показывает загрузку памяти, диска и процессора справа, обновляя их каждые 5 секунд.
- На Mac получается обычное приложение «Проводник Сферы» с иконкой, а изображение чёткое и на экране Retina.

Всё это около 2900 строк на «Сфере»: окно, рисование, шрифты и мышь работают через библиотеку графики, а запросы к серверу идут обычным `curl` в фоне.

## Как устроена программа

Вот три небольших куска настоящего кода. По ним видно, что окно на «Сфере» не требует чего-то особенного: это те же функции, структуры и текст.

### История папок: кнопки «<» и «>»

Адреса уже пройденных папок лежат в обычных текстовых строках, по одному адресу на строку. Кнопка «назад» берёт верхний адрес из первой строки, а текущую папку кладёт во вторую.

```
// Не даём истории расти бесконечно: выбрасываем самое старое.
функция укоротить_стек(текст стек): текст
    если (длина(стек) меньше 4000)
        вернуть часть_текста(стек, 0, длина(стек))
    конец
    целое п = 2000
    пока (п меньше длина(стек) и целое(байт_текста(стек, п)) != 10)
        п = п + 1
    конец
    вернуть часть_текста(стек, п + 1, длина(стек) - п - 1)
конец

функция перейти(Состояние с, текст путь): целое
    если (путь != с.путь)
        с.назад = укоротить_стек(с.назад + с.путь + "\n")
        с.вперёд = ""
    конец
    перейти_без_истории(с, путь)
    вернуть 0
конец

функция шаг_назад(Состояние с): целое
    если (длина(с.назад) == 0)
        вернуть 0
    конец
    текст цель = верх_стека(с.назад)
    с.назад = без_верха(с.назад)
    с.вперёд = с.вперёд + с.путь + "\n"
    перейти_без_истории(с, цель)
    вернуть 0
конец
```

{{инфо: Обратите внимание на `вернуть часть_текста(стек, 0, длина(стек))`. Если вернуть сам параметр, получится ссылка на временную строку, которая скоро исчезнет. Копия безопасна, поэтому в программе такие места написаны именно так.}}

### Запрос к серверу в фоне

Окно не должно замирать, пока сервер отвечает. Поэтому каждый запрос — маленький скрипт, который запускается в фоне и по окончании кладёт код ответа рядом. Окно на каждом кадре смотрит, появился ли этот файл.

```
функция запустить_слот(целое слот, текст тело): верно
    текст скрипт = путь_слота(слот, "sh")
    выполнить_команду("rm -f '" + для_оболочки(путь_слота(слот, "done")) + "'")
    результат из верного запись = записать_файл(скрипт, тело)
    если ( не запись.успешно)
        вернуть нет
    конец
    результат из целого запуск = выполнить_команду("sh '" + для_оболочки(скрипт) + "' > /dev/null 2>&1 &")
    вернуть запуск.успешно
конец

// Код ответа HTTP ("200", "401", "000" — нет связи) или "" пока идёт.
функция итог_слота(целое слот): текст
    результат из текста р = прочитать_файл(путь_слота(слот, "done"))
    если ( не р.успешно или длина(р.значение) == 0)
        вернуть ""
    конец
    вернуть обрезать_края(р.значение)
конец
```

### Большие папки за доли секунды

В папке `/usr/bin` больше полутора тысяч файлов. Чтобы окно не зависало, сервер отдаёт папку страницами по 250 записей и в компактном виде: у каждой записи поля фиксированной ширины. Клиент проходит строку один раз и никого не ищет по имени.

```
функция разобрать_компактный(текст о, Список из текстов т, Список из целых ч, целое поиск): целое
    очистить_тексты(т)
    очистить_целые(ч)
    целое число = число_из_части(о, 23, 10)
    целое байт = длина(о)
    целое поз = 33
    целое ин = 0
    пока (ин меньше число и поз + 28 не больше байт)
        целое папка = число_из_части(о, поз, 1)
        целое размер = число_из_части(о, поз + 1, 12)
        целое дата = число_из_части(о, поз + 13, 12)
        целое дл = число_из_части(о, поз + 25, 3)
        текст имя = часть_текста(о, поз + 28, дл)
        если (поиск == 1)
            добавить_запись_поиска(т, ч, имя, папка, размер, дата)
        иначе
            добавить_запись(т, ч, имя, папка, размер, дата)
        конец
        поз = поз + 28 + дл
        ин = ин + 1
    конец
    вернуть ин
конец
```
