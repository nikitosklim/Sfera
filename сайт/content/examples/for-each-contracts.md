# Список фигур

Перебираем список объектов с общим контрактом и считаем площадь.

## Код

```
// «для каждого» по списку контрактов.
контракт Фигура
    функция площадь(): целое;
    функция название(): текст;
конец

структура Квадрат : Фигура
    целое сторона;
    функция площадь(): целое
        вернуть это.сторона * это.сторона;
    конец
    функция название(): текст
        вернуть "квадрат";
    конец
конец

структура Прямоугольник : Фигура
    целое ширина;
    целое высота;
    функция площадь(): целое
        вернуть это.ширина * это.высота;
    конец
    функция название(): текст
        вернуть "прямоугольник";
    конец
конец

функция главная(): целое
    Список из Фигура фигуры = Список из Фигура();
    Квадрат к = Квадрат(3);
    Прямоугольник р = Прямоугольник(2, 5);
    фигуры.добавить(к);
    фигуры.добавить(р);

    целое всего = 0;
    для каждого ф в фигуры
        вывести("%(ф.название())%: %(ф.площадь())%");
        всего = всего + ф.площадь();
    конец
    вывести("Общая площадь: %всего%");
    вернуть 0;
конец
```

## Как запустить

Сохраните код в файл, например `контракты_для_каждого.код`, и выполните:

```
запустить контракты_для_каждого.код
```

## Как это работает, строка за строкой

- `контракт Фигура` — два умения: `площадь()` и `название()`.
- `структура Квадрат : Фигура` и `целое сторона;` — квадрат хранит одно число и обязан реализовать оба метода.
- `вернуть это.сторона * это.сторона;` — `это` значит «этот квадрат». Площадь квадрата — сторона в квадрате. {{инфо: Слово `это` — ссылка на объект, у которого вызвали метод. Для `Прямоугольник(2, 5)` это.ширина будет 2, а это.высота будет 5.}}
- `Список из Фигура фигуры = Список из Фигура();` — пустой список, в который можно класть любые структуры с контрактом `Фигура`. {{инфо: Обычный список хранит одинаковые вещи. Контракт позволяет хранить разные структуры вместе, если они умеют одно и то же.}}
- `Квадрат к = Квадрат(3);` — создаём квадрат со стороной 3. Конструктор принимает поля по порядку: у `Прямоугольник(2, 5)` ширина 2, высота 5.
- `фигуры.добавить(к);` — кладём в список. Исходные переменные `к` и `р` держите живыми, пока жив список.
- `для каждого ф в фигуры` — цикл по всем фигурам по очереди, `ф` каждый раз новая.
- `вывести("%(ф.название())%: %(ф.площадь())%");` — для каждой фигуры её название и площадь. Метод вызывается свой для каждого вида.
- `всего = всего + ф.площадь();` — копим общую площадь: 9 + 10 = 19.

## Что выведет программа

```
квадрат: 9
прямоугольник: 10
Общая площадь: 19
```
