# Словарь и перебор

Хранить пары «ключ — значение» и обойти их по порядку.

## Код

```
// Перебор словаря: ключ_по_индексу(i) и значение_по_индексу(i), порядок — как при вставке.
функция главная(): целое
    Словарь из текста и целого возрасты = Словарь из текста и целого();
    возрасты.положить("Аня", 25);
    возрасты.положить("Борис", 31);
    возрасты.положить("Вера", 40);

    целое i = 0;
    целое сумма = 0;
    пока (i меньше возрасты.размер())
        текст имя = возрасты.ключ_по_индексу(i);
        целое возраст = возрасты.значение_по_индексу(i);
        вывести("%имя%: %возраст%");
        сумма = сумма + возраст;
        i = i + 1;
    конец
    вывести("Сумма: %сумма%");
    возрасты.освободить();

    Словарь из целого и текста названия = Словарь из целого и текста();
    названия.положить(1, "один");
    названия.положить(2, "два");
    вывести("%(названия.ключ_по_индексу(1))% -> %(названия.значение_по_индексу(1))%");
    названия.освободить();
    вернуть 0;
конец
```

## Как запустить

Сохраните код в файл, например `словарь_перебор.код`, и выполните:

```
запустить словарь_перебор.код
```

## Как это работает, строка за строкой

- `Словарь из текста и целого возрасты = Словарь из текста и целого();` — словарь: имена (ключи) связаны с возрастами (значениями). {{инфо: Как телефонная книга: по имени находишь номер. Здесь ключ текст, значение целое число. Тип пишется слева обязательно.}}
- `возрасты.положить("Аня", 25);` — добавить пару. Три такие строки записывают Аню, Бориса и Веру.
- `целое i = 0;` — счётчик пар. `возрасты.размер()` — сколько пар сейчас в словаре (3).
- `пока (i меньше возрасты.размер())` — идём по номерам пар от 0 до 2.
- `возрасты.ключ_по_индексу(i)` — имя из пары с номером `i`. `возрасты.значение_по_индексу(i)` — её возраст. Порядок такой же, как при добавлении. {{инфо: Номер не является ключом, это порядок добавления. Аня добавлена первой, у неё номер 0. Ключом остаётся имя.}}
- `сумма = сумма + возраст;` — копим сумму возрастов: 25 + 31 + 40 = 96.
- `возрасты.освободить();` — вернуть память. Словарь освобождается вручную.
- Второй словарь `Словарь из целого и текста` — наоборот: числа ключи, слова значения. `ключ_по_индексу(1)` даёт 2 (вторую пару), `значение_по_индексу(1)` даёт «два».

## Что выведет программа

```
Аня: 25
Борис: 31
Вера: 40
Сумма: 96
2 -> два
```
