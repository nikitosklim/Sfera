# Словарь и перебор

Хранить пары «ключ — значение» и обойти их по порядку.

## Код

```
// Перебор словаря: ключ_по_индексу(i) и значение_по_индексу(i), порядок — как при вставке.
функция главная(): целое
    Словарь из текста и целого возрасты = Словарь из текста и целого();
    возрасты.положить("Аня", 25);
    возрасты.положить("Борис", 31);
    возрасты.положить("Вера", 40);

    целое i = 0;
    целое сумма = 0;
    пока (i меньше возрасты.размер())
        текст имя = возрасты.ключ_по_индексу(i);
        целое возраст = возрасты.значение_по_индексу(i);
        вывести("%имя%: %возраст%");
        сумма = сумма + возраст;
        i = i + 1;
    конец
    вывести("Сумма: %сумма%");
    возрасты.освободить();

    Словарь из целого и текста названия = Словарь из целого и текста();
    названия.положить(1, "один");
    названия.положить(2, "два");
    вывести("%(названия.ключ_по_индексу(1))% -> %(названия.значение_по_индексу(1))%");
    названия.освободить();
    вернуть 0;
конец
```

## Как запустить

Сохраните код в файл, например `словарь_перебор.код`, и выполните:

```
запустить словарь_перебор.код
```

## Как это работает

- `Словарь из текста и целого` связывает имена с возрастами.
- `ключ_по_индексу(i)` и `значение_по_индексу(i)` отдают пары в порядке добавления.
- Словарь освобождается вручную методом `освободить()`, когда он больше не нужен.

Исходник лежит в репозитории: [examples/словарь_перебор.код](https://github.com/nikitosklim/Sfera/blob/main/examples/словарь_перебор.код).
