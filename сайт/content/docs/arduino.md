# Сфера на Arduino

> **Простыми словами.** Плата Arduino Nano или Uno — это маленький компьютер без экрана и клавиатуры. Теперь программу для неё можно написать на Сфере: компилятор превращает её в машинный код для этого чипа, а готовый файл загружается в плату так же, как обычные программы Arduino.

## Как это работает

Программы на Сфере можно собирать для микроконтроллера ATmega328P (Arduino Uno, Nano, Pro Mini): флаг
`--целевая-платформа avr` (для другого процессора из семейства: `avr:atmega2560`) вместе с `--без-ос` и
`--только-собрать`. Получается объектный файл; готовый стартовый код из набора `avr-gcc` (он есть внутри Arduino IDE)
настроит стек, обнулит память и вызовет программу. Скрипт `examples/голое-железо/avr/собрать.sh` делает всё сразу:
собирает `.hex` и по желанию загружает его на плату через `avrdude`.

```
функция главная(): целое
    аппаратная_запись8(0x24, беззнак8(32))      // DDRB: вывод PB5 (светодиод на плате) — выход
    пока (да)
        аппаратная_запись8(0x25, беззнак8(32))  // PORTB: включить
        пауза(целое32(100000))
        аппаратная_запись8(0x25, беззнак8(0))   // выключить
        пауза(целое32(100000))
    конец
    вернуть 0
конец
```

Особенности: на плате 2 КБ оперативной памяти, поэтому служебные таблицы потоков не создаются, а кучи нет; пока доступны
числа, `верно` и обращения к регистрам. `целое` остаётся 64-битным, для быстрого кода берите `целое16`, `беззнак8` и подобные.
Раскладка данных у модуля задана для AVR (16-битные указатели), включена оптимизация кода. Прерываний пока нет. Проверено
в эмуляторе simavr (`examples/голое-железо/avr/проверить.sh`), на настоящей плате не проверялось.

## Что понадобится

- Собранный компилятор Сферы.
- Arduino IDE: в ней уже есть всё нужное для сборки и загрузки (`avr-gcc` и `avrdude`).
- Кабель USB с передачей данных.

## Шаги

1. Соберите программу: `./собрать.sh мигалка.код` в папке `examples/голое-железо/avr/`. Получится файл `мигалка.hex`.
2. Подключите плату и узнайте порт (на Mac он называется вроде `/dev/cu.usbserial-…`).
3. Загрузите: `./собрать.sh мигалка.код /dev/cu.usbserial-…`. Если плата не отвечает, это Nano со старым загрузчиком, добавьте `BAUD=57600` перед командой.
4. Светодиод на плате должен мигать: это ваша программа на Сфере.
