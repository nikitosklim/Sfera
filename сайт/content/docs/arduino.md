# Сфера на Arduino

> **Простыми словами.** Плата Arduino Nano или Uno — это маленький компьютер без экрана и клавиатуры. Теперь программу для неё можно написать на Сфере: компилятор превращает её в машинный код для этого чипа, а готовый файл загружается в плату так же, как обычные программы Arduino.

## Как это работает

Программы на Сфере можно собирать для микроконтроллера ATmega328P (Arduino Uno, Nano, Pro Mini): флаг
`--целевая-платформа avr` (для другого процессора из семейства: `avr:atmega2560`) вместе с `--без-ос` и
`--только-собрать`. Получается объектный файл; готовый стартовый код из набора `avr-gcc` (он есть внутри Arduino IDE)
настроит стек, обнулит память и вызовет программу. Скрипт `examples/голое-железо/avr/собрать.sh` делает всё сразу:
собирает `.hex` и по желанию загружает его на плату через `avrdude`.

```
функция главная(): целое
    аппаратная_запись8(0x24, беззнак8(32))      // DDRB: вывод PB5 (светодиод на плате) — выход
    пока (да)
        аппаратная_запись8(0x25, беззнак8(32))  // PORTB: включить
        пауза(целое32(100000))
        аппаратная_запись8(0x25, беззнак8(0))   // выключить
        пауза(целое32(100000))
    конец
    вернуть 0
конец
```

Особенности: на плате 2 КБ оперативной памяти, поэтому служебные таблицы потоков не создаются, а кучи нет; пока доступны
числа, `верно` и обращения к регистрам. `целое` остаётся 64-битным, для быстрого кода берите `целое16`, `беззнак8` и подобные.
Раскладка данных у модуля задана для AVR (16-битные указатели), включена оптимизация кода. Проверено
в эмуляторе simavr (`examples/голое-железо/avr/проверить.sh`), на настоящей плате не проверялось.

### Прерывания AVR

Функция с именем `прерывание_<имя>` становится обработчиком прерывания (без параметров и без значения):

```
функция прерывание_таймер1_сравнение_а()
    аппаратная_запись8(0x25, переключить_биты(аппаратное_чтение8(0x25), беззнак8(32)))
конец
```

Имена прерываний: `внешнее_0`, `внешнее_1`, `смена_выводов_0`, `смена_выводов_1`, `смена_выводов_2`, `сторожевой_таймер`,
`таймер2_сравнение_а`, `таймер2_сравнение_б`, `таймер2_переполнение`, `таймер1_захват`, `таймер1_сравнение_а`,
`таймер1_сравнение_б`, `таймер1_переполнение`, `таймер0_сравнение_а`, `таймер0_сравнение_б`, `таймер0_переполнение`,
`порт_spi`, `порт_приём`, `порт_буфер_пуст`, `порт_передача`, `ацп`, `память_eeprom`, `компаратор`, `шина_twi`.
Можно и по номеру вектора: `прерывание_13`. Два обработчика одного прерывания дают ошибку. Разрешить прерывания
нужно самому: `машинная_команда("sei")`.

### Литералы подстраиваются под размер

Число, написанное в коде, само по себе `целое` (64 бита). Но там, где размер ясен из контекста, его не нужно приводить вручную:

```
целое16 а = 5
беззнак8 б = 250
б = б + 3
если (б == 253)
    а = а + 1
конец
аппаратная_запись8(0x24, 32)
```

Размер берётся из объявления переменной, присваивания, параметра или результата функции, поля структуры, соседнего операнда в `+`, `==`, `<` и других операциях, из ширины аппаратной записи (`аппаратная_запись16` ждёт 16 бит) и из второго операнда битовых функций. Число должно помещаться в тип: `беззнак8 х = 300` по-прежнему ошибка. Если контекст неясен (например, `х = 5` без объявления), число остаётся `целое`.

### Глобальные массивы и таблицы во флэш-памяти

Массив можно объявить на верхнем уровне, он виден во всех функциях (в том числе в обработчиках прерываний):

```
целое16(3) оперативная = массив(100, 200, 300)
неизменно беззнак8(4) флэш = массив(10, 20, 30, 40)
```

Если все значения в `массив(...)` — числа, они записываются прямо в образ программы, а не вычисляются при запуске. На AVR массив с `неизменно` лежит во флэш-памяти (32 КБ у Nano), а не в оперативной (2 КБ): компилятор читает его командой `lpm`. Подходит для таблиц синусоиды, частот нот и тому подобного. Изменить такой массив нельзя. Обычный глобальный массив лежит в оперативной памяти и изменяем. На голом железе без операционной системы сообщение об ошибке при выходе за границы массива не печатается: программа останавливается.

### Синтезатор на Сфере

Готовая программа лежит в `examples/голое-железо/avr/синтезатор.код`: 4 голоса, 4 формы волны (пила, прямоугольник, треугольник, синус), атака, затухание и фильтр, MIDI по последовательному порту (31250 бод), четыре ручки на A0–A3, звук через ШИМ на D9. Это то же устройство, что на C++, но целиком на Сфере: прерывание таймера 2 на 20 кГц, таблицы синуса и частот нот во флэш-памяти, данные голосов в глобальных массивах. Программа занимает около 4,2 КБ флэша и 93 байта оперативной памяти, самое длинное прерывание звука укладывается в 360 тактов из 800 доступных. Проверено в эмуляторе (нота 60 звучит на 262 Гц, все четыре формы дают нужный спектр), на настоящей плате не проверялось. Схема подключения та же, что у C++-варианта; загрузка: `./собрать.sh синтезатор.код /dev/cu.usbserial-…`.

## Что понадобится

- Собранный компилятор Сферы.
- Arduino IDE: в ней уже есть всё нужное для сборки и загрузки (`avr-gcc` и `avrdude`).
- Кабель USB с передачей данных.

## Шаги

1. Соберите программу: `./собрать.sh мигалка.код` в папке `examples/голое-железо/avr/`. Получится файл `мигалка.hex`.
2. Подключите плату и узнайте порт (на Mac он называется вроде `/dev/cu.usbserial-…`).
3. Загрузите: `./собрать.sh мигалка.код /dev/cu.usbserial-…`. Если плата не отвечает, это Nano со старым загрузчиком, добавьте `BAUD=57600` перед командой.
4. Светодиод на плате должен мигать: это ваша программа на Сфере.
