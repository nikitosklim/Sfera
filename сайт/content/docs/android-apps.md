# Приложения для Android

Программу на Сфере можно превратить в обычное приложение для телефона: файл `.apk`,
который ставится и запускается как любое другое. Окно, касания пальцем, рисование и текст
даёт модуль `приложение_android` (он же работает на компьютере, так программу удобно
отлаживать в окне).

## Первое приложение

```
подключить приложение_android;

функция главная(): целое
    Приложение п = начать_приложение(40);      // окно на весь экран, шрифт 40 пикселей
    целое шар_х = п.ширина / 2;
    целое шар_у = п.высота / 2;

    пока (п.работает)
        целое ев = ждать_событие(п);            // 1 — коснулись, 2 — ведут палец, 3 — отпустили
        пока (ев != 0)
            если (ев == 1 или ев == 2)
                шар_х = п.х;
                шар_у = п.у;
            конец
            ев = ждать_событие(п);
        конец

        начать_кадр(п, 18, 22, 40);              // фон: красный, зелёный, синий (0–255)
        круг(п, шар_х, шар_у, 60, 255, 170, 40);
        написать(п, "Коснитесь экрана", 40, 60, 255, 255, 255);
        показать_кадр(п);
    конец
    закончить_приложение(п);
    вернуть 0;
конец
```

Готовая игра «Поймай шар» лежит в `examples/android/касания.код`.

## Что есть в модуле

| Функция | Что делает |
|---|---|
| `начать_приложение(размер_шрифта)` | открывает окно на весь экран, возвращает `Приложение` |
| `п.ширина`, `п.высота` | настоящий размер экрана в пикселях |
| `ждать_событие(п)` | одно событие из очереди: 0 — пусто, 1 — касание, 2 — движение, 3 — палец убран, 4 — закрытие окна |
| `п.нажато`, `п.х`, `п.у` | палец на экране сейчас и где |
| `начать_кадр(п, к, з, с)` / `показать_кадр(п)` | начало и конец кадра (около 60 кадров в секунду) |
| `прямоугольник`, `плитка`, `круг`, `линия` | рисование фигур; цвет — три числа от 0 до 255 |
| `написать(п, текст, х, у, к, з, с)` | надпись, кириллица работает |
| `внутри_прямоугольника(х, у, пх, пу, ширина, высота)` | попало ли касание в область (кнопки) |

Мышь на компьютере ведёт себя как палец. Если нужно больше (картинки, свои шрифты, кнопки,
таблицы), ниже лежит `графика.код`, на котором модуль построен: `подключить графика;`.

## Сборка приложения на компьютере

Нужны: Сфера (`сфера`, `запустить`, `сфера_apk` лежат в одной папке), Android NDK и файл
`Sfera-App-Template.apk` со страницы «Скачать».

```
сфера собрать-android игра.код --имя "Моя игра"
```

Команда соберёт программу под телефон (ARM64), положит её в шаблон приложения, подставит имя и
подпишет. Получится `игра.apk`: скопируйте на телефон и откройте (Android попросит разрешить
установку из этого источника).

- `--выход файл.apk` задаёт имя файла, `--пакет ru.sfera.app.игра` задаёт идентификатор приложения
  (латиница, цифры и «_»; по умолчанию он получается из названия).
- `--ndk ПАПКА` указывает NDK, если не задана переменная `ANDROID_NDK`.
- `--шаблон ФАЙЛ` указывает шаблон, если он лежит не в `~/.sfera/android/`.

Подпись создаётся один раз и хранится в `~/.sfera/apk-ключ.txt`. Пока вы собираете своим ключом,
новую версию можно ставить поверх старой. Сохраните этот файл: с другим ключом Android потребует
сначала удалить старое приложение.

## Ограничения

- Только ARM64 (почти все телефоны с 2017 года).
- Приложение работает на SDL2: окно и рисование есть, а датчиков, камеры и уведомлений в модуле пока нет.
- Приложение подписано вашим ключом, а не ключом магазина: для Google Play и RuStore нужна
  отдельная подготовка, а установка из файла работает сразу.
