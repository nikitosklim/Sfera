# Модуль «время»

> **Простыми словами.** Компьютер считает время одним числом: сколько секунд прошло с 1 января 1970 года. Это число называют «юникс-секундами», его даёт `юникс_время()`. Модуль «время» превращает такое число в понятную дату («23 ноября 2026, 14:36»), читает даты из текста и считает дни недели и разницу между датами.

Подключается строкой `подключить время`.

## Дата в программе

Дата хранится в структуре `ДатаВремя` с полями `год`, `месяц`, `день`, `час`, `минута`, `секунда`. Время считается по Гринвичу (UTC), если не указано другое.

## Функции

| Функция | Что делает |
|---|---|
| `сейчас()` | текущая дата и время (UTC) |
| `сейчас_в_москве()` | текущая дата и время в Москве (UTC+3) |
| `время_из_юникса(секунды)` | юникс-секунды → `ДатаВремя` (UTC) |
| `время_из_юникса_со_смещением(секунды, минуты)` | то же с часовым поясом: смещение в минутах, Москва — 180 |
| `юникс_из_времени(дата)` | `ДатаВремя` (UTC) → юникс-секунды |
| `разобрать_дату_время(текст)` | читает «ГГГГ-ММ-ДД», «ГГГГ-ММ-ДД ЧЧ:ММ:СС» или «ГГГГ-ММ-ДДTЧЧ:ММ:СССZ» → `результат из ДатаВремя` |
| `дата_время_в_текст(дата)` | «2026-11-23 14:36:05» |
| `дата_в_текст(дата)` | «2026-11-23» |
| `время_в_текст(дата)` | «14:36:05» |
| `дата_по_русски(дата)` | «23 ноября 2026, 14:36» |
| `день_недели(секунды)` | 1 — понедельник … 7 — воскресенье |
| `название_дня_недели(номер)` | «понедельник» … «воскресенье» |
| `название_месяца(номер)` | «январь» … «декабрь» |
| `название_месяца_в_дате(номер)` | «января» … «декабря» (как в «23 ноября») |
| `високосный_год(год)` | `да` или `нет` |
| `дней_в_месяце(год, месяц)` | 28–31 |
| `дней_между(начало, конец)` | целых суток между двумя моментами |
| `прибавить_дни(секунды, дни)` | сдвиг момента на дни (можно отрицательные) |
| `смещение_москвы()` | 180 |

## Пример

```сфера
подключить время

функция главная()
    результат из ДатаВремя р = разобрать_дату_время("2026-11-23 14:36:05")
    если (р.успешно)
        целое секунды = юникс_из_времени(р.значение)
        вывести(дата_по_русски(время_из_юникса_со_смещением(секунды, смещение_москвы())))
        вывести(название_дня_недели(день_недели(секунды)))
        вывести(дата_в_текст(время_из_юникса(прибавить_дни(секунды, 40))))
    конец
конец
```

```
23 ноября 2026, 17:36
понедельник
2027-01-02
```

## Что важно знать

- Часовой пояс задаётся смещением в минутах. Базы часовых поясов с переходом на летнее время (как в Европе и США) в модуле нет. В России перехода нет, так что для Москвы смещение 180 всегда верно.
- Несуществующие даты («30 февраля», «25:00») и лишние символы в тексте возвращают ошибку, а не подгоняются молча.
- Даты до 1970 года работают (юникс-секунды отрицательные), календарь — григорианский.
- Лог (`подключить лог`) подключает этот модуль сам и пишет время в UTC.
