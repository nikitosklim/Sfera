# Перечисления и «выбрать»

> **Простыми словами.** Иногда значение бывает одним из нескольких видов, и у каждого вида свои данные: у фигуры «круг» есть радиус, у «прямоугольника» ширина и высота, а у «точки» ничего. Для этого и нужно перечисление. Оператор `выбрать` смотрит, какой вид перед ним, и достаёт данные именно этого вида.

## Объявление

```
перечисление Фигура
    круг(дробное радиус)
    прямоугольник(дробное ширина, дробное высота)
    точка
конец
```

Каждая строка — один **вариант**. В скобках перечислены его данные: тип и имя, как у параметров функции. Вариант без данных (`точка`) пишется без скобок. Точка с запятой после варианта необязательна.

## Создание значения

Значение создаётся по имени перечисления и варианта, как вызов функции:

```
Фигура а = Фигура.круг(2.0);
Фигура б = Фигура.прямоугольник(3.0, 4.0);
Фигура т = Фигура.точка;
```

Количество данных должно совпадать с объявлением. Если их меньше или больше, компилятор сообщит об этом ошибкой с номером строки.

## Разбор через «выбрать»

```
функция площадь(Фигура ф): дробное
    выбрать ф
        когда круг(р)
            вернуть 3.14 * р * р
        когда прямоугольник(ш, выс)
            вернуть ш * выс
        когда точка
            вернуть 0.0
    конец
конец
```

- После `когда` идёт имя варианта и в скобках имена, под которыми данные доступны внутри ветки. Эти имена только для чтения.
- Если данные не нужны, скобки можно опустить: `когда круг`. Ненужное данное можно пропустить значком `_`: `когда прямоугольник(_, выс)`.
- Ветка `иначе` выполняется, если ни одна из веток `когда` не подошла.
- Весь разбор закрывается одним `конец`.

{{инфо: Если вы не разобрали все варианты и не написали `иначе`, компилятор остановится и перечислит пропущенные. Так добавление нового варианта в перечисление не даст забыть обновить все места, где оно разбирается.}}

## Одинаковые имена вариантов

Если вариант с таким именем есть в нескольких перечислениях, укажите, из какого вы разбираете:

```
выбрать команда
    когда Команда.стоп
        вывести("стоп")
    иначе
        вывести("едем")
конец
```

## Где можно использовать

Значение перечисления — обычная переменная, как структура. Его можно хранить в `Список из Фигура`, в поле структуры, передавать в функции и возвращать из них. Перечисление можно объявить в подключаемом файле и пользоваться им из другого.

## Как это устроено внутри

Компилятор превращает перечисление в обычную структуру: в ней есть поле `тег` с номером варианта и поля для данных каждого варианта (`круг_радиус`, `прямоугольник_ширина`). Создание `Фигура.круг(2.0)` — это вызов функции `Фигура__круг`, а `выбрать` — цепочка `если`. Поэтому память освобождается автоматически, как у структур (см. раздел про подсчёт ссылок).

## Ограничения

- Данные варианта могут быть числами, текстом и значениями `верно`. Структуры, списки и массивы в данных пока не поддерживаются.
- Имя варианта и имена данных не должны совпадать со служебными словами (`в`, `и`, `успех`, `ошибка`, `нет` и т. д.).
- У перечисления нет методов и обобщённых параметров.
