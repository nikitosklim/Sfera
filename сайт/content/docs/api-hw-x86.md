# Модули для x86: «железо_х86», «память_х86», «экран_х86», «задачи_х86», «диск_х86», «пользователь_х86»

Строительные блоки учебной операционной системы для компьютеров x86: порты, прерывания, память, экран, переключение задач, диск и запуск программ пользователя. Каждый модуль подключается своей строкой, например `подключить железо_х86;`.

> **Простыми словами.** Это «детали конструктора» для ядра: чтобы поговорить с клавиатурой, нужен порт; чтобы показать текст, нужен экран; чтобы запустить две программы по очереди, нужны задачи.

## Что за что отвечает

- **железо_х86** — команды процессора: порты ввода-вывода (`порт_вывод8`), доступ к памяти по адресу (`аппаратная_запись16`), остановка процессора.
- **память_х86** — физическая и виртуальная память: кадры по 4 КБ, учёт занятых и свободных.
- **экран_х86** — графический экран 800×600 и текстовая консоль поверх него (шрифт 8×16, 100 знаков в строке).
- **задачи_х86** — вытесняющая многозадачность: задачи переключаются по таймеру.
- **диск_х86** — чтение диска (ATA, режим PIO) и простая файловая система «СФС» только для чтения.
- **пользователь_х86** — запуск программ в пользовательском режиме (для них есть `сис_пользователя`).

## Самая маленькая программа

Выводит байты в последовательный порт COM1 и рисует зелёную букву «S» в углу экрана — без единого вызова стандартной библиотеки.

```
подключить железо_х86;

функция послать_байт(беззнак8 б)
    порт_вывод8(0x3F8, б);
конец

функция главная(): целое
    послать_байт(беззнак8(72));
    послать_байт(беззнак8(105));
    послать_байт(беззнак8(10));
    аппаратная_запись16(0xB8000, 0x0A53);
    остановиться_навсегда();
    вернуть 0;
конец
```

Адрес `0xB8000` — область памяти текстового экрана, а `0x0A53` — символ «S» (0x53) зелёного цвета (0x0A).

{{инфо: Эти программы запускаются в эмуляторе или собираются в образ диска скриптами из `examples/ос` и `examples/голое-железо`. В обычном режиме их запускать нельзя.}}


## Все функции и структуры

Полный список из исходников модуля. Пояснения взяты из комментариев к функциям.

### Модуль «железо_х86»

- `функция запретить_прерывания()`
- `функция разрешить_прерывания()`
- `функция ждать_прерывание()` — Усыпляет процессор до ближайшего прерывания.
- `функция остановиться_навсегда()` — Останавливает процессор навсегда: прерывания запрещены, процессор спит.
- `функция пустая_команда()`
- `функция задержка_порта()` — Короткая задержка после обращения к медленному устройству.

### Модуль «память_х86»

- `внешняя функция регистр_cr3(): целое` — инфо_загрузчика() объявлена в экран_х86 (подключите её раньше).
- `внешняя функция сбросить_страницу(целое адрес)`
- `функция память_состояние(целое поле): целое`
- `функция память_задать(целое поле, целое значение)`
- `функция вывести_шестн(целое число)`
- `функция паника(текст сообщение)` — Остановка ядра с сообщением. Сюда приходят при неисправимой ошибке.
- `функция кадр_занят(целое номер): целое`
- `функция кадр_пометить(целое номер, целое занят)`
- `функция память_подготовить()` — Подготавливает менеджер: узнаёт объём ОЗУ у загрузчика (Multiboot) и строит карту кадров.
- `функция выделить_кадр(): целое` — Выделяет один кадр. Возвращает его физический адрес или 0, если память кончилась.
- `функция освободить_кадр(целое адрес)`
- `функция кадр_обнулить(целое адрес)` — Обнуляет кадр.
- `функция таблица_ниже(целое таблица, целое номер): целое` — Следующая таблица по записи: если её нет, создаёт (кадр берётся из менеджера).
- `функция отобразить(целое виртуальный, целое физический, целое флаги)` — Отображает виртуальную страницу на кадр. Флаги: 1 — есть, 2 — запись (обычно 3).
- `функция снять_отображение(целое виртуальный): целое` — Убирает отображение страницы. Возвращает физический адрес кадра (0, если страница не была отображена).
- `функция sfera_pf(целое код_ошибки, целое адрес)` — Ошибка страницы (её вызывает стартовый код). В области 0x40000000…0x4FFFFFFF страница создаётся по требованию, любое другое обращение — паника.

### Модуль «экран_х86»

- `внешняя функция шрифт_адрес(): целое`
- `внешняя функция инфо_загрузчика(): целое`
- `функция экран_состояние(целое поле): целое`
- `функция экран_задать(целое поле, целое значение)`
- `функция мпк_читать(целое шина, целое устройство, целое смещение): целое` — Читает 32 бита из пространства настройки PCI.
- `функция видео_задать(целое номер, целое значение)`
- `функция экран_очистить(целое цвет)` — Закрашивает всю картинку цветом.
- `функция экран_настроить(): целое` — Включает экран и очищает его. Если загрузчик уже включил графику (поле экрана в сведениях Multiboot), берёт адрес и длину строки оттуда; иначе находит виртуальную видеокарту QEMU на шине PCI и включает режим 800×600 через порты Bochs VBE. Возвращает 1, если экран есть, иначе 0.
- `функция номер_знака(целое код): целое` — Номер знака в шрифте: 0–94 латиница и цифры, 95–158 «А…я», 159 «Ё», 160 «ё», 161 «, 162 », 163 —, 164 №.
- `функция экран_знак(целое номер, целое столбец, целое строка, целое цвет, целое фон)` — Рисует знак в клетке (столбец, строка).
- `функция экран_прокрутка()` — Сдвигает всё содержимое на одну текстовую строку вверх, нижнюю строку очищает.
- `функция экран_символ(целое код)` — Выводит один символ (код Юникода) в текущее место консоли.
- `функция экран_байт(целое байт)` — Принимает один байт текста в UTF-8 (русские буквы приходят двумя байтами).

### Модуль «задачи_х86»

- `функция задачи_подготовить()`
- `функция задача_создать(целое вход): целое` — Создаёт задачу, которая начнёт с функции по адресу «вход». Возвращает номер задачи или -1, если мест нет.
- `функция задачи_переключить(целое кадр): целое` — Вызывается из sfera_irq_timer: запоминает кадр текущей задачи и возвращает кадр следующей.
- `функция задача_завершить()` — Задача сообщает, что закончила. Эта функция не возвращается.
- `функция задача_состояние(целое номер): целое` — Состояние задачи: 0 — нет, 1 — работает, 2 — завершена.
- `функция задача_убрать(целое номер)` — Освобождает место и стек завершённой задачи.

### Модуль «диск_х86»

- `функция диск_ждать(): целое`
- `функция диск_читать_сектор(целое лба, целое адрес): целое` — Читает один сектор (номер сектора лба) по адресу в памяти. Возвращает 0 или -1 при ошибке.
- `функция фс_открыть(): целое` — Читает таблицу файлов. Возвращает число файлов или -1, если диска нет или это не СФС.
- `функция фс_имя(целое n): целое` — Имя файла номер n: байты по адресу, который возвращает функция (оканчиваются нулём).
- `функция фс_сектор(целое n): целое`
- `функция фс_размер(целое n): целое`
- `функция фс_найти(целое адрес, целое длина): целое` — Ищет файл, имя которого лежит в памяти по адресу «адрес» длиной «длина» байт. Возвращает номер или -1.

### Модуль «пользователь_х86»

- `внешняя функция войти_в_пользователя(целое вход, целое вершина_стека): целое`
- `внешняя функция образ_начало(): целое`
- `внешняя функция образ_размер(): целое`
- `функция sfera_сисвызов_ядро(целое номер, целое а, целое б, целое третий): целое` — Системные вызовы (зовёт стартовый код).
- `функция пользователь_подготовить()`
- `функция пользователь_выполнить(целое страниц, целое аргумент): целое` — Стек, запуск, уборка страниц. Возвращает код завершения (-1 — программа нарушила защиту памяти).
- `функция пользователь_запустить(целое аргумент): целое` — Запускает программу, вшитую в ядро.
- `функция пользователь_запустить_с_диска(целое сектор, целое размер, целое аргумент): целое` — Запускает программу с диска (требуется диск_х86): файл начинается с сектора «сектор», длина «размер» байт. Возвращает код завершения или -2, если диск не читается.
- `функция выделить_кадр_обнулённый(): целое`
