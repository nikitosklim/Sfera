# Модуль «json»

> **Простыми словами.** JSON — это текст, в котором записаны данные: `{"имя": "Ника", "очки": 120}`. Так обмениваются данными сайты, игры и приложения. Модуль «json» умеет достать из такого текста нужное значение и собрать новый JSON, чтобы вам не разбирать скобки и кавычки руками.

Подключается строкой `подключить json;`.

## Как читать: путь к значению

Читать удобно «по пути». Путь — это имена полей через точку. Если внутри массив, вместо имени пишут номер элемента, считая с нуля. Для `{"враги": [{"имя": "а"}, {"имя": "б"}]}` путь `враги.1.имя` значит «поле имя у второго врага».

Пустой путь (`""`) означает весь документ целиком.

## Функции чтения

| Функция | Что делает |
|---|---|
| `json_верен(текст)` | `да`, если весь текст — корректный JSON |
| `json_есть(текст, путь)` | есть ли значение по пути |
| `json_текст(текст, путь)` | строка по пути, уже без экранирования → `результат из текста` |
| `json_целое(текст, путь)` | целое число по пути → `результат из целого` |
| `json_логическое(текст, путь)` | `true`/`false` → `результат из целого` (1 или 0) |
| `json_размер(текст, путь)` | сколько элементов в массиве или полей в объекте → `результат из целого` |
| `json_значение(текст, путь)` | «сырой» JSON значения (строка останется в кавычках) → `результат из текста` |

Если пути нет или там значение другого вида, функции возвращают ошибку с понятным сообщением. Например `по пути 'игрок.имя' лежит не целое число`.

## Функции сборки

| Функция | Что делает |
|---|---|
| `json_в_кавычках(текст)` | строка в кавычках, с экранированием |
| `json_пара_текст(ключ, текст)` | пара `"ключ":"текст"` |
| `json_пара_целое(ключ, число)` | пара `"ключ":число` |
| `json_пара_логическое(ключ, значение)` | пара `"ключ":true` или `false` |
| `json_пара(ключ, готовый_json)` | пара с уже готовым значением (объект, массив) |
| `json_объект(пары)` | объект `{…}` из пар, перечисленных через запятую |
| `json_массив(элементы)` | массив `[…]` из значений через запятую |

## Пример

```сфера
подключить json;

функция главная()
    текст данные = "{\"игрок\": {\"имя\": \"Ника\", \"очки\": 120}, \"враги\": [{\"имя\": \"а\"}, {\"имя\": \"б\"}]}";

    результат из текста имя = json_текст(данные, "игрок.имя");
    результат из целого очки = json_целое(данные, "игрок.очки");
    результат из целого сколько = json_размер(данные, "враги");
    вывести("%(имя.значение)%: %(очки.значение)% очков, врагов: %(сколько.значение)%");

    текст пары = json_пара_текст("имя", "Ника") + "," + json_пара_целое("очки", 121);
    вывести(json_объект(пары));
конец
```

```
Ника: 120 очков, врагов: 2
{"имя":"Ника","очки":121}
```

## Что важно знать

- Путь — это точки, поэтому имя поля, в котором сама точка, по пути не достать.
- Дробные числа можно получить только как текст через `json_значение`: разбора дробного из текста в языке пока нет.
- Escape-последовательности `\n`, `\"` и `\uXXXX` разбираются, включая эмодзи. {{инфо: В Сфере внутри `%( … )%` нельзя писать строки в кавычках, поэтому пути и ключи для вывода кладут в переменные заранее.}}
- Модуль не строит дерево в памяти: каждый вызов проходит по тексту заново. Для небольших документов (ответы сервера, настройки, сохранения игр) этого достаточно. Если нужно прочитать много значений из огромного файла, это будет медленно.
