# Модуль «разметка»

Модуль превращает текст в формате Markdown в готовую HTML-страницу. Именно им собран этот сайт: страницы документации пишутся как обычный текст с `#`, `-` и ```` ``` ````, а модуль делает из них заголовки, списки, таблицы и подсвеченный код. Подключается строкой `подключить разметка`.

> **Простыми словами.** Вы даёте функции текст с «решётками» и «звёздочками», а получаете текст с тегами `<h1>`, `<ul>`, `<code>`, который можно сразу отдать браузеру.

## Главная функция

`разметка_в_ягр(источник)` принимает весь документ одним текстом и возвращает HTML. Память под результат выделена для вас — освобождать её вручную не нужно, пока вы не пишете свой менеджер памяти.

```
подключить разметка

функция главная(): целое
    текст источник = "# Привет\n\nЭто **важный** текст и `код`.\n\n- первый пункт\n- второй пункт\n"
    текст страница = разметка_в_ягр(источник)
    вывести(страница)
    вернуть 0
конец
```

**Что выведет программа:**

```
<h1 id="р1">Привет</h1>
<p>Это <strong>важный</strong> текст и <code>код</code>.</p>
<ul>
<li>первый пункт</li>
<li>второй пункт</li>
</ul>
```

Что здесь важно:

- Заголовки (`#`, `##`, …), списки, таблицы, цитаты и блоки кода понимаются так же, как на сайте.
- Блок кода с языком `код` получает подсветку ключевых слов Сферы, остальные блоки выводятся как есть.
- Опасные символы `<`, `>`, `&` внутри текста экранируются, поэтому чужой Markdown не сломает вашу страницу.

## Для чего это пригодится

- Блог или база знаний на Сфере: статьи лежат файлами `.md`, сервер превращает их в страницы по запросу.
- Документация проекта: один скрипт собирает все `.md` в готовый сайт.
- Описания и комментарии пользователей, если вы хотите разрешить простое форматирование.

{{инфо: Вспомогательные функции модуля (`писать_текст`, `найти_байт` и другие) нужны самой реализации. Для обычной работы достаточно `разметка_в_ягр`.}}


## Все функции и структуры

Полный список из исходников модуля. Пояснения взяты из комментариев к функциям.

### Модуль «разметка»

- `функция писать_байт(текст буфер, целое выход, целое б): целое`
- `функция писать_текст(текст буфер, целое выход, текст т): целое`
- `функция писать_экранированно(текст буфер, целое выход, текст источник, целое начало, целое до): целое`
- `функция найти_байт(текст т, целое от, целое до, целое б): целое`
- `функция найти_два_байта(текст т, целое от, целое до, целое б1, целое б2): целое`
- `функция конец_строки_с(текст т, целое от, целое n): целое`
- `функция без_возврата_каретки(текст т, целое от, целое до): целое` — строка [от, до) без завершающего \r
- `функция начинается_с_в(текст т, целое от, целое до, текст префикс): верно`
- `функция пустая_строка(текст т, целое от, целое до): верно`
- `функция писать_строчное(текст буфер, целое выход, текст т, целое от, целое до): целое`
- `функция слово_в_списке(текст список, текст т, целое от, целое до): верно` — Слово [от, до) есть в списке слов, разделённых пробелами.
- `функция байт_слова(целое б): верно` — байт буквы слова: латиница, цифры, «_» и любой байт многобайтного символа (кириллица)
- `функция открыть_участок(текст буфер, целое выход, текст класс): целое`
- `функция писать_подсвеченный(текст буфер, целое выход, текст т, целое от, целое до): целое` — Подсвеченный код [от, до): комментарии (к-ком), строки (к-стр), числа (к-чис), ключевые слова (к-сл), типы (к-тип).
- `функция писать_код(текст буфер, целое выход, текст т, целое от, целое до, целое яз_от, целое яз_до): целое` — Блок кода [от, до) с языком [яз_от, яз_до). Подсвечиваются блоки без языка и с языками «сфера»/«код»; остальные выводятся как есть.
- `функция закрыть_блок(текст буфер, целое выход, целое состояние): целое`
- `функция уровень_заголовка(текст т, целое от, целое до): целое` — сколько «#» в начале строки (1…4), иначе 0; после них обязателен пробел
- `функция длина_номера(текст т, целое от, целое до): целое` — Номер длины «1. » (цифры, точка, пробел) или 0
- `функция строка_таблицы(текст буфер, целое выход, текст т, целое от, целое до, текст ячейка): целое`
- `функция разделитель_таблицы(текст т, целое от, целое до): верно`
- `функция разметка_в_ягр(текст источник): текст`
- `функция оглавление_ягр(текст источник): текст`
- `функция заголовок_документа(текст источник): текст`
