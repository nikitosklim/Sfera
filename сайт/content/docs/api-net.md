# Модуль «сеть»

Низкоуровневые сокеты: подключиться к другому компьютеру по TCP, отправить и получить байты, а также принимать подключения самому. Подключается строкой `подключить сеть;`. Модуль «веб» построен поверх него.

> **Простыми словами.** Сокет — это «телефонная трубка». Вы создаёте её, звоните по адресу (IP и порт), говорите и слушаете, потом кладёте трубку.

## Клиент: позвонить и поговорить

Порядок действий всегда один:

1. `создать_сокет` — берём трубку.
2. `построить_адрес_сервера(ip, порт)` — набираем номер (собирает нужную структуру адреса).
3. `подключиться` — звоним.
4. `отправить_данные` и `получить_данные` — разговор.
5. `закрыть_сокет` — кладём трубку.

```
подключить сеть;

функция главная(): целое
    целое32 с = создать_сокет(целое32(2), целое32(1), целое32(0));
    текст адрес = построить_адрес_сервера("127.0.0.1", целое32(8080));
    если (подключиться(с, адрес, целое32(16)) != целое32(0))
        вывести("не удалось подключиться");
        вернуть 1;
    конец
    текст запрос = "GET / HTTP/1.0\r\n\r\n";
    отправить_данные(с, запрос, длина(запрос), целое32(0));
    текст буфер = выделить_память(1024);
    целое n = получить_данные(с, буфер, 1023, целое32(0));
    вывести("получено байт: " + целое_в_текст(n));
    закрыть_сокет(с);
    вернуть 0;
конец
```

Числа `2, 1, 0` — это «IPv4, TCP, протокол по умолчанию». Размер адреса всегда 16 байт.

## Сервер: ждать звонков

`привязать_сокет` закрепляет сокет за портом, `слушать_сокет` включает очередь, `принять_подключение` возвращает новый сокет для каждого позвонившего. Перед привязкой полезно вызвать `настроить_сокет`, чтобы порт можно было переиспользовать сразу после перезапуска.

{{инфо: Сетевые функции недоступны в браузерной площадке: в ней нет сети. Запускайте такие примеры у себя через `сфера запустить`.}}


## Все функции и структуры

Полный список из исходников модуля. Пояснения взяты из комментариев к функциям.

### Модуль «сеть»

- `внешняя функция создать_сокет(целое32 домен, целое32 тип, целое32 протокол): целое32` — Второе имя в "как "x", "y"" — символ для Windows (см. рантайм_windows/pthread_win.c): на Windows сокеты — Winsock, функции-обёртки подключаются автоматически. AF_INET = 2, SOCK_STREAM = 1 — используются как обычные числа при вызове, системе всё равно, как мы их называем у себя.
- `внешняя функция подключиться(целое32 сокет, текст адрес, целое32 размер_адреса): целое32`
- `внешняя функция отправить_данные(целое32 сокет, текст буфер, целое размер, целое32 флаги): целое`
- `внешняя функция получить_данные(целое32 сокет, текст буфер, целое размер, целое32 флаги): целое`
- `внешняя функция закрыть_сокет(целое32 сокет): целое32`
- `внешняя функция привязать_сокет(целое32 сокет, текст адрес, целое32 размер_адреса): целое32` — НОВОЕ: серверная сторона — то, чего не хватало для приёма входящих подключений (раньше библиотека умела только "подключиться К кому-то", не "принимать подключения ОТ кого-то"). Нужна для HTTP-сервера и вообще любого сервера на "Сфере".
- `внешняя функция слушать_сокет(целое32 сокет, целое32 очередь): целое32`
- `внешняя функция принять_подключение(целое32 сокет, текст адрес_клиента, текст размер_адреса_клиента): целое32`
- `внешняя функция настроить_сокет(целое32 сокет, целое32 уровень, целое32 опция, текст значение, целое32 размер_значения): целое32` — SOL_SOCKET = 1, SO_REUSEADDR = 2 (на Linux) — без этого повторный запуск сервера на том же порту после недавней остановки падает с "Address already in use" (система какое-то время держит порт занятым "на всякий случай") — SO_REUSEADDR явно разрешает занять его снова сразу.
- `внешняя функция получить_нулевой_указатель_сети(текст имя): текст` — НОВОЕ: нужен там, где системный вызов допускает необязательный указатель — например, "accept" не обязан сообщать адрес подключившегося клиента, если он не интересует вызывающую сторону (передаётся как NULL).
- `функция нулевой_указатель_сети(): текст`
- `внешняя функция сетевой_порядок_16(целое32 значение): целое32` — Преобразование в сетевой порядок байт — нужно системе, чтобы верно понять номер порта независимо от архитектуры процессора.
- `внешняя функция текст_в_ip(текст адрес): целое32` — Разбор текстового IP-адреса ("127.0.0.1") в числовой вид, ожидаемый системой — без этого пришлось бы делать DNS-резолвинг вручную (отдельная, более сложная задача, не нужная для подключения по готовому IP).
- `функция построить_адрес_сервера(текст ip, целое32 порт): текст` — Строит структуру "sockaddr_in" (16 байт, стандартный, фиксированный формат POSIX для адреса подключения) вручную, по байтам — тем же самым приёмом, что уже использовался для SDL_Event в графика.код: нет настоящего маршалинга структур через FFI, поэтому собираем байты сами.
