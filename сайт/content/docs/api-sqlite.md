# Модуль «база_данных»

Работа с SQLite — маленькой базой данных, которая живёт в одном файле. Подключается строкой `подключить база_данных;`. Программу с этим модулем нужно собирать с библиотекой sqlite3: флаг `--линковать sqlite3`.

> **Простыми словами.** База — это таблица в файле. Вы пишете запросы на языке SQL («создай таблицу», «добавь строку», «выбери людей старше двадцати»), а Сфера передаёт их SQLite.

## Открыть базу и выполнить запрос

`открыть_базу(путь)` возвращает `результат из текста`: в `.значение` лежит «ручка» открытой базы. Имя `:memory:` создаёт временную базу в памяти — удобно для проб. `выполнить_ясз(база, запрос)` выполняет запрос без результата: создание таблицы, вставка, удаление.

## Выбрать данные

Запрос с результатом проходит четыре шага: подготовить, привязать значения вместо `?`, шагать по строкам, завершить.

```
подключить база_данных;

функция главная(): целое
    результат из текста б = открыть_базу(":memory:");
    если (не б.успешно)
        вывести("не открылась: " + б.сообщение);
        вернуть 1;
    конец
    текст бд = б.значение;
    выполнить_ясз(бд, "CREATE TABLE люди (имя TEXT, возраст INTEGER)");
    выполнить_ясз(бд, "INSERT INTO люди VALUES ('Аня', 25)");
    выполнить_ясз(бд, "INSERT INTO люди VALUES ('Боря', 31)");

    текст буфер = выделить_память(8);
    sqlite_подготовить(бд, "SELECT имя, возраст FROM люди WHERE возраст > ? ORDER BY возраст", целое32(-1), буфер, нулевой_указатель_бд());
    текст запрос = прочитать_указатель(буфер, 0);
    sqlite_привязать_целое(запрос, целое32(1), целое32(20));
    пока (sqlite_шаг(запрос) == целое32(100))
        вывести(sqlite_колонка_текст(запрос, целое32(0)) + ": " + целое_в_текст(целое(sqlite_колонка_целое(запрос, целое32(1)))));
    конец
    sqlite_завершить(запрос);
    sqlite_закрыть(бд);
    вернуть 0;
конец
```

**Что выведет программа:**

```
Аня: 25
Боря: 31
```

Разберём:

- `sqlite_подготовить` разбирает запрос; `?` — место для значения. Так делать безопаснее, чем клеить значения в текст запроса: это защищает от подстановки чужого SQL.
- `sqlite_привязать_целое(запрос, номер, значение)` — номера считаются с 1. Для текста есть `sqlite_привязать_текст`.
- `sqlite_шаг` возвращает 100, пока есть очередная строка, и 101, когда строки кончились.
- `sqlite_колонка_текст` и `sqlite_колонка_целое` читают столбец текущей строки, номера столбцов с 0.
- `sqlite_завершить` обязателен — он освобождает запрос.
- `sqlite_закрыть` закрывает базу.

{{инфо: Базу в файле открывайте так же, указав путь вместо `:memory:`, например `открыть_базу("люди.db")`. Файл создастся сам.}}


## Все функции и структуры

Полный список из исходников модуля. Пояснения взяты из комментариев к функциям.

### Модуль «база_данных»

- `внешняя функция sqlite_открыть(текст имя_файла, текст буфер_для_указателя): целое32` — Открывает (или создаёт, если не существует) файл базы данных — "имя_файла" может быть и специальной строкой ":memory:" для временной, живущей только в памяти базы (полезно для тестов). Возвращает 0 при успехе (SQLITE_OK).
- `внешняя функция sqlite_закрыть(текст бд): целое32`
- `внешняя функция sqlite_выполнить(текст бд, текст sql, текст callback, текст callback_аргумент, текст буфер_ошибки): целое32` — Простое выполнение SQL без ожидания результатов (CREATE TABLE, INSERT, UPDATE, DELETE) — три средних параметра (callback, его аргумент, буфер для текста ошибки) передаются как "нулевой_указатель()", когда не нужны.
- `внешняя функция sqlite_текст_ошибки(текст бд): текст`
- `внешняя функция sqlite_подготовить(текст бд, текст sql, целое32 длина_sql, текст буфер_для_stmt, текст хвост): целое32` — Подготовленные выражения — нужны для SELECT (когда важен РЕЗУЛЬТАТ запроса, не только факт его выполнения) и для параметризованных запросов с "?" (безопасный способ вставить значение в SQL, без риска SQL-инъекции через простую склейку строк).
- `внешняя функция sqlite_шаг(текст выражение): целое32` — Делает один шаг выполнения — возвращает 100 (SQLITE_ROW), если готова очередная строка результата, 101 (SQLITE_DONE), когда строк больше нет.
- `внешняя функция sqlite_завершить(текст выражение): целое32`
- `внешняя функция sqlite_колонка_текст(текст выражение, целое32 колонка): текст` — Чтение значений из текущей строки результата — "колонка" нумеруется с 0.
- `внешняя функция sqlite_колонка_целое(текст выражение, целое32 колонка): целое32`
- `внешняя функция sqlite_привязать_текст(текст выражение, целое32 индекс, текст значение, целое32 длина, целое деструктор): целое32` — Привязка параметров к "?"-плейсхолдерам подготовленного выражения — "индекс" нумеруется с 1 (не с 0, таково соглашение самой SQLite).
- `внешняя функция sqlite_привязать_целое(текст выражение, целое32 индекс, целое32 значение): целое32`
- `внешняя функция получить_нулевой_указатель_бд(текст имя): текст` — Приём для получения null-указателя там, где C-функция допускает необязательный аргумент (например, callback у sqlite_выполнить, если результат не нужен) — тот же приём, что уже используется в графика.код и сеть.код: getenv() с заведомо несуществующим именем переменной окружения гарантированно возвращает NULL.
- `функция нулевой_указатель_бд(): текст`
- `функция открыть_базу(текст имя_файла): результат из текста` — Удобная обёртка: открывает базу и сразу возвращает готовый указатель на неё (а не просто код ошибки, как это делает сырая sqlite_открыть) — прячет "буфер + прочитать_указатель" ритуал, который иначе пришлось бы повторять в каждой программе, использующей эту библиотеку.
- `функция выполнить_ясз(текст бд, текст sql): результат из целого` — Удобная обёртка над sqlite_выполнить — для запросов без результата (CREATE TABLE, INSERT, UPDATE, DELETE), с понятным текстом ошибки на русском вместо голого числового кода.
