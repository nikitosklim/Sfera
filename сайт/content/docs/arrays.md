# Массивы

> **Простыми словами.** Массив — это ряд одинаковых коробок под одной вывеской. Размер массива задаётся сразу и потом не меняется. Если нужен набор, который растёт, берите `Список`.


Фиксированного размера, размер — часть типа. **Требуют явной
инициализации** литералом при объявлении:

```
целое(5) числа = массив(10, 20, 30, 40, 50);
числа(0) = 99;              // обращение и запись по индексу
вывести(целое_в_текст(числа(0)));
```

- `целое(5) числа = массив(10, 20, 30, 40, 50);` — пять целых чисел с именем `числа`. Число в скобках после типа это размер. {{инфо: Размер входит в тип: `целое(5)` и `целое(6)` разные типы. Поэтому в массив нельзя добавить новый элемент. Если нужно «растущее», берите Список.}}
- `числа(0) = 99;` — номер элемента пишут в круглых скобках. Первый элемент имеет номер 0, поэтому здесь меняем 10 на 99.
- `числа(0)` — прочитать элемент с номером 0.

## Массив массивов — `тип(N)(M)`

Вложенные фиксированные массивы — та же семантика, что и в C:
`тип(N)(M)` — это N элементов типа `тип(M)` (первый индекс выбирает
"строку"). Глубина вложенности не ограничена (`тип(N)(M)(K)` тоже
работает; старая запись — `тип[N][M]`):

```
целое(2)(3) м = массив(массив(1, 2, 3), массив(4, 5, 6));
вывести(целое_в_текст(м(0)(2)));   // 3
м(1)(0) = 99;
вывести(целое_в_текст(м(1)(0)));   // 99
```

Массив массивов — это таблица: `целое(2)(3)` значит «2 строки по 3 числа». `м(0)(2)` — строка 0, столбец 2, то есть число 3. Первый номер выбирает строку, второй — столбец в ней.

⚠️ Честное ограничение: элементы вложенного массива ограничены
скалярными типами — массив массивов **структур** (`Точка(2)(2)`) не
поддержан в этой версии.
