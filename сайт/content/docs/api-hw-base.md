# Модули «голое_железо» и «дробные_программно»

Основа для программ без операционной системы: драйверы, ядра, прошивки микроконтроллеров. Программа собирается с флагом `--без-ос`, а вместо стандартной библиотеки C компилятор обращается к функциям этих модулей. Подключаются строками `подключить голое_железо;` и `подключить дробные_программно;`.

> **Простыми словами.** Когда под вами нет операционной системы, некому выдать память, вывести текст или посчитать дробь. Эти модули — маленькая «операционная система внутри программы».

## «голое_железо»: память, строки, числа

- **Память:** распределитель `malloc` / `free` с настоящим освобождением, а также `memcpy`, `memmove`, `memset`, `memcmp`.
- **Строки:** `strlen`, `strcmp`, `strstr`, `strtol`, `strdup`.
- **Вывод:** целые и дробные числа превращаются в текст и уходят на устройство вывода.

Плата должна подсказать модулю две вещи: как вывести один символ (`sfera_вывод_символа`) и где лежит память под кучу (`sfera_куча_начало`, `sfera_куча_размер`). Обычно это делает модуль платы — см. страницу «Модули плат».

## «дробные_программно»: дроби без процессора

Не у каждого процессора есть блок для дробных чисел (так на многих микроконтроллерах). Этот модуль делает сложение, умножение и деление дробей обычными целочисленными операциями. Включайте его вместе с `голое_железо`, и `дробное` будет работать и там, где «железной» поддержки нет.

```
подключить голое_железо;
подключить дробные_программно;
подключить плата_rp2040;

функция главная(): целое
    sfera_плата_старт();
    вывести("Привет, Pico! Мы пишем на Сфере.");
    вернуть 0;
конец
```

{{инфо: Примеры для разных плат лежат в `examples/голое-железо`. Честная оговорка из репозитория: на реальных платах (Pico) примеры пока не проверялись, проверены в эмуляторе.}}


## Все функции и структуры

Полный список из исходников модуля. Пояснения взяты из комментариев к функциям.

### Модуль «голое_железо»

- `внешняя функция куча_начало(): целое`
- `внешняя функция куча_размер(): целое`
- `функция читать64(целое адрес): целое`
- `функция писать64(целое адрес, целое значение)`
- `функция копировать_байты(целое назначение, целое источник, целое размер)`
- `функция подготовить_кучу(целое база, целое объём)`
- `функция malloc(целое размер): текст`
- `функция free(текст указатель)`
- `функция memcpy(текст назначение, текст источник, целое размер): текст`
- `функция memmove(текст назначение, текст источник, целое размер): текст`
- `функция memset(текст назначение, целое32 значение, целое размер): текст`
- `функция memcmp(текст а, текст б, целое размер): целое32`
- `функция strlen(текст строка): целое`
- `функция strcmp(текст а, текст б): целое32`
- `функция strstr(текст строка, текст искомое): текст` — Первое вхождение «искомое» в «строка»: указатель на него или пустой указатель.
- `функция strtol(текст строка, текст конец_разбора, целое32 основание): целое` — Разбор целого числа (основание 10). Конец разбора записывается в «конец», если он не пустой.
- `функция strdup(текст строка): текст`
- `функция выдать_байт(целое режим, целое буфер, целое смещение, целое32 символ): целое`
- `функция выдать_цифры(целое режим, целое буфер, целое смещение, беззнак64 число, целое минимум): целое` — Беззнаковое число десятичными цифрами; «минимум» — сколько цифр писать как минимум (с нулями слева).
- `функция выдать_целое(целое режим, целое буфер, целое смещение, целое значение): целое`
- `функция выдать_слово(целое режим, целое буфер, целое смещение, целое32 а, целое32 б, целое32 в2): целое`
- `функция выдать_дробное(целое режим, целое буфер, целое смещение, дробное число): целое` — Дробное число как «%f»: знак, целая часть, точка, 6 знаков (с округлением).
- `функция sfera_целое_в_буфер(текст буфер, целое размер, целое значение)`
- `функция sfera_дробное_в_буфер(текст буфер, целое размер, дробное значение)`
- `функция sfera_вывод_текста(текст строка)`
- `функция sfera_вывод_целого(целое значение)`
- `функция sfera_вывод_дробного(дробное значение)`
- `функция вывести_текст(текст т)` — Выводит текст без перевода строки.
