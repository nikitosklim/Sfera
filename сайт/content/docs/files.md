# Файлы: удаление и папки (стандартная_библиотека/файлы.код)


`подключить файлы;` — `удалить_файл(путь)`, `создать_папку(путь)` (результат из верного) и `файл_существует(путь)`.
Пути — в UTF-8, на Windows кириллица в путях работает (вызовы `fopen`/`rename` и функции из `файлы.код`
идут через обёртки `рантайм_windows/pthread_win.c`, которые переводят путь в UTF-16). После обновления
компилятора пересоберите `pthread_win.o`:
`clang -c рантайм_windows\pthread_win.c -o "%LOCALAPPDATA%\Сфера\lib\sfera\pthread_win.o"`.
Аргументы командной строки на Windows приходят в кодировке консоли (ANSI), а не в UTF-8 — кириллицу в `аргументы_командной_строки()` пока не используйте.
Пример: `examples/файлы_удаление.код`.
