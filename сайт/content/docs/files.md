# Файлы: удаление и папки (стандартная_библиотека/файлы.код)

> **Простыми словами.** Файлы — это место, где программа хранит данные между запусками. Чтение и запись файлов (`записать_файл`, `прочитать_файл`) встроены в язык. Эта страница про дополнительные действия: создать папку, удалить файл, проверить, что файл существует.


`подключить файлы` — `удалить_файл(путь)`, `создать_папку(путь)` (результат из верного) и `файл_существует(путь)`.
Пути — в UTF-8, на Windows кириллица в путях работает (вызовы `fopen`/`rename` и функции из `файлы.код`
идут через обёртки `рантайм_windows/pthread_win.c`, которые переводят путь в UTF-16). После обновления
компилятора пересоберите `pthread_win.o`:
`clang -c рантайм_windows\pthread_win.c -o "%LOCALAPPDATA%\Сфера\lib\sfera\pthread_win.o"`.
Аргументы командной строки на Windows приходят в кодировке консоли (ANSI), а не в UTF-8 — кириллицу в `аргументы_командной_строки()` пока не используйте.
Пример: `examples/файлы_удаление.код`.

Короткий пример с объяснением:

```
подключить файлы

функция главная(): целое
    создать_папку("моя_папка")
    записать_файл("моя_папка/привет.txt", "Привет")
    если (файл_существует("моя_папка/привет.txt"))
        вывести("Файл создан")
    конец
    удалить_файл("моя_папка/привет.txt")
    удалить_файл("моя_папка")
    вернуть 0
конец
```

- `подключить файлы` — берём модуль с этими командами (встроенные `записать_файл` подключать не нужно).
- `создать_папку("моя_папка")` — делает папку рядом с программой.
- `записать_файл("моя_папка/привет.txt", "Привет")` — создаёт файл внутри папки: путь пишется через косую черту. {{инфо: Если файл уже есть, его содержимое будет заменено. Чтобы дописывать, а не заменять, нужны другие функции, например `дописать_в_файл_бинарно`.}}
- `файл_существует(...)` — отвечает `да` или `нет`, и условие `если` решает, что делать.
- `удалить_файл(...)` — стирает файл, а второй вызов стирает уже пустую папку. {{инфо: Функция умеет удалять и файлы, и пустые папки. Папка с чем-то внутри не удалится: сначала удалите содержимое. Результат тоже можно проверить через `.успешно`.}}

Полная подробная страница про функции модуля есть в [справочнике API](/документация/справочник-файлы).

## Попробуй сам

Откройте [«Попробовать»](/попробовать) и запустите только встроенную часть (в песочнице нет доступа к файлам, но вывод покажет, как выглядит вызов):

```
функция главная(): целое
    целое размер = длина("Привет, файл")
    вывести("В файл ушло бы байт: " + целое_в_текст(размер))
    вернуть 0
конец
```

Реальную запись в файл попробуйте на своём компьютере: сохраните пример выше в `файлы.код` и запустите `запустить файлы.код`.
