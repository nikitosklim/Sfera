# Модуль «графика»

Окна, рисование и простые элементы интерфейса на компьютере: прямоугольники, текст, картинки, кнопки, панели и поля ввода. Под капотом работает библиотека SDL2, поэтому программу собирают с флагами `--линковать SDL2 --линковать SDL2_ttf --линковать SDL2_image --линковать m`. Подключается строкой `подключить графика;`.

> **Простыми словами.** Вы открываете окно, в цикле рисуете на нём «кадр» (фон, фигуры, надписи) и показываете его. Нажатия мыши и клавиш приходят событиями.

## Что есть в модуле

- **Окно и кадр:** `инициализировать`, `создать_окно`, `закрыть_окно`, `завершить`, `размер_окна` (возвращает структуру `РазмерЭкрана`).
- **Фигуры:** `нарисовать_прямоугольник`, `обвести_прямоугольник`, `нарисовать_скруглённый_прямоугольник`.
- **Текст и картинки:** `нарисовать_текст`, `загрузить_картинку`, `нарисовать_картинку`, `нарисовать_картинку_текстурой`.
- **Готовые элементы:** структуры `Кнопка`, `Панель`, `ПолеВвода`, `Таблица` — со своими методами рисования и обработки нажатий.

{{инфо: Графика работает только на компьютере. В браузерной площадке и на голом железе её нет. Для телефона используйте модуль `приложение_android`, он устроен проще.}}

## Как выглядит программа

Каркас всегда один: открыть окно, цикл «обработать события — нарисовать — показать», закрыть окно. Готовые рабочие примеры лежат в папке `examples` репозитория, а полный список функций с сигнатурами приведён ниже.

```
подключить графика;

функция главная(): целое
    инициализировать(беззнак32(32));
    текст окно = создать_окно("Привет", целое32(100), целое32(100), целое32(640), целое32(480), беззнак32(4));
    // дальше: создать холст, нарисовать_прямоугольник(...), нарисовать_текст(...)
    // и цикл обработки событий до закрытия окна
    закрыть_окно(окно);
    завершить();
    вернуть 0;
конец
```

Собрать и запустить:

```
сфера запустить окно.код --линковать SDL2 --линковать SDL2_ttf --линковать SDL2_image --линковать m
```


## Все функции и структуры

Полный список из исходников модуля. Пояснения взяты из комментариев к функциям.

### Модуль «графика»

- `внешняя функция инициализировать(беззнак32 флаги): целое32`
- `внешняя функция завершить()`
- `внешняя функция создать_окно(текст заголовок, целое32 х, целое32 у, целое32 ширина, целое32 высота, беззнак32 флаги): текст`
- `внешняя функция закрыть_окно(текст окно)`
- `внешняя функция узнать_размер_окна_сырое(текст окно, текст буфер_ширины, текст буфер_высоты)` — НОВОЕ (якоря — адаптивное расположение UI под реальный размер экрана): на Android/iOS размер, переданный в создать_окно, лишь ориентировочный — реальная ОС всегда даёт приложению полноэкранное окно (см.
- `внешняя функция создать_холст(текст окно, целое32 индекс, беззнак32 флаги): текст`
- `внешняя функция задать_цвет(текст холст, беззнак8 к, беззнак8 з, беззнак8 с, беззнак8 а): целое32`
- `внешняя функция задать_режим_смешивания(текст холст, целое32 режим): целое32` — НОВОЕ: без этого альфа-канал (прозрачность) у задать_цвет тихо игнорируется при рисовании — SDL по умолчанию рисует "поверх" без учёта прозрачности (SDL_BLENDMODE_NONE). Нужна для полупрозрачного затемнения фона под всплывающими окнами. 1 = SDL_BLENDMODE_BLEND.
- `внешняя функция очистить_холст(текст холст): целое32`
- `внешняя функция показать_холст(текст холст)`
- `внешняя функция закрасить_область(текст холст, текст прямоугольник): целое32`
- `внешняя функция обвести_область(текст холст, текст прямоугольник): целое32`
- `внешняя функция нарисовать_линию(текст холст, целое32 x1, целое32 y1, целое32 x2, целое32 y2): целое32` — НОВОЕ: базовый кирпичик для табличной сетки — без него нельзя нарисовать ни одной разделительной линии между ячейками.
- `внешняя функция подождать(беззнак32 миллисекунды)`
- `внешняя функция узнать_ошибку(): текст`
- `внешняя функция android_лог(целое32 приоритет, текст тег, текст сообщение): целое32` — НОВОЕ: обычный "вывести" (printf/stdout) не попадает в системный лог Android сам по себе — нужен отдельный системный вызов логирования.
- `внешняя функция прочитать_пиксели(текст холст, текст область, беззнак32 формат, текст буфер_пикселей, целое32 шаг): целое32` — Чтение пикселей обратно с холста — полезно для отладки и автоматического тестирования графики (можно проверить, что нужный цвет реально оказался в нужном месте, а не просто "программа не упала").
- `внешняя функция квадратный_корень(дробное х): дробное` — НОВОЕ: рисование прямоугольников (кнопки, панели — фундамент любого визуального интерфейса).
- `функция нарисовать_прямоугольник(текст холст, целое32 х, целое32 у, целое32 ширина, целое32 высота): целое32` — Обычная функция САМОГО ЯЗЫКА (не "внешняя") — показывает, как строить удобный, кириллический API поверх низкоуровневых примитивов.
- `функция обвести_прямоугольник(текст холст, целое32 х, целое32 у, целое32 ширина, целое32 высота): целое32`
- `функция нарисовать_скруглённый_прямоугольник(текст холст, целое32 x, целое32 y, целое32 ширина, целое32 высота, целое32 радиус): целое32` — НОВОЕ: скруглённый прямоугольник — современный вид кнопок вместо обычных резких углов.
- `внешняя функция опросить_событие(текст буфер_события): целое32` — Обработка событий (клики мыши, закрытие окна). "опросить_событие" заполняет переданный буфер данными о событии — буфер нужно выделить заранее (через "выделить_память") и передать сюда, затем прочитать нужные поля через прочитать_целое32(буфер, смещение) — точные смещения полей проверены напрямую через C (offsetof), см.…
- `внешняя функция начать_ввод_текста()` — НОВОЕ: ввод текста с клавиатуры. SDL сама разбирает раскладку клавиатуры и отдаёт ГОТОВЫЙ UTF-8 текст (не отдельные "коды клавиш", требующие самостоятельного перевода) — идеально ложится на язык, где текст везде UTF-8 и работа с кириллицей — не второстепенный случай.
- `внешняя функция закончить_ввод_текста()`
- `внешняя функция инициализировать_шрифты(): целое32` — НОВОЕ: работа со шрифтами (SDL_ttf) — последний крупный кирпичик визуального интерфейса. Позволяет РЕАЛЬНО ПОКАЗАТЬ ТЕКСТ на экране (не только реагировать на его ввод) — обязательно для подписей кнопок, текста в редакторе кода будущей среды разработки.
- `внешняя функция открыть_шрифт(текст путь_к_файлу, целое32 размер): текст`
- `внешняя функция отрисовать_текст(текст шрифт, текст строка, беззнак32 цвет): текст` — ⚠️ НАЙДЕНО ПРИ РЕАЛЬНОМ ИСПОЛЬЗОВАНИИ: "_Solid" даёт грубый, "зубчатый" текст без сглаживания (несглаженная растеризация — каждый пиксель либо полностью цвета текста, либо полностью фона).
- `внешняя функция создать_текстуру(текст холст, текст поверхность): текст`
- `внешняя функция узнать_размер_текстуры(текст текстура, текст формат, текст доступ, текст ширина, текст высота): целое32`
- `внешняя функция показать_текстуру(текст холст, текст текстура, текст область_источника, текст область_назначения): целое32`
- `внешняя функция освободить_поверхность(текст поверхность)`
- `внешняя функция уничтожить_текстуру(текст текстура)`
- `внешняя функция открыть_файл_rw(текст путь_к_файлу, текст режим): текст` — НОВОЕ: загрузка картинок — только формат .bmp, встроенный в сам SDL2 напрямую, без дополнительных библиотек.
- `внешняя функция прочитать_bmp(текст источник, целое32 закрыть_после): текст`
- `функция загрузить_картинку(текст путь_к_файлу): текст`
- `внешняя функция получить_нулевой_указатель(текст имя): текст` — Приём для получения null-указателя (нужен там, где SDL допускает необязательный указатель — например, "область_источника" в показать_текстуру означает "вся текстура целиком"). getenv() с заведомо несуществующим именем переменной окружения гарантированно возвращает NULL.
- `функция нулевой_указатель(): текст`
- `функция нарисовать_текст(текст холст, текст шрифт, текст строка, целое32 х, целое32 у, беззнак32 цвет): целое32` — Рисует текст на холсте в позиции (х, у) заданным шрифтом и цветом. Собирает воедино весь путь: рендер в поверхность -> текстура -> копия на холст с нужным размером (запрошенным у самой текстуры).
- `функция нарисовать_картинку(текст холст, текст путь_к_файлу, целое32 х, целое32 у, целое32 ширина, целое32 высота): целое32` — НОВОЕ: картинка с ЗАДАННЫМ размером на экране (масштабирование под нужную область — например, под размер кнопки или иконки навбара, независимо от исходного размера файла). Загружает заново при каждом вызове — для статичного UI (иконки навбара, редко меняющиеся картинки) это приемлемо;
- `функция нарисовать_картинку_текстурой(текст холст, текст текстура, целое32 х, целое32 у, целое32 ширина, целое32 высота): целое32` — НОВОЕ: более быстрый путь для картинки, рисуемой много раз подряд (анимация, повторяющийся кадр) — принимает уже готовую текстуру (загруженную один раз через загрузить_картинку+создать_текстуру, до начала цикла отрисовки), не грузит файл заново на каждый вызов.
- `структура Таблица` — НОВОЕ: строгий, табличный стиль UI (по образцу Excel/1C) — вместо ярких скруглённых кнопок. Произвольное число колонок (ширины — Список<целое>), каждая строка получает тонкую серую границу, разделители между колонками и чередующийся (полосатый) фон для читаемости — тот же приём, что в любой настоящей таблице данных.
- `структура РазмерЭкрана` — НОВОЕ: первый настоящий виджет UI — кнопка. Никаких новых привязок к SDL2 не понадобилось: кнопка — это просто прямоугольник (уже умеем рисовать) плюс логика "попадает ли точка в его границы" (обычная арифметика самого языка Сфера).
- `функция размер_окна(текст окно): РазмерЭкрана`
- `структура Кнопка`
- `структура Панель` — НОВОЕ: панель — фон на всю ширину (верхний или нижний навбар, боковое меню, любая полоса интерфейса) плюс произвольный набор кнопок внутри.
- `функция удалить_последний_символ(текст строка): текст` — НОВОЕ: UTF-8-осознанное удаление последнего СИМВОЛА (не байта) из текста — нужно для клавиши Backspace в текстовом поле ввода. Язык "Сфера" полностью кириллический, а кириллица занимает 2 байта на символ в UTF-8 — простое "удалить последний байт" оставляло бы битую, нечитаемую половину буквы.
- `структура ПолеВвода` — НОВОЕ: текстовое поле ввода — фон со скруглёнными углами (тот же внешний вид, что и у Кнопка), поверх которого рисуется введённый текст и мигающий текстовый курсор.
