# Модуль «хранилище»

Хранилище — это маленькая «записная книжка» в файле: вы кладёте значение под именем (ключом) и потом достаёте его по этому имени. Базы данных и сторонние библиотеки не нужны. Подключается строкой `подключить хранилище`.

Внутри всё устроено просто: каждое изменение дописывается в конец файла, а старые записи не стираются. Поэтому при чтении побеждает самая свежая запись с этим ключом.

## Быстрый способ: функции с путём к файлу

```
подключить хранилище

функция главная(): целое
    текст файл = "данные.sfs"
    выполнить_команду("rm -f " + файл)

    результат из верного р1 = сохранить(файл, "имя", "Аня")
    результат из верного р2 = сохранить(файл, "город", "Тула")
    результат из верного р3 = сохранить(файл, "имя", "Анна")

    результат из текста имя = получить(файл, "имя")
    если (имя.успешно)
        вывести("имя: " + имя.значение)
    конец

    результат из верного у = удалить(файл, "город")
    результат из текста город = получить(файл, "город")
    если (не город.успешно)
        вывести("города больше нет: " + город.сообщение)
    конец
    вернуть 0
конец
```

**Что выведет программа:**

```
имя: Анна
города больше нет: ключ не найден
```

Разберём по строкам:

- `сохранить(файл, "имя", "Аня")` — записываем пару «ключ — значение». Если файла ещё нет, он создаётся.
- Повторное `сохранить` с тем же ключом не стирает старую запись, а дописывает новую. При чтении вы получите свежую: «Анна», а не «Аня».
- `получить(файл, "имя")` — возвращает `результат из текста`: ключа может не быть, поэтому смотрим `.успешно`.
- `удалить(файл, "город")` — помечает ключ удалённым. После этого `получить` скажет «ключ не найден».

Каждый такой вызов читает файл целиком. Для нескольких записей это незаметно, для тысяч заметно.

## Быстрее: открытое хранилище

`открыть_хранилище(путь)` один раз читает файл и строит в памяти список «где что лежит». После этого `получить` не сканирует файл, а прямо идёт к нужному месту.

```
подключить хранилище

функция главная(): целое
    текст файл = "данные2.sfs"
    выполнить_команду("rm -f " + файл)

    результат из Хранилище х = открыть_хранилище(файл)
    если (не х.успешно)
        вывести("не открылось: " + х.сообщение)
        вернуть 1
    конец
    результат из верного з1 = х.значение.сохранить("имя", "Анна")
    результат из верного з2 = х.значение.сохранить("возраст", "30")

    результат из текста а1 = х.значение.получить("имя")
    результат из текста а2 = х.значение.получить("возраст")
    вывести("имя: " + а1.значение)
    вывести("возраст: " + а2.значение)

    закрыть_хранилище(х.значение)
    вернуть 0
конец
```

**Что выведет программа:**

```
имя: Анна
возраст: 30
```

- `х.значение.сохранить(...)`, `.получить(...)`, `.удалить(...)` — те же действия, но уже через индекс в памяти.
- `закрыть_хранилище(...)` — освобождает память индекса. Сам файл остаётся на диске.
- `сжать_хранилище(...)` — переписывает файл заново и оставляет только свежие записи. Полезно, когда в файле накопилось много старых значений.

Значения и ключи здесь — только текст. Числа превращайте через `целое_в_текст` и `текст_в_целое`.


## Полный список объявлений

Так эти функции объявлены в исходниках модуля:

```
структура НайденнаяЗапись
функция сохранить(текст путь_к_файлу, текст ключ, текст значение): результат из верного
функция получить(текст путь_к_файлу, текст ключ): результат из текста
функция удалить(текст путь_к_файлу, текст ключ): результат из верного
структура Хранилище
функция открыть_хранилище(текст путь): результат из Хранилище
функция закрыть_хранилище(Хранилище хр): целое
функция сжать_хранилище(Хранилище хр): результат из Хранилище
```
