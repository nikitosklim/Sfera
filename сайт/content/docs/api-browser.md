# Модуль «браузер»

Позволяет писать код страницы на Сфере: программа компилируется в WebAssembly и работает прямо в браузере. Через модуль вы управляете страницей: находите элементы, меняете текст, слушаете нажатия, отправляете запросы на сервер. Подключается строкой `подключить браузер;`. Так устроены интерактивные части сайта языксфера.рф.

> **Простыми словами.** В браузере есть «объекты» (окно, документ, кнопка). Модуль выдаёт каждому объекту номер. Вы говорите: «возьми у объекта номер 5 свойство `document`» или «вызови у него метод `getAttribute`» — и браузер это делает.

## Основа: объекты по номерам

- `окно()` — номер глобального объекта `window`.
- `свойство(объект, имя)` — прочитать свойство; `задать(объект, имя, значение)` — записать.
- `вызвать0 … вызвать3(объект, имя, аргументы…)` — вызвать метод с нулём…тремя аргументами.
- `в_объект_текст(текст)`, `в_объект_число(число)` — превратить обычное значение в «объект» для передачи браузеру.
- `объект_в_текст`, `объект_в_число`, `объект_истина` — обратно, из ответа браузера в значение Сферы.

```
подключить браузер;

функция главная(): целое
    целое32 документ = свойство(окно(), "document");
    целое32 заголовок = вызвать1(документ, "getElementById", в_объект_текст("заголовок"));
    задать(заголовок, "textContent", в_объект_текст("Привет из Сферы!"));
    вернуть 0;
конец
```

Строка за строкой: берём `document`, ищем элемент с `id="заголовок"` и записываем ему новый текст.

## События и таймеры

- `слушать(объект, "click", "имя_функции")` — когда у объекта случится событие, вызвать вашу функцию по имени.
- `каждые_мс(1000, "имя_функции")` — вызывать функцию раз в секунду.
- Внутри обработчика `событие()` возвращает объект текущего события, а `метка()` / `сбросить(метка)` помогают освободить временные объекты.

## Запросы на сервер

`получить_зос`, `получить_текстом`, `отправить_форму`, `отправить_маяк` и версии «с токеном» делают запрос и вызывают ваш обработчик, когда ответ придёт; сам ответ забирает `результат_запроса()`. Это работа с сетью браузера, поэтому программа никогда не «зависает» в ожидании.

{{инфо: Эти функции работают только в программах, собранных под браузер. На компьютере они недоступны.}}

- `функция вызвать0(целое32 объект, текст имя): целое32` — Вызов метода объекта: вызвать0 — без аргументов, вызвать1 — с одним и так далее. Аргументы тоже ручки.
- `функция вызвать1(целое32 объект, текст имя, целое32 первый): целое32`
- `функция вызвать2(целое32 объект, текст имя, целое32 первый, целое32 второй): целое32`
- `функция вызвать3(целое32 объект, текст имя, целое32 первый, целое32 второй, целое32 третий): целое32`

- `функция объект_в_текст(целое32 объект): текст`
- `функция объект_в_число(целое32 объект): дробное`
- `функция объект_истина(целое32 объект): верно` — Истина ли значение с точки зрения страницы (не пусто, не 0, не пустая строка, не false).
- `функция слушать(целое32 объект, текст имя_события, текст обработчик): целое` — Подписка: при событии браузер вызовет функцию программы с таким именем (без параметров). Объект самого события доступен из обработчика через событие().
- `функция каждые_мс(целое32 мс, текст обработчик): целое`
- `функция событие(): целое32`
- `функция отправить_маяк(текст адрес, текст тело): целое` — Фоновая отправка данных на сервер при закрытии страницы (navigator.sendBeacon), форма application/x-www-form-urlencoded.
- `функция метка(): целое32`
- `функция сбросить(целое32 метка): целое`
- `функция получить_зос(текст адрес, текст обработчик): целое` — GET адреса, ответ — разобранный JSON ({ok:false}, если сервер ответил не JSON). Заголовок X-Sfera добавляется сам.
- `функция отправить_форму(текст адрес, текст тело, текст обработчик): целое` — POST с телом вида «поле=значение&…» (значения должны быть закодированы: см. кодировать()). Ответ — JSON.
- `функция получить_текстом(текст адрес, текст обработчик): целое` — GET адреса, ответ — просто текст.
- `функция хеш_пароля(текст имя, текст пароль, текст обработчик): целое` — Хеш пароля для входа: пароль не уходит на сервер. В ответе {ok, хеш} или {ok:false, ошибка}.
- `функция когда_готово(целое32 обещание, текст обработчик): целое` — Когда обещание страницы (Promise) выполнится, вызвать обработчик; значение будет в результат_запроса().
- `функция собрать_архив(целое32 файлы, текст манифест, текст обработчик): целое` — Собрать из выбранных файлов (массив File) архив пакета .tar.gz с манифестом пакет.сфера. В ответе {ok, данные} или {ok:false, ошибка}.
- `функция опубликовать_архив(текст имя, текст версия, целое32 данные, текст обработчик): целое` — Опубликовать готовый архив (ArrayBuffer) пакета имя версии. В ответе JSON сервера.
- `функция получить_зос_с_токеном(текст адрес, текст токен, текст обработчик): целое` — То же, что получить_зос и отправить_форму, но с токеном администратора (заголовок Authorization: Bearer). Ответ POST — JSON сервера с полем ok = «статус ответа успешный» и ошибка, если сервер её назвал.
- `функция отправить_форму_с_токеном(текст адрес, текст тело, текст токен, текст обработчик): целое`
- `функция результат_запроса(): целое32`
- `функция ничего(): целое32` — Пустая ручка: «ничего», чтобы позже подставить в неё найденный объект.
- `функция есть(целое32 объект): верно` — Есть ли объект (ручка не нулевая).
- `функция кодировать(текст значение): текст` — Кодирует текст для адреса и формы (encodeURIComponent).
- `функция элемент(текст идентификатор): целое32` — Элемент страницы по id (ручка 0, если такого нет).
- `функция знаков(текст источник): целое` — Число знаков (букв), а не байтов: русская буква в UTF-8 занимает два байта.
- `функция убрать_края(текст источник): текст` — Текст без пробелов и переводов строк по краям.
- `функция подстрока_или_пусто(текст источник, целое от, целое размер): текст`
- `функция поле_через(текст строка, целое разделитель, целое номер): текст` — Поле строки, разделённой символом (код байта): поле_через(строка, 124, 2) — третье поле при разделителе «|».
- `функция заканчивается(текст источник, текст хвост): верно` — Оканчивается ли текст хвостом.
