# Программа «Проводник»

> **Простыми словами.** Маленькое окно (600×600): слева файлы и папки вашего сервера, как в Finder или Проводнике Windows, справа — сведения о самом сервере: сколько занято памяти и диска, какая система и процессор. Токен вводится один раз, дальше программа входит сама. Она написана на Сфере.

## Что умеет

- **Файлы слева.** Двойной щелчок по папке открывает её, по файлу — скачивает и открывает программой вашей системы. Есть строка «..» для выхода на уровень выше, колесо мыши, стрелки, Enter и Backspace.
- **Сведения справа.** Сервер (имя, ОС, ядро), память и диск с полосками (зелёная, жёлтая от 70 %, красная от 90 %), процессор и нагрузка, время работы, подкачка. Данные обновляются каждые 5 секунд.
- **Токен запоминается.** После первого удачного входа адрес и токен лежат в `~/.sfera-проводник/настройки.txt` с правами 600 (читать может только вы). Кнопка «Выйти» стирает токен. Если сервер перестал принимать токен, программа сама вернёт на экран входа.
- **Программы спрашивают.** Файлы вроде `.sh`, `.exe`, `.app`, `.dmg` перед запуском показывают вопрос: «Скачать и запустить», «Только скачать» или «Отмена».

## Что нужно

- macOS или Linux. На Windows пока не работает: программа вызывает `curl` и `sh`.
- Библиотеки SDL2 и SDL2_ttf (те же, что нужны для графики в Сфере).
- На сервере запущен сайт Сферы с ручками `/api/файлы`, `/api/сервер`, `/api/скачать` (см. «Развёртывание», раздел 4а) и токен из файла `admin-token.txt`.

## Сборка и запуск

```bash
cd инструменты/проводник
запустить проводник.код --только-собрать --линковать SDL2 --линковать SDL2_ttf --линковать m
./проводник
```

На экране входа введите адрес (например `языксфера.рф`; для адреса с портом или `localhost` используется `http://`, для остальных `https://`) и токен. Токен можно вставить сочетанием Ctrl+V (на Mac — Cmd+V).

## Как это устроено

Программа не держит соединение сама: каждый запрос выполняет `curl` в фоне, поэтому окно не зависает. Токен не попадает в командную строку (его видно в `ps`): он лежит в файле заголовка с правами 600 в папке `~/.sfera-проводник`, а `curl` читает его через `-H @файл`. Скачанные файлы лежат в `~/.sfera-проводник/кэш`.

Подписи строк и панели собираются один раз на ответ сервера, а окно перерисовывается только при изменениях. Сфера пока не освобождает временные строки сама, и пересборка подписей на каждом кадре заняла бы за час больше гигабайта памяти. Тот же приём годится для любого окна, которое работает долго.

## Честные ограничения

- Пока нет перетаскивания файла на окно (загрузка на сервер) и скачивания папок целиком.
- Токен хранится открытым текстом в файле с правами 600. Связка ключей macOS и аналоги пока не используются.
- В списке показываются первые 1000 записей папки.
- Время файлов показано по Москве.
- Проверено в виртуальном экране Linux (Xvfb) и на локальном сервере; на настоящих macOS и на боевом сервере пока не пробовалось.
