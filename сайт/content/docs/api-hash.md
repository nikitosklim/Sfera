# Модуль «хеш»

> **Простыми словами.** Хеш — это «отпечаток» текста: короткая строка, которая меняется, если в тексте изменить хотя бы одну букву. По отпечатку нельзя восстановить исходный текст, но можно проверить, что два текста одинаковы. Хеши используют для паролей, проверки скачанных файлов и подписей.

Подключается строкой `подключить хеш`.

В названиях БАХ — «Безопасный Алгоритм Хеширования» (по-английски SHA). Подробнее о русских названиях: [Русские названия](/документация/русские-названия).

## Функции

| Функция | Что делает |
|---|---|
| `бах256_текстом(текст)` | БАХ-256 строкой из 64 шестнадцатеричных цифр |
| `бах256(текст)` | БАХ-256 как список из 32 байт |
| `бах1_текстом(текст)` | БАХ-1 строкой из 40 цифр |
| `бах1(текст)` | БАХ-1 как список из 20 байт |
| `основание64(список)` | кодирует список байт в Base64 |
| `шестнадцатеричная_строка(список)` | превращает байты в строку вида `ba7816bf…` |

Функции, которые возвращают список, нужно освобождать: `список.освободить()`.

## Пример

```сфера
подключить хеш

функция главная()
    вывести(бах256_текстом("abc"))
    вывести(бах256_текстом("abd"))
конец
```

```
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
a52d159f262b2c6ddb724a61840befc36eb30c88877a4030b65cbe86298449c9
```

{{инфо: Слово «abd» отличается от «abc» одной буквой, но отпечаток получится совсем другой. Именно поэтому хеш годится для проверки: любая правка меняет его целиком.}}

## Что важно знать

- Используйте **БАХ-256**. БАХ-1 устарел для защиты, он оставлен для совместимости, например для рукопожатия WebSocket.
- Для хранения паролей одного хеша мало: к паролю нужно добавлять случайную «соль». Готовой функции для паролей пока нет.
- Хешируются байты текста, то есть русские буквы считаются в UTF-8 (по два байта).
