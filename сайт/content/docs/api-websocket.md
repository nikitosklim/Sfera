# Модуль «вебсокет»

> **Простыми словами.** WebSocket — это «телефонная линия» между браузером и сервером: однажды соединились и обмениваются сообщениями в любую сторону, без повторных запросов. Модуль нужен, чтобы написать на Сфере сервер для сетевой игры или чата. Клиентская часть (в браузере) находится в [модуле «игра»](/документация/справочник-игра).

Подключается строкой `подключить вебсокет;`. Порт открывается так же, как для HTTP, функцией `открыть_порт` из модуля «веб».

## Функции

| Функция | Что делает |
|---|---|
| `принять_вебсокет(слушающий)` | ждёт игрока, делает рукопожатие, возвращает номер соединения (`результат из целого`) |
| `читать_сообщение(клиент)` | ждёт следующее текстовое сообщение (`результат из текста`); ошибка значит, что игрок отключился |
| `отправить_сообщение(клиент, текст)` | отправляет сообщение (до 65535 байт) |
| `закрыть_вебсокет(клиент)` | закрывает соединение |
| `sha1(текст)`, `base64(список)` | помощники рукопожатия; можно использовать отдельно |

## Устройство сервера

`принять_вебсокет` и `читать_сообщение` ждут, поэтому сервер строят так:

1. Несколько рабочих потоков (`параллельно`), и каждый в цикле принимает игрока и читает его сообщения.
2. Все сообщения рабочие потоки кладут в общий [канал](/документация/многопоточность), потому что канал — очередь.
3. Главный поток забирает сообщения из канала и рассылает ответы. Отправлять данные всем игрокам удобно из одного места, поэтому замки не нужны.

Полный рабочий пример на 70 строк — `игры/чат-сервер.код`: он рассылает каждое сообщение всем подключённым.

```
подключить вебсокет;

канал из текстов события = создать_канал();
целое слушающий = 0;

функция главная()
    результат из целого порт = открыть_порт(9001);
    слушающий = порт.значение;
    параллельно
        пока (да)
            результат из целого клиент = принять_вебсокет(слушающий);
            если (клиент.успешно)
                результат из текста с = читать_сообщение(клиент.значение);
                если (с.успешно)
                    события.отправить(с.значение);
                конец
            конец
        конец
    конец
    пока (да)
        вывести(события.получить());
    конец
конец
```

## Что пока не поддерживается

- Бинарные сообщения и сообщения длиннее 65535 байт.
- Шифрование `wss://`: поставьте перед сервером обычный прокси (nginx, Caddy), если игра выложена по `https://`.
