# Переменные

> **Простыми словами.** Переменная — это коробка с подписью: в неё кладут значение и потом достают по имени. Запись `целое возраст = 25;` читается: «коробка для целых, называется `возраст`, положи туда 25».


Объявление с явным типом — `тип имя = значение;`:

```
целое возраст = 25;
текст имя = "Иван";
верно активен = да;
```

- `целое возраст = 25;` — тип, имя, `=` и значение. Знак `=` значит «положить», а не «равно».
- `текст имя = "Иван";` — коробка для текста.
- `верно активен = да;` — коробка для «да» или «нет».

## Вывод типа (`имя = значение;`)

Тип слева можно опустить целиком — если `имя` ещё не объявлено в этой
области видимости, `имя = значение;` — это ОБЪЯВЛЕНИЕ, а не присваивание,
и тип выводится из выражения справа:

```
возраст = 25;              // выведено: целое
имя = "Иван";               // выведено: текст
итог = удвоить(21);          // выведено из типа возврата функции
точка = Точка(3, 4);         // выведено: Точка (вызов конструктора структуры)
```

Работает для любого выражения, тип которого семантический анализ может
определить напрямую (числовые и строковые литералы, `да`/`нет`, вызовы
функций и методов, конструкторы структур, арифметика и т. д.) — то есть
для подавляющего большинства реальных объявлений. Никакого отдельного
синтаксиса (вроде `:=`) не требуется — используется тот же оператор `=`,
что и у присваивания; различает их семантический анализ по тому, было ли
имя уже объявлено в текущей области видимости (см. `grammar.md`, раздел
4, и `ast::Оператор::Присваивание` — узел с этим именем на самом деле
неоднозначен и разрешается именно так).

⚠️ **Ограничения**:
- `Список из T`/`Словарь из Ключ и Значение` через вывод типа объявить нельзя
  — у них всегда только один типовый параметр в грамматике, конкретный
  `Т` для пустого литерала-контейнера вывести неоткуда; указывай тип
  явно (`Список из целых числа = Список из целых();`).
- `неизменно` требует явного типа (`неизменно целое максимум = 100;`) —
  вывод типа с `неизменно` не комбинируется в этой версии.
- Если выражение справа настолько сложное, что тип не определяется
  напрямую — честная ошибка компиляции ("не удалось вывести тип для
  '...' — выражение справа слишком сложное для текущей версии
  анализатора"), а не молчаливое падение к какому-то типу по умолчанию.

## Неизменяемые переменные

Ключевое слово `неизменно` перед типом запрещает переприсваивание:

```
неизменно целое максимум = 100;
```

Слово `неизменно` делает переменную константой: значение положили один раз и больше менять нельзя. Подходит для того, что не должно меняться: максимум, число дней в неделе. {{инфо: Если попытаться присвоить новое значение, компилятор не соберёт программу и покажет строку с ошибкой. Это защита от случайных поправок.}}

## Явные приведения типов

Синтаксис — имя типа как функция: `целое32(значение)`, `дробное(значение)`.

⚠️ **Важно**: приведение нужно даже при инициализации **числовым
литералом** — типы разной разрядности не смешиваются неявно нигде:

```
целое32 а = целое32(5);    // так, не "целое32 а = 5;"
целое итог = целое(а) + б;  // и здесь тоже явно
```

Запись `целое32(5)` называется приведением: она явно говорит, что 5 нужно положить в 32-битную коробку. Новичкам такие типы почти не встречаются: пока пишете обычное `целое`, приведение не нужно.

## Попробуй сам

Откройте [«Попробовать»](/попробовать) и запустите:

```
функция главная(): целое
    целое счёт = 0;
    счёт = счёт + 5;
    неизменно целое максимум = 100;
    вывести("Счёт: " + целое_в_текст(счёт) + " из " + целое_в_текст(максимум));
    вернуть 0;
конец
```

Потом попробуйте добавить строку `максимум = 200;` и прочитайте, что скажет компилятор.

## Глобальные переменные

Переменная, объявленная **вне функций**, живёт всё время работы программы и видна во всех функциях. Это удобно для состояния игры: счёта, положения героя, списка врагов, которые должны сохраняться между вызовами.

```
целое счёт = 0;
неизменно целое МАКС = 100;

функция прибавить(целое н)
    счёт = счёт + н;
конец

функция главная()
    прибавить(5);
    прибавить(7);
    вывести("счёт = %счёт%");    // счёт = 12
конец
```

- Начальное значение вычисляется в начале `главная`, по порядку объявления. Внутри можно вызывать функции и использовать ранее объявленные глобальные.
- Глобальной может быть переменная типа `целое`, `дробное`, `верно`, а также структура или список (`Список из целых`, `Игра игра = Игра(0);`). Изменяемый **текст** глобальным пока быть не может: храните его в поле структуры. Неизменяемые тексты-константы разрешены: `неизменно текст НАЗВАНИЕ = "Змейка";`.
- Локальная переменная с тем же именем «закрывает» глобальную внутри своей функции.
- Если глобальные нужны в нескольких файлах, объявляйте их в основном файле: имена глобальных из подключённых модулей не получают приставки модуля.
