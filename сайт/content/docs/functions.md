# Функции

> **Простыми словами.** Функция — это набор команд с именем. Вы описываете его один раз и вызываете сколько угодно раз. Функции получают данные в скобках (параметры) и могут вернуть результат (`вернуть`).


```
функция сложить(целое а, целое б): целое
    вернуть а + б;
конец
```

- `функция сложить(целое а, целое б): целое` — имя `сложить`; на входе два целых числа (`а` и `б`); на выходе целое.
- `вернуть а + б;` — посчитать и отдать результат. {{инфо: Вызов `сложить(2, 3)` превращается в число 5 прямо на месте вызова. Можно писать `целое итог = сложить(2, 3);` или сразу `вывести(целое_в_текст(сложить(2, 3)));`.}}

- Тип возврата указывается через `:` после списка параметров (старая запись: `->`)
- `вернуть` — оператор возврата значения
- Функция без возвращаемого значения просто не пишет `: тип`:

```
функция напечатать_дважды(текст сообщение): целое
    вывести(сообщение);
    вывести(сообщение);
    вернуть 0;
конец
```

Эта функция получает текст и печатает его два раза. Она ничего не считает, но формально всё равно возвращает `0`.

## Проверка аргументов при вызове

Компилятор проверяет и количество, и типы аргументов при каждом вызове
— как обычной функции, так и функции из подключённого модуля:

```
функция сложить(целое а, целое б): целое вернуть а + б; конец

сложить(5);        // ошибка: функция 'сложить' ожидает 2 аргумент(ов), передано 1
сложить(5, "три"); // ошибка: несовпадение типов для аргумента 2
сложить(5, 3);     // верно
```

Компилятор проверяет вызов: сколько аргументов передано и какого они типа. Если на вход нужны два целых числа, а вы дали одно или передали текст, программа не соберётся, и вы сразу увидите, где ошибка.

Параметр, объявленный как контракт, принимает любую структуру, реально
его реализующую (`структура X : ИмяКонтракта`) — не только буквально
значение самого контракта.

```
    вывести(целое_в_текст(удвоить(21)));

конец
```
