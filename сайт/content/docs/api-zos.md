# Модуль «зос»

> **Простыми словами.** ЗОС — «Запись Объектов Скрипта» (по-английски JSON) — это текст, в котором записаны данные: `{"имя": "Ника", "очки": 120}`. Так обмениваются данными сайты, игры и приложения. Модуль «зос» умеет достать из такого текста нужное значение и собрать новый ЗОС, чтобы вам не разбирать скобки и кавычки руками.

Подключается строкой `подключить зос`.

## Как читать: путь к значению

Читать удобно «по пути». Путь — это имена полей через точку. Если внутри массив, вместо имени пишут номер элемента, считая с нуля. Для `{"враги": [{"имя": "а"}, {"имя": "б"}]}` путь `враги.1.имя` значит «поле имя у второго врага».

Пустой путь (`""`) означает весь документ целиком.

## Функции чтения

| Функция | Что делает |
|---|---|
| `зос_верен(текст)` | `да`, если весь текст — корректный ЗОС |
| `зос_есть(текст, путь)` | есть ли значение по пути |
| `зос_текст(текст, путь)` | строка по пути, уже без экранирования → `результат из текста` |
| `зос_целое(текст, путь)` | целое число по пути → `результат из целого` |
| `зос_дробное(текст, путь)` | дробное число по пути → `результат из дробного` |
| `зос_логическое(текст, путь)` | `true`/`false` → `результат из целого` (1 или 0) |
| `зос_размер(текст, путь)` | сколько элементов в массиве или полей в объекте → `результат из целого` |
| `зос_значение(текст, путь)` | «сырой» ЗОС значения (строка останется в кавычках) → `результат из текста` |

Если пути нет или там значение другого вида, функции возвращают ошибку с понятным сообщением. Например `по пути 'игрок.имя' лежит не целое число`.

## Функции сборки

| Функция | Что делает |
|---|---|
| `зос_в_кавычках(текст)` | строка в кавычках, с экранированием |
| `зос_пара_текст(ключ, текст)` | пара `"ключ":"текст"` |
| `зос_пара_целое(ключ, число)` | пара `"ключ":число` |
| `зос_пара_логическое(ключ, значение)` | пара `"ключ":true` или `false` |
| `зос_пара(ключ, готовый_зос)` | пара с уже готовым значением (объект, массив) |
| `зос_объект(пары)` | объект `{…}` из пар, перечисленных через запятую |
| `зос_массив(элементы)` | массив `[…]` из значений через запятую |

## Пример

```сфера
подключить зос

функция главная()
    текст данные = "{\"игрок\": {\"имя\": \"Ника\", \"очки\": 120}, \"враги\": [{\"имя\": \"а\"}, {\"имя\": \"б\"}]}"

    результат из текста имя = зос_текст(данные, "игрок.имя")
    результат из целого очки = зос_целое(данные, "игрок.очки")
    результат из целого сколько = зос_размер(данные, "враги")
    вывести("%(имя.значение)%: %(очки.значение)% очков, врагов: %(сколько.значение)%")

    текст пары = зос_пара_текст("имя", "Ника") + "," + зос_пара_целое("очки", 121)
    вывести(зос_объект(пары))
конец
```

```
Ника: 120 очков, врагов: 2
{"имя":"Ника","очки":121}
```

## Что важно знать

- Путь — это точки, поэтому имя поля, в котором сама точка, по пути не достать.
- Escape-последовательности `\n`, `\"` и `\uXXXX` разбираются, включая эмодзи. {{инфо: В Сфере внутри `%( … )%` нельзя писать строки в кавычках, поэтому пути и ключи для вывода кладут в переменные заранее.}}
- Модуль не строит дерево в памяти: каждый вызов проходит по тексту заново. Для небольших документов (ответы сервера, настройки, сохранения игр) этого достаточно. Если нужно прочитать много значений из огромного файла, это будет медленно.
