# Модуль «веб»

Веб-модуль — набор готовых кирпичиков для сайта на Сфере: разбор запроса, ответы нужного типа, шаблоны, безопасная отдача файлов и cookie. Подключается строкой `подключить веб;`. Сайт языксфера.рф работает именно на нём.

> **Простыми словами.** Браузер присылает текст запроса, вы присылаете текст ответа. Модуль «веб» умеет читать первое и собирать второе, а мелочи (экранирование, типы файлов, статусы) берёт на себя.

## Мелкие помощники для текста и адресов

Эти функции не требуют сети — их можно пробовать как обычный код.

```
подключить веб;

функция главная(): целое
    вывести(заменить("а-б-в", "-", "+"));
    вывести(обрезать_края("   привет   "));
    вывести(экранировать_ягр("<b>\"x\" & y</b>"));
    вывести(декодировать_адрес("%%D0%%BF%%D1%%80%%D0%%B8+%%D0%%B2%%D0%%B5%%D1%%82"));
    вывести(параметр("имя=Аня&город=Тула", "город"));
    вывести(зос_строка("строка \"в кавычках\""));
    вывести(тип_содержимого("/страница.html"));
    вывести(тип_содержимого("/картинка.png"));
    вывести(описание_статуса(404));
    вернуть 0;
конец
```

**Что выведет программа:**

```
а+б+в
привет
&lt;b&gt;&quot;x&quot; &amp; y&lt;/b&gt;
при вет
Тула
"строка \"в кавычках\""
text/html; charset=utf-8
image/png
Not Found
```

Разберём:

- `заменить(текст, что, на_что)` — заменяет все вхождения.
- `обрезать_края` — убирает пробелы и переводы строк по краям.
- `экранировать_ягр` — заменяет `<`, `>`, `&`, кавычки на безопасные коды. Всегда применяйте к тексту, который пришёл от пользователя.
- `декодировать_адрес` — превращает `%D0%BF…` и `+` из адресной строки в обычный текст.
- `параметр(строка, имя)` — достаёт значение из `имя=Аня&город=Тула`.
- `зос_строка` — оборачивает текст в кавычки по правилам JSON.
- `тип_содержимого(путь)` — подбирает `Content-Type` по расширению файла.
- `описание_статуса(код)` — подпись к коду ответа: «OK», «Not Found».

{{инфо: В тексте Сферы `%` — начало вставки значения. Чтобы написать настоящий процент, как в адресе `%D0`, удваивайте его: `%%D0`.}}

## Шаблоны и безопасность путей

```
подключить веб;

функция главная(): целое
    Список из текстов имена = Список из текстов();
    Список из текстов значения = Список из текстов();
    имена.добавить("имя");
    значения.добавить("Аня");
    имена.добавить("город");
    значения.добавить("Тула");
    вывести(подставить("Привет, {{имя}} из города {{город}}!", имена, значения));
    вывести(заполнить("Привет, {{имя}}!", "имя", "Боря"));

    если (путь_безопасен("/статика/a.css"))
        вывести("путь безопасен");
    конец
    если (не путь_безопасен("/../секрет"))
        вывести("путь с .. запрещён");
    конец
    вернуть 0;
конец
```

**Что выведет программа:**

```
Привет, Аня из города Тула!
Привет, Боря!
путь безопасен
путь с .. запрещён
```

- `заполнить(шаблон, имя, значение)` — подставляет одно значение вместо `{{имя}}`.
- `подставить(шаблон, имена, значения)` — подставляет сразу несколько.
- `путь_безопасен` — проверяет, что запрошенный путь не выходит из папки через `..`. Вызывайте его перед отдачей любого файла.

## Cookie

`заголовок_печенья(имя, значение, секунд)` собирает строку `Set-Cookie` с защитными флагами `HttpOnly` и `SameSite=Lax`. Чтение — `значение_печенья(запрос, имя)`.

## Сервер: порт, запрос, ответ

Эти функции работают с настоящей сетью, поэтому в браузерной площадке они не запускаются — пример показан без запуска.

```
подключить веб;

функция главная(): целое
    результат из целого порт = открыть_порт(8080);
    если (не порт.успешно)
        вывести("порт занят: " + порт.сообщение);
        вернуть 1;
    конец
    // дальше цикл: принять подключение, прочитать_запрос, отправить ответ_ягр(...)
    вернуть 0;
конец
```

Ответы собираются готовыми функциями: `ответ_текстом`, `ответ_ягр`, `ответ_зос`, `перенаправить`, `ответ_с_заголовками`, `ответ_файлом`, `ответ_файлом_для`. Загрузку файла от пользователя принимает `принять_тело_в_файл`. Полный список с сигнатурами ниже.

{{инфо: `открыть_порт` сам включает игнорирование сигнала SIGPIPE: если браузер оборвал соединение посреди ответа, сервер не падает.}}


## Все функции и структуры

Полный список из исходников модуля. Пояснения взяты из комментариев к функциям.

### Модуль «веб»

- `структура Запрос`
- `функция срез(текст источник, целое начало, целое сколько): текст` — Безопасная подстрока: при любой ошибке возвращает пустой текст.
- `функция заменить(текст источник, текст что, текст чем): текст` — Заменяет все вхождения «что» на «чем». Пустое «что» не заменяется.
- `функция заполнить(текст шаблон, текст имя, текст значение): текст` — Подставляет значение вместо {{имя}} в шаблоне. Удобно, но для горячего пути (каждый запрос) лучше подставить(): она делает один проход и один буфер.
- `функция обойти_шаблон(текст шаблон, Список из текстов имена, Список из текстов значения, текст буфер, целое писать): целое` — Один проход по шаблону: считает длину результата (писать = 0) или записывает его в буфер (писать = 1). Возвращает длину. Неизвестные {{имена}} остаются как есть.
- `функция подставить(текст шаблон, Список из текстов имена, Список из текстов значения): текст` — Подставляет сразу несколько значений: имена[k] → значения[k]. Результат выделен в куче — вызывающая сторона освобождает его освободить_память().
- `функция обрезать_края(текст источник): текст` — Убирает пробелы, табуляции и переводы строк по краям.
- `функция прочитать_шаблон(текст путь): текст` — Читает файл-шаблон; если файла нет — пустой текст.
- `функция экранировать_ягр(текст источник): текст` — Экранирует <, >, & и кавычки — для вставки пользовательского текста в HTML. Результат выделен в куче — вызывающая сторона освобождает его освободить_память().
- `функция цифра_16(целое б): целое`
- `функция декодировать_адрес(текст источник): текст` — "%D0%BF%D1%80" → «пр», "+" → пробел. Неверные последовательности остаются как есть.
- `функция параметр(текст строка_параметров, текст имя): текст` — Значение параметра из строки вида "а=1&б=2" (строка после "?" или тело формы). Если параметра нет — пустой текст.
- `функция путь_безопасен(текст путь): верно` — Путь допустим для отдачи файла: начинается с "/", без "..", обратных слэшей, двоеточий (диски Windows) и нулевых байтов.
- `функция оканчивается_на(текст источник, текст окончание): верно`
- `функция тип_содержимого(текст путь): текст`
- `внешняя функция установить_действие_сигнала(целое32 номер, целое64 действие): целое64` — Браузер может оборвать соединение посреди ответа. Запись в закрытый сокет тогда присылает процессу сигнал SIGPIPE (13), и по умолчанию он завершает весь сервер. Мы этот сигнал игнорируем: запись просто вернёт ошибку, а сервер продолжит работать.
- `функция открыть_порт(целое порт): результат из целого` — Открывает сокет и начинает слушать порт на всех интерфейсах.
- `функция прочитать_порцию(целое32 клиент): текст` — Читает одну порцию данных (до 4096 байт) и возвращает её текстом. Пустой текст — конец данных.
- `функция заголовок(Запрос з, текст имя): текст` — Значение заголовка запроса (без учёта регистра имени). Нет заголовка — пустой текст.
- `функция прочитать_запрос(целое32 клиент): результат из Запрос` — Читает и разбирает запрос. Ошибка — если соединение оборвалось или запрос не HTTP.
- `функция подсмотреть_порцию(целое32 клиент): текст` — Смотрит на пришедшие байты, не забирая их из сокета (MSG_PEEK). Возвращает текст до первого нулевого байта; пустой текст — соединение закрыто или данных нет.
- `функция потребить_байты(целое32 клиент, целое n): целое` — Забирает из сокета ровно n байт и выбрасывает их.
- `функция принять_тело_в_файл(целое32 клиент, текст путь, целое всего): результат из целого` — Принимает ровно «всего» байт тела запроса прямо в файл (бинарно, кусками по 64 КБ). Подходит для загрузки установщиков в сотни мегабайт. Возвращает число принятых байт.
- `функция значение_печенья(Запрос з, текст имя): текст` — Значение cookie из заголовка Cookie запроса. Нет такой cookie — пустой текст.
- `функция заголовок_печенья(текст имя, текст значение, целое секунд): текст` — Строка заголовка Set-Cookie (значение — только безопасные символы: латиница, цифры, -_.).
- `функция зос_строка(текст источник): текст` — Строка в виде JSON-строки (в кавычках, с экранированием).
- `функция описание_статуса(целое код): текст`
- `функция заголовки_ответа(целое код, текст тип, целое размер, текст дополнительно): текст`
- `функция ответ_текстом(целое32 клиент, целое код, текст тип, текст тело): целое` — Отправляет страницу (текст) с заданным кодом и типом содержимого.
- `функция ответ_ягр(целое32 клиент, целое код, текст тело): целое`
- `функция перенаправить(целое32 клиент, текст адрес): целое`
- `функция перенаправить_навсегда(целое32 клиент, текст адрес): целое` — Постоянное перенаправление (301): поисковики переносят вес старого адреса на новый. Адрес должен быть в ASCII (кириллицу кодируйте через %XX).
- `функция ответ_с_заголовками(целое32 клиент, Запрос з, целое код, текст тип, текст тело, текст дополнительно): целое` — Ответ с дополнительными заголовками (например, Set-Cookie или Cache-Control).
- `функция ответ_зос(целое32 клиент, целое код, текст тело): целое`
- `функция разобрать_диапазон(текст значение, целое всего): текст` — Разбор «Range: bytes=a-b». Возвращает «начало,конец» (включительно) или "" — если заголовка нет/он непонятен, или "bad" — диапазон за пределами файла.
- `функция ответ_файлом_для(целое32 клиент, Запрос з, текст путь_к_файлу, текст имя_для_скачивания, верно скачать, текст кеш): верно` — Отдача файла с поддержкой докачки (Range), ETag/304 и HEAD. кеш — значение Cache-Control (например "public, max-age=300") или "" — без него. ETag строится по размеру файла: меняя файл, меняйте и его имя/размер.
- `функция ответ_файлом(целое32 клиент, текст путь_к_файлу, текст имя_для_скачивания, верно скачать): верно` — Отдаёт файл частями по 64 КБ — подходит и для маленьких страниц, и для установщиков в сотни мегабайт (в памяти держится только одна часть). скачать = да — браузер предложит сохранить файл, а не открывать его. Возвращает да, если файл найден и отправлен.
