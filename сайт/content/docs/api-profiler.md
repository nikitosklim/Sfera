# Модуль «профилировщик»

Профилировщик показывает, куда за всё время работы уходит больше всего времени. Вы ставите «секундомер» вокруг участков кода. В конце профилировщик говорит: этот участок вызывали столько-то раз, всего он занял столько-то, в среднем столько-то. Подключается строкой `подключить профилировщик;`.

## Пример

```
подключить профилировщик;

функция работа(целое n): целое
    целое сумма = 0;
    целое k = 0;
    пока (k меньше n)
        сумма = сумма + k;
        k = k + 1;
    конец
    вернуть сумма;
конец

функция главная(): целое
    Профилировщик п = создать_профилировщик();

    начать_замер(п, "работа");
    целое а = работа(50000);
    закончить_замер(п, "работа");

    начать_замер(п, "работа");
    целое б = работа(50000);
    закончить_замер(п, "работа");

    вывести("вызовов: " + целое_в_текст(замер_вызовов(п, "работа")));
    профиль_напечатать(п);
    вернуть 0;
конец
```

Время зависит от компьютера, поэтому реальный вывод мы здесь не запускаем. У вас будет примерно так:

```
вызовов: 2
работа: вызовов=2, всего=0.112 мс, среднее=0.056 мс
```

Разберём:

- `создать_профилировщик()` — заводим профилировщик.
- `начать_замер(п, "работа")` — включаем секундомер для участка с именем «работа».
- `закончить_замер(п, "работа")` — останавливаем его и прибавляем время к итогу этого имени. Один и тот же участок можно мерить сколько угодно раз.
- `замер_вызовов(п, имя)` — сколько раз участок измеряли. `замер_всего_нс(п, имя)` — всё накопленное время в наносекундах.
- `профиль_отчёт(п)` — сводка как `текст`. `профиль_напечатать(п)` — то же, но сразу на экран. Участки идут в порядке первого замера.

Один и тот же участок нельзя мерить вложенно: пока он не закончен, повторный `начать_замер` с тем же именем затирает время начала. Для вложенных участков с разными именами всё работает. А если нужно «что за чем шло» в одном запросе, используйте модуль «трейсинг».


## Полный список объявлений

Так эти функции объявлены в исходниках модуля:

```
структура Профилировщик
функция создать_профилировщик(): Профилировщик
функция начать_замер(Профилировщик п, текст имя)
функция закончить_замер(Профилировщик п, текст имя)
функция замер_вызовов(Профилировщик п, текст имя): целое
функция замер_всего_нс(Профилировщик п, текст имя): целое
функция профиль_отчёт(Профилировщик п): текст
функция профиль_напечатать(Профилировщик п)
```
