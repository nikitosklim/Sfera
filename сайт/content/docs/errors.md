# Обработка ошибок — результат из Т


Вместо исключений — обёртка `результат из Т`, содержащая три поля:
`.успешно` (`верно`), `.значение` (тип `Т`, валиден только при успехе),
`.сообщение` (текст ошибки, валиден только при неудаче).

```
функция разделить(целое а, целое б): результат из целого
    если (б == 0)
        вернуть ошибка("деление на ноль");
    конец
    вернуть успех(а / б);
конец

функция главная(): целое
    результат из целого итог = разделить(10, 2);
    если (итог.успешно)
        вывести(целое_в_текст(итог.значение));
    иначе
        вывести("Ошибка: " + итог.сообщение);
    конец
    вернуть 0;
конец
```

Многие встроенные функции (`подстрока`, `найти`, `прочитать_файл` и
другие) сами возвращают `результат из Т` — обязательно проверяй
`.успешно` перед использованием `.значение`.
