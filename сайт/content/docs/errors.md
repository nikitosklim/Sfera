# Обработка ошибок — результат из Т

> **Простыми словами.** Иногда операция не получается: файла нет, на ноль делить нельзя. Вместо того чтобы ломать программу, такие функции возвращают «коробочку» `результат`: в ней записано, получилось ли, и лежит либо ответ, либо объяснение ошибки.


Вместо исключений — обёртка `результат из Т`, содержащая три поля:
`.успешно` (`верно`), `.значение` (тип `Т`, валиден только при успехе),
`.сообщение` (текст ошибки, валиден только при неудаче).

```
функция разделить(целое а, целое б): результат из целого
    если (б == 0)
        вернуть ошибка("деление на ноль");
    конец
    вернуть успех(а / б);
конец

функция главная(): целое
    результат из целого итог = разделить(10, 2);
    если (итог.успешно)
        вывести(целое_в_текст(итог.значение));
    иначе
        вывести("Ошибка: " + итог.сообщение);
    конец
    вернуть 0;
конец
```

Многие
Построчно:

- `функция разделить(...): результат из целого` — функция честно предупреждает: «могу вернуть число, а могу вернуть ошибку».
- `вернуть ошибка("деление на ноль");` — вернуть неудачу с объяснением.
- `вернуть успех(а / б);` — вернуть удачу с ответом. {{инфо: `успех(...)` и `ошибка(...)` — две готовые функции, которые упаковывают ответ в коробочку.}}
- `результат из целого итог = разделить(10, 2);` — ловим коробочку целиком, пока не открывая.
- `если (итог.успешно)` — смотрим на ячейку `.успешно`. Если `да`, внутри лежит ответ в `.значение`. Иначе объяснение лежит в `.сообщение`. {{инфо: Нельзя читать `.значение`, не проверив `.успешно`: при неудаче значения нет. Хорошая привычка: сначала проверка, потом чтение.}}

Многие встроенные функции (`подстрока`, `найти`, `прочитать_файл` и
другие) сами возвращают `результат из Т` — обязательно проверяй
`.успешно` перед использованием `.значение`.

## Попробуй сам

Откройте [«Попробовать»](/попробовать) и запустите:

```
функция разделить(целое а, целое б): результат из целого
    если (б == 0)
        вернуть ошибка("деление на ноль");
    конец
    вернуть успех(а / б);
конец

функция главная(): целое
    результат из целого итог = разделить(10, 0);
    если (итог.успешно)
        вывести("Ответ: " + целое_в_текст(итог.значение));
    иначе
        вывести("Ошибка: " + итог.сообщение);
    конец
    вернуть 0;
конец
```

Замените 0 на 2 и убедитесь, что вывод изменится.
