# Структуры

> **Простыми словами.** Структура — это «чертёж» для собственных типов данных. Например, точка на карте состоит из двух чисел, `х` и `у`. Структура собирает их вместе под одним именем, а ещё может иметь свои функции (методы).


```
структура Точка
    целое х;
    целое у;

    функция сумма_координат(): целое
        вернуть это.х + это.у;
    конец
конец
```

- `структура Точка` ... `конец` — описываем новый тип с именем `Точка`.
- `целое х;` и `целое у;` — поля: у каждой точки будут свои `х` и `у`. {{инфо: Поля как ящики в шкафу: шкаф (структура) один, а ящиков внутри несколько, и у каждого своё имя и тип. Значения в них появятся, когда вы создадите точку конкретными числами.}}
- `функция сумма_координат(): целое` — метод: функция, которая живёт внутри структуры и работает с её полями.
- `это.х + это.у` — `это` значит «эта самая точка, у которой вызвали метод». {{инфо: Если у вас две точки, `а` и `б`, то `а.сумма_координат()` посчитает по `а`, а `б.сумма_координат()` по `б`. В обоих случаях код метода один, а `это` указывает на разные объекты.}}

- Поля объявляются как обычные переменные, без значений по умолчанию
- Методы — обычные функции внутри тела структуры
- **`это`** — ссылка на текущий экземпляр внутри метода (аналог
  `self`/`this` в других языках)
- **Конструктор генерируется автоматически**, по всем полям в порядке
  объявления:

```
Точка точка = Точка(3, 4);
вывести(точка.сумма_координат());   // выведет 7
```

- `Точка точка = Точка(3, 4);` — создаём конкретную точку: в `х` кладётся 3, в `у` кладётся 4. Конструктор получает значения в том порядке, в каком объявлены поля.
- `точка.сумма_координат()` — вызов метода: «точка, посчитай свою сумму». Получится 7.

Структуры — всегда объекты в куче (передаются по ссылке), с
автоматическим подсчётом ссылок — см. [ARC](/документация/управление-памятью).

## Слабые ссылки

Поле, объявленное как `слабая Тип`, не увеличивает счётчик ссылок —
нужно для разрыва циклических ссылок (например, родитель ↔ потомок):

```
структура Цель
    текст имя;
конец

структура Держатель
    текст имя;
    слабая Цель цель;    // не увеличивает счётчик ссылок "Цель"
конец

функция главная(): целое
    Цель цель = Цель("моя цель");
    Держатель держатель = Держатель("держатель", цель);
    вывести(держатель.цель.имя);
    вернуть 0;
конец
```

## Проверка живости
Что здесь происходит: `Держатель` хранит ссылку на `Цель`, но слово `слабая` значит «не удерживай её в памяти». {{инфо: Обычно пока на объект кто-то ссылается, он живёт в памяти. Если два объекта ссылаются друг на друга, оба никогда не освободятся: каждый держит другого. Слабая ссылка разрывает такой круг: она смотрит на объект, но не мешает его освободить. Это тема для продвинутых, новичкам она пока не нужна.}}

## Проверка живости — `.жива()`

Перед обращением к цели через слабую ссылку можно (и нужно) проверить,
не была ли она уже освобождена — метод `жива()` доступен на любом
доступе к полю, объявленному как `слабая`:

```
если (держатель.цель.жива())
    вывести(держатель.цель.имя);
иначе
    вывести("цель уже освобождена");
конец
```

Работает безопасно даже после того, как цель "логически" умерла (её
счётчик сильных ссылок дошёл до нуля) — пока жива хотя бы одна слабая
ссылка на неё, компилятор откладывает реальное освобождение памяти
именно для того, чтобы `жива()` могла её безопасно проверить, не
рискуя обращением к уже переиспользованной памяти. Как только
последняя слабая ссылка тоже перестаёт существовать — отложенное
освобождение происходит немедленно.

## Попробуй сам

Откройте [«Попробовать»](/попробовать) и запустите:

```
структура Точка
    целое х;
    целое у;

    функция сумма_координат(): целое
        вернуть это.х + это.у;
    конец
конец

функция главная(): целое
    Точка точка = Точка(3, 4);
    вывести(целое_в_текст(точка.сумма_координат()));
    точка.х = 10;
    вывести(целое_в_текст(точка.сумма_координат()));
    вернуть 0;
конец
```

Должно получиться 7 и потом 14. Добавьте метод `произведение()`.
