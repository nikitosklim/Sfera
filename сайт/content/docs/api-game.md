# Модуль «игра»

> **Простыми словами.** Библиотека для игр, которые запускаются прямо в браузере. Вы рисуете фигуры и текст на холсте, спрашиваете, какие клавиши нажаты, и описываете один кадр игры. Браузер сам вызывает ваш кадр около 60 раз в секунду. Готовую игру можно выложить на itch.io: игрокам ничего не надо устанавливать.

Подключается строкой `подключить игра`. Игра собирается в WebAssembly скриптом `собрать-игру.sh`.

## Минимальная игра

```
подключить игра

целое х = 40
целое скорость = 3

функция кадр()
    очистить(10, 10, 40)
    цвет(255, 200, 0)
    круг(х, 100, 20)
    х = х + скорость
    если (х больше 600 или х меньше 40)
        скорость = 0 - скорость
        звук(440, 50)
    конец
конец

функция главная()
    холст(640, 360)
    запустить_игру("кадр")
конец
```

- `холст(640, 360)` задаёт размер игрового поля в пикселях.
- `запустить_игру("кадр")` говорит браузеру: «вызывай функцию `кадр` каждый кадр». Функция без параметров.
- Состояние игры (`х`, `скорость`) хранится в [глобальных переменных](/документация/переменные), потому что `кадр` вызывается снова и снова.

## Рисование

| Функция | Что делает |
|---|---|
| `холст(ширина, высота)` | размер поля, вызывается один раз |
| `цвет(к, з, с)` | цвет следующих фигур, каждая составляющая от 0 до 255 |
| `очистить(к, з, с)` | закрашивает всё поле, обычно первая команда кадра |
| `прямоугольник(х, у, ширина, высота)` | закрашенный прямоугольник |
| `круг(х, у, радиус)` | закрашенный круг с центром в (х, у) |
| `линия(х1, у1, х2, у2, толщина)` | отрезок |
| `надпись(текст, х, у, размер)` | текст с левым верхним углом в (х, у) |

Начало координат в левом верхнем углу: `х` растёт вправо, `у` растёт вниз.

## Ввод

| Функция | Что делает |
|---|---|
| `клавиша("влево")` | `да`, пока клавиша зажата |
| `клавиша_нажата("пробел")` | `да` один раз на нажатие |
| `мышь_х()`, `мышь_у()` | положение мыши на поле |
| `мышь_зажата()` | зажата ли левая кнопка или палец на экране |
| `мышь_нажата()` | был ли клик с прошлого кадра |

Имена клавиш: `"влево"`, `"вправо"`, `"вверх"`, `"вниз"`, `"пробел"`, `"ввод"`, `"escape"`, а также латинские буквы и цифры: `"a"`, `"w"`, `"1"`.

## Ход игры, звук и рекорды

- `случайное(до)` — случайное число от 0 до `до - 1`.
- `время_мс()` — миллисекунды с начала игры. Удобно, если змейка должна двигаться раз в 110 мс, а не каждый кадр.
- `звук(частота, мс)` — короткий звук, например `звук(440, 100)`.
- `сохранить("имя", число)` и `взять_сохранённое("имя")` — запомнить число в браузере (рекорд) и прочитать его. Нет значения — вернёт 0.

## Игра по сети

Игра в браузере может общаться с сервером на Сфере по WebSocket. Серверная часть описана в [модуле «вебсокет»](/документация/справочник-вебсокет).

| Функция | Что делает |
|---|---|
| `соединиться("ws://localhost:9001")` | начинает подключение к серверу в фоне |
| `соединено()` | `да`, когда можно отправлять сообщения |
| `соединение_закрыто()` | `да`, если сервер недоступен или отключился |
| `отправить_серверу("текст")` | отправляет сообщение |
| `есть_сообщение()` | пришло ли сообщение, которое ещё не прочитано |
| `прочитать_сообщение()` | берёт следующее сообщение, сообщения идут по порядку |
| `разорвать_соединение()` | закрывает соединение |

Пример: `игры/общий-холст.код` (клиент) вместе с `игры/чат-сервер.код` (сервер). Клик по полю отправляет точку серверу, а сервер рассылает её всем игрокам.

Игра на itch.io, которой нужен сервер, работает только пока этот сервер запущен и доступен по адресу, а страница игры открыта по `https://` может подключаться только к `wss://`. Для первых экспериментов запускайте сервер на своём компьютере.

## Как выложить игру на itch.io

1. Соберите игру: `./собрать-игру.sh игры/змейка.код`.
2. Получится папка `игры/змейка-веб/` и архив `игры/змейка-веб.zip`.
3. На itch.io создайте проект с типом **HTML**, загрузите zip и отметьте «This file will be played in the browser».

Пример целой игры лежит в файле `игры/змейка.код` в репозитории.
