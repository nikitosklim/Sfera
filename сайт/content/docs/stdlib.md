# Стандартная библиотека

> **Простыми словами.** Стандартная библиотека — набор готовых «инструментов», которые уже встроены в язык: работа с текстом, числами, файлами, временем. Их не нужно подключать и писать самому: вы просто вызываете `длина(...)`, `найти(...)` или `абс(...)`. Ниже они разложены по ящикам по назначению.


## Текст

| Функция | Описание |
|---|---|
| `длина(текст)` | Длина строки в байтах |
| `подстрока(текст, начало, длина)` | Часть строки → `результат из текста` |
| `содержит(текст, подстрока)` | Проверка вхождения → `верно` |
| `найти(текст, подстрока)` | Позиция вхождения → `результат из целого` |
| `регистр_в_верхний(текст)` | В верхний регистр |
| `регистр_в_нижний(текст)` | В нижний регистр |
| `текст_в_целое(текст)` | Разбор числа → `результат из целого` |

- `длина(текст)` считает **байты**, а не буквы: русская буква занимает два байта. {{инфо: Поэтому `длина("Сфера")` — это 10, а не 5. Текст в Сфере хранится в UTF-8, где латинская буква занимает один байт, а кириллическая — два.}}
- `подстрока`, `найти`, `текст_в_целое` возвращают `результат`: они могут не получиться (нет такого места, текст не число). Всегда проверяйте `.успешно`.
- `подстрока(с, 0, 6)` тоже работает в байтах, поэтому от «Привет» она даст «При» (шесть байт — три буквы).

## Преобразование в текст

| Функция | Описание |
|---|---|
| `целое_в_текст(целое)` | Число → текст |
| `дробное_в_текст(дробное)` | Дробное → текст |
| `верно_в_текст(верно)` | `да`/`нет` → текст |

- Чтобы склеить число с текстом, сначала превратите его: `"Возраст: " + целое_в_текст(25)`. {{инфо: Сфера не склеивает текст и число молча: так вы всегда видите, где происходит превращение. Более короткая запись — `"Возраст: %возраст%"` с подстановкой.}}

## Математика

| Функция | Описание |
|---|---|
| `абс(число)` | Модуль числа |
| `мин(а, б)` | Меньшее из двух |
| `макс(а, б)` | Большее из двух |

- Все три работают одинаково: `мин(4, 9)` даёт 4, `макс(4, 9)` даёт 9, `абс(0 - 5)` даёт 5.

## Ввод-вывод

| Функция | Описание |
|---|---|
| `вывести(текст)` | Печать строки на экран |
| `прочитать_строку()` | Чтение строки из консоли → `результат из текста` |
| `прочитать_файл(путь)` | Чтение файла целиком → `результат из текста` |
| `записать_файл(путь, содержимое)` | Запись файла |
| `размер_файла(путь)` | Размер в байтах, без чтения содержимого → `результат из целого` |
| `дописать_в_файл_бинарно(путь, буфер, размер)` | Добавляет байты в конец файла (не через `strlen`, безопасно для бинарных данных) |
| `прочитать_часть_файла(путь, смещение, размер)` | Точечное чтение диапазона байт → `результат из текста` |
| `переименовать_файл(старый, новый)` | Портативная замена файла (C `rename()`) |
| `выполнить_команду(команда)` | Запуск команды операционной системы |
| `аргументы_командной_строки()` | Аргументы запуска программы → `Список из текстов` |

- Функции работы с файлами возвращают `результат`: файла может не быть, диск может быть закрыт на запись. Подробнее — на странице [«Файлы»](/документация/файлы).
- `вывести(...)` печатает строку и переходит на новую; `прочитать_строку()` ждёт, пока пользователь введёт строку и нажмёт Enter.

## Память "по смещению" (для низкоуровневой работы)

| Функция | Описание |
|---|---|
| `прочитать_целое32(буфер, смещение)` | Чтение 4 байт из буфера |
| `записать_целое32(буфер, смещение, значение)` | Запись 4 байт в буфер |
| `прочитать_текст_по_смещению(буфер, смещение)` | Чтение строки по адресу |
| `байт_текста(текст, индекс)` | Чтение одного байта текста (0-255) |
| `прочитать_указатель(буфер, смещение)` | Чтение 8-байтового указателя из памяти |

## Время

| Функция | Описание |
|---|---|
| `юникс_время()` | Текущее unix-время — целые секунды с 1970-01-01 UTC |
| `монотонное_время_нс()` | Монотонные часы, наносекунды — НЕ календарная дата (точка отсчёта произвольная), не переводятся назад при коррекции системного времени; полезна только РАЗНИЦА двух вызовов. Для измерения длительности (см. `трейсинг.код` ниже), не для меток времени в логах. |

## Попробуй сам

Поменяйте строку и посмотрите, как меняются `длина`, `найти` и `подстрока`. Заметьте: русские буквы занимают по два байта.

```попробуй
функция главная(): целое
    текст с = "Привет, Сфера";
    вывести("Байт: " + целое_в_текст(длина(с)));
    вывести(регистр_в_верхний("abc"));
    если (содержит(с, "Сфера"))
        вывести("нашли");
    конец
    результат из целого п = найти(с, "Сфера");
    если (п.успешно)
        вывести("с позиции " + целое_в_текст(п.значение));
    конец
    результат из целого ч = текст_в_целое("123");
    вывести(целое_в_текст(ч.значение + 1));
    результат из целого плохо = текст_в_целое("abc");
    если (не плохо.успешно)
        вывести("не число");
    конец
    вывести(целое_в_текст(мин(4, 9)) + " " + целое_в_текст(макс(4, 9)) + " " + целое_в_текст(абс(0 - 5)));
    результат из текста часть = подстрока(с, 0, 6);
    если (часть.успешно)
        вывести(часть.значение);
    конец
    вернуть 0;
конец
```

## Проверь себя

Ответьте в уме, потом нажмите «показать ответ».

1. Сколько вернёт `длина("Сфера")`? {{ответ: 10: пять русских букв по два байта.}}
2. Как превратить число 25 в текст для склейки со строкой? {{ответ: `целое_в_текст(25)`.}}
3. Почему `текст_в_целое("abc")` не роняет программу? {{ответ: Она возвращает `результат`, у которого `.успешно` равно `нет`; решать, что делать дальше, вы можете сами.}}

## Названия без латиницы

В Сфере всё можно набрать, не переключая раскладку. Поэтому у иностранных сокращений есть русские аналоги: расшифровка переводится на русский, и от неё берутся первые буквы.

| Откуда | Как расшифровывается по-русски | Имя в Сфере |
|---|---|---|
| JSON | Запись Объектов Скрипта | `зос_…`, модуль `зос` |
| HTML | Язык Гипертекстовой Разметки | `…_ягр` |
| SQL | Язык Структурированных Запросов | `…_ясз` |
| SHA | Безопасный Алгоритм Хеширования | `бах1` |
| Base64 | основание 64 | `основание64` |
| UTF-8 | Формат Преобразования Юникода | `…_фпю8` |
| PCI | Межсоединение Периферийных Компонентов | `мпк_…` |
| cookie | печенье | `значение_печенья`, `заголовок_печенья` |
| Unix | юникс | `время_из_юникса` |
| span | участок | `открыть_участок` |

{{инфо: Исключение одно: функции `malloc`, `memcpy`, `strlen` и другие в модуле для голого железа. Они подменяют библиотеку C и обязаны называться так же.}}
