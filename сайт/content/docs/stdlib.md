# Стандартная библиотека


## Текст

| Функция | Описание |
|---|---|
| `длина(текст)` | Длина строки в байтах |
| `подстрока(текст, начало, длина)` | Часть строки → `результат из текста` |
| `содержит(текст, подстрока)` | Проверка вхождения → `верно` |
| `найти(текст, подстрока)` | Позиция вхождения → `результат из целого` |
| `регистр_в_верхний(текст)` | В верхний регистр |
| `регистр_в_нижний(текст)` | В нижний регистр |
| `текст_в_целое(текст)` | Разбор числа → `результат из целого` |

## Преобразование в текст

| Функция | Описание |
|---|---|
| `целое_в_текст(целое)` | Число → текст |
| `дробное_в_текст(дробное)` | Дробное → текст |
| `верно_в_текст(верно)` | `да`/`нет` → текст |

## Математика

| Функция | Описание |
|---|---|
| `абс(число)` | Модуль числа |
| `мин(а, б)` | Меньшее из двух |
| `макс(а, б)` | Большее из двух |

## Ввод-вывод

| Функция | Описание |
|---|---|
| `вывести(текст)` | Печать строки на экран |
| `прочитать_строку()` | Чтение строки из консоли → `результат из текста` |
| `прочитать_файл(путь)` | Чтение файла целиком → `результат из текста` |
| `записать_файл(путь, содержимое)` | Запись файла |
| `размер_файла(путь)` | Размер в байтах, без чтения содержимого → `результат из целого` |
| `дописать_в_файл_бинарно(путь, буфер, размер)` | Добавляет байты в конец файла (не через `strlen`, безопасно для бинарных данных) |
| `прочитать_часть_файла(путь, смещение, размер)` | Точечное чтение диапазона байт → `результат из текста` |
| `переименовать_файл(старый, новый)` | Портативная замена файла (C `rename()`) |
| `выполнить_команду(команда)` | Запуск команды операционной системы |
| `аргументы_командной_строки()` | Аргументы запуска программы → `Список из текстов` |

## Память "по смещению" (для низкоуровневой работы)

| Функция | Описание |
|---|---|
| `прочитать_целое32(буфер, смещение)` | Чтение 4 байт из буфера |
| `записать_целое32(буфер, смещение, значение)` | Запись 4 байт в буфер |
| `прочитать_текст_по_смещению(буфер, смещение)` | Чтение строки по адресу |
| `байт_текста(текст, индекс)` | Чтение одного байта текста (0-255) |
| `прочитать_указатель(буфер, смещение)` | Чтение 8-байтового указателя из памяти |

## Время

| Функция | Описание |
|---|---|
| `юникс_время()` | Текущее unix-время — целые секунды с 1970-01-01 UTC |
| `монотонное_время_нс()` | Монотонные часы, наносекунды — НЕ календарная дата (точка отсчёта произвольная), не переводятся назад при коррекции системного времени; полезна только РАЗНИЦА двух вызовов. Для измерения длительности (см. `трейсинг.код` ниже), не для меток времени в логах. |
