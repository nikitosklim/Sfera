# Веб-сервер (стандартная_библиотека/веб.код)

> **Простыми словами.** Эта библиотека превращает вашу программу в сайт: она принимает запросы от браузера и отдаёт страницы. Сам сайт Сферы написан с её помощью. Ниже список готовых команд; рабочий минимальный сервер разобран по строкам в [уроке «Свой веб-сервер»](/уроки/свой-веб-сервер).


Поверх `сеть.код`: разбор запроса, ответы, шаблоны, отдача файлов.

- `открыть_порт(порт): результат из целого` — слушающий сокет.

Как читать список ниже: слева имя команды, справа что она делает. Если в конце стоит `результат из ...`, значит, команда может не получиться, и результат нужно проверить через `.успешно`.

- `открыть_порт(порт): результат из целого` — слушающий сокет.
- `прочитать_запрос(клиент): результат из Запрос` — поля `метод`, `путь`, `параметры`, `заголовки`, `тело`.
- `ответ_ягр(клиент, код, тело)`, `ответ_текстом`, `перенаправить`, `ответ_файлом(клиент, путь, имя, скачать)` — файл отдаётся кусками по 64 КБ.
- `ответ_файлом_для(клиент, запрос, путь, имя, скачать, кеш)` — докачка (Range), ETag/304, HEAD.
- `ответ_зос`, `зос_строка`, `ответ_с_заголовками`, `значение_печенья`, `заголовок_печенья`.
- `принять_тело_в_файл(клиент, путь, байт)` — тело PUT потоком в файл (для загрузки больших файлов); тело POST-форм до 64 КБ — в `запрос.тело`.
- `подставить(шаблон, имена, значения)` — замена `{{имя}}`; результат нужно освободить `освободить_память`.
- `экранировать_ягр`, `декодировать_адрес`, `параметр`, `путь_безопасен`, `тип_содержимого`.

Пример целиком — папка `сайт/`. В строках `%имя%` — подстановка, поэтому буквальный `%` пишите как `%%`.
