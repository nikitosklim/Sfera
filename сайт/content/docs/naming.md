# Русские названия: как в Сфере пишется HTML, JSON, SQL

> **Простыми словами.** В Сфере всё набирается на русской раскладке: ни `function`, ни `if`, ни `json`. Если в других языках у чего-то английское название или аббревиатура, у нас есть русское имя. Эта страница — словарь: найдите знакомое слово и узнайте, как оно называется в Сфере.

## Правило

Программист на Сфере не должен переключать раскладку посреди строки. Поэтому у всего, что вы вызываете, русское имя. Для иностранных сокращений мы делаем так:

1. Расшифровываем аббревиатуру, например JSON — JavaScript Object Notation.
2. Переводим расшифровку на русский: «Запись Объектов Скрипта».
3. Берём первые буквы: **ЗОС**. В коде пишется строчными: `зос_текст`.

Если у слова есть обычный русский перевод, берём его без сокращения: cookie — это `печенье`.

## Словарь

| В других языках | Как называется в Сфере | Расшифровка |
|---|---|---|
| JSON | `зос` (модуль и приставка `зос_…`) | Запись Объектов Скрипта |
| HTML | `ягр` (окончание `…_ягр`) | Язык Гипертекстовой Разметки |
| SQL | `ясз` (окончание `…_ясз`) | Язык Структурированных Запросов |
| SHA-1 | `бах1` | Безопасный Алгоритм Хеширования |
| Base64 | `основание64` | основание 64 |
| UTF-8 | `фпю8` | Формат Преобразования Юникода |
| PCI | `мпк_…` | Межсоединение Периферийных Компонентов |
| cookie | `печенье` (`значение_печенья`) | перевод слова |
| Unix-время | `юникс` (`время_из_юникса`) | перевод на русскую запись |
| span (участок трассировки) | `участок` (`открыть_участок`) | перевод слова |

## Как в Сфере пишется JSON?

Модуль называется `зос`: `подключить зос;`. Читать значения можно по пути: `зос_текст(данные, "игрок.имя")`. Подробности в [справочнике модуля «зос»](/документация/справочник-зос).

## Как в Сфере пишется HTML?

Сокращение `ягр`. В модуле «веб» это `ответ_ягр(...)` (отправить страницу) и `экранировать_ягр(...)` (защитить текст от разметки). Модуль «разметка» превращает Markdown в страницу функцией `разметка_в_ягр(...)`. См. [справочник «веб»](/документация/справочник-веб) и [справочник «разметка»](/документация/справочник-разметка).

## Как в Сфере пишется SQL?

Сокращение `ясз`. Запрос к базе выполняет `выполнить_ясз(...)`. См. [справочник «база_данных»](/документация/справочник-sqlite).

## Как в Сфере пишется SHA и Base64?

Хеш SHA-1 в модуле «вебсокет» называется `бах1`, а кодирование Base64 — `основание64`. Для SHA-256 будет `бах256`.

## Как в Сфере пишется cookie?

`печенье`: функции `значение_печенья` и `заголовок_печенья` в модуле «веб».

## Что делать, если нужного слова здесь нет

Если вы встретили английское название, которого нет в этом словаре, напишите нам: мы придумаем русское имя и добавим его сюда. Новые функции языка называются по этому же правилу.
