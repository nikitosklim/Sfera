# Основы синтаксиса

> **Простыми словами.** Синтаксис — это «правописание» языка: как писать команды, чтобы компьютер их понял. В Сфере его правил немного: одна команда на строку (`;` не нужна), слово `конец` после блока, комментарии после `//`.


- **Комментарии**: `//` до конца строки, `/* ... */` — многострочные
- **Оператор заканчивается переводом строки**, точка с запятой (`;`) необязательна — подробности ниже
- **Блоки кода** — тело идёт сразу после заголовка и закрывается
  словом `конец` (никакого «начало» и никаких `{ }` не нужно; старая
  запись в фигурных скобках тоже работает — см. раздел
  [«Два способа записи»](/документация/два-способа-записи))
- Язык **полностью кириллический** — все ключевые слова, имена
  встроенных функций и типов пишутся кириллицей

Пример, где все правила работают вместе:

```
// Это комментарий: компьютер его пропускает
функция главная(): целое
    вывести("Привет") /* и это тоже
                          комментарий */
    вернуть 0
конец
```

- `// Это комментарий...` — всё после двух косых черт до конца строки игнорируется. Так оставляют заметки себе и другим.
- `функция главная(): целое` ... `конец` — блок: заголовок и тело. Тело закрывается словом `конец`. {{инфо: Блоки в языках без слова `конец` обычно обозначают фигурными скобками `{ }`. В Сфере этого не нужно: слово `конец` читается по-русски и сразу понятно. Старая запись со скобками тоже работает.}}
- `вывести("Привет")` — команда заканчивается концом строки; точка с запятой необязательна.
- `/* ... */` — комментарий на несколько строк.

### Точка с запятой: можно без неё, можно с ней

Оператор (объявление, присваивание, вызов, `вернуть`, `прервать`, `продолжить`) заканчивается **переводом строки**. Основная запись в Сфере — без `;`:

```
функция главная(): целое
    целое а = 5
    а = а + 1
    вывести(а)
    вернуть 0
конец
```

Старая запись с `;` по-прежнему работает, и стили можно смешивать даже в одной функции. Весь старый код и все пакеты продолжат собираться без изменений:

```
функция главная(): целое
    целое а = 5;
    а = а + 1
    вывести(а);
    вернуть 0
конец
```

**Когда `;` всё же нужна.** Если на одной строке стоят два оператора, между ними ставят `;`:

```
целое х = 1; целое у = 2
```

Без неё компилятор скажет: «после оператора нужен перевод строки или «;»». После последнего оператора на строке `;` не нужна. Перед словами `конец`, `иначе` и `когда` она тоже не нужна, поэтому короткий блок можно записать в одну строку: `если (а > 3) вывести("да") конец`.

**Как переносить длинные выражения.** Если строка заканчивается знаком операции, запятой или открытой скобкой, выражение продолжается на следующей строке:

```
целое итог = первое +
    второе +
    третье

вывести("а", 
    "б")
```

Оператор в начале следующей строки (`+ третье`) продолжением не считается: компилятор решит, что предыдущая команда закончилась. Ставьте знак в конец строки.

**Две ловушки.**
- Строка, которая начинается с `(` или `[`, всегда считается новым оператором, а не продолжением предыдущей строки.
- `вернуть` без значения определяется концом строки: если написать `вернуть`, а значение перенести на следующую строку, функция вернёт пустоту, а значение станет отдельным оператором. Пишите `вернуть значение` в одной строке.

**Что выбрать.** Для нового кода рекомендуется запись без `;`: в документации, уроках и примерах на сайте она используется везде. Запись с `;` остаётся полноценной частью языка. Её можно выбрать по привычке или для старого кода, а переводить старый код не обязательно.
