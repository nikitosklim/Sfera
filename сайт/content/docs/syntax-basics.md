# Основы синтаксиса


- **Комментарии**: `//` до конца строки, `/* ... */` — многострочные
- **Каждый оператор заканчивается точкой с запятой** (`;`)
- **Блоки кода** — тело идёт сразу после заголовка и закрывается
  словом `конец` (никакого «начало» и никаких `{ }` не нужно; старая
  запись в фигурных скобках тоже работает — см. раздел
  [«Два способа записи»](/docs/two-syntaxes))
- Язык **полностью кириллический** — все ключевые слова, имена
  встроенных функций и типов пишутся кириллицей
