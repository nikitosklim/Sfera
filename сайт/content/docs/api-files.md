# Модуль «файлы»

Дополняет встроенные функции работы с файлами (`записать_файл`, `прочитать_файл`, `размер_файла` — они описаны на странице «Встроенные функции»). Чтобы пользоваться модулем, в начале программы напишите:

```
подключить файлы;
```

Слово `подключить` говорит компилятору: «возьми готовые функции из этого модуля, они мне нужны».

## Пример: создать папку, записать файл, проверить, удалить

```
подключить файлы;

функция главная(): целое
    создать_папку("моя_папка");
    записать_файл("моя_папка/привет.txt", "Привет из файла");
    вывести("Файл есть? " + верно_в_текст(файл_существует("моя_папка/привет.txt")));
    удалить_файл("моя_папка/привет.txt");
    удалить_файл("моя_папка");
    вывести("Файл есть после удаления? " + верно_в_текст(файл_существует("моя_папка/привет.txt")));
    вернуть 0;
конец
```

**Что выведет программа:**

```
Файл есть? да
Файл есть после удаления? нет
```

Построчно: `создать_папку(...)` делает папку; `записать_файл(...)` кладёт в неё файл; `файл_существует(...)` отвечает `да` или `нет`; `удалить_файл(...)` стирает файл, а потом и пустую папку (одна и та же функция умеет и то и другое).

## Функции

### удалить_файл
`удалить_файл(путь): результат из верного`

Удаляет файл или **пустую** папку. Если что-то пошло не так (нет такого файла, нет прав), `.успешно` будет `нет`, а в `.сообщение` лежит объяснение.

### создать_папку
`создать_папку(путь): результат из верного`

Создаёт одну папку. Папка, в которой вы создаёте, уже должна существовать: сразу `a/b/c` не получится, сначала создайте `a`, потом `a/b`.

### файл_существует
`файл_существует(путь): верно`

Отвечает `да`, если файл можно открыть для чтения, и `нет`, если нельзя.

Пути пишите в обычном виде, русские буквы в них работают, в том числе на Windows.


## Полный список объявлений

Так эти функции объявлены в исходниках модуля:

```
функция удалить_файл(текст путь): результат из верного
функция создать_папку(текст путь): результат из верного
функция файл_существует(текст путь): верно
```
