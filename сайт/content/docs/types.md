# Типы данных


## Целые числа

| Тип | Размер | Знаковый |
|---|---|---|
| `целое` | 64 бита | да |
| `целое8` | 8 бит | да |
| `целое16` | 16 бит | да |
| `целое32` | 32 бита | да |
| `целое64` | 64 бита | да (то же, что `целое`) |
| `беззнак8` | 8 бит | нет |
| `беззнак16` | 16 бит | нет |
| `беззнак32` | 32 бита | нет |
| `беззнак64` | 64 бита | нет |

⚠️ **Важно**: типы разной разрядности **не смешиваются неявно** —
`целое32` и `целое` в одном выражении требуют явного приведения:

```
целое32 а = 5;
целое б = 10;
целое итог = целое(а) + б;   // явное приведение обязательно
```

## Дробные числа

`дробное` (по умолчанию, 64 бита), `дробное32`, `дробное64`.

## Текст

`текст` — строка. Литералы в двойных кавычках: `"привет"`.
Конкатенация — оператором `+`:

```
текст имя = "Аня";
текст приветствие = "Привет, " + имя + "!";
```

Экранированные последовательности внутри строк: `\n` (новая строка),
`\r` (возврат каретки — важно для сетевых протоколов вроде HTTP, где
строки заголовков разделяются именно парой `\r\n`), `\t` (табуляция),
`\"` (кавычка), `\\` (обратный слеш).

## Логический тип

`верно` — булев тип. Литералы: `да` (истина) и `нет` (ложь) —
**не** `true`/`false`.

```
верно готово = да;
если (готово)
    вывести("Готово!");
конец
```
