# Типы данных

> **Простыми словами.** Тип данных — это «вид» значения: число, текст или «да/нет». Тип говорит компьютеру, сколько места занять и что с этим значением можно делать. Для начала вам нужны четыре типа: `целое`, `дробное`, `текст` и `верно`. Остальные нужны, когда важна точность размера, например в драйверах.


## Целые числа

| Тип | Размер | Знаковый |
|---|---|---|
| `целое` | 64 бита | да |
| `целое8` | 8 бит | да |
| `целое16` | 16 бит | да |
| `целое32` | 32 бита | да |
| `целое64` | 64 бита | да (то же, что `целое`) |
| `беззнак8` | 8 бит | нет |
| `беззнак16` | 16 бит | нет |
| `беззнак32` | 32 бита | нет |
| `беззнак64` | 64 бита | нет |

⚠️ **Важно**: типы разной разрядности **не смешиваются неявно** —
`целое32` и `целое` в одном выражении требуют явного приведения:

```
целое32 а = 5;
целое б = 10;
целое итог = целое(а) + б;   // явное приведение обязательно
```

- `целое32 а = 5;` — число, которое занимает 32 бита (маленькая коробка). `целое б = 10;` — обычная коробка на 64 бита. {{инфо: Бит — одна цифра двоичной записи, 0 или 1. Чем больше бит, тем большие числа влезают: в 32 бита до примерно 2 миллиардов, в 64 бита до примерно 9 квинтиллионов. Для школьных задач хватает обычного `целое`.}}
- `целое(а)` — «превратить число `а` в обычное целое». Разные коробки без явного превращения не складываются: так компилятор защищает вас от неожиданных потерь.

## Дробные числа

`дробное` (по умолчанию, 64 бита), `дробное32`, `дробное64`.

## Текст

`текст` — строка. Литералы в двойных кавычках: `"привет"`.
Конкатенация — оператором `+`:

```
текст имя = "Аня";
текст приветствие = "Привет, " + имя + "!";
```

Знак `+` между текстами склеивает их: получится «Привет, Аня!». Склеивать можно только текст с текстом, числа сначала превращают через `целое_в_текст`.

Экранированные последовательности внутри строк: `\n` (новая строка),
`\r` (возврат каретки — важно для сетевых протоколов вроде HTTP, где
строки заголовков разделяются именно парой `\r\n`), `\t` (табуляция),
`\"` (кавычка), `\\` (обратный слеш).

## Логический тип

`верно` — булев тип. Литералы: `да` (истина) и `нет` (ложь) —
**не** `true`/`false`.

```
верно готово = да;
если (готово)
    вывести("Готово!");
конец
```

Условие `если (готово)` срабатывает, когда в переменной `да`. Писать `готово == да` не нужно: переменная и так хранит нужный ответ.

## Попробуй сам

Откройте [«Попробовать»](/попробовать) и запустите:

```
функция главная(): целое
    целое возраст = 12;
    дробное рост = 1.5;
    текст имя = "Аня";
    верно ученица = да;
    вывести("Меня зовут " + имя + ", мне " + целое_в_текст(возраст));
    вернуть 0;
конец
```

Попробуйте заменить `целое возраст = 12;` на `целое возраст = "двенадцать";` и посмотрите, как компилятор сообщит об ошибке типа.
