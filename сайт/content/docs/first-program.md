# Первая программа


```
функция главная(): целое
    вывести("Привет, мир!");
    вернуть 0;
конец
```

Каждая программа обязана иметь функцию `главная`, возвращающую `целое`
(код завершения — `0` означает успех). Компилируется командой:

```bash
запустить привет.код -c
```

⚠️ **Без `-c` программа не только соберётся, но и сразу запустится** —
удобно для быстрой проверки. Флаг `-c` можно писать и кириллицей, как
`-с` (по первой букве слова "собрать") — оба варианта равнозначны и
работают одинаково. Внешне кириллическая "с" и латинская "c" выглядят
неотличимо на экране, но для компьютера это разные символы — поэтому
поддержаны **оба**, а не только один, чтобы привычная латинская `-c`
(как почти везде в мире разработки) продолжала работать без сюрпризов.
То же самое верно для `-b`/`-б` (`--библиотека`).
