# Управляющие конструкции

> **Простыми словами.** Управляющие конструкции — это «развилки» и «повторения». `если` выбирает, что делать, `пока` повторяет, пока условие верно, `для каждого` обходит набор по одному элементу. Слова `прервать` и `продолжить` помогают выйти из повторения раньше времени.


## Условие

```
если (х больше 10)
    вывести("Больше десяти")
иначе если (х больше 0)
    вывести("Положительное")
иначе
    вывести("Ноль или отрицательное")
конец
```

Сверху вниз: если `х больше 10`, выполняется первая строка. Иначе проверяется `х больше 0`. Иначе (ни одно условие не подошло) выполняется последняя ветка. Цепочка закрывается одним `конец`. {{инфо: Как только какое-то условие верно, остальные ветки пропускаются целиком. Поэтому порядок проверок важен: идите от самых «узких» условий к самым широким.}}

## Цикл с условием

```
целое счётчик = 0
пока (счётчик меньше 5)
    вывести(целое_в_текст(счётчик))
    счётчик = счётчик + 1
конец
```

- `целое счётчик = 0` — начальное значение.
- `пока (счётчик меньше 5)` — перед каждым кругом проверяем условие.
- `счётчик = счётчик + 1` — шаг: без него цикл бесконечен. {{инфо: Бесконечный цикл можно остановить сочетанием клавиш Ctrl+C в терминале.}}

## Цикл по коллекции

```
целое(3) числа = массив(1, 2, 3)
для каждого элемент в числа
    вывести(целое_в_текст(элемент))
конец
```

Работает
- `целое(3) числа = массив(1, 2, 3)` — массив из трёх целых чисел.
- `для каждого элемент в числа` — на каждом круге в `элемент` попадает очередное число: 1, потом 2, потом 3. Счётчик заводить не нужно.

Работает и с `Список из T` — тип переменной цикла выводится автоматически
из типа элемента списка:

```
Список из целых числа = Список из целых()
числа.добавить(1)
числа.добавить(2)
для каждого элемент в числа
    вывести(целое_в_текст(элемент))
конец
```

## Досрочный выход и переход к следующей итерации

`прервать` — немедленно выходит из ближайшего охватывающего цикла
(`пока` или `для каждого`). `продолжить` — пропускает остаток тела
текущей итерации и переходит к следующей (для `для каждого` — к
следующему элементу).

```
целое i = 0
пока (i меньше 100)
    i = i + 1
    если (i % 2 == 0)
        продолжить // пропустить чётные
    конец
    если (i больше 10)
        прервать // остановиться после 10
    конец
    вывести(целое_в_текст(i))
конец
```

Оба ключевых слова действуют только на САМЫЙ БЛИЖНИЙ охватывающий
цикл — во вложенных циклах `прервать` не выходит из внешнего, только
из внутреннего. Использование вне цикла — ошибка компиляции.

⚠️ **Честное ограничение**: тело `параллельно ... конец` компилируется в
отдельную функцию (см. раздел «Многопоточность») — `прервать`/
`продолжить` внутри него могут относиться только к циклу, объявленному
НЕПОСРЕДСТВЕННО внутри того же блока `параллельно`, не к циклу снаружи
него.

## Попробуй сам

Откройте [«Попробовать»](/попробовать) и запустите:

```
функция главная(): целое
    целое i = 1
    пока (i не больше 10)
        если (i % 2 == 0)
            вывести(целое_в_текст(i) + " чётное")
        конец
        i = i + 1
    конец
    вернуть 0
конец
```

Измените условие, чтобы выводились нечётные числа.
