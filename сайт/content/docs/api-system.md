# Модуль «система»

> **Простыми словами.** Модуль отвечает на вопросы «что за компьютер?» и «что лежит в этой папке?»: сколько памяти, какой процессор и система, сколько места на диске, какие файлы и папки в каталоге. Он нужен программам-проводникам, мониторингу и панелям сервера.

Подключается строкой `подключить система`. **Работает только на Linux x86_64** (для macOS и Windows внутри системы другие структуры, поэтому модуль там не заработает).

## Функции

| Функция | Что делает |
|---|---|
| `список_папки(путь)` | содержимое папки → `результат из Список из ЗаписьПапки` (сначала папки, потом файлы, по алфавиту) |
| `это_папка(путь)` | `да`, если путь — папка |
| `сведения_о_системе(путь_диска)` | параметры компьютера одним ЗОС-текстом |
| `прочитать_системный_файл(путь)` | читает файл кусками, в том числе «виртуальные» файлы Linux (`/proc/meminfo`), у которых размер 0 и которые обычная `прочитать_файл` не читает |

Запись папки — структура `ЗаписьПапки` с полями `имя`, `папка` (`да`/`нет`), `размер` (байты) и `изменён` (юникс-секунды, их легко превратить в дату модулем «время»).

## Что возвращает `сведения_о_системе`

Поля ЗОС: `хост`, `ос`, `ядро`, `процессор`, `ядер`, `память_всего_кб`, `память_доступно_кб`, `своп_всего_кб`, `своп_свободно_кб`, `диск_всего` и `диск_свободно` (байты), `время_работы_сек`, `нагрузка` (за 1, 5 и 15 минут), `время_сервера`. Читать их удобно через модуль «зос»: `зос_целое(сведения, "ядер")`.

## Пример

```сфера
подключить система
подключить файлы

функция главная()
    создать_папку("/tmp/пример_система")
    записать_файл("/tmp/пример_система/заметка.txt", "привет")
    результат из Список из ЗаписьПапки л = список_папки("/tmp/пример_система")
    Список из ЗаписьПапки з = л.значение
    ЗаписьПапки первая = з.получить(0)
    вывести("%(первая.имя)%, байт: %(первая.размер)%")
    удалить_файл("/tmp/пример_система/заметка.txt")
    удалить_файл("/tmp/пример_система")
конец
```

```
заметка.txt, байт: 12
```

## Что важно знать

- Имена сортируются побайтово, регистр учитывается: заглавные буквы идут раньше строчных.
- Значения, которых система не дала, возвращаются как 0 или пустой текст, а не как ошибка.
- Модуль читает только то, что доступно пользователю, от которого запущена программа.
