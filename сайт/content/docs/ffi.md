# Внешние функции (FFI)

> **Простыми словами.** Вокруг вас огромный мир готовых библиотек, написанных на языке C: работа с сетью, графикой, базами данных. Внешняя функция — это «дверь» из Сферы в такую библиотеку. Вы говорите: «Вот функция, она называется так-то, принимает такое-то и возвращает такое-то», — и после этого вызываете её как обычную.


Позволяет вызывать функции из C-библиотек напрямую:

```
внешняя функция получить_переменную_окружения(текст имя): текст как "getenv";
```

Строка после `как` — настоящее имя символа в библиотеке (если
совпадает с именем в Сфере, можно опустить).

- `внешняя функция` — объявляем, что тело функции написано не здесь.
- `получить_переменную_окружения(текст имя): текст` — так функция будет называться у вас, с какими параметрами и что вернёт. {{инфо: Типы нужно указать верно: компилятор не может проверить, что на самом деле лежит в библиотеке. Если сказать, что функция возвращает `текст`, а она возвращает число, программа поведёт себя непредсказуемо.}}
- `как "getenv"` — настоящее имя из библиотеки C. Сфера на самом деле вызовет именно `getenv`.

Если на Windows функция называется иначе, укажите второе имя через запятую.
При нативной сборке на Windows используется оно, на остальных платформах —
первое:

```
внешняя функция закрыть_сокет(целое32 сокет): целое32 как "close", "sfera_win_close";
```

Так устроена сетевая библиотека (`сайт/сеть.код`): под Windows подключаются
обёртки Winsock из `рантайм_windows/pthread_win.c`, а код на «Сфере» остаётся
одним для всех платформ.

- Два имени после `как` — это «имя на всех системах, кроме Windows» и «имя на Windows». {{инфо: Одна и та же вещь в разных системах нередко называется по-разному. Два имени позволяют написать программу один раз и не думать о системе.}}

## Попробуй сам

Читаем переменную окружения `HOME` — домашнюю папку пользователя. Попробуйте другие названия: `PATH`, `USER`. Эта программа обращается к системе, поэтому запускайте её у себя на компьютере (`запустить программа.код`), а не в браузерной площадке.

```
внешняя функция получить_переменную_окружения(текст имя): текст как "getenv";

функция главная(): целое
    текст дом = получить_переменную_окружения("HOME");
    вывести("Домашняя папка: " + дом);
    вернуть 0;
конец
```

## Проверь себя

Ответьте в уме, потом нажмите «показать ответ».

1. Что значит строка после слова `как`? {{ответ: Настоящее имя функции в библиотеке C. В Сфере вы вызываете её под своим именем, а компилятор подставляет настоящее.}}
2. Зачем два имени через запятую? {{ответ: Первое используется на всех системах, кроме Windows, второе — на Windows, где та же функция может называться иначе.}}
3. Что будет, если указать неверный тип результата? {{ответ: Компилятор не сможет это проверить — поведение будет непредсказуемым. За верность типов отвечаете вы.}}
