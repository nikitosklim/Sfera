# Внешние функции (FFI)


Позволяет вызывать функции из C-библиотек напрямую:

```
внешняя функция получить_переменную_окружения(текст имя): текст как "getenv";
```

Строка после `как` — настоящее имя символа в библиотеке (если
совпадает с именем в Сфере, можно опустить).

Если на Windows функция называется иначе, укажите второе имя через запятую.
При нативной сборке на Windows используется оно, на остальных платформах —
первое:

```
внешняя функция закрыть_сокет(целое32 сокет): целое32 как "close", "sfera_win_close";
```

Так устроена сетевая библиотека (`сайт/сеть.код`): под Windows подключаются
обёртки Winsock из `рантайм_windows/pthread_win.c`, а код на «Сфере» остаётся
одним для всех платформ.
