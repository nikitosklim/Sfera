# Markdown в HTML (стандартная_библиотека/разметка.код)


`подключить разметка;` — `markdown_в_html(текст)`, `оглавление_html(текст)`, `заголовок_документа(текст)`.
Поддержаны заголовки, абзацы, списки, цитаты, таблицы, блоки кода (с подсветкой «Сферы»), `код`, **жирный**, *курсив*, ссылки.
Сырой HTML из исходника экранируется. Результаты — в куче, освобождает вызывающий (`освободить_память`).
