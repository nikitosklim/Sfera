# Markdown в HTML (стандартная_библиотека/разметка.код)

> **Простыми словами.** Markdown — простой способ писать текст со структурой: `# Заголовок`, `**жирный**`, списки. Эта библиотека превращает такой текст в готовую HTML-страницу. Именно так устроены уроки и документация на этом сайте.


`подключить разметка` — `разметка_в_ягр(текст)`, `оглавление_ягр(текст)`, `заголовок_документа(текст)`.
Поддержаны заголовки, абзацы, списки, цитаты, таблицы, блоки кода (с подсветкой «Сферы»), `код`, **жирный**, *курсив*, ссылки.
Сырой HTML из исходника экранируется. Результаты — в куче, освобождает вызывающий (`освободить_память`).

Как это выглядит в коде:

```
подключить разметка

функция главная(): целое
    текст html = разметка_в_ягр("# Привет\n\nЭто **важно**.")
    вывести(html)
    освободить_память(html)
    вернуть 0
конец
```

- `разметка_в_ягр(...)` — берёт текст с разметкой и возвращает HTML: заголовок станет тегом `<h1>` (с автоматическим номером-якорем), звёздочки превратят слово в жирное.
- `освободить_память(html)` — результат лежит в памяти, которую вы получили от функции, поэтому после использования её нужно вернуть. {{инфо: Функции вроде `разметка_в_ягр` выделяют память под ответ. Освободить её может только тот, кто её использовал, то есть вы.}}
