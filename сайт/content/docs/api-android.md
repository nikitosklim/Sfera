# Модуль «приложение_android»

Простой способ сделать приложение для телефона: вы рисуете кадры и реагируете на касания, а модуль берёт на себя окно, события и показ. Подключается строкой `подключить приложение_android;`. Тот же код запускается и на компьютере (в окне SDL2), и на телефоне.

> **Простыми словами.** Приложение — это цикл. В каждом витке вы читаете касания, двигаете то, что нужно, рисуете всё заново и показываете кадр.

## Каркас приложения

```
подключить приложение_android;

функция главная(): целое
    Приложение п = начать_приложение(40);
    целое счёт = 0;

    пока (п.работает)
        целое ев = ждать_событие(п);
        пока (ев != 0)
            если (ев == 1)
                счёт = счёт + 1;
            конец
            ев = ждать_событие(п);
        конец

        начать_кадр(п, 18, 22, 40);
        написать(п, "Касаний: " + целое_в_текст(счёт), 40, 60, 255, 255, 255);
        если (п.нажато)
            круг(п, п.х, п.у, 24, 80, 200, 255);
        конец
        показать_кадр(п);
    конец
    закончить_приложение(п);
    вернуть 0;
конец
```

Как это читать:

- `начать_приложение(размер_шрифта)` открывает окно и возвращает структуру `Приложение` с полями `ширина`, `высота`, `работает`, `нажато`, `х`, `у`.
- `ждать_событие(п)` отдаёт событие по одному; `0` — события кончились. Значение `1` — касание.
- `начать_кадр(п, красный, зелёный, синий)` заливает фон цветом (числа от 0 до 255).
- `показать_кадр(п)` выводит всё нарисованное на экран.

## Что можно рисовать

Цвет везде задаётся тремя числами 0–255 в конце.

- `прямоугольник(п, х, у, ширина, высота, к, з, с)` и `плитка(…)` — с округлёнными углами.
- `круг(п, х, у, радиус, к, з, с)`, `линия(п, х1, у1, х2, у2, к, з, с)`.
- `написать(п, строка, х, у, к, з, с)` — текст.
- `внутри_прямоугольника(х, у, пх, пу, ширина, высота)` — попало ли касание (х, у) в область: основа для кнопок.

## Сборка для телефона

```
сфера собрать-android программа.код --имя "Моя игра"
```

На компьютере для проверки: `запустить программа.код --линковать SDL2 --линковать SDL2_ttf --линковать m`. Полный пример игры лежит в `examples/android/касания.код`.


## Все функции и структуры

Полный список из исходников модуля. Пояснения взяты из комментариев к функциям.

### Модуль «приложение_android»

- `внешняя функция указатель_в_число(текст р): целое64` — Указатели SDL хранятся в структуре как числа: поле типа «текст» язык копирует как строку, и настоящий указатель терялся бы (тот же приём, что в панели Android).
- `внешняя функция число_в_указатель(целое64 н): текст`
- `структура Приложение`
- `функция окно_п(Приложение п): текст`
- `функция холст_п(Приложение п): текст`
- `функция буфер_п(Приложение п): текст`
- `функция шрифт_п(Приложение п): текст`
- `функция начать_приложение(целое размер_шрифта): Приложение` — Открывает окно на весь экран и загружает шрифт указанного размера (в пикселях; для телефона 28–40).
- `функция ждать_событие(Приложение п): целое` — Берёт одно событие из очереди. Возвращает: 0 — событий нет; 1 — палец коснулся (х, у в п.х, п.у); 2 — палец движется; 3 — палец убран; 4 — окно закрывается (п.работает станет «нет»); 5 — другое событие (можно пропустить). Вызывать нужно в цикле, пока не вернётся 0, иначе события копятся.
- `функция начать_кадр(Приложение п, целое к, целое з, целое с): целое` — Заливает весь экран цветом (красный, зелёный, синий — от 0 до 255) — так начинается каждый кадр.
- `функция показать_кадр(Приложение п): целое` — Выводит нарисованное на экран и ждёт до следующего кадра (около 60 кадров в секунду).
- `функция прямоугольник(Приложение п, целое х, целое у, целое ширина, целое высота, целое к, целое з, целое с): целое` — Закрашенный прямоугольник.
- `функция плитка(Приложение п, целое х, целое у, целое ширина, целое высота, целое радиус, целое к, целое з, целое с): целое` — Прямоугольник со скруглёнными углами (радиус — в пикселях).
- `функция круг(Приложение п, целое х, целое у, целое радиус, целое к, целое з, целое с): целое` — Закрашенный круг с центром (х, у).
- `функция линия(Приложение п, целое х1, целое у1, целое х2, целое у2, целое к, целое з, целое с): целое` — Линия толщиной в один пиксель.
- `функция написать(Приложение п, текст строка, целое х, целое у, целое к, целое з, целое с): целое` — Надпись с левым верхним углом в (х, у). Кириллица работает.
- `функция внутри_прямоугольника(целое х, целое у, целое пх, целое пу, целое ширина, целое высота): верно` — Попадает ли точка (х, у) в прямоугольник — для кнопок и нажатий.
- `функция закончить_приложение(Приложение п): целое` — Закрывает окно.
