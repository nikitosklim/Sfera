# Быстрый старт

За десять минут вы установите «Сферу», напишете первую программу и запустите её. Весь язык — на русском: ключевые слова, типы, стандартная библиотека. Набирать код можно, не переключая раскладку.

> **Простыми словами.** Программа — это текстовый файл с инструкциями. Компилятор `запустить` читает этот файл, превращает его в команды для процессора и запускает. Вам нужен только текстовый редактор и одна команда в терминале.

## Что понадобится

- Windows 10/11, Linux или macOS.
- Любой текстовый редактор. Подсветку и подсказки в редакторах даёт языковой сервер `сфера_lsp` из репозитория.
- Файлы с программами имеют расширение `.код`, кодировка — UTF-8.

## Установка

**Windows.** Скачайте установщик в разделе [«Загрузки»](/загрузки) либо возьмите исходники с [GitHub](https://github.com/nikitosklim/Sfera) и запустите от имени администратора скрипт `установить-windows.ps1`. Он ставит Rust, LLVM и всё нужное, собирает компилятор и добавляет в `PATH` команду `запустить`.

**Linux и macOS.** Нужны Rust и LLVM 18 (переменная `LLVM_SYS_180_PREFIX` должна указывать на его установку):

```bash
git clone https://github.com/nikitosklim/Sfera
cd Sfera
./собрать.sh
```

Скрипт соберёт компилятор и положит команду `запустить` в `/usr/local/bin`, а стандартную библиотеку — в `/usr/local/lib/sfera`.

Проверьте установку: команда `запустить` без аргументов напечатает подсказку по использованию.

## Первая программа

Создайте файл `привет.код`:

```сфера
функция главная()
    вывести("Привет, мир!")
конец
```

Здесь всего три важные вещи:

- каждая программа начинается с функции `главная`; {{инфо: Если вы хотите, чтобы программа сообщала системе «код завершения», пишите `функция главная(): целое` и в конце `вернуть 0`. Ноль — успех, любое другое число — ошибка. Скрипты и сборка читают этот код. Для первых программ он не нужен, поэтому здесь его нет.}}
- блок закрывается словом `конец` — открывающей скобки нет; {{инфо: Вместо фигурных скобок, как в C, мы пишем слово `конец`. Так проще читать: сразу видно, что блок закончился.}}
- каждая команда пишется на своей строке, точка с запятой в конце не нужна. {{инфо: Команда заканчивается там, где заканчивается строка. Если вы привыкли к другим языкам и хотите ставить `;`, ставьте: обе записи правильные. Два оператора в одной строке нужно разделять `;`.}}

Разберём по строкам:

- `функция главная()` — объявляем функцию с именем `главная`; пустые скобки значат, что на вход ей ничего не нужно.
- `вывести("Привет, мир!")` — печатаем строку на экран.
- `конец` — закрываем функцию.

## Запуск и сборка

```bash
запустить привет.код
```

Эта команда собирает программу и сразу запускает её. Чтобы только собрать исполняемый файл, добавьте флаг `-c` (подойдёт и кириллическая `-с`, либо `--только-собрать`):

```bash
запустить привет.код -c
```

Рядом появится готовый исполняемый файл `привет` (на Windows — `привет.exe`), который можно запускать без компилятора.

## Строки с подстановкой

Внутри строки можно вставлять значения переменных через `%имя%`, а произвольные выражения — через `%(выражение)%`. Сам знак процента пишется как `%%`.

```сфера
функция главная(): целое
    целое возраст = 30
    дробное рост = 1.82
    текст имя = "Никита"
    верно студент = нет
    вывести("Имя: %имя%")
    вывести("Возраст: %возраст%, рост: %рост%")
    вывести("Студент: %студент%")
    вывести("Через 5 лет: %(возраст + 5)%")
    вернуть 0
конец
```

Построчно: `%имя%` заменяется значением переменной `имя`, а `%(возраст + 5)%` — результатом вычисления. {{инфо: Если нужен сам знак процента, пишите `%%`. Например, `"Скидка 10%%"` выведет «Скидка 10%».}}

Результат:

```
Имя: Никита
Возраст: 30, рост: 1.820000
Студент: нет
Через 5 лет: 35
```

## Попробуй сам

Поменяйте имя и возраст, добавьте новую переменную и выведите её. Если что-то написано неверно, компилятор объяснит по-русски, что не так.

```попробуй
функция главная(): целое
    целое возраст = 30
    дробное рост = 1.82
    текст имя = "Никита"
    верно студент = нет
    вывести("Имя: %имя%")
    вывести("Возраст: %возраст%, рост: %рост%")
    вывести("Студент: %студент%")
    вывести("Через 5 лет: %(возраст + 5)%")
    вернуть 0
конец
```

## Проверь себя

Ответьте в уме, потом нажмите «показать ответ».

1. С какой функции начинается программа? {{ответ: С функции `главная`.}}
2. Какое слово закрывает блок? {{ответ: `конец`.}}
3. Как вставить выражение `возраст + 5` в строку? {{ответ: `%(возраст + 5)%`.}}
4. Как только собрать программу, не запуская? {{ответ: Добавить флаг `-c`: `запустить привет.код -c`.}}
