# Курс, урок 7. Структуры: свои типы данных

До сих пор у нас были готовые типы: `целое`, `текст`, `Список`. Но мир устроен сложнее. Ученик — это не одно число и не один текст: у него есть имя **и** балл **и** класс. Хранить это в трёх отдельных списках неудобно: легко перепутать, чей балл лежит под номером 3.

Для этого в Сфере есть **структуры**: вы сами придумываете новый тип и собираете в него нужные части.

> **Простыми словами.** Структура — это анкета. В анкете есть графы («Имя», «Балл»), а каждый заполненный бланк — один конкретный человек.

## Первая структура

```сфера
структура Ученик
    текст имя
    целое балл
конец

функция главная()
    Ученик а = Ученик("Аня", 95)
    вывести("%(а.имя)% набрала %(а.балл)% баллов")
    а.балл = 100
    вывести("Теперь %(а.балл)%")
конец
```

```
Аня набрала 95 баллов
Теперь 100
```

Разберём:

- `структура Ученик ... конец` — описываем новый тип. Это чертёж, самих учеников пока нет. {{инфо: Имя типа принято писать с большой буквы: `Ученик`, `Точка`. Так сразу видно, где тип, а где переменная.}}
- `текст имя` и `целое балл` — **поля**: графы анкеты. У каждого ученика они свои.
- `Ученик а = Ученик("Аня", 95)` — заводим переменную типа `Ученик` и заполняем бланк. Значения идут в том порядке, в каком поля записаны в описании. {{инфо: Если перепутать порядок, например написать `Ученик(95, "Аня")`, компилятор скажет, что ожидался текст, а получено число. Такие ошибки ловятся ещё до запуска.}}
- `а.имя` — «имя у ученика а». Точка читается как «у».
- `а.балл = 100` — поле можно менять, как обычную переменную.

В тексте с подстановкой вокруг `а.имя` нужны скобки: `%(а.имя)%`. Просто `%а.имя%` Сфера не поймёт.

## Методы: функции внутри структуры

Часто нужно не только хранить данные, но и что-то с ними делать. Функцию можно положить прямо в структуру, тогда она называется **методом**:

```сфера
структура Ученик
    текст имя
    целое балл

    функция оценка(): целое
        если (это.балл не меньше 90)
            вернуть 5
        конец
        если (это.балл не меньше 70)
            вернуть 4
        конец
        вернуть 3
    конец

    функция представиться()
        вывести("%(это.имя)%: %(это.балл)% баллов, оценка %(это.оценка())%")
    конец
конец

функция главная()
    Ученик а = Ученик("Аня", 95)
    Ученик б = Ученик("Борис", 72)
    а.представиться()
    б.представиться()
конец
```

```
Аня: 95 баллов, оценка 5
Борис: 72 баллов, оценка 4
```

- `это` — «тот самый ученик, у которого вызвали метод». Для `а.представиться()` это Аня, для `б.представиться()` — Борис. Код метода один, а `это` каждый раз указывает на своего ученика. {{инфо: Слово `это` — как «я» в анкете: когда Аня говорит «я», она имеет в виду Аню, а когда Борис — Бориса. Метод написан один раз «от первого лица».}}
- `это.оценка()` — внутри одного метода можно вызвать другой.
- Методы вызывают через точку: `а.представиться()`

## Структуры и списки

Структуры особенно хороши в списках: получается целая таблица.

```сфера
структура Ученик
    текст имя
    целое балл
конец

функция лучший(Список из Ученик группа): Ученик
    Ученик л = группа.получить(0)
    для каждого у в группа
        если (у.балл больше л.балл)
            л = у
        конец
    конец
    вернуть л
конец

функция главная()
    Список из Ученик группа = Список из Ученик()
    группа.добавить(Ученик("Аня", 95))
    группа.добавить(Ученик("Вера", 60))
    группа.добавить(Ученик("Борис", 91))
    Ученик л = лучший(группа)
    вывести("Лучший: %(л.имя)%")
    вывести("Всего учеников: %(группа.размер())%")
конец
```

```
Лучший: Аня
Всего учеников: 3
```

Это тот же поиск наибольшего из урока 6, только сравниваем не числа, а поле `балл` у каждого ученика. Функция принимает список учеников и возвращает одного ученика, а не число.

{{инфо: Структура в Сфере — это не копия, а ссылка на один и тот же объект. Если передать ученика в функцию и изменить у него `балл`, он изменится и снаружи. Так же и в списке: `группа.получить(0)` отдаёт того самого ученика, а не его фотографию. Подробности в разделе про [управление памятью](/документация/управление-памятью).}}

## Попробуй сам

Добавьте в структуру `Точка` метод `расстояние_до_нуля()`, который возвращает `х * х + у * у` (квадрат расстояния до начала координат), и выведите его для точки (3, 4). Должно получиться 25.

```попробуй
структура Точка
    целое х
    целое у
конец

функция главная()
    Точка т = Точка(3, 4)
    вывести("х = %(т.х)%, у = %(т.у)%")
конец
```

## Что запомнить

- Структура собирает несколько значений в один тип: `структура Имя ... конец`.
- Поля — это переменные внутри структуры, а значения задаются при создании: `Имя(значение1, значение2)`.
- К полю обращаются через точку: `а.балл`.
- Методы — функции внутри структуры, внутри них `это` — сам объект.
- В тексте с подстановкой обращение к полю берут в скобки: `%(а.имя)%`.

## Упражнения

1. Опишите структуру `Книга` с полями `название` (текст) и `страниц` (целое). Создайте книгу и выведите «Название: N страниц».
2. Добавьте в `Книга` метод `толстая()`, который возвращает `да`, если страниц больше 300, и `нет` в противном случае (тип результата `верно`).
3. Сделайте список из трёх книг и выведите название самой тонкой.
4. Опишите структуру `Счёт` с полем `баланс` и методом `пополнить(целое сумма)`, который прибавляет сумму к балансу. Пополните счёт дважды и выведите итог.

### Упражнение 2

Метод возвращает условие целиком, потому что сравнение уже даёт `да` или `нет`:

```сфера решение
структура Книга
    текст название
    целое страниц

    функция толстая(): верно
        вернуть это.страниц больше 300
    конец
конец

функция главная()
    Книга а = Книга("Сказки", 120)
    Книга б = Книга("Война и мир", 1300)
    если (а.толстая())
        вывести("%(а.название)% толстая")
    иначе
        вывести("%(а.название)% тонкая")
    конец
    если (б.толстая())
        вывести("%(б.название)% толстая")
    иначе
        вывести("%(б.название)% тонкая")
    конец
конец
```

### Упражнение 3

Поиск наименьшего, как в уроке 6: запоминаем первую книгу и заменяем её, если нашли тоньше:

```сфера решение
структура Книга
    текст название
    целое страниц
конец

функция главная()
    Список из Книга полка = Список из Книга()
    полка.добавить(Книга("Сказки", 120))
    полка.добавить(Книга("Война и мир", 1300))
    полка.добавить(Книга("Рассказы", 80))

    Книга тонкая = полка.получить(0)
    для каждого к в полка
        если (к.страниц меньше тонкая.страниц)
            тонкая = к
        конец
    конец
    вывести("Самая тонкая: %(тонкая.название)%")
конец
```
