# Курс, урок 8. Когда что-то не работает

Ошибки бывают у всех, даже у тех, кто пишет программы двадцать лет. Разница лишь в том, что опытный программист не пугается ошибки, а читает её и ищет причину. В этом уроке научимся делать так же.

> **Простыми словами.** Ошибка в программе — это не «компьютер сердится». Это записка от компилятора: «вот здесь я не понял, что вы имели в виду». Записку нужно просто прочитать.

## Три вида ошибок

1. **Программа не собирается.** Компилятор нашёл ошибку ещё до запуска и ничего не запустил. Это самый удобный случай: он сам называет строку и причину.
2. **Программа падает при работе.** Собралась, но на каком-то шаге сломалась, например разделила на ноль.
3. **Программа работает, но делает не то.** Самый коварный вид: никто не ругается, а ответ неверный.

## Как читать сообщение компилятора

Возьмём программу, в которой два оператора записали в одной строке без разделителя:

```
функция главная()
    целое х = 5 вывести("х = %х%")
конец
```

Компилятор ответит:

```
Ошибка парсера в файле 'о1.код' на строке 2, столбец 17: конец объявления: после оператора нужен перевод строки или «;», но встретилось имя «вывести»
```

Читаем по частям:

- **«Ошибка парсера»** — вид ошибки. Парсер проверяет, правильно ли записаны предложения. Значит, дело в написании, а не в смысле.
- **«на строке 2, столбец 15»** — адрес: вторая строка, семнадцатый символ. Откройте программу и найдите это место. {{инфо: Иногда ошибка на самом деле на строке выше: компилятор замечает проблему там, где перестал понимать, а причина могла быть раньше. Привычка «посмотреть строку выше» полезна всегда.}}
- **«после оператора нужен перевод строки или «;»»** — что случилось и где. Два оператора в одной строке нужно разделить `;` или перенести второй на новую строку. Ответ почти всегда прямо в тексте.

Вот другие частые сообщения и что они значат:

| Сообщение | Что случилось | Что делать |
|---|---|---|
| `не хватает слова «конец» — блок не закрыт` | У `если`, `пока` или функции нет закрывающего `конец` | Посчитайте: сколько открыли блоков, столько и `конец` |
| `переменная 'б' не объявлена (может, вы имели в виду 'а'?)` | Использовали имя, которое не объявляли, или опечатались | Сверьте имя с объявлением |
| `несовпадение типов для 'возраст': ожидался тип 'целое', получен тип 'текст'` | В коробку для числа кладут текст | Проверьте, что кладёте; текст в число превращает `текст_в_целое` |
| `незакрытый текстовый литерал` | Забыли закрывающую кавычку | Найдите строку и поставьте `"` |
| `условие в скобках: ожидалось «)», но встретилось «=»` | Написали `=` вместо `==` | Для сравнения нужно два знака |

{{инфо: Компилятор Сферы показывает сообщение по-русски и старается подсказать, как исправить. Если он говорит «может, вы имели в виду», то в девяти случаях из десяти так и есть.}}

Главное правило: **исправляйте ошибки по одной, сверху вниз**. Первая ошибка часто тянет за собой остальные, а после её исправления половина сообщений исчезает.

## Программа падает при работе

Эти ошибки компилятор не видит заранее: программа выглядит правильно, но на некоторых данных ломается.

### Деление на ноль

```
функция главная()
    целое а = 10
    целое б = 0
    вывести("%(а / б)%")
конец
```

Программа соберётся, но при запуске остановится с сообщением `Ошибка выполнения: деление на ноль` (код завершения 1). {{инфо: Сфера сама проверяет делитель и останавливает программу понятным сообщением, а не продолжает с неверными числами. Если видите такое, ищите в программе деление и проверьте, что делитель может оказаться нулём.}} Лекарство одно: перед делением проверить делитель самому.

```сфера
функция главная()
    целое а = 10
    целое б = 0
    если (б == 0)
        вывести("На ноль делить нельзя")
    иначе
        вывести("%(а / б)%")
    конец
конец
```

```
На ноль делить нельзя
```

### Выход за границы списка

Номера в списке идут от 0 до `размер() - 1`. Если попросить элемент с номером 5 из списка на один элемент, Сфера остановит программу с сообщением вида `Ошибка выполнения: в списке нет элемента с номером 5 (всего элементов: 1)`. То же самое с массивами: `в массиве нет элемента с номером …`. Остановка лучше, чем тихая работа с неверными данными, но пользователю она всё равно неприятна.

Поэтому перед `получить(i)` проверяйте номер:

```сфера
функция главная()
    Список из целых л = Список из целых()
    л.добавить(10)
    л.добавить(20)

    целое i = 5
    если (i меньше л.размер() и i не меньше 0)
        вывести("%(л.получить(i))%")
    иначе
        вывести("Нет элемента с номером %i%, всего их %(л.размер())%")
    конец
    л.освободить()
конец
```

```
Нет элемента с номером 5, всего их 2
```

Здесь пригодилось, что `и` проверяет слева направо и останавливается сразу, как ответ ясен (урок 3).

### Бесконечный цикл

Если программа «зависла» и ничего не делает или бесконечно печатает одно и то же, скорее всего, в цикле `пока` забыли изменить счётчик (урок 4). Остановите её сочетанием Ctrl+C и посмотрите на цикл: меняется ли что-то внутри него так, чтобы условие когда-нибудь стало неверным?

## Программа работает, но неверно

Здесь компилятор не поможет: ему ничего не кажется странным. Нужно самому посмотреть, что происходит внутри. Самый простой способ называется **отладочная печать**: добавьте в нужные места `вывести`, которые показывают значения переменных.

Программа должна сложить числа от 1 до 5, но выдаёт не 15:

```сфера
функция главная()
    целое сумма = 0
    целое i = 1
    пока (i меньше 5)
        сумма = сумма + i
        i = i + 1
    конец
    вывести("Сумма: %сумма%")
конец
```

```
Сумма: 10
```

Что не так? Добавим печать внутрь цикла, чтобы увидеть каждый шаг:

```сфера
функция главная()
    целое сумма = 0
    целое i = 1
    пока (i меньше 5)
        сумма = сумма + i
        вывести("отладка: i = %i%, сумма = %сумма%")
        i = i + 1
    конец
    вывести("Сумма: %сумма%")
конец
```

```
отладка: i = 1, сумма = 1
отладка: i = 2, сумма = 3
отладка: i = 3, сумма = 6
отладка: i = 4, сумма = 10
Сумма: 10
```

Теперь видно: последнее значение `i` в цикле было 4, пятёрка в сумму не попала. Условие `i меньше 5` останавливается на четырёх, а нужно `i не больше 5`. Исправили условие, убрали отладочную печать, и программа даёт 15. {{инфо: Такая ошибка называется «ошибкой на единицу» и встречается постоянно. Если вы считаете границы и получилось на один шаг меньше или больше, проверьте: нужно «меньше» или «не больше»?}}

## Порядок действий, когда что-то не так

1. **Прочитайте сообщение целиком.** Не пролистывайте: ответ чаще всего в нём.
2. **Найдите место.** Откройте строку, которую назвал компилятор, и посмотрите на неё и на строку выше.
3. **Сузьте поиск.** Если программа большая, временно уберите всё лишнее (или закомментируйте строки знаком `//`) и оставьте самый маленький кусок, где ошибка ещё видна.
4. **Печатайте значения.** Поставьте `вывести` туда, где сомневаетесь, и сравните то, что вы ожидали, с тем, что получилось.
5. **Меняйте что-то одно.** Если изменили три вещи сразу и стало лучше, неясно, какая помогла.
6. **Объясните вслух.** Расскажите, что делает программа, строка за строкой, хоть игрушке, хоть самому себе. Часто ошибка находится на полпути рассказа. {{инфо: Этот приём называют «метод резиновой уточки»: программисты действительно ставят на стол игрушку и объясняют ей свой код.}}

## Что запомнить

- Ошибок три вида: не собирается, падает, работает неверно.
- Сообщение компилятора называет строку и причину: читайте его целиком.
- Исправляйте по одной ошибке, сверху вниз.
- Перед делением проверяйте делитель, перед `получить(i)` проверяйте номер.
- Если программа работает неверно, печатайте значения переменных.

## Упражнения

В каждой программе есть ошибка. Найдите её, прочитав сообщение или запустив программу, и исправьте.

1. Два оператора в одной строке без разделителя:

```
функция главная()
    вывести("Привет") вывести("Мир")
конец
```

2. Опечатка в имени переменной:

```
функция главная()
    целое цена = 100
    вывести("Цена: %цены%")
конец
```

3. Программа должна вывести числа от 1 до 5, но выводит только до 4:

```
функция главная()
    целое i = 1
    пока (i меньше 5)
        вывести("%i%")
        i = i + 1
    конец
конец
```

4. Программа зависает:

```
функция главная()
    целое i = 1
    пока (i не больше 3)
        вывести("круг %i%")
    конец
конец
```

5. Программа должна вывести среднее число от деления суммы на количество, но список пуст и она падает. Добавьте проверку:

```
функция главная()
    Список из целых л = Список из целых()
    целое сумма = 0
    для каждого х в л
        сумма = сумма + х
    конец
    вывести("Среднее: %(сумма / л.размер())%")
    л.освободить()
конец
```

## Решения упражнений

Сначала попробуйте найти ошибки сами. Решение откроется по кнопке.

### Упражнение 1

Компилятор пишет: «после оператора нужен перевод строки или «;»» и указывает на строку 2. Переносим второй оператор на новую строку (или ставим `;` между ними):

```сфера решение
функция главная()
    вывести("Привет")
    вывести("Мир")
конец
```

### Упражнение 2

Компилятор пишет: «переменная 'цены' не объявлена (может, вы имели в виду 'цена'?)». Переменная называется `цена`:

```сфера решение
функция главная()
    целое цена = 100
    вывести("Цена: %цена%")
конец
```

### Упражнение 3

Условие `i меньше 5` перестаёт выполняться при `i`, равном 5, и пятёрка не печатается. Нужно `не больше`:

```сфера решение
функция главная()
    целое i = 1
    пока (i не больше 5)
        вывести("%i%")
        i = i + 1
    конец
конец
```

### Упражнение 4

В цикле никто не меняет `i`, поэтому условие всегда верно. Не хватает строки `i = i + 1`:

```сфера решение
функция главная()
    целое i = 1
    пока (i не больше 3)
        вывести("круг %i%")
        i = i + 1
    конец
конец
```

### Упражнение 5

У пустого списка размер 0, а делить на ноль нельзя (программа остановится с ошибкой). Проверяем размер перед делением:

```сфера решение
функция главная()
    Список из целых л = Список из целых()
    целое сумма = 0
    для каждого х в л
        сумма = сумма + х
    конец
    если (л.размер() == 0)
        вывести("Список пуст, среднего нет")
    иначе
        вывести("Среднее: %(сумма / л.размер())%")
    конец
    л.освободить()
конец
```
