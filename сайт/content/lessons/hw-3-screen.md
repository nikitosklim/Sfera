# Железо 3. Экран и русские буквы

Порт — это хорошо, но ОС должна уметь рисовать. В нашем ядре экран устроен так: видеокарта даёт **кадровый буфер** — область памяти, где каждый пиксель — 4 байта. Запишем туда цвет, и точка появится на экране.

![Мини-ОС на Сфере в QEMU: русские команды и ответы](/статика/os-screen.png)

## Как найти экран

Библиотека `экран_х86` ищет видеокарту на шине PCI (`pci_читать`), переключает её в режим 800×600 с 32 битами на пиксель через порты Bochs VBE и узнаёт адрес кадрового буфера. Если ядро загружено нашим загрузчиком, режим уже включён через BIOS, и адрес экрана приходит в сведениях загрузчика.

## Шрифт с кириллицей

Видеокарта не умеет рисовать буквы, поэтому нужен свой шрифт: для каждого знака 16 байт, 8 бит на строку клетки. Мы сделали его из DejaVu Sans Mono скриптом `инструменты/шрифт/сделать_шрифт.py`: ASCII, все русские буквы, «ёЁ», кавычки-ёлочки, тире и «№».

Рисование знака — цикл по 16 строкам и 8 точкам:

```
функция экран_знак(целое номер, целое столбец, целое строка, целое цвет, целое фон)
    целое база = экран_состояние(0);
    целое образ = шрифт_адрес() + номер * 16;
    целое ряд = 0;
    пока (ряд < 16)
        целое биты = целое(аппаратное_чтение8(образ + ряд));
        целое адрес = база + (строка * 16 + ряд) * экран_состояние(40) + столбец * 32;
        целое точка = 0;
        пока (точка < 8)
            если (наложить_маску(биты, сдвинуть_вправо(128, точка)) != 0)
                аппаратная_запись32(адрес + точка * 4, беззнак32(цвет));
            иначе
                аппаратная_запись32(адрес + точка * 4, беззнак32(фон));
            конец
            точка = точка + 1;
        конец
        ряд = ряд + 1;
    конец
конец
```

Каждая точка — это `аппаратная_запись32` прямо в видеопамять.

## UTF-8

Текст в Сфере хранится как UTF-8: русская буква занимает два байта. Экран разбирает их сам: первый байт вида `110xxxxx` несёт 5 старших бит кода, второй `10xxxxxx` — 6 младших. Склеить код буквы можно теми же словами, что мы уже видели:

```
целое код = включить_биты(сдвинуть_влево(наложить_маску(а, 31), 6), наложить_маску(б, 63));
```

Дальше `номер_знака(код)` переводит код Юникода в номер картинки в нашем шрифте: `А–я` идут подряд, поэтому это простая арифметика.

## Один вывод для всех

Плата ОС подменяет `sfera_вывод_символа`: каждый символ уходит и на экран, и в последовательный порт. Поэтому в программе пишем просто `вывести("…")`, а всё остальное делает плата. Тест `./проверить.sh` в папке `examples/ос` сравнивает даже снимок экрана: если рисование изменится хоть на один пиксель, проверка упадёт.
