# Курс, урок 4. Повторение и циклы

Компьютер не устаёт повторять. Чтобы не писать одну и ту же команду сто раз, используют **циклы**.

## Цикл «пока»

Цикл `пока` повторяет блок, пока условие верно:

```сфера
функция главная(): целое
    целое i = 1;
    пока (i не больше 5)
        вывести("Шаг %i%");
        i = i + 1;
    конец
    вернуть 0;
конец
```

```
Шаг 1
Шаг 2
Шаг 3
Шаг 4
Шаг 5
```

Как компьютер проходит этот цикл, шаг за шагом:

- `целое i = 1;` — счётчик. Он считает, на каком мы шаге. Букву `i` берут по привычке, имя может быть любым.
- `пока (i не больше 5)` — «пока `i` не больше пяти». Перед каждым кругом компьютер проверяет условие заново. {{инфо: Круг 1: i = 1, условие верно, выполняем. Круг 2: i = 2, верно. … Круг 5: i = 5, верно (5 не больше 5). Потом i становится 6, условие `6 не больше 5` неверно, и цикл заканчивается. Компьютер перепрыгивает на строку после `конец` цикла.}}
- `вывести("Шаг %i%");` — печатаем номер шага.
- `i = i + 1;` — увеличиваем счётчик на единицу. Без этой строки `i` всегда равно 1, условие всегда верно, и цикл не закончится никогда. {{инфо: Такой цикл называется бесконечным. Программа будто зависла и грузит процессор. Остановить её можно сочетанием клавиш Ctrl+C в терминале. Это самая частая ошибка новичков, не пугайтесь: ничего не сломается.}}
- `конец` — здесь заканчивается тело цикла. Дойдя до него, компьютер возвращается к строке `пока` и проверяет условие снова.

Три части есть у любого цикла: начальное значение (`i = 1`), условие продолжения (`i не больше 5`) и изменение (`i = i + 1`). Если забыть изменение, цикл никогда не закончится. Остановить такую программу можно сочетанием Ctrl+C.

## Сумма чисел

Типичная задача: сложить числа от 1 до 100:

```сфера
функция главная(): целое
    целое сумма = 0;
    целое i = 1;
    пока (i не больше 100)
        сумма = сумма + i;
        i = i + 1;
    конец
    вывести("Сумма от 1 до 100: %сумма%");
    вернуть 0;
конец
```

```
Сумма от 1 до 100: 5050
```

Идея: заводим «копилку» `сумма`, в начале в ней 0. Счётчик `i` идёт от 1 до 100, и на каждом круге мы кладём в копилку текущее `i`.

- `целое сумма = 0;` — пустая копилка. {{инфо: Начальное значение обязательно. Если не задать 0, в коробке может оказаться что угодно, и сумма получится неверной. Это как начинать считать деньги с пустой ладони.}}
- `сумма = сумма + i;` — «новая сумма = старая сумма + текущее число». На круге 1 это 0 + 1 = 1, на круге 2 это 1 + 2 = 3, на круге 3 это 3 + 3 = 6, и так до 100.
- `вывести(...)` стоит после `конец` цикла, поэтому печатается один раз, когда всё сложено.

## Таблица умножения

Циклы можно вкладывать друг в друга:

```сфера
функция главная(): целое
    целое строка = 1;
    пока (строка не больше 3)
        целое столбец = 1;
        пока (столбец не больше 3)
            вывести("%строка% x %столбец% = %(строка * столбец)%");
            столбец = столбец + 1;
        конец
        строка = строка + 1;
    конец
    вернуть 0;
конец
```

```
1 x 1 = 1
1 x 2 = 2
1 x 3 = 3
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
```

Как это работает:

- Внешний цикл (`строка`) идёт по числам 1, 2, 3. Для каждого из них заново запускается внутренний цикл. {{инфо: Представьте часовую и минутную стрелки. Пока часовая стоит на одном делении, минутная делает полный круг. Здесь `строка` — медленная стрелка, `столбец` — быстрая. Для строки 1 столбец пробегает 1, 2, 3. Потом строка становится 2, и столбец снова бежит с 1.}}
- `целое столбец = 1;` стоит **внутри** внешнего цикла. Поэтому на каждом новом круге строки счётчик столбцов обнуляется и снова начинает с 1.
- `%(строка * столбец)%` — произведение двух счётчиков прямо в тексте.
- Два `конец` подряд: первый закрывает внутренний цикл, второй внешний.

## Прервать и продолжить

`прервать` выходит из цикла, `продолжить` переходит к следующему шагу:

```сфера
функция главная(): целое
    целое n = 0;
    пока (n меньше 100)
        n = n + 1;
        если (n % 3 != 0)
            продолжить;
        конец
        если (n больше 20)
            прервать;
        конец
        вывести("Делится на 3: %n%");
    конец
    вернуть 0;
конец
```

```
Делится на 3: 3
Делится на 3: 6
Делится на 3: 9
Делится на 3: 12
Делится на 3: 15
Делится на 3: 18
```

Разбор по строкам:

- `пока (n меньше 100)` — цикл крутится, пока n меньше 100. Но выйдем мы из него раньше.
- `n = n + 1;` — увеличиваем счётчик в самом начале круга. Поэтому n пробегает 1, 2, 3...
- `если (n % 3 != 0)` — «остаток от деления на 3 не равен нулю», то есть число на 3 **не** делится. {{инфо: Знак `!=` читается «не равно». Если число не делится на 3 (например, 4), мы вызываем `продолжить`: остаток круга пропускается, и компьютер сразу возвращается к `пока`.}}
- `продолжить;` — «хватит на этом круге, переходи к следующему». Строки ниже в этом круге не выполняются.
- `если (n больше 20)` и `прервать;` — «если число перевалило за 20, выйди из цикла совсем». {{инфо: Разница: `продолжить` пропускает один круг, а `прервать` заканчивает весь цикл. Когда n = 21, число делится на 3, но больше 20, поэтому цикл обрывается. Поэтому в выводе нет 21, 24 и дальше.}}
- `вывести(...)` выполняется только для чисел, которые делятся на 3 и не больше 20.

## Цикл по набору

Когда нужно обойти все элементы, удобнее цикл `для каждого`. С наборами данных мы подробно познакомимся в шестом уроке, а пока вот короткий пример:

```сфера
функция главная(): целое
    целое(4) оценки = массив(5, 4, 5, 3);
    целое сумма = 0;
    для каждого оценка в оценки
        сумма = сумма + оценка;
    конец
    вывести("Сумма оценок: %сумма%");
    вернуть 0;
конец
```

```
Сумма оценок: 17
```

Разбор по строкам:

- `целое(4) оценки = массив(5, 4, 5, 3);` — «набор из четырёх целых чисел» с названием `оценки`. {{инфо: Массив — это ряд коробок под одной вывеской. `целое(4)` значит «четыре коробки с целыми числами», а в `массив(5, 4, 5, 3)` перечислено, что в них положить. Позже, в уроке 6, будут ещё Списки, которые умеют расти.}}
- `для каждого оценка в оценки` — «для каждой оценки из набора оценок»: цикл сам берёт элементы по одному, в переменную `оценка` попадает 5, потом 4, потом 5, потом 3. {{инфо: Не нужно заводить счётчик и следить за концом набора, цикл сам остановится, когда элементы кончатся. Имя `оценка` (единственное число) вы придумываете сами, а `оценки` — это название всего набора.}}
- `сумма = сумма + оценка;` — прибавляем очередную оценку в копилку: 5 + 4 + 5 + 3 = 17.

## Что запомнить

- `пока (условие) … конец` повторяет блок, пока условие верно.
- У цикла есть начало, условие и шаг изменения: без шага он бесконечен.
- Циклы можно вкладывать друг в друга.
- `прервать` выходит из цикла, `продолжить` пропускает остаток шага.

## Проверь себя

Ответьте в уме, потом нажмите «показать ответ».

1. Сколько раз выполнится цикл `целое i = 0; пока (i меньше 3) ... i = i + 1; конец`? {{ответ: Три раза: при i = 0, 1 и 2. Когда i станет 3, условие станет неверным.}}
2. Чем `прервать` отличается от `продолжить`? {{ответ: `прервать` выходит из цикла совсем, `продолжить` пропускает остаток текущего круга и идёт на следующий.}}
3. Что будет, если в цикле `пока` забыть изменить счётчик? {{ответ: Цикл никогда не закончится. Остановить программу можно сочетанием Ctrl+C.}}
