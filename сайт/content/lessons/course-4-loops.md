# Курс, урок 4. Повторение и циклы

Компьютер не устаёт повторять. Чтобы не писать одну и ту же команду сто раз, используют **циклы**.

## Цикл «пока»

Цикл `пока` повторяет блок, пока условие верно:

```сфера
функция главная(): целое
    целое i = 1;
    пока (i не больше 5)
        вывести("Шаг %i%");
        i = i + 1;
    конец
    вернуть 0;
конец
```

```
Шаг 1
Шаг 2
Шаг 3
Шаг 4
Шаг 5
```

Три части есть у любого цикла: начальное значение (`i = 1`), условие продолжения (`i не больше 5`) и изменение (`i = i + 1`). Если забыть изменение, цикл никогда не закончится. Остановить такую программу можно сочетанием Ctrl+C.

## Сумма чисел

Типичная задача: сложить числа от 1 до 100:

```сфера
функция главная(): целое
    целое сумма = 0;
    целое i = 1;
    пока (i не больше 100)
        сумма = сумма + i;
        i = i + 1;
    конец
    вывести("Сумма от 1 до 100: %сумма%");
    вернуть 0;
конец
```

```
Сумма от 1 до 100: 5050
```

## Таблица умножения

Циклы можно вкладывать друг в друга:

```сфера
функция главная(): целое
    целое строка = 1;
    пока (строка не больше 3)
        целое столбец = 1;
        пока (столбец не больше 3)
            вывести("%строка% x %столбец% = %(строка * столбец)%");
            столбец = столбец + 1;
        конец
        строка = строка + 1;
    конец
    вернуть 0;
конец
```

```
1 x 1 = 1
1 x 2 = 2
1 x 3 = 3
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
```

## Прервать и продолжить

`прервать` выходит из цикла, `продолжить` переходит к следующему шагу:

```сфера
функция главная(): целое
    целое n = 0;
    пока (n меньше 100)
        n = n + 1;
        если (n % 3 != 0)
            продолжить;
        конец
        если (n больше 20)
            прервать;
        конец
        вывести("Делится на 3: %n%");
    конец
    вернуть 0;
конец
```

```
Делится на 3: 3
Делится на 3: 6
Делится на 3: 9
Делится на 3: 12
Делится на 3: 15
Делится на 3: 18
```

## Цикл по набору

Когда нужно обойти все элементы, удобнее цикл `для каждого`. С наборами данных мы подробно познакомимся в шестом уроке, а пока вот короткий пример:

```сфера
функция главная(): целое
    целое(4) оценки = массив(5, 4, 5, 3);
    целое сумма = 0;
    для каждого оценка в оценки
        сумма = сумма + оценка;
    конец
    вывести("Сумма оценок: %сумма%");
    вернуть 0;
конец
```

```
Сумма оценок: 17
```

## Что запомнить

- `пока (условие) … конец` повторяет блок, пока условие верно.
- У цикла есть начало, условие и шаг изменения: без шага он бесконечен.
- Циклы можно вкладывать друг в друга.
- `прервать` выходит из цикла, `продолжить` пропускает остаток шага.

## Упражнения

1. Выведите числа от 10 до 1 по убыванию.
2. Найдите сумму всех чётных чисел от 1 до 50.
3. Выведите таблицу умножения на число, которое вводит пользователь.
4. Задача «Три и пять»: для чисел от 1 до 30 выводите «Три», если число делится на 3, «Пять», если на 5, «Три-Пять», если на оба, и само число в остальных случаях.
