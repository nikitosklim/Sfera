# Урок 5. Контракты и полиморфизм

Контракт — список методов, которые должна уметь структура. Структура заявляет контракт через двоеточие, а компилятор проверяет, что все методы есть и сигнатуры совпадают.

## Один код — разные реализации

Функция принимает контракт как тип параметра и работает с любой подходящей структурой:

```сфера
контракт Печатаемый
    функция напечатать(): текст
конец

структура Кот : Печатаемый
    функция напечатать(): текст
        вернуть "Мяу"
    конец
конец

структура Собака : Печатаемый
    функция напечатать(): текст
        вернуть "Гав"
    конец
конец

функция озвучить(Печатаемый существо): целое
    вывести(существо.напечатать())
    вернуть 0
конец

функция главная(): целое
    Кот кот = Кот()
    Собака пёс = Собака()
    озвучить(кот)
    озвучить(пёс)
    вернуть 0
конец
```

```
Мяу
Гав
```

Построчно:

- `контракт Печатаемый` — список умений: «любая структура с таким контрактом обязана уметь `напечатать()` и вернуть текст». Тела у функции в контракте нет, только заголовок. {{инфо: Контракт похож на должностную инструкцию: не говорит, как работать, но перечисляет, что нужно уметь. Кошка и собака делают это по-разному, но обе умеют «напечатать».}}
- `структура Кот : Печатаемый` — после двоеточия указываем, какой контракт выполняет структура. Компилятор проверит, что метод есть и заголовок совпадает.
- `функция озвучить(Печатаемый существо)` — параметр типа «контракт»: сюда подойдёт любая структура с этим контрактом.
- `существо.напечатать()` — какая именно реализация вызовется (кошкина или собачья), решается во время работы программы. {{инфо: Это и называется полиморфизмом: один и тот же вызов делает разное, в зависимости от того, какой объект ему дали.}}

Выбор реализации происходит во время выполнения. Важная деталь: объект нужно сначала сохранить в переменную. Вызов вида `озвучить(Кот())` не работает.

## Коллекция разных объектов

Через контракт можно хранить в одном списке разные структуры:

```сфера
контракт Фигура
    функция площадь(): целое
    функция название(): текст
конец

структура Квадрат : Фигура
    целое сторона
    функция площадь(): целое
        вернуть это.сторона * это.сторона
    конец
    функция название(): текст
        вернуть "квадрат"
    конец
конец

структура Прямоугольник : Фигура
    целое ширина
    целое высота
    функция площадь(): целое
        вернуть это.ширина * это.высота
    конец
    функция название(): текст
        вернуть "прямоугольник"
    конец
конец

функция главная(): целое
    Список из Фигура фигуры = Список из Фигура()
    Квадрат к = Квадрат(3)
    Прямоугольник р = Прямоугольник(2, 5)
    фигуры.добавить(к)
    фигуры.добавить(р)

    целое всего = 0
    для каждого ф в фигуры
        вывести("%(ф.название())%: %(ф.площадь())%")
        всего = всего + ф.площадь()
    конец
    вывести("Общая площадь: %всего%")
    вернуть 0
конец
```

```
квадрат: 9
прямоугольник: 10
Общая площадь: 19
```

Список контрактов можно обходить циклом `для каждого` (или `пока` с `получить(индекс)`). Исходные переменные (`к`, `р`) держите живыми, пока жив список.
