# Железо 6. Другие процессоры: RISC-V и ARM

Мы начали с x86-64, но язык не привязан к нему. Компилятор умеет собирать код под RISC-V и ARM, а запускать всё это можно в том же QEMU.

## Флаг платформы

```
запустить программа.код --только-собрать --без-ос --целевая-платформа riscv64-unknown-elf
```

Поддерживаются четыре цели:

- `riscv64-unknown-elf` — 64-битный RISC-V (плата QEMU `virt`);
- `riscv32-unknown-elf` — 32-битный RISC-V, без блока дробных чисел;
- `thumbv7em-none-eabihf` — ARM Cortex-M7 (микроконтроллеры, плата `mps2-an500`);
- `thumbv6m-none-eabi` — ARM Cortex-M0+ без дробного блока (плата `mps2-an385`).

Нужны `clang`, `ld.lld` и соответствующий `qemu-system-…`.

## Та же программа

Возьмём программу из первого урока и заменим только плату: вместо `плата_х86_пк` подключим `плата_riscv_virt`.

```
подключить голое_железо;
подключить плата_riscv_virt;

функция главная(): целое
    sfera_плата_старт();
    вывести("Привет с голого железа!");
    целое сумма = 0;
    целое i = 1;
    пока (i <= 10)
        сумма = сумма + i;
        i = i + 1;
    конец
    вывести("сумма от 1 до 10 равна %сумма%");
    вернуть 0;
конец
```

Сборка и запуск:

```
clang --target=riscv64-unknown-elf -march=rv64gc -c examples/голое-железо/riscv/запуск_riscv64.s -o запуск.o
запустить привет_железо.код --только-собрать --без-ос --целевая-платформа riscv64-unknown-elf
ld.lld -T examples/голое-железо/riscv/компоновка_riscv64.ld запуск.o привет_железо.o -o ядро.elf
qemu-system-riscv64 -machine virt -bios none -kernel ядро.elf -display none -serial stdio
```

Вывод тот же:

```
Привет с голого железа!
сумма от 1 до 10 равна 55
```

Плата отличается только тем, как отправляется символ (у `virt` это регистр UART по адресу `0x10000000`), а весь рантайм: строки, числа, куча — остаётся нашим.

## Дробные числа без блока вычислений

У маленьких процессоров (RISC-V 32 и Cortex-M0+) нет блока для дробных чисел. Мы написали их на Сфере: библиотека `дробные_программно` реализует сложение, умножение и деление дробных числами на целочисленных командах, а ещё 64-битные операции для 32-битных процессоров. Подключаем её, и `вывести(2.5)` работает и там, где железо не умеет считать дроби. Проверка (`тесты/test_дробные_программно`) сверяет результаты с обычными дробными вычислениями компьютера.

## Проверка всех целей

В каждой папке `examples/голое-железо/…` есть свой `проверить.sh`. Он собирает тесты (вывод, куча, таймер) и сверяет вывод с `.ожидание`. Это тот же приём, что для ОС: никаких «работает у меня», только сравнение с эталоном.
