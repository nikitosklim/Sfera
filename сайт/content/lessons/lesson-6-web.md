# Урок 6. Свой веб-сервер

Этот сайт написан на «Сфере»: сервер, шаблоны, раздача файлов и загрузка установщиков. В уроке — минимальный сервер на библиотеке `веб.код` из стандартной библиотеки.

## Минимальный сервер

```сфера
подключить веб;

функция главная(): целое
    результат из целого открыт = открыть_порт(8090);
    если ( не открыт.успешно)
        вывести(открыт.сообщение);
        вернуть 1;
    конец
    целое32 слушающий = целое32(открыт.значение);
    вывести("Сервер слушает на http://localhost:8090");

    пока (да)
        целое32 клиент = принять_подключение(слушающий, нулевой_указатель_сети(), нулевой_указатель_сети());
        если (клиент не меньше целое32(0))
            результат из Запрос запрос = прочитать_запрос(клиент);
            если (запрос.успешно)
                Запрос з = запрос.значение;
                если (з.путь == "/")
                    ответ_html(клиент, 200, "<h1>Привет из Сферы!</h1><p><a href=\"/время\">Который час?</a></p>");
                иначе если (з.путь == "/время")
                    ответ_html(клиент, 200, "<p>Секунд с 1970 года: " + целое_в_текст(юникс_время()) + "</p>");
                иначе
                    ответ_html(клиент, 404, "<h1>Нет такой страницы</h1>");
                конец
            конец
            закрыть_сокет(клиент);
        конец
    конец
    вернуть 0;
конец
```

Запустите программу и откройте в браузере `http://localhost:8090/`. По адресу `/время` увидите число секунд, а по любому другому — страницу с кодом 404.

Разбор по строкам:

- `подключить веб;` — берём готовую библиотеку для сайтов. Она сама подтянет всё, что ей нужно.
- `результат из целого открыт = открыть_порт(8090);` — просим систему «слушать» порт 8090. {{инфо: Порт — это номер «двери» в вашем компьютере. Браузер стучится в дверь с номером 8090 на адрес `localhost` (это «ваш же компьютер»). Если эта дверь уже занята другой программой, открыть не получится, поэтому ответ приходит в коробочке с проверкой.}}
- `если ( не открыт.успешно)` ... `вернуть 1;` — не вышло: печатаем причину и заканчиваем программу с кодом 1 (ошибка).
- `целое32 слушающий = целое32(открыт.значение);` — запоминаем «номер двери». Это число, по которому дальше мы будем принимать гостей.
- `пока (да)` — вечный цикл: сервер работает, пока его не остановят.
- `принять_подключение(слушающий, ...)` — ждём, пока кто-нибудь придёт. Когда браузер постучался, получаем «номер связи» с ним (`клиент`). {{инфо: Функция останавливает программу, пока никто не пришёл. Двух нулевых указателей в конце не бойтесь: это значит «мне не нужно знать адрес гостя».}}
- `прочитать_запрос(клиент)` — разбираем, что именно попросил браузер: страницу, адрес, параметры. Результат в структуре `Запрос` с полями `метод`, `путь`, `параметры`, `заголовки`, `тело`.
- `если (з.путь == "/")` и ветки `иначе если` — по адресу решаем, что показать: главную, время или ошибку 404.
- `ответ_html(клиент, 200, "...")` — отправляем страницу. Число 200 — код «всё хорошо», 404 — «такой страницы нет». {{инфо: Эти коды браузеры и поисковики понимают одинаково. 200 значит успех, 404 «не найдено», 500 «ошибка на сервере».}}
- `закрыть_сокет(клиент);` — вешаем трубку: разговор с этим гостем закончен.

## Что умеет `веб.код`

- `параметр(з.параметры, "имя")` — значение из строки запроса `?имя=значение`;
- `ответ_файлом_для(…)` — отдача файлов с докачкой (`Range`), `ETag` и поддержкой `HEAD`; большие файлы идут кусками по 64 КБ;
- `подставить(шаблон, имена, значения)` — шаблоны с `{{имя}}`;
- `значение_cookie`, `заголовок_cookie`, `ответ_json`, `экранировать_html`;
- `принять_тело_в_файл` — приём больших загрузок (через него сделана загрузка установщиков на этот сайт).

## Многопоточность

Пример выше обслуживает по одному клиенту. Сайт запускает пул из 16 потоков, каждый из которых в цикле принимает подключения с общего сокета. Исходники — в [репозитории](https://github.com/nikitosklim/Sfera) в папке `сайт/`: `сервер.код` и `сайт.код`.

## Безопасность

- Любой путь, пришедший из запроса, проверяйте функцией `путь_безопасен` до обращения к файлам.
- Весь текст пользователя, который вставляете в HTML, пропускайте через `экранировать_html`.
- HTTPS в язык пока не встроен: на сервере ставьте перед программой Caddy или nginx (см. `сайт/DEPLOY.md`).

## Проверь себя

Ответьте в уме, потом нажмите «показать ответ».

1. Что такое порт? {{ответ: Номер «двери» компьютера, через которую программа принимает подключения. У каждой службы свой номер.}}
2. Почему результат `открыть_порт` нужно проверять? {{ответ: Порт может быть занят другой программой, тогда открыть его не получится.}}
3. Зачем пропускать текст пользователя через `экранировать_html`? {{ответ: Чтобы чужой текст не превратился в код страницы: так защищаются от вставки вредных скриптов.}}

## Упражнения

1. Добавьте страницу `/привет?имя=…`, которая здоровается с гостем (не забудьте экранировать имя).
2. Сделайте счётчик посещений в файле (подсказка: `дописать_в_файл_бинарно` и `размер_файла`).
