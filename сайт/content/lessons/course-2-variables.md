# Курс, урок 2. Переменные и данные

Программа работает с данными: числами, текстами, ответами «да» или «нет». Чтобы данные не потерять, их кладут в **переменные**.

## Переменная — это коробка с именем

Мы называем коробку и кладём в неё значение. Потом достаём его по имени:

```сфера
функция главная(): целое
    целое возраст = 15;
    текст имя = "Аня";
    дробное рост = 1.62;
    верно ученица = да;

    вывести("Меня зовут %имя%, мне %возраст% лет.");
    вывести("Рост: %рост% м");
    вывести("Ученица: %ученица%");
    вернуть 0;
конец
```

```
Меня зовут Аня, мне 15 лет.
Рост: 1.620000 м
Ученица: да
```

Запись читается так: «тип имя = значение;». Основные типы:

| Тип | Что хранит | Пример |
|---|---|---|
| `целое` | целые числа | `42`, `-7` |
| `дробное` | числа с точкой | `3.14` |
| `текст` | строки | `"Привет"` |
| `верно` | да или нет | `да`, `нет` |

Подстановка `%имя%` внутри текста вставляет значение переменной.

## Менять значения

Переменную можно менять, это и есть смысл слова «переменная»:

```сфера
функция главная(): целое
    целое счёт = 0;
    счёт = счёт + 10;
    счёт = счёт * 3;
    вывести("Счёт: %счёт%");
    вернуть 0;
конец
```

```
Счёт: 30
```

Строка `счёт = счёт + 10;` читается так: «возьми старое значение, прибавь 10 и положи обратно».

## Арифметика

Доступны `+`, `-`, `*`, `/` и `%` (остаток от деления). Скобки работают как в математике:

```сфера
функция главная(): целое
    целое а = 17;
    целое б = 5;
    вывести("Сумма: %(а + б)%");
    вывести("Разность: %(а - б)%");
    вывести("Произведение: %(а * б)%");
    вывести("Целое частное: %(а / б)%");
    вывести("Остаток: %(а % б)%");
    вернуть 0;
конец
```

```
Сумма: 22
Разность: 12
Произведение: 85
Целое частное: 3
Остаток: 2
```

Деление целых чисел даёт целое: `17 / 5` равно `3`. Остаток от деления пригодится, чтобы проверять чётность и делимость.

## Ввод с клавиатуры

Программа может спросить пользователя. `прочитать_строку()` ждёт, пока вы наберёте текст и нажмёте Enter. Она возвращает не просто текст, а `результат из текста`: у него есть признак `успешно` и само `значение`:

```сфера
функция главная(): целое
    вывести("Как вас зовут?");
    результат из текста ответ = прочитать_строку();
    если (ответ.успешно)
        текст имя = ответ.значение;
        вывести("Здравствуйте, %имя%!");
    конец
    вернуть 0;
конец
```

```
Как вас зовут?
Мария
Здравствуйте, Мария!
```

Значение лежит в поле `.значение`. В подстановку `%…%` кладут обычные переменные, поэтому сначала достаём его в переменную `имя`.

Чтобы прочитать число, текст нужно превратить в число. Это тоже может не получиться (человек набрал буквы), поэтому `текст_в_целое` тоже возвращает `результат`:

```сфера
функция главная(): целое
    вывести("Сколько вам лет?");
    результат из текста ответ = прочитать_строку();
    если (ответ.успешно)
        результат из целого возраст = текст_в_целое(ответ.значение);
        если (возраст.успешно)
            вывести("Через 10 лет вам будет %(возраст.значение + 10)%.");
        иначе
            вывести("Это не число.");
        конец
    конец
    вернуть 0;
конец
```

```
Сколько вам лет?
16
Через 10 лет вам будет 26.
```

## Что запомнить

- Переменная — имя для значения. Запись: «тип имя = значение;».
- Основные типы: `целое`, `дробное`, `текст`, `верно`.
- `%имя%` вставляет значение в текст, `%( … )%` вычисляет выражение.
- `прочитать_строку()` и `текст_в_целое()` возвращают `результат`: сначала проверяем `успешно`, потом берём `значение`.

## Упражнения

1. Программа спрашивает имя и год рождения и выводит, сколько лет человеку в этом году.
2. Площадь и периметр прямоугольника по двум введённым сторонам.
3. Перевод температуры из градусов Цельсия в Фаренгейты: `ц * 9 / 5 + 32`.
4. Введите количество минут и выведите, сколько это часов и минут (подсказка: `/` и `%`).
