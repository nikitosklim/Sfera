# Курс, урок 2. Переменные и данные

Программа работает с данными: числами, текстами, ответами «да» или «нет». Чтобы данные не потерять, их кладут в **переменные**.

## Переменная — это коробка с именем

Мы называем коробку и кладём в неё значение. Потом достаём его по имени:

```сфера
функция главная(): целое
    целое возраст = 15;
    текст имя = "Аня";
    дробное рост = 1.62;
    верно ученица = да;

    вывести("Меня зовут %имя%, мне %возраст% лет.");
    вывести("Рост: %рост% м");
    вывести("Ученица: %ученица%");
    вернуть 0;
конец
```

```
Меня зовут Аня, мне 15 лет.
Рост: 1.620000 м
Ученица: да
```

Разбор по строкам:

- `целое возраст = 15;` — создаём коробку для целого числа, подписываем «возраст» и кладём в неё 15. {{инфо: Строка читается слева направо: тип (`целое` — какие вещи можно класть в коробку), имя (`возраст` — подпись на коробке, её придумываете вы) и значение после знака `=`. Знак `=` здесь значит «положить», а не «равно, как в математике». Точка с запятой закрывает команду.}}
- `текст имя = "Аня";` — коробка для текста. Текст всегда в двойных кавычках.
- `дробное рост = 1.62;` — коробка для числа с точкой. Именно точка, не запятая. {{инфо: В программировании дробная часть отделяется точкой: `1.62`. Запятая нужна для другого (например, чтобы разделять значения в скобках), и компьютер поймёт её неправильно. Поэтому на экране вы увидите `1.620000`: компьютер показывает шесть знаков после точки.}}
- `верно ученица = да;` — коробка, в которую можно положить только `да` или `нет`.
- Пустая строка между блоками нужна только людям: так код легче читать.
- `вывести("Меня зовут %имя%, мне %возраст% лет.");` — печатаем фразу. {{инфо: Знаки `%...%` внутри кавычек значат «здесь вставь то, что лежит в коробке с таким именем». Компьютер сам достаёт значение: вместо `%имя%` получится «Аня», вместо `%возраст%` — 15. Если коробки с таким именем нет, компилятор покажет ошибку.}}

Запись читается так: «тип имя = значение;». Основные типы:

| Тип | Что хранит | Пример |
|---|---|---|
| `целое` | целые числа | `42`, `-7` |
| `дробное` | числа с точкой | `3.14` |
| `текст` | строки | `"Привет"` |
| `верно` | да или нет | `да`, `нет` |

Подстановка `%имя%` внутри текста вставляет значение переменной.

## Менять значения

Переменную можно менять, это и есть смысл слова «переменная»:

```сфера
функция главная(): целое
    целое счёт = 0;
    счёт = счёт + 10;
    счёт = счёт * 3;
    вывести("Счёт: %счёт%");
    вернуть 0;
конец
```

```
Счёт: 30
```

Разбор по строкам:

- `целое счёт = 0;` — коробка «счёт», внутри 0.
- `счёт = счёт + 10;` — достать из коробки старое значение (0), прибавить 10 и положить результат обратно (10). {{инфо: В математике «счёт = счёт + 10» невозможно, это не уравнение. В программе знак `=` значит «положить». Сначала считается правая часть: 0 + 10 = 10. Потом результат кладётся в коробку слева, и старое значение стирается. Тип в начале не пишем: коробка уже создана строкой выше.}}
- `счёт = счёт * 3;` — теперь внутри 10. Умножаем на 3 и кладём обратно: получается 30.
- `вывести("Счёт: %счёт%");` — печатаем текущее содержимое коробки: 30.

Строка `счёт = счёт + 10;` читается так: «возьми старое значение, прибавь 10 и положи обратно».

## Арифметика

Доступны `+`, `-`, `*`, `/` и `%` (остаток от деления). Скобки работают как в математике:

```сфера
функция главная(): целое
    целое а = 17;
    целое б = 5;
    вывести("Сумма: %(а + б)%");
    вывести("Разность: %(а - б)%");
    вывести("Произведение: %(а * б)%");
    вывести("Целое частное: %(а / б)%");
    вывести("Остаток: %(а % б)%");
    вернуть 0;
конец
```

```
Сумма: 22
Разность: 12
Произведение: 85
Целое частное: 3
Остаток: 2
```

Разбор по строкам:

- `целое а = 17;` и `целое б = 5;` — две коробки с числами. Имена `а` и `б` можно придумать любые.
- `вывести("Сумма: %(а + б)%");` — внутри `%( )%` можно считать. Здесь 17 + 5 = 22. {{инфо: Когда внутри подстановки не просто имя, а действие, нужны круглые скобки: `%(а + б)%`. Без скобок `%а + б%` не сработает. Компьютер сначала считает то, что в скобках, и вставляет результат в текст.}}
- `вывести("Целое частное: %(а / б)%");` — 17 разделить на 5 будет 3, дробная часть отбрасывается. {{инфо: Когда делят два целых числа, ответ тоже целый: 17 / 5 = 3, потому что 5 помещается в 17 три раза (5 + 5 + 5 = 15). Остальное, 2, и есть остаток. Отбросить дробную часть значит не округлить, а просто выкинуть её: 19 / 5 тоже будет 3.}}
- `вывести("Остаток: %(а % б)%");` — знак `%` внутри скобок значит «остаток от деления». 17 = 5·3 + 2, остаток 2. {{инфо: Остаток помогает проверять чётность: если `число % 2` равно 0, число чётное. Ещё его используют, чтобы узнать, делится ли число на другое без остатка, и чтобы «ходить по кругу», например по дням недели.}}

Деление целых чисел даёт целое: `17 / 5` равно `3`. Остаток от деления пригодится, чтобы проверять чётность и делимость.

## Ввод с клавиатуры

Программа может спросить пользователя. `прочитать_строку()` ждёт, пока вы наберёте текст и нажмёте Enter. Она возвращает не просто текст, а `результат из текста`: у него есть признак `успешно` и само `значение`:

```сфера
функция главная(): целое
    вывести("Как вас зовут?");
    результат из текста ответ = прочитать_строку();
    если (ответ.успешно)
        текст имя = ответ.значение;
        вывести("Здравствуйте, %имя%!");
    конец
    вернуть 0;
конец
```

```
Как вас зовут?
Мария
Здравствуйте, Мария!
```

Разбор по строкам:

- `вывести("Как вас зовут?");` — задаём вопрос на экране.
- `результат из текста ответ = прочитать_строку();` — ждём, пока человек напечатает слово и нажмёт Enter. {{инфо: Программа останавливается и ждёт. Когда человек нажал Enter, всё напечатанное попадает в коробку `ответ`. Но коробка особая: `результат из текста` — это «коробка с двумя ячейками». В одной (`успешно`) записано, получилось ли прочитать. В другой (`значение`) лежит сам текст. Так сделано, потому что чтение может не получиться, например если ввод закрыли.}}
- `если (ответ.успешно)` — «если чтение получилось». Всё до `конец` выполняется только в этом случае. {{инфо: Точка в `ответ.успешно` значит «открой ячейку `успешно` в коробке `ответ`». Там лежит `да` или `нет`. Если `да`, выполняются команды внутри блока. Блок `если` закрывается своим `конец`, он отдельный от `конец` функции.}}
- `текст имя = ответ.значение;` — достаём текст из ячейки `значение` и кладём в простую коробку `имя`.
- `вывести("Здравствуйте, %имя%!");` — приветствие с подставленным именем.
- `конец` (первый) — закрывает `если`; `конец` (последний) закрывает `функцию`.

Значение лежит в поле `.значение`. В подстановку `%…%` кладут обычные переменные, поэтому сначала достаём его в переменную `имя`.

Чтобы прочитать число, текст нужно превратить в число. Это тоже может не получиться (человек набрал буквы), поэтому `текст_в_целое` тоже возвращает `результат`:

```сфера
функция главная(): целое
    вывести("Сколько вам лет?");
    результат из текста ответ = прочитать_строку();
    если (ответ.успешно)
        результат из целого возраст = текст_в_целое(ответ.значение);
        если (возраст.успешно)
            вывести("Через 10 лет вам будет %(возраст.значение + 10)%.");
        иначе
            вывести("Это не число.");
        конец
    конец
    вернуть 0;
конец
```

```
Сколько вам лет?
16
Через 10 лет вам будет 26.
```

Что нового здесь:

- `текст_в_целое(ответ.значение)` — превращает набранные символы «16» в настоящее число 16. {{инфо: Всё, что человек набирает на клавиатуре, компьютер считает текстом. Текст «16» — это два символа, как «ab». Складывать его с 10 нельзя. `текст_в_целое` разбирает символы и собирает из них число. Если ввели «привет», число не получится, поэтому функция снова возвращает коробочку с `успешно` и `значение`.}}
- `если (возраст.успешно)` ... `иначе` ... `конец` — «если число получилось, сделай одно, иначе (в противном случае) другое». {{инфо: `иначе` — запасной путь. Выполняется ровно один из двух блоков: либо тот, что после `если`, либо тот, что после `иначе`. Здесь запасной путь честно говорит человеку «Это не число», а не падает с ошибкой.}}
- `%(возраст.значение + 10)%` — берём число из ячейки и прибавляем 10 прямо в подстановке.

## Попробуй сам

Поменяйте возраст и рост, затем заведите свою коробку: `текст город = "...";`, и выведите фразу «Живу в ...» с подстановкой `%город%`.

```попробуй
функция главная(): целое
    целое возраст = 15;
    дробное рост = 1.62;
    вывести("Мне %возраст% лет, рост %рост% м.");
    вернуть 0;
конец
```

## Что запомнить

- Переменная — имя для значения. Запись: «тип имя = значение;».
- Основные типы: `целое`, `дробное`, `текст`, `верно`.
- `%имя%` вставляет значение в текст, `%( … )%` вычисляет выражение.
- `прочитать_строку()` и `текст_в_целое()` возвращают `результат`: сначала проверяем `успешно`, потом берём `значение`.

## Проверь себя

Ответьте в уме, потом нажмите «показать ответ».

1. Какого типа должна быть переменная для числа `3.14`? {{ответ: `дробное`. Целые числа без точки хранит тип `целое`.}}
2. Чему будет равно `х` после строк `целое х = 4;` и `х = х * 2 + 1;`? {{ответ: 9. Сначала считается правая часть: 4 * 2 + 1 = 9, потом результат кладётся в `х`.}}
3. Чему равно `17 % 5`? {{ответ: 2. Это остаток от деления: 17 = 5·3 + 2.}}

## Упражнения

1. Программа спрашивает имя и год рождения и выводит, сколько лет человеку в этом году.
2. Площадь и периметр прямоугольника по двум введённым сторонам.
3. Перевод температуры из градусов Цельсия в Фаренгейты: `ц * 9 / 5 + 32`.
4. Введите количество минут и выведите, сколько это часов и минут (подсказка: `/` и `%`).
