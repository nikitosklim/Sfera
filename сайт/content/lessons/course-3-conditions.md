# Курс, урок 3. Решения и условия

Программа становится умной, когда умеет выбирать. «Если на улице дождь, взять зонт, иначе надеть очки». Это называется **условием**.

## Если и иначе

```сфера
функция главная(): целое
    целое температура = 8;
    если (температура меньше 10)
        вывести("Надень куртку");
    иначе
        вывести("Хватит футболки");
    конец
    вернуть 0;
конец
```

```
Надень куртку
```

Условие пишется в скобках. Если оно верно, выполняется первая ветка, иначе вторая. Блок закрывается `конец`.

## Сравнения

| Запись | Смысл |
|---|---|
| `a == b` | равно |
| `a != b` | не равно |
| `a больше b` | больше |
| `a меньше b` | меньше |
| `a не больше b` | меньше или равно |
| `a не меньше b` | больше или равно |

Обратите внимание: сравнение пишется двойным `==`, потому что одинарное `=` кладёт значение в переменную.

## Несколько вариантов

Ветки можно соединять цепочкой `иначе если`:

```сфера
функция главная(): целое
    целое баллы = 74;
    если (баллы не меньше 90)
        вывести("Отлично");
    иначе если (баллы не меньше 70)
        вывести("Хорошо");
    иначе если (баллы не меньше 50)
        вывести("Удовлетворительно");
    иначе
        вывести("Нужно подтянуть");
    конец
    вернуть 0;
конец
```

```
Хорошо
```

Проверка идёт сверху вниз и останавливается на первом верном условии. Цепочка закрывается одним `конец`, а `иначе` и `если` стоят на одной строке.

## И, или, не

Условия можно объединять: `и` — должны выполниться оба, `или` — хотя бы одно, `не` — наоборот.

```сфера
функция главная(): целое
    целое возраст = 14;
    верно есть_билет = да;

    если (возраст не меньше 12 и есть_билет)
        вывести("Проходите в зал");
    иначе
        вывести("Вход закрыт");
    конец

    целое день = 6;
    если (день == 6 или день == 7)
        вывести("Выходной");
    иначе
        вывести("Рабочий день");
    конец
    вернуть 0;
конец
```

```
Проходите в зал
Выходной
```

## Чётное или нет

Остаток от деления на 2 у чётного числа равен нулю:

```сфера
функция главная(): целое
    вывести("Введите число:");
    результат из текста ответ = прочитать_строку();
    если (ответ.успешно)
        результат из целого число = текст_в_целое(ответ.значение);
        если (число.успешно)
            целое n = число.значение;
            если (n % 2 == 0)
                вывести("%n% — чётное");
            иначе
                вывести("%n% — нечётное");
            конец
        иначе
            вывести("Это не число");
        конец
    конец
    вернуть 0;
конец
```

```
Введите число:
7
7 — нечётное
```

## Что запомнить

- `если (условие) … иначе … конец` выбирает одну из двух веток.
- Цепочка `иначе если` проверяет варианты по порядку.
- Сравнения: `==`, `!=`, `больше`, `меньше`, `не больше`, `не меньше`.
- Условия соединяют словами `и`, `или`, `не`.

## Упражнения

1. Введите два числа и выведите большее.
2. Определите, високосный ли год: год делится на 4, но не делится на 100, либо делится на 400.
3. Программа спрашивает пароль и пишет «Верно» или «Неверно» (пароль задайте в коде; тексты сравниваются через `==`).
4. По росту и весу рассчитайте индекс массы тела `вес / (рост * рост)` и выведите категорию. Используйте дробные числа.
