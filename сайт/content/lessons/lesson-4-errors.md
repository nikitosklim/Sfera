# Урок 4. Ошибки без исключений

В «Сфере» нет исключений. Функция, которая может не получиться, возвращает обёртку `результат из T` с тремя полями: `.успешно`, `.значение` (только при успехе) и `.сообщение` (только при ошибке). Создают её функции `успех(x)` и `ошибка("текст")`.

## Свои функции с результатом

```сфера
функция разделить(целое а, целое б): результат из целого
    если (б == 0)
        вернуть ошибка("деление на ноль");
    конец
    вернуть успех(а / б);
конец

функция главная(): целое
    результат из целого хорошо = разделить(10, 2);
    если (хорошо.успешно)
        вывести("10 / 2 = %(хорошо.значение)%");
    иначе
        вывести("Ошибка: %(хорошо.сообщение)%");
    конец

    результат из целого плохо = разделить(1, 0);
    если (плохо.успешно)
        вывести("1 / 0 = %(плохо.значение)%");
    иначе
        вывести("Ошибка: %(плохо.сообщение)%");
    конец
    вернуть 0;
конец
```

```
10 / 2 = 5
Ошибка: деление на ноль
```

Построчно:

- `функция разделить(целое а, целое б): результат из целого` — функция может не получиться (на ноль делить нельзя), поэтому возвращает не просто число, а коробочку `результат из целого`.
- `вернуть ошибка("деление на ноль");` — вернуть неудачу с объяснением. Объяснение потом читается через `.сообщение`. {{инфо: Вместо исключений Сфера использует коробочки: функция не «падает», а честно сообщает, что не получилось. Вызывающий код обязан посмотреть на `.успешно`. Так ошибки не потеряются незаметно.}}
- `вернуть успех(а / б);` — вернуть удачу с ответом. Ответ читается через `.значение`.
- `если (хорошо.успешно)` — проверка перед использованием значения. Читать `.значение` у неудачи нельзя: там ничего нет.

Всегда проверяйте `.успешно` перед чтением `.значение`.

## Встроенные функции

Многие встроенные функции — `прочитать_файл`, `найти`, `подстрока`, `текст_в_целое` — тоже возвращают `результат`:

```сфера
функция главная(): целое
    результат из текста файл = прочитать_файл("несуществующий.txt");
    если ( не файл.успешно)
        вывести("Не удалось прочитать файл: %(файл.сообщение)%");
        вернуть 1;
    конец
    вывести(файл.значение);
    вернуть 0;
конец
```

```
Не удалось прочитать файл: не удалось открыть файл
```

Код возврата `1` из `главной` сообщает операционной системе, что программа завершилась с ошибкой.

## Опциональный тип

Когда значения может просто не быть и сообщение не нужно, используйте `тип?` с полем `.есть`. Обычное значение «поднимается» в опциональное само, а отсутствие записывается словом `неуказано`:

```сфера
функция главная(): целое
    целое? возраст = 25;
    целое? неизвестно = неуказано;

    если (возраст.есть)
        вывести("Возраст: %(возраст.значение)%");
    конец
    если ( не неизвестно.есть)
        вывести("Значение не задано");
    конец

    неизвестно = 30;
    если (неизвестно.есть)
        вывести("Теперь задано: %(неизвестно.значение)%");
    конец
    вернуть 0;
конец
```

```
Возраст: 25
Значение не задано
Теперь задано: 30
```

Построчно:

- `целое? возраст = 25;` — знак `?` после типа значит «может быть, а может не быть». {{инфо: Опциональный тип нужен, когда значения может просто не быть и объяснять почему не нужно. Например, «возраст неизвестен».}}
- `целое? неизвестно = неуказано;` — слово `неуказано` значит «значения нет».
- `возраст.есть` — `да`, если значение есть. Только тогда безопасно читать `.значение`.
- `неизвестно = 30;` — обычное число «поднимается» в опциональное само, и теперь `.есть` равно `да`.

Ограничения: `T` — только числа и `верно`, а опциональные значения пока работают только как локальные переменные (не как параметры, не как поля).

## Попробуй сам

Измените делитель на 0 и убедитесь, что программа не падает, а печатает сообщение об ошибке.

```попробуй
функция разделить(целое а, целое б): результат из целого
    если (б == 0)
        вернуть ошибка("деление на ноль");
    конец
    вернуть успех(а / б);
конец

функция главная(): целое
    результат из целого р = разделить(10, 2);
    если (р.успешно)
        вывести("Ответ: %(р.значение)%");
    иначе
        вывести("Ошибка: %(р.сообщение)%");
    конец
    вернуть 0;
конец
```

## Проверь себя

Ответьте в уме, потом нажмите «показать ответ».

1. Какие поля есть у `результат из T`? {{ответ: `.успешно`, `.значение` (только при успехе) и `.сообщение` (только при ошибке).}}
2. Чем опциональный тип `целое?` отличается от `результат из целого`? {{ответ: У опционального только `.есть` и `.значение`: он говорит, есть ли значение, но не объясняет почему его нет. `результат` умеет и объяснять.}}
3. Что нужно сделать перед чтением `.значение`? {{ответ: Проверить `.успешно` (или `.есть` у опционального).}}
