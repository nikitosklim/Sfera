# Курс, урок 6. Списки и текст

До сих пор мы хранили одно значение в одной переменной. А если данных много: оценки класса, список покупок, слова из предложения? Для этого нужны **списки**.

## Список

`Список из целых` хранит сколько угодно целых чисел. Элементы нумеруются **с нуля**: первый имеет номер 0.

```сфера
функция главная(): целое
    Список из целых оценки = Список из целых();
    оценки.добавить(5);
    оценки.добавить(4);
    оценки.добавить(3);
    оценки.добавить(5);

    вывести("Оценок: %(оценки.размер())%");
    вывести("Первая: %(оценки.получить(0))%");

    для каждого оценка в оценки
        вывести("оценка: %оценка%");
    конец
    оценки.освободить();
    вернуть 0;
конец
```

```
Оценок: 4
Первая: 5
оценка: 5
оценка: 4
оценка: 3
оценка: 5
```

`добавить` кладёт элемент в конец, `размер` показывает, сколько элементов, `получить(номер)` достаёт элемент. Когда список больше не нужен, вызываем `освободить`: так мы возвращаем память системе.

## Средний балл и максимум

Хранить данные мало: их нужно обрабатывать. Найдём среднее и самую высокую оценку:

```сфера
функция главная(): целое
    Список из целых оценки = Список из целых();
    оценки.добавить(5);
    оценки.добавить(3);
    оценки.добавить(4);
    оценки.добавить(5);
    оценки.добавить(2);

    целое сумма = 0;
    целое лучшая = оценки.получить(0);
    для каждого оценка в оценки
        сумма = сумма + оценка;
        если (оценка больше лучшая)
            лучшая = оценка;
        конец
    конец
    дробное среднее = дробное(сумма) / дробное(оценки.размер());
    вывести("Сумма: %сумма%");
    вывести("Лучшая: %лучшая%");
    вывести("Средний балл: %среднее%");
    оценки.освободить();
    вернуть 0;
конец
```

```
Сумма: 19
Лучшая: 5
Средний балл: 3.800000
```

Приём «взять первый элемент как лучший и сравнивать с ним остальные» годится для поиска наибольшего и наименьшего в любом наборе.

## Список текстов

Списки бывают не только числовыми:

```сфера
функция главная(): целое
    Список из текстов друзья = Список из текстов();
    друзья.добавить("Аня");
    друзья.добавить("Борис");
    друзья.добавить("Вера");

    целое номер = 1;
    для каждого имя в друзья
        вывести("%номер%. %имя%");
        номер = номер + 1;
    конец
    друзья.освободить();
    вернуть 0;
конец
```

```
1. Аня
2. Борис
3. Вера
```

## Работа с текстом

Текст тоже можно исследовать. Функция `длина` считает **байты**: русская буква занимает два байта, поэтому для русских слов длина получается вдвое больше числа букв.

```сфера
функция главная(): целое
    текст фраза = "Привет, Сфера!";

    если (содержит(фраза, "Сфера"))
        вывести("Слово найдено");
    конец

    результат из целого позиция = найти(фраза, ",");
    если (позиция.успешно)
        вывести("Запятая на позиции %(позиция.значение)%");
    конец

    вывести(регистр_в_верхний("привет") + " " + регистр_в_нижний("МИР"));
    вернуть 0;
конец
```

```
Слово найдено
Запятая на позиции 12
ПРИВЕТ мир
```

Позиции тоже считаются в байтах, поэтому запятая стоит на 12-м месте, а не на 7-м. Для латинских букв и цифр байт равен символу.

## Что запомнить

- Список хранит много значений одного типа: `Список из целых`, `Список из текстов`.
- Нумерация идёт с нуля, `добавить` кладёт в конец, `получить` достаёт по номеру.
- Для обхода всех элементов — цикл `для каждого`.
- Максимум, минимум и сумму ищут проходом по списку с промежуточной переменной.
- Освобождайте список методом `освободить`, когда он больше не нужен.

## Упражнения

1. Введите пять чисел с клавиатуры, сложите их в список и выведите в обратном порядке (подсказка: цикл `пока` и номера от `размер() - 1` до 0).
2. Найдите в списке наименьшее число.
3. Посчитайте, сколько в списке чётных чисел.
4. Составьте список из пяти имён и выведите только те, в которых есть буква «а» (используйте `содержит`).
