# Курс, урок 6. Списки и текст

До сих пор мы хранили одно значение в одной переменной. А если данных много: оценки класса, список покупок, слова из предложения? Для этого нужны **списки**.

## Список

`Список из целых` хранит сколько угодно целых чисел. Элементы нумеруются **с нуля**: первый имеет номер 0.

```сфера
функция главная()
    Список из целых оценки = Список из целых();
    оценки.добавить(5);
    оценки.добавить(4);
    оценки.добавить(3);
    оценки.добавить(5);

    вывести("Оценок: %(оценки.размер())%");
    вывести("Первая: %(оценки.получить(0))%");

    для каждого оценка в оценки
        вывести("оценка: %оценка%");
    конец
    оценки.освободить();
конец
```

```
Оценок: 4
Первая: 5
оценка: 5
оценка: 4
оценка: 3
оценка: 5
```

Разбор по строкам:

- `Список из целых оценки = Список из целых();` — создаём пустой список для целых чисел с именем `оценки`. {{инфо: Список — это коробка, которая растёт сама: кладёшь больше, становится больше. Слева тип и имя (`Список из целых оценки`), справа создание нового пустого списка (`Список из целых()`). Скобки в конце обязательны: они значат «создай». Все элементы списка одного типа: в список целых нельзя положить текст.}}
- `оценки.добавить(5);` — положить пятёрку в конец списка. Точка между именем и действием значит «у списка `оценки` вызвать действие `добавить`». Ещё три таких строки добавляют 4, 3, 5.
- `оценки.размер()` — сколько сейчас элементов: 4. Скобки пишем, хотя внутри пусто.
- `оценки.получить(0)` — элемент с номером 0, то есть самый первый. {{инфо: Номера в списках начинаются с нуля. Если в списке 4 элемента, их номера 0, 1, 2, 3, а номера 4 нет. Попросить несуществующий номер значит ошибка. Нумерация с нуля — договорённость почти всех языков программирования: номер означает «сколько элементов пропустить с начала».}}
- `для каждого оценка в оценки` — цикл по всем элементам по очереди. Вы уже видели такой в уроке 4.
- `оценки.освободить();` — «я закончил, забери память». {{инфо: Списки занимают место в памяти компьютера. Когда список больше не нужен, его освобождают, чтобы память вернулась системе. Если забыть, в маленькой программе ничего страшного не будет, она закончится и система всё заберёт. Но в программе, которая работает часами, утечки накапливаются. Лучше привыкнуть освобождать сразу.}}

`добавить` кладёт элемент в конец, `размер` показывает, сколько элементов, `получить(номер)` достаёт элемент. Когда список больше не нужен, вызываем `освободить`: так мы возвращаем память системе.

## Средний балл и максимум

Хранить данные мало: их нужно обрабатывать. Найдём среднее и самую высокую оценку:

```сфера
функция главная()
    Список из целых оценки = Список из целых();
    оценки.добавить(5);
    оценки.добавить(3);
    оценки.добавить(4);
    оценки.добавить(5);
    оценки.добавить(2);

    целое сумма = 0;
    целое лучшая = оценки.получить(0);
    для каждого оценка в оценки
        сумма = сумма + оценка;
        если (оценка больше лучшая)
            лучшая = оценка;
        конец
    конец
    дробное среднее = дробное(сумма) / дробное(оценки.размер());
    вывести("Сумма: %сумма%");
    вывести("Лучшая: %лучшая%");
    вывести("Средний балл: %среднее%");
    оценки.освободить();
конец
```

```
Сумма: 19
Лучшая: 5
Средний балл: 3.800000
```

Разбор по строкам:

- `целое лучшая = оценки.получить(0);` — для начала объявляем лучшей первую оценку. {{инфо: Нам нужна точка отсчёта. Если начать с 0, всё сработало бы для положительных оценок, но для чисел, которые могут быть отрицательными, это не годится. Первый элемент списка всегда подходит: он реальное число из набора.}}
- `сумма = сумма + оценка;` — копим сумму, как в уроке 4.
- `если (оценка больше лучшая)` и `лучшая = оценка;` — если нашли оценку выше лучшей, запоминаем её как новую лучшую. К концу цикла в `лучшая` лежит максимум.
- `дробное среднее = дробное(сумма) / дробное(оценки.размер());` — сумму делим на количество. {{инфо: Оба числа превращаются в дробные функцией `дробное(...)`, иначе целое деление отбросило бы дробную часть: 19 / 5 дало бы 3. Теперь 19.0 / 5.0 = 3.8. Среднее — это сумма, делённая на количество элементов.}}

Приём «взять первый элемент как лучший и сравнивать с ним остальные» годится для поиска наибольшего и наименьшего в любом наборе.

## Список текстов

Списки бывают не только числовыми:

```сфера
функция главная()
    Список из текстов друзья = Список из текстов();
    друзья.добавить("Аня");
    друзья.добавить("Борис");
    друзья.добавить("Вера");

    целое номер = 1;
    для каждого имя в друзья
        вывести("%номер%. %имя%");
        номер = номер + 1;
    конец
    друзья.освободить();
конец
```

```
1. Аня
2. Борис
3. Вера
```

Что нового здесь:

- `Список из текстов друзья = Список из текстов();` — тот же список, только для текстов.
- `целое номер = 1;` и `номер = номер + 1;` — самодельный счётчик, чтобы пронумеровать строки: цикл `для каждого` сам номера не даёт.
- `вывести("%номер%. %имя%");` — в один текст можно подставить сразу две переменные.

## Работа с текстом

Текст тоже можно исследовать. Функция `длина` считает **байты**: русская буква занимает два байта, поэтому для русских слов длина получается вдвое больше числа букв.

```сфера
функция главная()
    текст фраза = "Привет, Сфера!";

    если (содержит(фраза, "Сфера"))
        вывести("Слово найдено");
    конец

    результат из целого позиция = найти(фраза, ",");
    если (позиция.успешно)
        вывести("Запятая на позиции %(позиция.значение)%");
    конец

    вывести(регистр_в_верхний("привет") + " " + регистр_в_нижний("МИР"));
конец
```

```
Слово найдено
Запятая на позиции 12
ПРИВЕТ мир
```

Разбор по строкам:

- `содержит(фраза, "Сфера")` — отвечает `да`, если слово «Сфера» встречается внутри фразы. {{инфо: Функция принимает два текста: где искать и что искать. Если искомое нашлось хотя бы раз, ответ `да`. Результат подходит прямо для условия `если`.}}
- `результат из целого позиция = найти(фраза, ",");` — ищем, на каком месте стоит запятая. Ответ приходит в коробочке: вдруг запятой нет. {{инфо: Позиции считаются в байтах от нуля. В слове «Привет» шесть русских букв, каждая занимает два байта, поэтому запятая после него стоит на позиции 12, а не 6. Для английских букв и цифр один символ равен одному байту.}}
- `позиция.успешно` и `позиция.значение` — «нашлось ли» и «где».
- `регистр_в_верхний("привет")` — превращает все буквы в заглавные. `регистр_в_нижний("МИР")` — в строчные. Знак `+` между текстами склеивает их.

Позиции тоже считаются в байтах, поэтому запятая стоит на 12-м месте, а не на 7-м. Для латинских букв и цифр байт равен символу.

## Попробуй сам


## Что запомнить

- Список хранит много значений одного типа: `Список из целых`, `Список из текстов`.
- Нумерация идёт с нуля, `добавить` кладёт в конец, `получить` достаёт по номеру.
- Для обхода всех элементов — цикл `для каждого`.
- Максимум, минимум и сумму ищут проходом по списку с промежуточной переменной.
- Освобождайте список методом `освободить`, когда он больше не нужен.

## Решения упражнений

Сначала попробуйте решить сами: даже неудачная попытка учит больше, чем готовый ответ. Решение откроется по кнопке. Ваш вариант может отличаться от нашего, и это нормально: главное, чтобы программа делала то, что просили.

### Упражнение 1

Складываем введённые числа в список, а потом идём с конца к началу:

```сфера решение
функция главная()
    Список из целых числа = Список из целых();
    целое i = 0;
    пока (i меньше 5)
        вывести("Число %(i + 1)%:");
        результат из текста ответ = прочитать_строку();
        если (ответ.успешно)
            результат из целого н = текст_в_целое(ответ.значение);
            если (н.успешно)
                числа.добавить(н.значение);
            конец
        конец
        i = i + 1;
    конец

    целое j = числа.размер() - 1;
    пока (j не меньше 0)
        вывести("%(числа.получить(j))%");
        j = j - 1;
    конец
    числа.освободить();
конец
```
