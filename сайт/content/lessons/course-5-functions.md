# Курс, урок 5. Функции

Когда программа растёт, её нужно делить на части. **Функция** — это именованный кусок программы, который можно вызывать сколько угодно раз.

## Своя функция

Мы уже писали функцию `главная`. Вот ещё одна:

```сфера
функция поздороваться(текст имя)
    вывести("Привет, %имя%!");
конец

функция главная(): целое
    поздороваться("Аня");
    поздороваться("Борис");
    вернуть 0;
конец
```

```
Привет, Аня!
Привет, Борис!
```

В скобках после имени перечислены **параметры**: данные, которые функция получает снаружи.

## Функция, которая возвращает значение

Функция может посчитать результат и вернуть его. Тип результата пишется после двоеточия:

```сфера
функция квадрат(целое х): целое
    вернуть х * х;
конец

функция среднее(целое а, целое б): дробное
    вернуть дробное(а + б) / 2.0;
конец

функция главная(): целое
    вывести("Квадрат 7 равен %(квадрат(7))%");
    вывести("Среднее 4 и 9: %(среднее(4, 9))%");
    вернуть 0;
конец
```

```
Квадрат 7 равен 49
Среднее 4 и 9: 6.500000
```

## Зачем нужны функции

- **Не повторяться.** Одну и ту же логику пишем один раз.
- **Давать имена.** `проверить_пароль(...)` понятнее, чем десять строк кода.
- **Проверять по частям.** Маленькую функцию легко проверить отдельно.

## Функция, которая вызывает саму себя

Факториал числа `n` — это произведение чисел от 1 до `n`. Его можно записать через функцию, которая вызывает саму себя. Это называется **рекурсией**:

```сфера
функция факториал(целое n): целое
    если (n не больше 1)
        вернуть 1;
    конец
    вернуть n * факториал(n - 1);
конец

функция главная(): целое
    вывести("5! = %(факториал(5))%");
    вывести("10! = %(факториал(10))%");
    вернуть 0;
конец
```

```
5! = 120
10! = 3628800
```

У рекурсии всегда есть условие остановки (здесь `n не больше 1`). Без него функция вызывала бы сама себя бесконечно.

## Функция-проверка

Функции удобно использовать для вопросов, на которые отвечают «да» или «нет»:

```сфера
функция простое(целое n): верно
    если (n меньше 2)
        вернуть нет;
    конец
    целое д = 2;
    пока (д * д не больше n)
        если (n % д == 0)
            вернуть нет;
        конец
        д = д + 1;
    конец
    вернуть да;
конец

функция главная(): целое
    целое n = 1;
    пока (n не больше 30)
        если (простое(n))
            вывести("%n% — простое");
        конец
        n = n + 1;
    конец
    вернуть 0;
конец
```

```
2 — простое
3 — простое
5 — простое
7 — простое
11 — простое
13 — простое
17 — простое
19 — простое
23 — простое
29 — простое
```

## Что запомнить

- Функция объявляется словом `функция`, параметры пишутся в скобках.
- Тип результата указывается после двоеточия, значение возвращает `вернуть`.
- Функция может вызывать другие функции и даже саму себя (рекурсия).
- Хорошая функция делает одну понятную вещь и называется глаголом или вопросом.
