# Курс, урок 5. Функции

Когда программа растёт, её нужно делить на части. **Функция** — это именованный кусок программы, который можно вызывать сколько угодно раз.

## Своя функция

Мы уже писали функцию `главная`. Вот ещё одна:

```сфера
функция поздороваться(текст имя)
    вывести("Привет, %имя%!");
конец

функция главная()
    поздороваться("Аня");
    поздороваться("Борис");
конец
```

```
Привет, Аня!
Привет, Борис!
```

Разбор по строкам:

- `функция поздороваться(текст имя)` — объявляем свою команду. Имя `поздороваться`, а в скобках — что ей нужно получить: текст, который внутри будет называться `имя`. {{инфо: Параметр — это «пустая коробка», которую функция заводит при вызове. Когда вы пишете `поздороваться("Аня")`, слово «Аня» кладётся в коробку `имя`, и внутри функции его можно использовать. Через скобки функции передают данные. Тип параметра (`текст`) нужен, чтобы компьютер знал, какие данные ждать. Если типа результата после скобок нет (двоеточия нет), функция ничего не возвращает, она просто что-то делает.}}
- `вывести("Привет, %имя%!");` — единственная команда нашей функции.
- `конец` — закрывает функцию `поздороваться`.
- `поздороваться("Аня");` — вызов: «выполни команду `поздороваться`, а в `имя` положи "Аня"». {{инфо: Компьютер прыгает внутрь функции, выполняет её строки, а потом возвращается на строку после вызова. Вызывать можно сколько угодно раз и с разными данными. Определение функции пишут один раз.}}
- Второй вызов даёт «Привет, Борис!». Один код, разные данные.

В скобках после имени перечислены **параметры**: данные, которые функция получает снаружи.

## Функция, которая возвращает значение

Функция может посчитать результат и вернуть его. Тип результата пишется после двоеточия:

```сфера
функция квадрат(целое х): целое
    вернуть х * х;
конец

функция среднее(целое а, целое б): дробное
    вернуть дробное(а + б) / 2.0;
конец

функция главная()
    вывести("Квадрат 7 равен %(квадрат(7))%");
    вывести("Среднее 4 и 9: %(среднее(4, 9))%");
конец
```

```
Квадрат 7 равен 49
Среднее 4 и 9: 6.500000
```

Разбор по строкам:

- `функция квадрат(целое х): целое` — «функция `квадрат` получает целое `х` и возвращает целое». Двоеточие и тип после скобок говорят, что функция отдаёт ответ.
- `вернуть х * х;` — «посчитай и отдай это значение назад тому, кто вызвал». {{инфо: `вернуть` сразу заканчивает работу функции. Всё, что написано после него в этой функции, не выполнится. Результат подставляется на место вызова: `квадрат(7)` превращается в число 49 прямо в том месте, где вы её вызвали.}}
- `функция среднее(целое а, целое б): дробное` — два параметра через запятую. Результат дробный: среднее двух чисел может быть с половинкой.
- `вернуть дробное(а + б) / 2.0;` — сумма превращается в дробное число, и только потом делится. {{инфо: Если делить целые числа, дробная часть пропадёт: 13 / 2 дало бы 6. Чтобы получить 6.5, число превращают в дробное функцией `дробное(...)` и делят на `2.0` (с точкой). Тогда компьютер считает по правилам дробных чисел.}}
- `%(квадрат(7))%` — вызов функции можно писать прямо внутри подстановки, в скобках.

## Зачем нужны функции

- **Не повторяться.** Одну и ту же логику пишем один раз.
- **Давать имена.** `проверить_пароль(...)` понятнее, чем десять строк кода.
- **Проверять по частям.** Маленькую функцию легко проверить отдельно.

## Функция, которая вызывает саму себя

Факториал числа `n` — это произведение чисел от 1 до `n`. Его можно записать через функцию, которая вызывает саму себя. Это называется **рекурсией**:

```сфера
функция факториал(целое n): целое
    если (n не больше 1)
        вернуть 1;
    конец
    вернуть n * факториал(n - 1);
конец

функция главная()
    вывести("5! = %(факториал(5))%");
    вывести("10! = %(факториал(10))%");
конец
```

```
5! = 120
10! = 3628800
```

Разбор по строкам:

- `если (n не больше 1)` — условие остановки: для 1 (и 0) ответ известен без вычислений.
- `вернуть 1;` — отдаём ответ «1» и выходим из функции.
- `вернуть n * факториал(n - 1);` — для остальных чисел: «n умножить на факториал числа на единицу меньше». Функция вызывает сама себя, но с меньшим числом. {{инфо: Посмотрим на `факториал(3)`. Он считает 3 * факториал(2). Тот считает 2 * факториал(1). А факториал(1) сразу отвечает 1. Теперь ответы идут обратно: 2 * 1 = 2, потом 3 * 2 = 6. Каждое число меньше предыдущего, поэтому когда-нибудь дойдём до 1 и остановимся. Если убрать условие остановки, функция будет вызывать себя бесконечно, и программа упадёт с ошибкой переполнения.}}

У рекурсии всегда есть условие остановки (здесь `n не больше 1`). Без него функция вызывала бы сама себя бесконечно.

## Функция-проверка

Функции удобно использовать для вопросов, на которые отвечают «да» или «нет»:

```сфера
функция простое(целое n): верно
    если (n меньше 2)
        вернуть нет;
    конец
    целое д = 2;
    пока (д * д не больше n)
        если (n % д == 0)
            вернуть нет;
        конец
        д = д + 1;
    конец
    вернуть да;
конец

функция главная()
    целое n = 1;
    пока (n не больше 30)
        если (простое(n))
            вывести("%n% — простое");
        конец
        n = n + 1;
    конец
конец
```

```
2 — простое
3 — простое
5 — простое
7 — простое
11 — простое
13 — простое
17 — простое
19 — простое
23 — простое
29 — простое
```

Разбор функции `простое`:

- `функция простое(целое n): верно` — функция-вопрос: на выходе `да` или `нет`.
- `если (n меньше 2)` и `вернуть нет;` — числа меньше 2 простыми не считаются, сразу отвечаем «нет».
- `целое д = 2;` — пробный делитель, начинаем с двойки.
- `пока (д * д не больше n)` — пробуем делители, пока `д` в квадрате не больше `n`. {{инфо: Если у числа есть делитель, то есть и пара ему, и один из них не больше корня из числа. Например, у 36 пары: 2·18, 3·12, 4·9, 6·6. Меньший делитель не больше 6, это корень из 36. Поэтому проверять делители дальше корня не нужно, и программа работает быстрее. Условие `д * д не больше n` — это и есть «д не больше корня из n».}}
- `если (n % д == 0)` и `вернуть нет;` — «если n делится на д без остатка, значит число составное», сразу отвечаем «нет».
- `д = д + 1;` — пробуем следующий делитель.
- `вернуть да;` — делителей не нашлось, число простое. Стоит после цикла.
- В `главная` строка `если (простое(n))` — вызов функции прямо в условии: она возвращает `да` или `нет`, этого достаточно.

## Попробуй сам

Допишите функцию `куб`, которая возвращает число, умноженное само на себя три раза, и выведите `куб(3)`. Должно получиться 27.

```попробуй
функция квадрат(целое х): целое
    вернуть х * х;
конец

функция главная()
    вывести("Квадрат 7 равен %(квадрат(7))%");
конец
```

## Что запомнить

- Функция объявляется словом `функция`, параметры пишутся в скобках.
- Тип результата указывается после двоеточия, значение возвращает `вернуть`.
- Функция может вызывать другие функции и даже саму себя (рекурсия).
- Хорошая функция делает одну понятную вещь и называется глаголом или вопросом.

## Упражнения

1. Напишите функцию `максимум(а, б)`, которая возвращает большее из двух чисел.
2. Напишите функцию `чётное(n)` и используйте её, чтобы вывести чётные числа от 1 до 20.
3. Напишите функцию `степень(основание, показатель)` через цикл.
4. Числа Фибоначчи: 1, 1, 2, 3, 5, 8… Напишите функцию `фибоначчи(n)` рекурсивно.

## Решения упражнений

Сначала попробуйте решить сами: даже неудачная попытка учит больше, чем готовый ответ. Решение откроется по кнопке. Ваш вариант может отличаться от нашего, и это нормально: главное, чтобы программа делала то, что просили.

### Упражнение 1

Функция получает два числа и возвращает одно:

```сфера решение
функция максимум(целое а, целое б): целое
    если (а больше б)
        вернуть а;
    конец
    вернуть б;
конец

функция главная()
    вывести("Максимум из 8 и 13: %(максимум(8, 13))%");
конец
```

### Упражнение 2

Функция-проверка возвращает `верно` или `нет`, а цикл просто спрашивает у неё про каждое число:

```сфера решение
функция чётное(целое n): верно
    вернуть n % 2 == 0;
конец

функция главная()
    целое i = 1;
    пока (i не больше 20)
        если (чётное(i))
            вывести("%i%");
        конец
        i = i + 1;
    конец
конец
```

### Упражнение 3

Умножаем результат на основание столько раз, каков показатель:

```сфера решение
функция степень(целое основание, целое показатель): целое
    целое итог = 1;
    целое i = 0;
    пока (i меньше показатель)
        итог = итог * основание;
        i = i + 1;
    конец
    вернуть итог;
конец

функция главная()
    вывести("2 в степени 10 = %(степень(2, 10))%");
конец
```

### Упражнение 4

Первые два числа равны 1, а каждое следующее — сумма двух предыдущих. Условие остановки — `n не больше 2`:

```сфера решение
функция фибоначчи(целое n): целое
    если (n не больше 2)
        вернуть 1;
    конец
    вернуть фибоначчи(n - 1) + фибоначчи(n - 2);
конец

функция главная()
    целое i = 1;
    пока (i не больше 10)
        вывести("%(фибоначчи(i))%");
        i = i + 1;
    конец
конец
```
