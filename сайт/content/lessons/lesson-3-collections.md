# Урок 3. Список, Словарь и текст

## Список

`Список из T` — растущий массив. Тип нужно указывать явно слева, вывести его из значения нельзя:

```сфера
функция главная(): целое
    Список из целых числа = Список из целых();
    числа.добавить(10);
    числа.добавить(20);
    числа.добавить(30);

    вывести("Размер: %(числа.размер())%");
    вывести("Первое: %(числа.получить(0))%");

    числа.удалить(1);
    для каждого число в числа
        вывести("элемент: %число%");
    конец
    числа.освободить();
    вернуть 0;
конец
```

```
Размер: 3
Первое: 10
элемент: 10
элемент: 30
```

Построчно:

- `Список из целых числа = Список из целых();` — создаём пустой список целых. Тип слева писать обязательно. {{инфо: Список — это коробка, которая растёт сама. Все элементы одного типа. Скобки справа создают новый пустой список.}}
- `числа.добавить(10);` — положить в конец. После трёх добавлений порядок: 10, 20, 30.
- `числа.получить(0)` — элемент с номером 0 (нумерация с нуля).
- `числа.удалить(1);` — убрать элемент с номером 1, то есть 20. Хвост сдвигается влево: остаётся 10, 30.
- `числа.освободить();` — вернуть память системе, когда список больше не нужен.

`удалить(индекс)` убирает элемент и сдвигает хвост влево. Список не освобождается сам — когда он больше не нужен, вызовите `.освободить()`.

## Словарь

`Словарь из К и З` хранит пары «ключ — значение». Метод `получить` возвращает не значение, а `результат из …`: ключа может не быть, и это нужно проверить:

```сфера
функция главная(): целое
    Словарь из текста и целого возрасты = Словарь из текста и целого();
    возрасты.положить("Аня", 25);
    возрасты.положить("Борис", 31);
    возрасты.положить("Аня", 26);

    вывести("Записей: %(возрасты.размер())%");

    результат из целого аня = возрасты.получить("Аня");
    если (аня.успешно)
        вывести("Аня: %(аня.значение)%");
    конец

    результат из целого вера = возрасты.получить("Вера");
    если ( не вера.успешно)
        вывести("Веры в словаре нет");
    конец
    возрасты.освободить();
    вернуть 0;
конец
```

```
Записей: 2
Аня: 26
Веры в словаре нет
```

Построчно:

- `Словарь из текста и целого возрасты = ...` — словарь, где ключи это тексты, а значения целые числа. {{инфо: Словарь похож на телефонную книгу: по имени (ключу) находишь номер (значение). Ключи не повторяются.}}
- `возрасты.положить("Аня", 26);` — второй `положить` с тем же ключом заменяет значение, поэтому записей по-прежнему две.
- `результат из целого аня = возрасты.получить("Аня");` — ищем по ключу. Ответ приходит в коробочке: ключа может не оказаться. {{инфо: В коробочке `результат` две ячейки: `.успешно` (нашли ли) и `.значение` (что нашли). Сначала проверяйте `.успешно`.}}
- `если ( не вера.успешно)` — «если не нашли», то есть Веры в словаре нет.

Повторный `положить` с тем же ключом заменяет значение (Аня стала 26, а записей по-прежнему две). Словарь тоже нужно освобождать вручную.

Чтобы перебрать все пары, используйте `ключ_по_индексу(i)` и `значение_по_индексу(i)` для `i` от `0` до `размер() - 1`; порядок — как при первой вставке:

```сфера
пока (i меньше возрасты.размер())
    текст имя = возрасты.ключ_по_индексу(i);
    целое возраст = возрасты.значение_по_индексу(i);
    вывести("%имя%: %возраст%");
    i = i + 1;
конец
```

Возвращённый текст принадлежит словарю, его освобождать не нужно.

## Текст

Строки — это байты в UTF-8, поэтому `длина` считает байты, а не буквы: в кириллице одна буква занимает два байта. Позиции из `найти` тоже в байтах.

```сфера
функция главная(): целое
    текст фраза = "Привет, Сфера!";
    вывести("Длина в байтах: %(длина(фраза))%");
    вывести(регистр_в_верхний("abc") + " " + регистр_в_нижний("ABC"));

    если (содержит(фраза, "Сфера"))
        вывести("Нашли слово");
    конец

    результат из целого позиция = найти(фраза, ",");
    если (позиция.успешно)
        вывести("Запятая на позиции %(позиция.значение)%");
    конец

    результат из целого число = текст_в_целое("123");
    если (число.успешно)
        вывести("Число плюс один: %(число.значение + 1)%");
    конец
    вернуть 0;
конец
```

```
Длина в байтах: 25
ABC abc
Нашли слово
Запятая на позиции 12
Число плюс один: 124
```

В «Привет, Сфера!» 14 символов, но 25 байт — по два на каждую русскую букву и по одному на запятую, пробел и восклицательный знак.

Основные функции: `длина`, `содержит`, `найти`, `подстрока`, `регистр_в_верхний`, `регистр_в_нижний`, `текст_в_целое`. Сложение строк делается знаком `+`.

## Попробуй сам

Добавьте в словарь ещё одного человека и выведите его возраст. Потом попросите возраст того, кого нет: убедитесь, что программа честно сообщает об этом.

```попробуй
функция главная(): целое
    Словарь из текста и целого возрасты = Словарь из текста и целого();
    возрасты.положить("Аня", 25);
    возрасты.положить("Борис", 31);
    результат из целого р = возрасты.получить("Аня");
    если (р.успешно)
        вывести("Аня: %(р.значение)%");
    иначе
        вывести("Не нашли");
    конец
    возрасты.освободить();
    вернуть 0;
конец
```

## Проверь себя

Ответьте в уме, потом нажмите «показать ответ».

1. Что вернёт `получить` у словаря, если ключа нет? {{ответ: Коробочку, у которой `.успешно` равно `нет`: значения в ней нет.}}
2. Почему у «Привет, Сфера!» длина 25, а не 14? {{ответ: `длина` считает байты, а русская буква занимает два байта. Запятая, пробел и «!» занимают по одному.}}
3. Что делает `удалить(1)` у списка? {{ответ: Убирает элемент с номером 1 (второй по счёту) и сдвигает остальные влево.}}

## Упражнения

1. Посчитайте среднее значение списка чисел.
2. Сохраните в словаре число жителей пяти городов и выведите население выбранного.
3. Проверьте, содержит ли строка слово «конец», и выведите позицию.
