# Урок 2. Функции и структуры

## Функции

Функция объявляется словом `функция`. Тип результата пишется после двоеточия, а `вернуть` возвращает значение. Если функция ничего не возвращает (только выводит или делает что-то), тип и `вернуть` не пишут:

```сфера
функция площадь(целое ширина, целое высота): целое
    вернуть ширина * высота
конец

функция факториал(целое n): целое
    если (n не больше 1)
        вернуть 1
    конец
    вернуть n * факториал(n - 1)
конец

функция поприветствовать(текст имя)
    вывести("Привет, %имя%!")
конец

функция главная()
    вывести("Площадь: %(площадь(6, 7))%")
    вывести("5! = %(факториал(5))%")
    поприветствовать("Сфера")
конец
```

```
Площадь: 42
5! = 120
Привет, Сфера!
```

Построчно:

- `функция площадь(целое ширина, целое высота): целое` — функция принимает два целых числа и возвращает целое. {{инфо: Данные в скобках называются параметрами, их типы пишутся перед именами. После двоеточия идёт тип результата. Функция с таким заголовком обязана где-то написать `вернуть ...` с целым числом.}}
- `вернуть ширина * высота` — посчитать и отдать результат вызвавшему.
- `функция поприветствовать(текст имя)` — вернуть нечего, поэтому после скобок нет ни двоеточия, ни типа, а внутри нет `вернуть`. Так же устроена и `главная`: она просто выполняет команды.
- `поприветствовать("Сфера")` — вызов функции, которая ничего не возвращает: нам важно только действие.

Функция может вызывать сама себя (рекурсия) — так считается факториал. Компилятор проверяет число и типы аргументов при каждом вызове.

## Структуры

Структура собирает поля и методы в один тип. Метод — это обычная функция внутри структуры, а `это` — ссылка на текущий объект. Конструктор создаётся автоматически и принимает все поля в порядке объявления:

```сфера
структура Прямоугольник
    целое ширина
    целое высота

    функция площадь(): целое
        вернуть это.ширина * это.высота
    конец

    функция описание(): текст
        вернуть "прямоугольник " + целое_в_текст(это.ширина) + "x" + целое_в_текст(это.высота)
    конец
конец

функция главная(): целое
    Прямоугольник р = Прямоугольник(4, 5)
    вывести(р.описание())
    вывести("площадь: %(р.площадь())%")
    р.ширина = 10
    вывести("после изменения: %(р.площадь())%")
    вернуть 0
конец
```

```
прямоугольник 4x5
площадь: 20
после изменения: 50
```

Построчно:

- `структура Прямоугольник` ... `конец` — описание нового типа: из каких частей он состоит.
- `целое ширина` и `целое высота` — поля: переменные, которые есть у каждого прямоугольника. {{инфо: Структура как чертёж: по нему можно сделать сколько угодно прямоугольников, у каждого свои ширина и высота. Поля пишутся без значений: значения задаст конструктор.}}
- `функция площадь(): целое` внутри структуры — метод: функция, которая принадлежит структуре.
- `это.ширина` — «ширина того прямоугольника, у которого вызвали метод». {{инфо: Слово `это` — ссылка на текущий объект. Когда вы пишете `р.площадь()`, внутри метода `это` указывает на `р`. Так один и тот же метод работает для любого прямоугольника.}}
- `Прямоугольник р = Прямоугольник(4, 5)` — создаём объект: скобки передают значения полей в порядке объявления (ширина 4, высота 5).
- `р.ширина = 10` — меняем поле, и `р.площадь()` теперь даёт 50.

Структуры всегда живут в куче и передаются по ссылке: если передать `р` в функцию и изменить поле там, оно изменится и у вызывающего. Память освобождается автоматически — по счётчику ссылок.

## Что запомнить

- `функция имя(тип а, тип б): тип` — тип результата после двоеточия.
- Поля структуры не имеют значений по умолчанию, их задаёт конструктор: `Прямоугольник(4, 5)`.
- Методы обращаются к полям через `это.поле`.

## Попробуй сам

Добавьте в структуру метод `периметр()`, который возвращает `2 * (это.ширина + это.высота)`, и выведите его для `р`. Для прямоугольника 4 на 5 должно получиться 18.

```попробуй
структура Прямоугольник
    целое ширина
    целое высота

    функция площадь(): целое
        вернуть это.ширина * это.высота
    конец
конец

функция главная(): целое
    Прямоугольник р = Прямоугольник(4, 5)
    вывести("площадь: %(р.площадь())%")
    вернуть 0
конец
```

## Проверь себя

Ответьте в уме, потом нажмите «показать ответ».

1. Что такое `это` внутри метода? {{ответ: Ссылка на текущий объект: тот, у которого вызвали метод.}}
2. В каком порядке конструктор принимает значения полей? {{ответ: В порядке, в котором поля объявлены в структуре.}}
3. Что будет у вызывающего кода, если функция изменила поле переданной структуры? {{ответ: Поле изменится и у вызывающего: структуры передаются по ссылке.}}
