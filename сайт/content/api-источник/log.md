# Модуль «лог»

Лог — это дневник программы: она сама записывает, что делает, а вы потом читаете. Каждая запись выглядит так:

```
[2026-09-29 19:42:46] ОШИБКА: не удалось подключиться к базе данных
```

В начале стоит время (всегда по Гринвичу, UTC), потом уровень важности, потом ваше сообщение. Подключается строкой `подключить лог`.

## Пример

```код
подключить лог

функция главная(): целое
    Логгер журнал = создать_логгер(уровень_инфо(), да, "")
    лог_отладка(журнал, "это сообщение не появится: уровень ниже инфо")
    лог_инфо(журнал, "программа запущена")
    лог_предупреждение(журнал, "мало места на диске")
    лог_ошибка(журнал, "не удалось открыть файл")
    вернуть 0
конец
```

Время в строках лога каждый раз новое, поэтому вывод этого примера мы не показываем. Разберём строку `создать_логгер(уровень_инфо(), да, "")`:

- `уровень_инфо()` — самый низкий уровень, который нужно записывать. Всё, что менее важно (отладка), будет молча пропущено.
- `да` — писать ли на экран.
- `""` — пустой текст значит «в файл не писать». Если вместо него дать путь, например `"журнал.txt"`, записи будут дописываться ещё и в этот файл.

## Уровни важности

От самого тихого к самому громкому: `уровень_отладка()` = 0, `уровень_инфо()` = 1, `уровень_предупреждение()` = 2, `уровень_ошибка()` = 3, `уровень_критическая()` = 4. Каждой функции `лог_...` соответствует свой уровень.
