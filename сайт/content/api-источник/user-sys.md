# Модуль «сис_пользователя»

Системные вызовы для программ, которые работают внутри учебной операционной системы Сферы в «пользовательском режиме» (кольцо 3). Подключается строкой `подключить сис_пользователя;`. Обычному приложению на компьютере он не нужен — у него есть `вывести` и файлы.

> **Простыми словами.** Программа пользователя не имеет права трогать железо сама. Она просит ядро: «выведи символ», «скажи время». Этот модуль — удобные обёртки над такими просьбами.

## Что умеет

- `писать_символ(байт)` — выводит один байт на экран через ядро.
- `писать_текст(текст)` — выводит строку по байтам.
- `писать_число(число)` — выводит число в десятичном виде.
- `аргумент_программы()` — число, которое ядро передало программе при запуске.
- `тики()` — счётчик таймера ядра; по нему можно измерять время и делать паузы.
- `сисвызов(номер, а, б)` — «сырая» просьба к ядру: 1 — вывод символа, 2 — выход, 3 — тики, 4 — аргумент.

```код
подключить сис_пользователя;

функция главная(): целое
    писать_текст("Привет из пользовательской программы!");
    писать_символ(10);
    писать_число(аргумент_программы());
    писать_символ(10);
    вернуть 0;
конец
```

{{инфо: Такие программы собираются особым скриптом `examples/ос/собрать_ядро.sh` вместе с ядром. Подробнее — на странице «Операционная система».}}
