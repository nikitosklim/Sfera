# Модуль «сеть»

Низкоуровневые сокеты: подключиться к другому компьютеру по TCP, отправить и получить байты, а также принимать подключения самому. Подключается строкой `подключить сеть`. Модуль «веб» построен поверх него.

> **Простыми словами.** Сокет — это «телефонная трубка». Вы создаёте её, звоните по адресу (IP и порт), говорите и слушаете, потом кладёте трубку.

## Клиент: позвонить и поговорить

Порядок действий всегда один:

1. `создать_сокет` — берём трубку.
2. `построить_адрес_сервера(ip, порт)` — набираем номер (собирает нужную структуру адреса).
3. `подключиться` — звоним.
4. `отправить_данные` и `получить_данные` — разговор.
5. `закрыть_сокет` — кладём трубку.

```код
подключить сеть

функция главная(): целое
    целое32 с = создать_сокет(целое32(2), целое32(1), целое32(0))
    текст адрес = построить_адрес_сервера("127.0.0.1", целое32(8080))
    если (подключиться(с, адрес, целое32(16)) != целое32(0))
        вывести("не удалось подключиться")
        вернуть 1
    конец
    текст запрос = "GET / HTTP/1.0\r\n\r\n"
    отправить_данные(с, запрос, длина(запрос), целое32(0))
    текст буфер = выделить_память(1024)
    целое n = получить_данные(с, буфер, 1023, целое32(0))
    вывести("получено байт: " + целое_в_текст(n))
    закрыть_сокет(с)
    вернуть 0
конец
```

Числа `2, 1, 0` — это «IPv4, TCP, протокол по умолчанию». Размер адреса всегда 16 байт.

## Сервер: ждать звонков

`привязать_сокет` закрепляет сокет за портом, `слушать_сокет` включает очередь, `принять_подключение` возвращает новый сокет для каждого позвонившего. Перед привязкой полезно вызвать `настроить_сокет`, чтобы порт можно было переиспользовать сразу после перезапуска.

{{инфо: Сетевые функции недоступны в браузерной площадке: в ней нет сети. Запускайте такие примеры у себя через `сфера запустить`.}}
