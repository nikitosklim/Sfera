# Модуль «веб»

Веб-модуль — набор готовых кирпичиков для сайта на Сфере: разбор запроса, ответы нужного типа, шаблоны, безопасная отдача файлов и cookie. Подключается строкой `подключить веб`. Сайт языксфера.рф работает именно на нём.

> **Простыми словами.** Браузер присылает текст запроса, вы присылаете текст ответа. Модуль «веб» умеет читать первое и собирать второе, а мелочи (экранирование, типы файлов, статусы) берёт на себя.

## Мелкие помощники для текста и адресов

Эти функции не требуют сети — их можно пробовать как обычный код.

```код запустить
подключить веб

функция главная(): целое
    вывести(заменить("а-б-в", "-", "+"))
    вывести(обрезать_края("   привет   "))
    вывести(экранировать_ягр("<b>\"x\" & y</b>"))
    вывести(декодировать_адрес("%%D0%%BF%%D1%%80%%D0%%B8+%%D0%%B2%%D0%%B5%%D1%%82"))
    вывести(параметр("имя=Аня&город=Тула", "город"))
    вывести(зос_строка("строка \"в кавычках\""))
    вывести(тип_содержимого("/страница.html"))
    вывести(тип_содержимого("/картинка.png"))
    вывести(описание_статуса(404))
    вернуть 0
конец
```

Разберём:

- `заменить(текст, что, на_что)` — заменяет все вхождения.
- `обрезать_края` — убирает пробелы и переводы строк по краям.
- `экранировать_ягр` — заменяет `<`, `>`, `&`, кавычки на безопасные коды. Всегда применяйте к тексту, который пришёл от пользователя.
- `декодировать_адрес` — превращает `%D0%BF…` и `+` из адресной строки в обычный текст.
- `параметр(строка, имя)` — достаёт значение из `имя=Аня&город=Тула`.
- `зос_строка` — оборачивает текст в кавычки по правилам JSON.
- `тип_содержимого(путь)` — подбирает `Content-Type` по расширению файла.
- `описание_статуса(код)` — подпись к коду ответа: «OK», «Not Found».

{{инфо: В тексте Сферы `%` — начало вставки значения. Чтобы написать настоящий процент, как в адресе `%D0`, удваивайте его: `%%D0`.}}

## Шаблоны и безопасность путей

```код запустить
подключить веб

функция главная(): целое
    Список из текстов имена = Список из текстов()
    Список из текстов значения = Список из текстов()
    имена.добавить("имя")
    значения.добавить("Аня")
    имена.добавить("город")
    значения.добавить("Тула")
    вывести(подставить("Привет, {{имя}} из города {{город}}!", имена, значения))
    вывести(заполнить("Привет, {{имя}}!", "имя", "Боря"))

    если (путь_безопасен("/статика/a.css"))
        вывести("путь безопасен")
    конец
    если (не путь_безопасен("/../секрет"))
        вывести("путь с .. запрещён")
    конец
    вернуть 0
конец
```

- `заполнить(шаблон, имя, значение)` — подставляет одно значение вместо `{{имя}}`.
- `подставить(шаблон, имена, значения)` — подставляет сразу несколько.
- `путь_безопасен` — проверяет, что запрошенный путь не выходит из папки через `..`. Вызывайте его перед отдачей любого файла.

## Cookie

`заголовок_печенья(имя, значение, секунд)` собирает строку `Set-Cookie` с защитными флагами `HttpOnly` и `SameSite=Lax`. Чтение — `значение_печенья(запрос, имя)`.

## Сервер: порт, запрос, ответ

Эти функции работают с настоящей сетью, поэтому в браузерной площадке они не запускаются — пример показан без запуска.

```код
подключить веб

функция главная(): целое
    результат из целого порт = открыть_порт(8080)
    если (не порт.успешно)
        вывести("порт занят: " + порт.сообщение)
        вернуть 1
    конец
    // дальше цикл: принять подключение, прочитать_запрос, отправить ответ_ягр(...)
    вернуть 0
конец
```

Ответы собираются готовыми функциями: `ответ_текстом`, `ответ_ягр`, `ответ_зос`, `перенаправить`, `ответ_с_заголовками`, `ответ_файлом`, `ответ_файлом_для`. Загрузку файла от пользователя принимает `принять_тело_в_файл`. Полный список с сигнатурами ниже.

{{инфо: `открыть_порт` сам включает игнорирование сигнала SIGPIPE: если браузер оборвал соединение посреди ответа, сервер не падает.}}
