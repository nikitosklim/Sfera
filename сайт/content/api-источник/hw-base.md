# Модули «голое_железо» и «дробные_программно»

Основа для программ без операционной системы: драйверы, ядра, прошивки микроконтроллеров. Программа собирается с флагом `--без-ос`, а вместо стандартной библиотеки C компилятор обращается к функциям этих модулей. Подключаются строками `подключить голое_железо` и `подключить дробные_программно`.

> **Простыми словами.** Когда под вами нет операционной системы, некому выдать память, вывести текст или посчитать дробь. Эти модули — маленькая «операционная система внутри программы».

## «голое_железо»: память, строки, числа

- **Память:** распределитель `malloc` / `free` с настоящим освобождением, а также `memcpy`, `memmove`, `memset`, `memcmp`.
- **Строки:** `strlen`, `strcmp`, `strstr`, `strtol`, `strdup`.
- **Вывод:** целые и дробные числа превращаются в текст и уходят на устройство вывода.

Плата должна подсказать модулю две вещи: как вывести один символ (`sfera_вывод_символа`) и где лежит память под кучу (`sfera_куча_начало`, `sfera_куча_размер`). Обычно это делает модуль платы — см. страницу «Модули плат».

## «дробные_программно»: дроби без процессора

Не у каждого процессора есть блок для дробных чисел (так на многих микроконтроллерах). Этот модуль делает сложение, умножение и деление дробей обычными целочисленными операциями. Включайте его вместе с `голое_железо`, и `дробное` будет работать и там, где «железной» поддержки нет.

```код
подключить голое_железо
подключить дробные_программно
подключить плата_rp2040

функция главная(): целое
    sfera_плата_старт()
    вывести("Привет, Pico! Мы пишем на Сфере.")
    вернуть 0
конец
```

{{инфо: Примеры для разных плат лежат в `examples/голое-железо`. Честная оговорка из репозитория: на реальных платах (Pico) примеры пока не проверялись, проверены в эмуляторе.}}
