# Модуль «трейсинг»

Трейсинг отвечает на вопрос «что программа делала и сколько времени это заняло». Вы оборачиваете участки кода в «спаны» (от англ. span, отрезок), а потом получаете дерево с длительностями. Подключается строкой `подключить трейсинг;`.

## Пример

```код
подключить трейсинг;

функция работа(целое n): целое
    целое сумма = 0;
    целое k = 0;
    пока (k меньше n)
        сумма = сумма + k;
        k = k + 1;
    конец
    вернуть сумма;
конец

функция главная(): целое
    Трейсер т = создать_трейсер();

    спан_начать(т, "запрос");
    спан_начать(т, "посчитать");
    целое а = работа(100000);
    спан_завершить(т);
    спан_завершить(т);

    трейс_напечатать(т);
    вернуть 0;
конец
```

Время у каждого запуска своё, поэтому реальный вывод мы здесь не запускаем. У вас получится что-то вроде:

```
  посчитать: 0.123 мс
запрос: 0.141 мс
```

Разберём:

- `создать_трейсер()` — заводим «блокнот», куда будут записываться спаны.
- `спан_начать(т, "запрос")` — «начало участка с именем запрос». Участки вкладываются друг в друга, как скобки.
- `спан_завершить(т)` — закрывает последний открытый участок. Каждому `спан_начать` должен соответствовать свой `спан_завершить`.
- `трейс_напечатать(т)` — печатает все закрытые участки. Вложенные идут с отступом, а длительность — в миллисекундах.

## Остальные функции

- `трейс_снимок(т)` — то же дерево, но как `текст`, а не на экран. Удобно, чтобы записать в лог.
- `трейс_записать_файл(т, "путь")` — записывает дерево в файл. Возвращает `результат`: файл может не открыться.
- `трейс_очистить(т)` — стирает записи и начинает «с чистого листа».

Один `Трейсер` — на один поток. Если потоков несколько, заведите по трейсеру на каждый.
