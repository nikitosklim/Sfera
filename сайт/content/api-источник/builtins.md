# Встроенные функции

Встроенные функции работают сразу, ничего подключать не нужно. Просто пишите их имя и в скобках то, с чем нужно поработать.

Слово «аргумент» значит то, что вы передаёте функции в скобках. В `длина("привет")` аргумент один: слово `"привет"`. Слово «результат» значит то, что функция отдаёт обратно: число, текст или «да»/«нет».

Блоки с пометкой «Что выведет программа» получены запуском настоящего компилятора, так что вы увидите то же самое.

## Вывод на экран и ввод

### вывести
`вывести(значение)`

Печатает значение на экран и переводит курсор на новую строку. Принимает текст, целое число, дробное число или `да`/`нет`.

Это первая функция, которую вы запустите в жизни: она позволяет программе «говорить» с человеком.

```код запустить
функция главная(): целое
    вывести("Привет, мир!")
    вывести(42)
    вывести(3.5)
    вывести(да)
    вернуть 0
конец
```

Строки из нескольких частей склеивают знаком `+`. Но склеивать можно только текст с текстом: число сначала переведите в текст через `целое_в_текст`.

### прочитать_строку
`прочитать_строку(): результат из текста`

Ждёт, пока человек напечатает что-нибудь и нажмёт Enter, и отдаёт напечатанное. Так программа получает данные от пользователя.

Результат имеет тип `результат из текста`: у такой «коробочки» есть два поля. `.успешно` говорит, получилось ли прочитать (например, ввод мог закончиться), а `.значение` хранит сам текст. Подробнее про такие «коробочки» в уроке про ошибки.

```код
функция главная(): целое
    вывести("Как вас зовут?")
    результат из текста имя = прочитать_строку()
    если (имя.успешно)
        вывести("Привет, " + имя.значение + "!")
    конец
    вернуть 0
конец
```

### аргументы_командной_строки
`аргументы_командной_строки(): Список из текст`

Отдаёт список слов, которые человек дописал после имени программы при запуске. Если запустить `./программа один два`, в списке будет `один` и `два`.

```код
функция главная(): целое
    Список из текст слова = аргументы_командной_строки()
    вывести("Слов после имени программы: " + целое_в_текст(слова.размер()))
    для каждого слово в слова
        вывести(слово)
    конец
    вернуть 0
конец
```

## Числа и превращение в текст

### целое_в_текст
`целое_в_текст(число): текст`

Превращает целое число в текст. Нужна, чтобы вставить число в сообщение: склеивать с `+` можно только текст с текстом.

```код запустить
функция главная(): целое
    целое возраст = 12
    вывести("Мне " + целое_в_текст(возраст) + " лет")
    вернуть 0
конец
```

### дробное_в_текст
`дробное_в_текст(число): текст`

То же самое для дробных чисел (с точкой). Выводит шесть знаков после точки.

```код запустить
функция главная(): целое
    дробное рост = 1.5
    вывести("Рост: " + дробное_в_текст(рост))
    вернуть 0
конец
```

### верно_в_текст
`верно_в_текст(значение): текст`

Превращает `да` или `нет` в текст «да» или «нет», чтобы вставить в сообщение.

```код запустить
функция главная(): целое
    верно готово = да
    вывести("Готово? " + верно_в_текст(готово))
    вернуть 0
конец
```

### текст_в_целое
`текст_в_целое(текст): результат из целого`

Делает обратное: читает число из текста. Например, из `"123"` получится 123. Человек мог ввести не число (`"abc"`), поэтому функция отдаёт «коробочку» с полями `.успешно` и `.значение`. Сначала проверьте `.успешно`, потом берите `.значение`.

```код запустить
функция главная(): целое
    результат из целого хорошее = текст_в_целое("123")
    результат из целого плохое = текст_в_целое("abc")
    вывести("Первое получилось? " + верно_в_текст(хорошее.успешно))
    вывести("Значение плюс один: " + целое_в_текст(хорошее.значение + 1))
    вывести("Второе получилось? " + верно_в_текст(плохое.успешно))
    вернуть 0
конец
```

### абс
`абс(число): число`

Модуль числа: если число отрицательное, делает его положительным. «Расстояние от нуля».

```код запустить
функция главная(): целое
    вывести(целое_в_текст(абс(0 - 5)))
    вывести(целое_в_текст(абс(7)))
    вернуть 0
конец
```

Минус перед числом в Сфере пишется как вычитание из нуля: `0 - 5`.

### мин
`мин(а, б): число`

Меньшее из двух чисел.

### макс
`макс(а, б): число`

Большее из двух чисел.

```код запустить
функция главная(): целое
    вывести("Меньшее: " + целое_в_текст(мин(3, 8)))
    вывести("Большее: " + целое_в_текст(макс(3, 8)))
    вернуть 0
конец
```

## Работа с текстом

Важно знать: Сфера считает текст в **байтах**, а не в буквах. Латинская буква занимает один байт, русская занимает два. Поэтому у слова «привет» длина 12, а не 6.

### длина
`длина(текст): целое`

Сколько байт занимает текст.

```код запустить
функция главная(): целое
    вывести(целое_в_текст(длина("hello")))
    вывести(целое_в_текст(длина("привет")))
    вернуть 0
конец
```

### содержит
`содержит(текст, кусок): верно`

Отвечает `да`, если `кусок` встречается внутри `текст`, и `нет`, если нет.

```код запустить
функция главная(): целое
    текст фраза = "Привет, мир"
    вывести(верно_в_текст(содержит(фраза, "мир")))
    вывести(верно_в_текст(содержит(фраза, "кот")))
    вернуть 0
конец
```

### найти
`найти(текст, кусок): результат из целого`

Ищет `кусок` в тексте и говорит, где он начинается. Позиции считаются в байтах от нуля. Если куска нет, `.успешно` будет `нет`.

```код запустить
функция главная(): целое
    результат из целого место = найти("Привет, мир", "мир")
    если (место.успешно)
        вывести("Начинается с позиции " + целое_в_текст(место.значение))
    иначе
        вывести("Такого слова нет")
    конец
    вернуть 0
конец
```

### подстрока
`подстрока(текст, начало, длина): результат из текста`

Вырезает кусок текста: с позиции `начало` и ровно `длина` байт. Позиции считаются в байтах, поэтому для русских слов берите длину, кратную двум: одна буква занимает два байта. Результат лежит в `.значение`.

```код запустить
функция главная(): целое
    результат из текста часть = подстрока("Привет, мир", 0, 12)
    вывести(часть.значение)
    вернуть 0
конец
```

### регистр_в_верхний
`регистр_в_верхний(текст): текст`

Делает все буквы заглавными. Работает и для русских.

### регистр_в_нижний
`регистр_в_нижний(текст): текст`

Делает все буквы строчными.

```код запустить
функция главная(): целое
    вывести(регистр_в_верхний("Привет, мир"))
    вывести(регистр_в_нижний("Привет, мир"))
    вернуть 0
конец
```

### байт_текста
`байт_текста(текст, номер): целое32`

Один байт текста по номеру (от 0 до 255). Нужна для тонкой работы с текстом, например чтобы по очереди проверить каждый символ.

```код запустить
функция главная(): целое
    вывести(целое_в_текст(целое(байт_текста("A", 0))))
    вернуть 0
конец
```

Это число 65: так компьютер хранит букву `A`.

## Файлы

Файл читается и записывается целиком или кусочками. Все функции файлов, которые могут не получиться (файла нет, нет прав), отдают «коробочку» с `.успешно`, и сначала нужно проверить её.

### записать_файл
`записать_файл(путь, содержимое): результат из верного`

Создаёт файл по пути `путь` и кладёт в него `содержимое`. Если файл уже был, прежнее содержимое пропадёт.

### прочитать_файл
`прочитать_файл(путь): результат из текста`

Читает файл целиком и отдаёт его содержимое как текст.

```код запустить
функция главная(): целое
    записать_файл("заметка.txt", "Купить хлеб")
    результат из текста файл = прочитать_файл("заметка.txt")
    если (файл.успешно)
        вывести("В файле: " + файл.значение)
    иначе
        вывести("Не удалось прочитать файл")
    конец
    вернуть 0
конец
```

### размер_файла
`размер_файла(путь): результат из целого`

Сколько байт в файле. Содержимое при этом не читается, поэтому это быстро даже для огромных файлов. Если файла нет, `.успешно` будет `нет`.

### дописать_в_файл_бинарно
`дописать_в_файл_бинарно(путь, буфер, размер)`

Добавляет байты в конец файла. Нужна тем, кто работает с «сырыми» данными, например с картинками. Для обычного текста берите `записать_файл`.

### прочитать_часть_файла
`прочитать_часть_файла(путь, смещение, размер): результат из текста`

Читает не весь файл, а только кусок: `размер` байт, начиная с позиции `смещение`. Удобно для больших файлов.

### переименовать_файл
`переименовать_файл(старое_имя, новое_имя)`

Меняет имя файла или переносит его в другое место.

## Запуск других программ

### выполнить_команду
`выполнить_команду(команда)`

Запускает команду операционной системы так, будто вы напечатали её в терминале. Например, `выполнить_команду("ls")` покажет файлы в папке.

Будьте осторожны: нельзя подставлять в команду то, что ввёл посторонний человек. Это опасно, ведь он может дописать что-нибудь вредное.

## Время

### юникс_время
`юникс_время(): целое`

Сколько секунд прошло с 1 января 1970 года (по Гринвичу). Это стандартный способ хранить момент времени одним числом.

### монотонное_время_нс
`монотонное_время_нс(): целое`

Часы в наносекундах для измерения того, сколько что-то длилось. Само число ничего не значит, смысл имеет только разность двух вызовов: запомнили до, запомнили после, вычли.

```код запустить
функция главная(): целое
    целое до = монотонное_время_нс()
    целое сумма = 0
    целое номер = 0
    пока (номер меньше 100000)
        сумма = сумма + номер
        номер = номер + 1
    конец
    целое после = монотонное_время_нс()
    вывести("Посчитано, сумма " + целое_в_текст(сумма))
    вывести("Это заняло меньше секунды: " + верно_в_текст(после - до меньше 1000000000))
    вернуть 0
конец
```

## Потоки

### дождаться_поток и дождаться_все_потоки
`дождаться_поток(поток)`, `дождаться_все_потоки()`

Нужны, когда программа делает несколько дел одновременно. Первая ждёт, пока закончит один конкретный поток; вторая ждёт все сразу. Подробно: страница «Потоки» в документации.

## Список

`Список из тип` растёт по мере работы: в него можно добавлять сколько угодно элементов. Все элементы одного типа. Нумерация элементов идёт с нуля: первый элемент имеет номер 0.

```код запустить
функция главная(): целое
    Список из целое числа = Список из целое()
    числа.добавить(10)
    числа.добавить(20)
    числа.добавить(30)
    вывести("Элементов: " + целое_в_текст(числа.размер()))
    вывести("Второй элемент: " + целое_в_текст(числа.получить(1)))
    числа.удалить(0)
    вывести("После удаления первого: " + целое_в_текст(числа.размер()))
    для каждого х в числа
        вывести(целое_в_текст(х))
    конец
    вернуть 0
конец
```

### .добавить
`список.добавить(элемент)` кладёт элемент в конец списка.

### .получить
`список.получить(номер)` отдаёт элемент с таким номером. Нумерация с нуля.

### .размер
`список.размер()` говорит, сколько элементов в списке.

### .удалить
`список.удалить(номер)` убирает элемент с таким номером; следующие сдвигаются на его место.

### для каждого
`для каждого х в список ... конец` повторяет блок для каждого элемента, подставляя его вместо `х`.

## Словарь

`Словарь из Ключ и Значение` хранит пары «ключ → значение», как телефонная книга: по имени находишь номер. Ключи не повторяются.

```код запустить
функция главная(): целое
    Словарь из текст и целое возраст = Словарь из текст и целое()
    возраст.положить("Аня", 12)
    возраст.положить("Борис", 14)
    результат из целого аня = возраст.получить("Аня")
    вывести("Возраст Ани: " + целое_в_текст(аня.значение))
    результат из целого вика = возраст.получить("Вика")
    вывести("Вика найдена? " + верно_в_текст(вика.успешно))
    вывести("Пар в словаре: " + целое_в_текст(возраст.размер()))
    вернуть 0
конец
```

### .положить
`словарь.положить(ключ, значение)` добавляет пару. Если такой ключ уже есть, значение заменится.

### .получить
`словарь.получить(ключ): результат из Значение` ищет значение по ключу. Если ключа нет, `.успешно` будет `нет`.

### .размер
`словарь.размер()` число пар в словаре.

### .ключ_по_индексу и .значение_по_индексу
`словарь.ключ_по_индексу(номер)` и `словарь.значение_по_индексу(номер)` отдают ключ и значение пары по её порядковому номеру (с нуля). Так можно обойти весь словарь циклом.

## Результат: успех и ошибка

Многие операции могут не получиться: файла нет, в тексте не число. Чтобы программа не падала, такие функции отдают «коробочку» `результат из T`.

- `.успешно` равно `да`, если всё получилось.
- `.значение` хранит ответ, если получилось.
- `.сообщение` хранит объяснение, если не получилось.

Свои функции возвращают такие коробочки через `успех(значение)` и `ошибка("что не так")`.

```код запустить
функция поделить(целое а, целое б): результат из целого
    если (б == 0)
        вернуть ошибка("на ноль делить нельзя")
    конец
    вернуть успех(а / б)
конец

функция главная(): целое
    результат из целого ответ = поделить(10, 2)
    если (ответ.успешно)
        вывести("10 / 2 = " + целое_в_текст(ответ.значение))
    конец
    результат из целого плохо = поделить(1, 0)
    вывести("Получилось? " + верно_в_текст(плохо.успешно))
    вывести("Почему: " + плохо.сообщение)
    вернуть 0
конец
```

## Для продвинутых: память и «железо»

Эти функции нужны тем, кто пишет драйверы, работает с «железом» или напрямую с памятью. Новичкам они не понадобятся. Подробно они описаны в курсе «Железо».

`прочитать_целое32`, `записать_целое32`, `прочитать_целое64`, `записать_целое64`, `прочитать_указатель`, `прочитать_текст_по_смещению`, `записать_байт`, `адрес_текста`, `указатель_по_адресу`, `адрес_функции`, `биты_дробного`, `дробное_из_битов`, `аппаратное_чтение8/16/32/64`, `аппаратная_запись8/16/32/64`, `порт_ввод8/16/32`, `порт_вывод8/16/32`, `машинная_команда`.
