# Модули для x86: «железо_х86», «память_х86», «экран_х86», «задачи_х86», «диск_х86», «пользователь_х86»

Строительные блоки учебной операционной системы для компьютеров x86: порты, прерывания, память, экран, переключение задач, диск и запуск программ пользователя. Каждый модуль подключается своей строкой, например `подключить железо_х86;`.

> **Простыми словами.** Это «детали конструктора» для ядра: чтобы поговорить с клавиатурой, нужен порт; чтобы показать текст, нужен экран; чтобы запустить две программы по очереди, нужны задачи.

## Что за что отвечает

- **железо_х86** — команды процессора: порты ввода-вывода (`порт_вывод8`), доступ к памяти по адресу (`аппаратная_запись16`), остановка процессора.
- **память_х86** — физическая и виртуальная память: кадры по 4 КБ, учёт занятых и свободных.
- **экран_х86** — графический экран 800×600 и текстовая консоль поверх него (шрифт 8×16, 100 знаков в строке).
- **задачи_х86** — вытесняющая многозадачность: задачи переключаются по таймеру.
- **диск_х86** — чтение диска (ATA, режим PIO) и простая файловая система «СФС» только для чтения.
- **пользователь_х86** — запуск программ в пользовательском режиме (для них есть `сис_пользователя`).

## Самая маленькая программа

Выводит байты в последовательный порт COM1 и рисует зелёную букву «S» в углу экрана — без единого вызова стандартной библиотеки.

```код
подключить железо_х86;

функция послать_байт(беззнак8 б)
    порт_вывод8(0x3F8, б);
конец

функция главная(): целое
    послать_байт(беззнак8(72));
    послать_байт(беззнак8(105));
    послать_байт(беззнак8(10));
    аппаратная_запись16(0xB8000, 0x0A53);
    остановиться_навсегда();
    вернуть 0;
конец
```

Адрес `0xB8000` — область памяти текстового экрана, а `0x0A53` — символ «S» (0x53) зелёного цвета (0x0A).

{{инфо: Эти программы запускаются в эмуляторе или собираются в образ диска скриптами из `examples/ос` и `examples/голое-железо`. В обычном режиме их запускать нельзя.}}
