# Модуль «метрики»

Метрики — это счётчики и показания, которые программа ведёт про саму себя: сколько запросов обработано, какая сейчас температура. Подключается строкой `подключить метрики;`.

Бывает два вида:

- **счётчик** только растёт (запросов стало на один больше);
- **измеритель** может и расти, и убывать (занято памяти сейчас).

## Пример

```код запустить
подключить метрики;

функция главная(): целое
    Метрики м = создать_метрики();
    счётчик_увеличить_на_единицу(м, "запросы");
    счётчик_увеличить_на_единицу(м, "запросы");
    счётчик_увеличить(м, "ошибки", 5);
    измеритель_установить(м, "температура", 21.5);
    измеритель_увеличить(м, "температура", 0.5);
    вывести("Запросов: " + целое_в_текст(счётчик_значение(м, "запросы")));
    вывести("Ошибок: " + целое_в_текст(счётчик_значение(м, "ошибки")));
    вывести("Температура: " + дробное_в_текст(измеритель_значение(м, "температура")));
    вернуть 0;
конец
```

Первый аргумент у всех функций — «коробка» `м`, в которой лежат все счётчики. Второй — имя счётчика, которое вы придумываете сами. Если такого имени ещё нет, оно появится само.
