# Модуль «графика»

Окна, рисование и простые элементы интерфейса на компьютере: прямоугольники, текст, картинки, кнопки, панели и поля ввода. Под капотом работает библиотека SDL2, поэтому программу собирают с флагами `--линковать SDL2 --линковать SDL2_ttf --линковать SDL2_image --линковать m`. Подключается строкой `подключить графика`.

> **Простыми словами.** Вы открываете окно, в цикле рисуете на нём «кадр» (фон, фигуры, надписи) и показываете его. Нажатия мыши и клавиш приходят событиями.

## Что есть в модуле

- **Окно и кадр:** `инициализировать`, `создать_окно`, `закрыть_окно`, `завершить`, `размер_окна` (возвращает структуру `РазмерЭкрана`).
- **Фигуры:** `нарисовать_прямоугольник`, `обвести_прямоугольник`, `нарисовать_скруглённый_прямоугольник`.
- **Текст и картинки:** `нарисовать_текст`, `загрузить_картинку`, `нарисовать_картинку`, `нарисовать_картинку_текстурой`.
- **Готовые элементы:** структуры `Кнопка`, `Панель`, `ПолеВвода`, `Таблица` — со своими методами рисования и обработки нажатий.

{{инфо: Графика работает только на компьютере. В браузерной площадке и на голом железе её нет. Для телефона используйте модуль `приложение_android`, он устроен проще.}}

## Как выглядит программа

Каркас всегда один: открыть окно, цикл «обработать события — нарисовать — показать», закрыть окно. Готовые рабочие примеры лежат в папке `examples` репозитория, а полный список функций с сигнатурами приведён ниже.

```код
подключить графика

функция главная(): целое
    инициализировать(беззнак32(32))
    текст окно = создать_окно("Привет", целое32(100), целое32(100), целое32(640), целое32(480), беззнак32(4))
    // дальше: создать холст, нарисовать_прямоугольник(...), нарисовать_текст(...)
    // и цикл обработки событий до закрытия окна
    закрыть_окно(окно)
    завершить()
    вернуть 0
конец
```

Собрать и запустить:

```
сфера запустить окно.код --линковать SDL2 --линковать SDL2_ttf --линковать SDL2_image --линковать m
```
