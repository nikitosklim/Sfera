О языке «Сфера»

«Сфера» — компилируемый язык программирования на русском. Мы делаем его, чтобы писать настоящие программы на родном языке, а учиться программированию было проще.

Зачем нужен язык

Почти все языки программирования написаны на английском. Новичку приходится одновременно понимать идею программы и расшифровывать слова вроде while, return и exception. Из-за этого порог входа выше, чем нужно.

«Сфера» убирает этот барьер, но остаётся настоящим языком общего назначения: код компилируется в быстрый машинный код, а не работает внутри учебной оболочки. Начать можно в школе, а продолжить в профессиональной разработке, не меняя язык.

Какие цели мы ставим

  • Сделать программирование доступнее. Код, ошибки и документация на русском, понятные сообщения и короткий путь до первой программы.
  • Дать язык для серьёзных задач. Нативный код, потоки, сеть, базы данных и свои инструменты разработки.
  • Сохранить простоту. Мало скрытой магии: ошибки видны в типах, память освобождается предсказуемо, блоки заканчиваются словом «конец».
  • Собрать экосистему. Пакеты, реестр, расширение для редактора, уроки и примеры, чтобы всё необходимое было в одном месте.
  • Оставаться открытыми. Исходный код доступен всем под лицензией MIT.

Что умеет «Сфера» сегодня

Это не планы, а то, что уже работает и входит в текущие версии:

  • Настоящий компиляторИсходный код превращается в машинные инструкции через LLVM 18. Готовая программа запускается без интерпретатора и виртуальной машины.
  • Русский язык целикомКлючевые слова, стандартная библиотека, сообщения об ошибках и документация по-русски. Новый синтаксис без скобок и стрелок набирается на русской раскладке.
  • Автоматическая памятьПодсчёт ссылок (ARC): память освобождается сама, без пауз сборщика мусора.
  • Контракты и обобщённые типыКонтракты описывают поведение, а Список из T и Словарь из К и З хранят данные любого типа.
  • Ошибки как значенияТип результат из T заставляет проверить успех. Скрытых исключений нет.
  • МногопоточностьБлок «параллельно», каналы между потоками и повторяемый порядок выполнения.
  • Сеть и серверTCP-сокеты, HTTP-сервер и клиент. Этот сайт работает на сервере, написанном на «Сфере».
  • ДанныеSQLite из программы и собственное хранилище без внешних зависимостей.
  • ГрафикаОкна и рисование на SDL. Панель разработчика написана на самой «Сфере».
  • ИнструментыОтладчик, языковой сервер, расширение для VS Code и панель разработчика.
  • ПакетыПакетный менеджер, публичный реестр с версиями и проверкой SHA-256, публикация одной командой.
  • Много платформWindows, macOS, Linux и Android. Приложение для Android умеет запускать программы прямо на телефоне.
  • Короткая командаВсё делается командой «сфера»: запустить, установить, опубликовать.
  • Сайт на самой «Сфере»Мы написали на «Сфере» сайт, сервер, статистику и реестр пакетов. Внешних веб-библиотек нет.

Посмотреть, что можно создать на «Сфере» по направлениям: Windows, macOS, Linux, Android, сайты, серверы и другие.

Чем «Сфера» может быть лучше

Мы не соревнуемся в зрелости с языками, которым по двадцать-тридцать лет. Но в нескольких вещах у «Сферы» есть настоящие преимущества. Вот они на примерах.

Читается без перевода

Одна и та же программа на Python и на «Сфере». В «Сфере» в строке видны только русские слова, а типы записаны явно:

Python
гости = ["Аня", "Борис"]
for имя in гости:
    print(f"Привет, {имя}!")
Сфера
Список из текстов гости = Список из текстов();
гости.добавить("Аня");
гости.добавить("Борис");
для каждого имя в гости
    вывести("Привет, %имя%!");
конец

Ошибки видны в типах

Преобразование текста в число может не получиться. В «Сфере» результат несёт признак успеха, и компилятор не даст про него забыть. Скрытых исключений, которые вылетают из любого места, нет. Похожий подход у Go и Rust, но в «Сфере» он записывается по-русски и без лишних символов:

Python
try:
    n = int("42")
    print("Число:", n)
except ValueError:
    print("Это не число")
Go
n, err := strconv.Atoi("42")
if err != nil {
    fmt.Println("Это не число")
} else {
    fmt.Println("Число:", n)
}
Rust
match "42".parse::<i32>() {
    Ok(n) => println!("Число: {}", n),
    Err(_) => println!("Это не число"),
}
Сфера
результат из целого итог = текст_в_целое("42");
если (итог.успешно)
    вывести("Число: %(итог.значение)%");
иначе
    вывести("Это не число");
конец

Один файл вместо среды выполнения

Программа на «Сфере» собирается в обычный исполняемый файл. Пользователю не нужно ставить Python, Java или .NET. Достаточно передать файл, как с программой на C++ или Go.

Память без пауз и без ручного управления

В Python, Java и Go память освобождает сборщик мусора, который иногда приостанавливает программу. В C++ память нужно освобождать самому или аккуратно оборачивать в классы. В «Сфере» используется подсчёт ссылок: освобождение происходит в предсказуемые моменты, а писать код проще, чем на C++.

Где мы пока уступаем

Экосистема. У Python или JavaScript миллионы пакетов, а наш реестр только растёт.

Зрелость. Язык молодой, он быстро меняется, а часть возможностей описана как «известные ограничения».

Оптимизации и инструменты. Компилятор доводит код до машинного через LLVM, но тонкой настройки и готовых IDE уровня крупных языков пока нет.

Сообщения об ошибках. Они есть и с подсказками, но мы продолжаем их улучшать.

Мы честно пишем об этом, потому что хотим, чтобы вы выбирали «Сферу» осознанно. Список ограничений ведём в документации.
