Как установить

Windows
  1. Скачайте архив для Windows и распакуйте его в любую папку, например в C:\Sfera.
  2. Запустите Sfera-Panel.exe. Если Windows покажет окно «Windows защитила ваш компьютер», нажмите «Подробнее» и затем «Выполнить в любом случае»: приложение пока не подписано сертификатом разработчика.
  3. В панели нажмите «Установить Сферу». Она поставит компилятор и всё необходимое (понадобится интернет).
  4. Откройте новое окно PowerShell и проверьте: запустить --версия.
macOS (Intel и Apple Silicon)
  1. Выберите архив под ваш Mac: «Intel» для процессоров Intel, «Apple Silicon / ARM» для M1 и новее. Узнать можно в меню → «Об этом Mac».
  2. Распакуйте архив и перенесите «Панель Сферы» в папку «Программы» (именно туда: оттуда панель берёт компилятор).
  3. При первом запуске нажмите на приложении правой кнопкой и выберите «Открыть», затем подтвердите. Если macOS пишет, что приложение повреждено, выполните в Терминале: xattr -dr com.apple.quarantine "/Applications/Панель Сферы.app"
  4. В панели нажмите «Установить язык». Для сборки нужен Homebrew: brew install llvm@18 sdl2 sdl2_ttf.
Linux
  1. Распакуйте архив: tar -xf Sfera-Panel-Linux-*.tar.xz.
  2. Установите зависимости: sudo apt install llvm-18 clang libsdl2-2.0-0 libsdl2-ttf-2.0-0 (для других дистрибутивов найдите аналогичные пакеты).
  3. Запустите панель из распакованной папки. Подробности — в README.
Android
  1. Скачайте файл .apk прямо на телефон.
  2. Откройте его. Если Android спросит, разрешите установку из этого источника (браузера или файлового менеджера).
  3. Запустите «Сфера»: внутри редактор, запуск программ на самом телефоне, документация и уроки без интернета.
  4. Обновления ставятся поверх без удаления.

Файл можно проверить: под каждой строкой в таблице есть контрольная сумма SHA-256. Исходный код и подробные инструкции — в README.
