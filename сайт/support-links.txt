# Способы поддержки проекта: по одной строке «название | ссылка | описание».
# Строки со ссылкой, начинающейся не с https:// или http://, не показываются.
# Пример (уберите решётку и подставьте свою ссылку):
# Boosty | https://boosty.to/ваш-аккаунт | Регулярная поддержка проекта по подписке
# ЮMoney | https://yoomoney.ru/to/ваш-номер | Разовое пожертвование
# GitHub Sponsors | https://github.com/sponsors/nikitosklim | Поддержка через GitHub
