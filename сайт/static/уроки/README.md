# Картинки для уроков

Кладите сюда свои картинки (png, jpg, svg, webp). Имена лучше писать без пробелов: `цикл-по-кругу.png`.

В тексте урока (`сайт/content/lessons/*.md`) картинка вставляется так:

    ![Подпись под картинкой](/статика/уроки/цикл-по-кругу.png)

Текст в квадратных скобках станет подписью и описанием для незрячих. Если файла нет, на сайте покажется абстрактная заглушка с названием файла: так видно, какую картинку нужно положить.
