# Сайт языка «Сфера»

Сайт, написанный на самой «Сфере»: HTTP-сервер на `стандартная_библиотека/веб.код`
и `сеть.код`, страницы — обычные `.html`, стили — обычный `.css`.

## Структура

- `сервер.код` — точка входа, маршрутизация, пул из 16 рабочих потоков.
- `сайт.код` — сборка страницы из шаблонов, счётчик посещений, список загрузок.
- `pages/` — HTML-шаблоны. `layout.html` — общий каркас (`{{заголовок}}`, `{{содержимое}}`, `{{счётчик}}`).
- `static/` — CSS, картинки (`/static/...`).
- `content/docs/`, `content/articles/` — статьи и документация в Markdown (`/docs`, `/articles`), список — `list.txt` в папке.
- Подсветка кода «Сферы» и оглавление строятся автоматически (`разметка.код`).
- `downloads/` — файлы для скачивания (`/files/...`) и список `list.txt`.

## Запуск

Запускайте **изнутри папки `сайт`** (пути к папкам относительные):

```
cd сайт
..\target\release\запустить.exe сервер.код        (Windows)
../target/release/запустить сервер.код            (Linux/macOS)
```

Порт — первым аргументом, по умолчанию 8080. Откройте http://localhost:8080/.

## Установочные файлы

Положите файл в `downloads/` и добавьте строку в `downloads/list.txt`:

```
имя файла | название | описание | SHA-256 (необязательно)
```

Скачивать можно только файлы из списка. Отсутствующие файлы на странице скрываются.
Через браузер: страница `/admin` (токен — `make-token.ps1`/`.sh`), файлы до 2 ГБ, PUT потоком в файл.
Или `add-download.ps1` / `add-download.sh` — копируют файл, считают SHA-256 и дописывают строку.
Выкладка на сервер: см. `DEPLOY.md`.

## Ограничения

- Пути к файлам — только ASCII (на Windows `fopen` работает в ANSI), поэтому папки названы латиницей.
- GET/HEAD и загрузка PUT с токеном. Докачка (Range) и ETag у файлов есть. HTTPS — через обратный прокси (nginx, caddy).
- Счётчик посещений — размер файла `visits.log` (каждый визит дописывает 1 байт).
- Небольшая утечка памяти на запрос (≈0,5–1,5 КБ); для долгой работы перезапускайте сервер по расписанию.
