# Сайт языка «Сфера»

Первый настоящий сайт, работающий полностью на самой «Сфере» — без единой
внешней веб-библиотеки. Собран из уже существующих кирпичей:
`стандартная_библиотека/сеть.код` (HTTP-сервер, маршрутизация, параллельная
обработка подключений) и `стандартная_библиотека/хранилище.код`
(собственное хранилище данных — им же посчитаны посещения, отображаемые
прямо на страницах).

`память.код`, `сеть.код`, `хранилище.код` здесь — копии файлов из
`../стандартная_библиотека/` (нужны рядом, поскольку `подключить` пока
ищет файлы только по относительному пути, без поддержки путей вида
`../папка/файл`).

## Структура

- `сайт.код` — страницы (`/`, `/about`, `/docs`, `404`) и общее CSS-оформление.
- `сервер.код` — точка входа: HTTP-сервер, маршрутизация к страницам,
  счётчик посещений.

## Запуск

```bash
запустить сервер.код --только-собрать
./сервер
```

Затем открой `http://localhost:8080/` в браузере.

⚠️ Честно, узкое ограничение: счётчик посещений — независимо открывает
и закрывает файл хранилища на каждый запрос, из любого потока-обработчика.
При настоящей одновременной нагрузке возможна гонка за запись (один
инкремент может потеряться) — для демонстрационного сайта это приемлемо;
правильное решение (одно общее, разделяемое между потоками Хранилище) —
отдельная, следующая задача.

Подробности архитектуры и найденных по пути багов — в
`../ИСТОРИЯ_РАЗРАБОТКИ.md`.
