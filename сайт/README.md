# Сайт языка «Сфера»

Сайт, написанный на самой «Сфере»: HTTP-сервер на `стандартная_библиотека/веб.код`
и `сеть.код`, страницы — обычные `.html`, стили — обычный `.css`.

## Структура

- `сервер.код` — точка входа, маршрутизация, пул из 16 рабочих потоков.
- `сайт.код` — сборка страницы из шаблонов, счётчик посещений, список загрузок.
- `pages/` — HTML-шаблоны. `layout.html` — общий каркас (`{{заголовок}}`, `{{содержимое}}`, `{{счётчик}}`).
- `static/` — CSS, картинки (`/статика/...`).
- `content/docs/`, `content/lessons/`, `content/examples/`, `content/articles/` — материалы в Markdown (`/docs`, `/lessons`, `/examples`, `/articles`); список каждого раздела — `list.txt` в папке (`имя | название | описание | метка`).
- `/поиск` — поиск по всем материалам (индекс отдаёт `/поиск-данные`).
- `/support` — страница поддержки; способы пожертвования берутся из `support-links.txt`.
- `split-docs.py` — разбивает `../ДОКУМЕНТАЦИЯ_ЯЗЫКА.md` на темы в `content/docs/` (нужен только при обновлении документации).
- Подсветка кода «Сферы» и оглавление строятся автоматически (`разметка.код`).
- `downloads/` — файлы для скачивания (`/файлы/...`) и список `list.txt`.

## Запуск

Запускайте **изнутри папки `сайт`** (пути к папкам относительные):

```
cd сайт
..\target\release\запустить.exe сервер.код        (Windows)
../target/release/запустить сервер.код            (Linux/macOS)
```

Порт — первым аргументом, по умолчанию 8080. Откройте http://localhost:8080/.

## Установочные файлы

Положите файл в `downloads/` и добавьте строку в `downloads/list.txt`:

```
имя файла | название | описание | SHA-256 (необязательно)
```

Скачивать можно только файлы из списка. Отсутствующие файлы на странице скрываются.
Через браузер: страница `/управление` (токен — `make-token.ps1`/`.sh`), файлы до 2 ГБ, PUT потоком в файл.
Или `add-download.ps1` / `add-download.sh` — копируют файл, считают SHA-256 и дописывают строку.
Выкладка на сервер: см. `DEPLOY.md`.

## Ограничения

- Пути к файлам — только ASCII (на Windows `fopen` работает в ANSI), поэтому папки названы латиницей.
- GET/HEAD и загрузка PUT с токеном. Докачка (Range) и ETag у файлов есть. HTTPS — через обратный прокси (nginx, caddy).
- Счётчик посещений — размер файла `visits.log` (каждый визит дописывает 1 байт).
- Небольшая утечка памяти на запрос (≈0,5–1,5 КБ); для долгой работы перезапускайте сервер по расписанию.

## Программы Сферы на страницах (wasm)

Логика страниц написана на Сфере: исходники лежат в `сайт/клиент/*.код`, библиотека моста — `стандартная_библиотека/браузер.код`.
Сервер сам собирает их в WebAssembly (`--целевая-платформа wasm32-wasi --wasm-хост`) при первом запросе
`/статика/клиент/<имя>.wasm` и кладёт сборку в `данные/клиент/` (нужна та же настройка `данные/компилятор.txt`, что для «Попробовать»).
На странице модуль подключает загрузчик: `<script src="/статика/сфера-хост.js" data-модуль="имя" data-запас="/статика/имя.js" defer></script>`.
Если сборка недоступна, загрузчик включает запасной JS из `data-запас`.

Сейчас на Сфере: счётчик времени (`стат`), фильтр статей (`статьи`), вход и профиль (`аккаунт`), звёзды, комментарии и модерация (`оценки`),
публикация пакета (`публикация`), блок «Пользователи» в админке (`админ_пользователи`); поиск работает на сервере (`поиск.код`).
Остаётся JS: сам загрузчик `сфера-хост.js`, запуск wasm на странице «Попробовать» (`sfera-wasm.js`), остальные блоки админки и сниппет Яндекс Метрики.
